## D. 依赖关系 —— 谁解锁谁

```
① 11 份草稿发出 ──► 4 条外部 issue 解锁 ──► G1 原理图/PCB 定稿
                    └─► JBD 的 2D 外形图 ──► 镜框开模 ──► G2

④ 内部 59 条 ──► 纸面滴水不漏 (不直接解锁 G0, 但让外部一解锁就能直接进 G1)
```
