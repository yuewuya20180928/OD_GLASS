## 2. ★ 本项目最特殊的一项: 光生物安全

为什么这项不能省:

```
1. 走鹃Ⅱ 光机 = LED 光源 + 衍射光波导 → 直射用户视网膜
2. 眼镜是**贴脸、长期佩戴**的受检物 (8h+ 持续接触)
3. ISO 13732-1 已经把皮肤侧的 43°C 定成红线, 光侧是同等级别的暴露
4. 衍射光波导 + LED 的**光谱与光通量**目前我们**一个数都没有** (光机参数只有 98mW / 480Hz)
   → 连评估所需的输入数据都缺
```

**行动**:
- 光机规格书拿到后 (JBD 问询已含 LED 波长/亮度/光通量) → 补进问询清单
- 找一家认证机构做**光生物安全预评估** (国内做光辐射的机构不多, 建议连同电池一起问)
- ⚠️ 这条会**卡在 JBD 的光机参数**上 → 已并入 `state/outbox/jbd_query.md` 的追加项

## 3. 省事路线建议 (1 台样机阶段)

| 做法 | 成本 | 说明 |
|---|---|---|
| **电池选有 GB 31241 报告的现成型号** | ¥0 | 丰江 / ATL 等正规厂的型号都有 → **直接买, 不用自己送检** |

> ★ 原则: **1 台样机阶段不做正式认证, 只做"路径确认"** —— 让认证机构出一份"你这条路需要做什么、要多少钱、多久"的清单, 量产前再正式送检。
