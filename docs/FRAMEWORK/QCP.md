## 1. 来料检验 (到货即检, 不合格**不要**装进样机)

| 物料 | 看什么 | 判据 | 谁检 |
|---|---|---|---|
| **ARS45** (酷芯微) | 型号/批次/丝印/引脚完好/球位 | 与订单一致; 引脚无损伤 | 收件人 + main |
| **电池** (340mAh 软包) | 丝印 (型号/容量/电压/执行标准) | **必须印 GB 31241**; 电压 3.82V ±0.05; 无鼓包/漏液/划伤 | main |
| **传感器模组** | 型号/丝印/镜头/排线/金手指 | 与选型一致; 镜头无划伤/镀膜无划痕; 排线完好 | hw-lead |
| **镜头** | 通光/镀膜/外观/焦距标记 | 通光无划伤无气泡; AR 镀膜 R<2%@60° (需厂家报告) | hw-lead |
| **走鹃Ⅱ 光机** | 型号/尺寸/出光面/连接器 | 与 JBD spec 一致 (待 JBD 回) | main |
| **衍射光波导** | 2D 外形/耦入区/镀膜/彩虹纹 | 与 JBD 2D 图一致 (待 JBD 回) | mech-lead |
| **PCB** | 尺寸/厚度/层数/孔位/阻抗/丝印 | 50×12mm ±0.15; 厚 0.8/1.0mm; 4-6 层; **孔位按新版 (ISS-049)**; 阻抗 coupon 报告 | hw-lead |
| **Type-C 母座** | 型号/尺寸/镀金 | 母座 8.94×3.26; 面板开孔 9.5×3.6 | hw-lead |
| **NTC** | 型号/B值/引线 | 贴 SoC 背面用; 精度 ±1°C | hw-lead |
| **打印件 (PA-CF)** | 尺寸/壁厚/层纹/支撑痕/螺钉柱 | 按 `MECH/print/MEASURE_CHECKLIST.md` 41 项; 壁厚 ≥0.8; 螺钉柱沿 Z 开槽 | mech-lead |
| **金属骨架** | 铣削面平面度/⌀2.0 H7 销孔 | **定位面 ≤5µm** (打印公差不进定位链); H7 销合格 | mech-lead |
| **石墨/导热垫/铝件** | 尺寸/厚度/导热率 | 骨架止于 PCB 段后缘 (★不得延伸进电池段) | mech-lead |

**通用规则**: 每项检验**拍照 + 记批次 + 记合格/不合格**; 不合格件**单独隔离**, 不许"先用着"。

## 2. 整机测试项 (= `state/measurements.yaml` 的 10 项实测)

> ★ **kind 必须是"实测"** —— 推算值阶段门直接拒绝
> ★ 记录格式统一: `id / value / unit / kind=实测 / by / when / evidence(照片或日志路径)`

| id | 测什么 | 仪器/方法 | 合格判据 | 归属 |
|---|---|---|---|---|
| **M-PRINT** | 打印件关键配合尺寸 | 卡尺/千分尺/塞尺 | 按测量清单逐项; 壁厚 ≥0.8mm | mech-lead |
| **M-FIT** | 电池/PCB/光机装配干涉 | 实物装配 + 卡尺 | 无干涉; 间隙落在设计值 ±0.15mm | mech-lead |
| **M-WEIGHT** | 整机重量 | 电子秤 | 目标 30-40g (当前推算 50.1-74.0g → 预计超标, 记录即可) | mech-lead |
| **M-NPU** | 纯 NPU 耗时 (不含前后处理) | **软件打点** (计时点夹紧) | **≤16.67ms → 60fps 达标; >16.67ms → 兜底切 30fps** | sw-lead |
| **M-E2E** | 端到端 (口径 A / C) | 口径C=软件打点; 口径A=高速摄影/示波器 (无设备则用推算并标 [推算]) | 口径A <60ms; 口径C <42.3ms | sw-lead |
| **M-SKIN** | 皮肤侧温度 (稳态) | 贴片热电偶 + 采集仪 | **≤43°C** (设计目标 38-40°C) | mech-lead |
| **M-POWER** | 整机功耗 (满载/待机) | 电流探针/电源表 | 待机 **<0.05W** (硬约束); 满载记录实测值 | sw-lead |
| **M-BATT** | 续航 | 计时 (按 Q4 = 按需触发口径) | **≥60min** (按需触发场景) | sw-lead |
| **M-CHRG** | 充电场景皮肤温度 | 热电偶 + 充电中 | **≤43°C**; 且**充电时必须禁 OD** (四重验证含旁路) | sw-lead |
| **M-OPTIC** | 光机逐帧延迟 | 高速摄影/示波器 (无设备 → 标未验) | 记录值; 老板 19:23 定: 主观眩晕验收为**补充**验收 | sw-lead |

## 3. 主观验收 (老板 19:23 定, 零设备, 1 台样机即可)

| 验收 | 怎么做 | 判据 |
|---|---|---|
| **M-DIZZY 眩晕/拖影** | 佩戴样机做**连续快速头部转动** + 快速走动 + 视线切换, 观察 5 分钟 | 无眩晕 / 无明显拖影 / 无撕裂感; 有则记录现象与出现条件 |
| 佩戴舒适 | 连续佩戴 30 分钟 | 鼻托无压痛; 镜腿无夹痛; 皮肤侧无热感 |
| 充电行为 | 充电时试戴 | 皮肤侧应明显不烫 (对照 75.1°C 推算) |

> ★ 主观验收**不能替代**数字验收 (它验不了"60ms"这个数) —— 两者都做, 各管各的。

## 4. 上电自检 (EVT 阶段, sw-lead 模板 `SW/EVT_TEMPLATE.md`)

| 段 | 检查 |
|---|---|
| EVT-1 上电 | 电源时序/各域电压/电流/充电状态可读 |
