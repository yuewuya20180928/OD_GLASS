## 三个必须每天问自己的问题

1. **哪个风险的『应急备选』已经用掉了?** (备选不是无限的 —— 备选用完 = 要重新做方案)
2. **哪个风险的触发条件已经发生了, 但还没人处理?** (触发条件成立 ≠ 风险消失)
3. **哪个风险的责任人不在三个总工里?** → 那是 main 或 boss 的, 不能挂着
