## C. 镜框正中剖面 (整机第一厚度约束)

```
        摄像头窗口 (镜框上沿, 需局部加厚 10-12mm)
            ↓
   ┌────────────────────────────────┐
   │   镜框上沿: 摄像头模组          │
   │   镜筒外径 ⌀6.0-6.5 (净空 ⌀7.5)  │   ← 硬件总工给的镜筒需求
   │   镜头总高 3.7-4.6mm             │      (三档只差 ≤0.9mm → 可先开模)
   │   模组沿光轴 5.0-5.9mm           │
   ├────────────────────────────────┤
   │   正中 光学舱 14×10×6mm          │
   │   ┌────────┐ ┌──────────┐       │
   │   │走鹃Ⅱ   │ │分光件    │       │ ← 分光 0.79cc (是光机 4 倍)
   │   │0.18cc  │ │0.79cc    │       │
   │   └────────┘ └──────────┘       │
   │   正中厚 ≥11.8mm (一拖二)         │
   └────────────────────────────────┘
```

| 方案 | 镜框正中厚 | 分光件 | 评价 |
|---|---|---|---|
| 一拖二双目 (Plan A) | **≥11.8mm** | 需自研 0.79cc | ❌ 镜框做不成薄片式 |
| 双光机 (Plan B) | **4.8mm** | 不需要 | ✅ **结构上简单得多** (R13 备选) |

**分光精度**: 与光机共基准 ≤0.25°/0.175mm@40mm; 分光面需 ≤5µm → **不能用打印面** (FDM Ra 10-30µm)
