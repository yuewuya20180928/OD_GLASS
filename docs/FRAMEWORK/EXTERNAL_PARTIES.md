## 1. 酷芯微 (ARS45 原厂) —— 关键路径

### 1.1 承诺项 (第二轮问询, 按优先级)

| 优先级 | 问什么 | 卡住什么 | 等级 |
|---|---|---|---|
| **P0-1** | **显示 TX 接口**: 有无 MIPI-DSI TX? DP1.4 是只有 RX 还是有 TX? lane 数/速率/最高分辨率@帧率? DSI TX 与 DP RX 能否同时工作? DDC 地址可配? | **要不要加桥接芯片** (BOM+功耗+4-8 周采购) | 🔴 |
| **P0-2** | **FCCSP ball pitch** + 完整球位图 | **选型一票否决**: ≥0.4 可行 / 0.35 极限 / ≤0.3 须 HDI (违反 4-6 层锁死) | 🔴 |
| **P0-3** | **启动存储**: 有无内置 boot storage / eMMC? rootfs+权重+固件放哪? | 板宽 12 vs 15mm (eMMC 吃 25% 板面积) | 🔴 |
| **P0-4** | **电源域表** (轨名/电压/典型&最大电流/上电时序) | 电压域清单写不出 → 原理图只能画顶层骨架 | 🔴 |
| **P1-5** | **NPU 口径**: yolov5 INT8 单帧实测 (纯 NPU vs SDK 总耗时) / **输出是否强制 FP32** / 连续推理降频 / 首帧预热 / 分阶段 profiling | **端到端 50.3 vs 67.0ms** 的分水岭 | 🔴 |
| **P1-6** | **★借评估板实测** —— 最值钱的一条 | 实测值比书面答复省时间; 没有它 M-NPU 永远是 0 数据 | 🔴 |
| **P1-7** | MIPI-CSI 输入侧: lane 数/速率/电压域/AC 耦合/MCLK/帧同步引出/**充电状态可读** | 高速差分布局 + 禁 OD 门禁 | 🔴 |
| **P1-8** | 内部主时钟/DDR 时钟频率 + 开关电源频率 | 谐波落频点 → 滤波/屏蔽布局 | 🟡 |

### 1.3 ★ 未回时的备份方案 (现在就定, 不等)
| 缺什么 | 备份方案 | 代价 |
|---|---|---|
| 显示 TX 结论 | **双出口都留** (DSI_TX/DP_TX 走 0Ω/DNP) → PCB 出板前再定; 并行询价桥接芯片 | 板面积 + 桥接芯片 4-8 周 |
| FCCSP pitch | 若 ≤0.3mm → **HDI 直接违反 4-6 层锁死** → 要么加层数(老板拍板) 要么换 SoC | ★这是**唯一可能推翻主控选型**的一条 → 备份 = AR9481 备选 (tracker §2.1) |

## 3. 桥接芯片供应商 —— 唯一的"抢时间"动作

- **现状**: 草稿就绪, 老板决定**保留不发**
- **为什么不阻塞**: 原理图双出口已留 → PCB 出板前再定用哪条
- **为什么仍值得发**: 串行最坏 10 周 (原厂 1 周 + 询价 3 天 + 采购 8 周) vs 并行 4-8 周从今天起算; 样品只买 1 片, **钱几乎不花**
- **硬指标**: 端到端延迟 <10ms / 整片功耗 <100mW / 封装 ≤6×6mm / 辐射与传导数据 / DDC 地址可配 / DNP 端头处理方案
