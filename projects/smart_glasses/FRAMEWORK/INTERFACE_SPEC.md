# 跨模块接口规格书 (Interface Spec) — ISS-030

> 生成 2026-10-25 | 配套: `INTERFACES.md` (契约台账) + 各总工的 `interface_claims` (41 条取值)
> **ISS-030 的由来**: 41 条 `interface_claims` 是**取值** (如 `50x12mm`), 不是**接口规格**
> —— 连接器/引脚/电平/时序/**机械公差**/**装配顺序**/**热路径** 全缺。
> 本文件补的就是这一层。**规格变更必须走 `FRAMEWORK/CHANGE_LOG.md`。**

---

## 0. 三类接口, 三种写法

| 类 | 例子 | 必须写清 | 谁定 | 冲突怎么裁 |
|---|---|---|---|---|
| **电气** | MIPI-CSI / MIPI-DSI / I2C / USB | 器件/引脚/电平/速率/时序/阻抗 | hw-lead (硬件主) + sw-lead (软件主) | merge 检出同名不同值 → 项目总工裁决 |
| **机械** | PCB ↔ 镜脚 / 镜框光学舱 / 骨架 ↔ 打印件 | 尺寸/公差/配合/紧固件/装配顺序 | mech-lead (结构主) | 同上 |
| **热** | SoC ↔ 骨架 ↔ 石墨 ↔ 皮肤 | 接触路径/导热垫/是否隔热/热路终点 | mech-lead | 同上 |

## 3. 热接口 (★最容易被结构改动破坏)

| 环节 | 约束 |
|---|---|
| SoC 底面散热焊盘 | → 0.3mm 导热垫 → 铝/铜骨架 (纵向延伸, 兼 PCB 支撑) → 石墨 (面内扩展到上表面 + 铰链侧前端) → 对流 |
| **不得有塑料隔断** | 打印件 k=0.2, 插进热路 **+94 K/W** |
| 上下分壳 | 上壳装 PCB/骨架, 下壳贴皮肤只放电池 |
| ★**骨架/石墨不得延伸进电池段** | 延伸则并联热路 **4.50 K/W**, 进皮肤热量 **92.5% → 95.7%** |
| 隔热层 | 解 A 缩到 PCB/SoC 段, **仍原封不动留在 SoC 与皮肤之间** (皮肤 46.5°C 不变) |
| 充电板 | **已挪出镜脚 → 挪到镜框上沿/铰链侧 + 铝屏蔽罩 (EMI+散热) + 与皮肤侧隔断** |

## 4. 软件侧接口契约

| 项 | 契约 |
|---|---|
| 帧率 | 显示槽位 60Hz (兜底 30Hz) —— **与合成策略一起切** |
| 合成策略 | 异步最新帧 (默认) / 等 OD (兜底) —— 两件一起切 |
| 框龄 | `age = ceil(T_od / 16.67ms)`; **鱼眼下框龄用反投影后的方位角算, 不是像素行** (ISS-053) |
| 温控 | Tj 4 档, 切档 ≤16.67ms |
| 充电状态 | 必须能读到 (否则禁 OD 门禁实现不了, ISS-043) |
| 内存 | 静态+峰值 ~175-188MB / 512MB → 余量充足, **不是瓶颈** |
| 烧录 | USB/ADB + 版本管理 + 回滚 (ISS-029) |

## 5. 变更规则

1. 任何接口取值变化 → 改对应总工的 `interface_claims` → `merge.py` 自动检出同名不同值 → **项目总工裁决** → 同步本文件 + `CHANGE_LOG.md`
2. 机械接口变化 → 必须更新 `MECH/fit_check.py` 判据 + 打印包 (ISS-050)
3. **本文件里的"⬜ 待补"项, 在补上之前不能进 G1 原理图定稿** —— 机械接口没定义就出图 = 装不上
