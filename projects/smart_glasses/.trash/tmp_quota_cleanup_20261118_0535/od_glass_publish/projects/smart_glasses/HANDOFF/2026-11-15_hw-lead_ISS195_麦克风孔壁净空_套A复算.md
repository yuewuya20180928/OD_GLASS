## 附.2 独立复算 (不 import 脚本, 自己按 §3.2 公式算)

```python
def wall(pinset, x=5.00, y=12.00, w=2.90, h=1.60):
    px0,px1 = x-w/2, x+w/2;  py0,py1 = y-h/2, y+h/2
    out={}
    for pn,(hx,hy,d) in pinset.items():
        dx=max(px0-hx,0.0,hx-px1); dy=max(py0-hy,0.0,hy-py1)
        out[pn]=round(math.hypot(dx,dy)-d/2.0,4)   # 孔壁净空 = 孔心到封装边距离 - 孔半径
    return out
```
