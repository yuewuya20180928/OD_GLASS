## §1 病灶 (★为什么单一字符串会反复打红★)

### 1.1 病灶本体

`MECH/display_biosafety_v2_check.py` L40 定义单一常量:

```python

```

L95~120 `check_c1()` 的判定逻辑 (★实读脚本原文★):

```python
for i, line in enumerate(_read(root, rel).split("\n"), 1):
    if "走鹃" not in line:
        continue
    if MARKER in line:
```

⇒ ★**判据做的是「字符串相等」, 不是「语义判定」** ★ ⇒ ★**作废标注的写法 (形态) 有几种, 门禁就有几种打红的方式** ★

### 1.3 病灶的代价 (不是「红一次」这么简单)

1. ★**打假红 = 消耗主力和总工的信任** ★: 红 ⇒ 要人逐行去判「这是假阳性还是真漏标」⇒ ★**本单这 5 行就花了一次人工判读** ★
