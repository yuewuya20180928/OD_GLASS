## 1. (a) 两档各自"为什么合格"的最坏余量算式 (对判据 0.60)

### 1.1 算式 (与 ISS-213 §5.1 / `MECH/check_demo_struct_truth.py` G2.2~G2.4 **同式**)

```
g_worst(单边) = ( 开孔名义 − 工艺公差 − 母座本体 ) / 2
判定:  g_worst(X) ≥ 判据 0.60  且  g_worst(Y) ≥ 判据 0.60
```

| 量 | 值 | 证据 |
|---|---|---|
| 母座本体 (USB Type-C receptacle) | **8.94 × 3.26** | `[官方]` USB Type-C 规范 (ISS-213 沿用) |
| FDM 外形公差 | **±0.30** | `[官方-项目内]` `MECH/fit_check.py` 口径 (ISS-213 沿用); 另见 `[官网]` Prusa KB "An Original Prusa will be accurate to at least 0.2 mm" / 可动配合 "at least 0.3 mm" ⇒ **0.30 是保守侧取值** |
| 金属·CNC 公差 | **±0.05** | `[推算]` ISS-213 口径 (金属件可达); **本单 §2.3 给出 ISO 2768 对照, 并要求图纸指定值** |
| 判据 CRIT | **0.60** | `[官方-项目内]` `MECH/service_port_check.py` L113 (CRIT = 2 × 0.30) —— **本单一个数没松** |

### 1.2 逐档算式 (算出来的, 可复核)

**第三档 A — FDM 直成型 10.50 × 4.80**
```
g_X = (10.50 − 0.30 − 8.94) / 2 = 1.26 / 2 = 0.630 mm   ≥ 0.60  ✅  (余 0.030)
g_Y = ( 4.80 − 0.30 − 3.26) / 2 = 1.24 / 2 = 0.620 mm   ≥ 0.60  ✅  (余 0.020)
```

**第三档 B — 金属·CNC 10.25 × 4.55**
```
g_X = (10.25 − 0.05 − 8.94) / 2 = 1.26 / 2 = 0.630 mm   ≥ 0.60  ✅  (余 0.030)
g_Y = ( 4.55 − 0.05 − 3.26) / 2 = 1.24 / 2 = 0.620 mm   ≥ 0.60  ✅  (余 0.020)
```

**两档现候选 (必须仍然不合格 —— 否则就等于把"假二选一"又扶正)**
```
现口径 9.50×3.60:  g_X = (9.50 − 0.30 − 8.94)/2 = 0.130  ❌   g_Y = (3.60 − 0.30 − 3.26)/2 = 0.020  ❌
ISS-089 10.00×4.20: g_X = (10.00 − 0.30 − 8.94)/2 = 0.380 ❌  g_Y = (4.20 − 0.30 − 3.26)/2 = 0.320  ❌
```

★**余量只剩 0.02~0.03 mm** ⇒ 这不是"宽裕", 这是 **刚好压在判据上** ⇒ 加工余量 (§2) 必须按 §2 走, 且 **实物装母座后的塞尺实测 (§3 N22~N25) 是唯一放行依据**。

### 1.3 ★金属档的公差口径敏感性 (本单新算, 必读)

金属件一旦下料, **公差带口径直接决定合不合格**:

| 公差口径 | 开口宽 10.25 | 开口高 4.55 | 最坏单边 X | 最坏单边 Y | 判定 |
|---|---|---|---|---|---|
| ISO 2768-**m** (中) 一般公差 | ±0.20 | ±0.10 | 0.555 | 0.595 | ❌ **不合格** |
| ISO 2768-**f** (细) 一般公差 | ±0.10 | ±0.05 | 0.605 | 0.620 | ✅ 但 X 只余 **0.005 mm** |
| **★图纸逐项指定 ±0.05** (本单要求) | ±0.05 | ±0.05 | **0.630** | **0.620** | ✅ |

- ISO 2768 数值出处 `[官网]`: 金属 **f (细)** 类 —— 0.5~3mm **±0.05** / 3~6 **±0.05** / 6~30 **±0.10** / 30~120 **±0.15**; **m (中)** 类 —— 0.5~3 **±0.1** / 3~6 **±0.1** / 6~30 **±0.2** (Protolabs Network / APPORO / ISO 2768-1 表)。`[官网]` ISO 2768-1 本身为标准文本 (本单未付费调阅原文, 数值取自多家公开转录表, 已在 §5 登记)。
- ⇒ **★结论 1: 金属档 **不许**用 2768-m 一般公差** (X/Y 双双不合格);
- ⇒ **★结论 2: 2768-f 一般公差虽然过, 但 X 只余 0.005 mm** ⇒ **开口尺寸必须在图纸上逐项标注公差 (±0.05)**, 不能吃一般公差;
- ⇒ **★结论 3: 阳极氧化等表面处理会再吃掉 0.005~0.025 mm 的开口直径** (§2.3) ⇒ 图纸必须写 "**开口尺寸按氧化后计**" 或把机加工开口放大 0.010~0.020 补偿。

### 2.1 第三档 A —— FDM 直成型 (PA-CF / 拓竹 P2S, 0.4 硬化钢喷嘴 / 层高 0.2mm)

| 余量项 | 取值 | 证据 | 说明 |

| 设备精度参照 | 静态 0.2mm / 可动配合 0.3mm | `[官网]` Prusa KB "Modeling with 3D printing in mind" (help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135) | ⇒ 0.30 是 **保守侧** 取值 |
| **收缩率 (XY 外形缩放)** | **本项目值 [0数据]** | `[0数据]` | PA-CF 的收缩比 **随材料批次/喷嘴/温度/湿度变**, 官网只给方法不给本项目值 ⇒ 见 §2.4 降级 ① |

| **孔径补偿 (XY Hole Compensation)** | **本项目值 [0数据]**, 补偿值 = (标称 − 实测)/2, 步进 0.02mm | `[官网]` Bambu Lab Wiki "XY Hole / Contour Compensation" (wiki.bambulab.com/en/software/bambu-studio/xy-hole-contour-compensation) | 官网原文: 孔打印偏小的原因 = 材料收缩 / elephant's foot / 湿料 / 流速未调 / 孔径接近喷嘴 / **无导入角** / 接缝; ⇒ **本试样的孔全部 ≥⌀4.0 (远离喷嘴), 且开口不是圆孔, 不吃补偿** ⇒ 补偿值主要用于 §3 的孔径试样 |
| **elephant's foot (首层外扩)** | **0.20 mm** (0.4 喷嘴) | `[官网]` Prusa KB "Elephant foot compensation" (help.prusa3d.com/article/elephant-foot-compensation_114487) —— "Values around 0.2 mm usually work well for the default 0.4 mm nozzle" | ★**只影响贴板的首层面 ⇒ 开口 (在板厚中部) 不受影响; 面板"外形 X/Y" 在贴板面会偏大 ~0.20 ⇒ §3 N5/N6 注明"在距底面 3mm 处量"** |
| **层纹方向 (★硬要求)** | **开口面板必须平放打印** (面板在 XY 面内, 板厚沿 Z) | `[推算]` + `[官网]` Prusa KB 精度分级 | 见下 |
| 打印后静置 | **24 h** | `[官方-项目内]` `MECH/print/README.md` 打印参数 (PA-CF 吸湿) | 现有 Rev B 包已定死, 本单不改 |
| 打印前干燥 | PA-CF 80~90 °C / 8~12 h | `[官网]` Bambu Lab Wiki "Filament Drying Recommendations" + "Filament guide" 材料表 (PA-CF/GF: Required, 80~90 ℃, 8~12 h) | ★**不干料 ⇒ 收缩率与孔径都不可比** ⇒ 干燥是 §2.4 降级 ① 的前置条件 |

**★层纹方向 (为什么必须平放)**: 开口是"沿板厚方向"的一个通孔。它的 **配合尺寸 (X/Y) 在板面内** ⇒ 只要板面 **平行于层纹面**, 配合尺寸就整段落在 **层内 (in-layer)**, 受的是 0.2mm 级的面内精度; 若把板面 **垂直于层纹面** (立着打), 配合尺寸就变成 **层间累积尺寸**, 误差按层高 × 层数累积 ⇒ 4.80 高的开口 (24 层) 误差直接堆上去。
⇒ **本试样 `frame_typec_coupon_tier3_revb.stl` 的板面在 XY 平面、板厚沿 Z ⇒ 天然平放** (面板 A/B 都是 z 0~3.00 的板, 孔沿 Z 通) ⇒ 下片时 **不要把件转 90° 立打**。
⇒ ★另: 立打时开口侧壁会出现沿插入方向的层纹台阶 (类似导轨) —— 平打时台阶方向与插拔方向垂直, 对插装有利。

### 5.3 ★本轮新踩的坑 ⑤ (补记进 `verify_pack_revb.py` 头)

盒端面是 **三角扇** (扇心 + 4 角点), **射线命中扇心 (mid_y, mid_z) 会同时打到 4 个扇形三角形** ⇒ 命中数由 1 变 4 (偶数) ⇒ **奇偶判内外直接翻车**。
本轮实测: 5 个探针点踩中扇心 (如 (6.75, 0.75, 1.5) 正好是 Panel A 底壁盒的扇心) ⇒ STL 互验 9/14。
⇒ **纪律: 互验探针的 (y,z) 必须避开每个被穿越盒的 (mid_y, mid_z)** ⇒ 第三档 14 个采样点已逐一改开 (如 (6.75, **4.20**, 1.5) 而不是 (6.75, 3.90, 1.5))。
⇒ ★这条已写进 `verify_pack_revb.py` 的文件头"踩过的坑"清单 (Rev A 那 4 条之后新增第 5 条)。
