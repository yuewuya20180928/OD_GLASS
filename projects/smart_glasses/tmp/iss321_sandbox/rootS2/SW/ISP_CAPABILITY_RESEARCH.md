## ② ★反解: 60ms 硬线下 ISP 段最多能占多少 ms (降级方案 B 的数字)

> **口径**: 直接用 `HW/e2e_budget_rk3572.py` 的既有模型 (`T_FIXED` 五段拆分 / `age` 台阶 / 模式A / 模式B),
> 把 ISP 段 S3 换成变量 X。**60ms 不是我写死的**, 是从 `display_out_max_for(..., budget_ms=60.0)` 的函数默认值取的。
> **自检**: X = 8.00 ms 时, 我的公式**逐位复现** `e2e_budget_rk3572.e2e()` 的 modeA/modeB (差 < 1e-9) ⇒ 证明没跑偏。

```
模式A (显示等 OD):   e2e = T_FIXED − S3 + X + T_od          ⇒ X ≤ 60 − (T_FIXED − S3) − T_od
模式B (异步 60fps):  e2e = T_FIXED − S3 + X + age × 16.67   ⇒ X ≤ 60 − (T_FIXED − S3) − age × 16.67
                    (T_FIXED = 34.00, S3 = 8.00 ⇒ T_FIXED − S3 = 26.00)
```

| 基线 (RK3572) | S5 | T_od | age | 模式A 现值 | 模式B 现值 | ★**ISP 上限 模式A** | ★**ISP 上限 模式B** |
