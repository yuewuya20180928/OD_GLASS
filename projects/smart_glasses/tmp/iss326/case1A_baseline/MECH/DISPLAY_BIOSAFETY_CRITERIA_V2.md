### ① 出光面辐亮度 L_eye (Cd/m²)

| 项 | 内容 |

| **怎么测** | ① 光谱辐射计 + **11 mrad 接受角限孔** (IEC 62471-7 §8.3 口径), 镜头对准出瞳面中心, 距出瞳 = **评估距离 (眼点距, 同类公开值 18 mm)**; ② 驱动面板 **全白 / 100% APL / 90 Hz / 100% duty** (最坏工况); ③ 同步记录环境光与腔体温度; ④ 扫 3 个位置 (中心 + 眼盒四角) 取**最大**; ⑤ 在 **-10 / 25 / 50 °C** 三点各测一遍 (§④); ⑥ 结果按 L_B = Σ L_λ·B(λ)·Δλ 折算 |

### ② 光谱分布与蓝光峰值波长 / 蓝光占比上限

| 项 | 内容 |
|---|---|
| **判据 ②-a (主波长)** | ★**蓝光主波长 λ_B ≥ 460 nm**。理由: B(λ) 在 435–440 nm 取 1.00 (最危险), 460 nm 取 0.80, 470 nm 取 0.62 (↓22%), 480 nm 取 0.45 (↓44%)。⇒ **λ_B 每往后挪 10 nm, 光生物安全余量就多一截**; 但代价是 DCI-P3 色域下降 + 发光效率下降 + 波导 FOV 匹配变差 |

| **数值来源** | ②-a: B(λ) 表 (IEC 62471 Table 4.2) `[媒体]`; ②-b: DCI-P3 基色 CIE 1931 计算 `[推算]`; ②-c: IEC 62471 Table 6.1 限值 × 1% 设计余量 `[推算]` |

### ③ 45–50 °C 下的亮度行为

> ★**派活前提修正 (见 C-6)**: 「硅基 OLED 高温下亮度衰减是已知现象」→ 公开资料支持的是 **高温加速退化 (寿命 L50 缩短)**, 而不是"瞬时辐亮度随温度单调下降"。公开文献里 **EQE 的温度系数方向在硅基 OLED 上没有可引用的数值** ⇒ ⇒ **判据不写成 "45–50 °C 衰减 ≤ X%"** (那等于押一个未证实的方向), 而写成 **"全温区出瞳白场辐亮度最大值 ≤ ① 的上限"** —— 这个写法 **对温度系数方向不敏感**, 是稳的。

| 项 | 内容 |
|---|---|
| **判据 ③-a (光生物安全口径)** | ★**全温区 (-10 ~ +50 °C) 出瞳白场辐亮度的最大值 L_white,max ≤ 1500 cd/m²** (RG0 目标) / **≤ 4000 cd/m²** (RG1 可接受)。即: 光生物安全的输入量取**全温区最大值**, 不是 25 °C 标称值 |
| **判据 ③-b (寿命口径)** | 面板在 **50 °C / 实际占空比 (OD 场景远低于 100% duty)** 下的 **L50 ≥ 整机设计寿命**。拟合用拉伸指数 L(t) = L₀·exp(−(t/τ)^β) |
| **判据 ③-c (结构侧红线, MECH 地界)** | ★**镜框内光学腔体稳态温度 ≤ 50 °C**; ★**面板结温 ≤ 60 °C**。60 °C 取 JBD 同类光引擎的公开工作温度上限作**可比红线** `[官网]` (不是视涯的规格, 视涯未公开) |
| **判据 ③-d (热源口径)** | 面板 **468 mW @ 90 Hz / 100 % duty** `[官网]` ⇒ 腔体热源 **0.47 W** (满屏白时最坏) ⇒ 镜框必须有 **≥ 0.5 W 的被动散热面** (镜框上表面 + 铰链侧), **不得做密闭腔**。⇒ 与 `MECH/MECH_BUDGET.md` M4 结论 (贴皮肤镜腿可持续上限 0.15–0.2 W) 不冲突: **光学件在镜框, 不进皮肤热路径**, 但**镜框外壳温度会升** |
| **数值来源** | ③-a: 判据 ① + §2.2 温度锚; ③-b: 面板 datasheet 无 L50 ⇒ `[0数据]`; ③-c: JBD 蜂鸟Ⅱ 工作温度 -20~60 °C `[官网]`; ③-d: 视涯 468 mW `[官网]` + `MECH/MECH_BUDGET.md` M4 (ISO 13732-1 43 °C 红线) |
| **证据等级** | ③-a `[推算]`; ③-b `[0数据]`; ③-c `[官网]`(可比红线) + `[推算]`(腔体 50 °C); ③-d `[官网]` + `[推算]` |
| **怎么测** | ① 恒温箱 (-10/25/50 °C) × 腔体热平衡 × 出瞳光谱辐亮度扫描 (× ④ 的台架); ② 面板结温: 面板背面贴 NTC 或用红外测温 (硅基 OLED 玻璃背面, 发射率低 ⇒ **优先贴 NTC**); ③ 腔体温度: 镜框内空气 + 腔壁 NTC; ④ L50: 恒温箱内按实际占空比连续点亮, 每 100 h 记一次白场亮度, 外推 |
| **查不到时的降级方案** | ★**面板无温度曲线 ⇒ 降级为"整机热-亮联合台架"** (见 ① 的降级方案)。★**面板无 L50 ⇒ 降级为 EVT 实测外推**, 且在整机设计寿命确定前 **按 5000 h @ 50 °C 作为占位判据**, EVT 后替换为实测外推值 |

### ⑤ 观察距离与视场角

> ★**先分清三个"角", 混了就判错档**:

| 角 | 含义 | 我们的取值 | 证据 |
|---|---|---|---|
| **评估距离 (观察距离) d** | 出瞳面 → 观察者眼睛 (眼点距 / eye relief) | ★**目标 15–20 mm** (公开同类: 瑞声×Dispelix **出瞳距 18 mm**) | `[媒体]` |
| **测量视场 / 接受角** | IEC 62471 的**测量窗口**, 与产品 FOV 无关 | **0.011 rad (11 mrad)**; ≥10 000 s 曝光时平均视场放宽到 **0.1 rad** | `[媒体]` IEC 62471-7 §8.3 + Table 5.5 |
| **波导出射 FOV (Ω_fov)** | 决定 LB 折算的分母 (§3.5) | 公开同类 **20°–30°(D)** | `[媒体]` |

| 项 | 内容 |
|---|---|
| **判据 ⑤-a (大/小光源判定)** | ★**我们走「大光源」口径 ⇒ 用辐亮度限值 L_B (Exempt 100 W/(m²·sr)), 不用小光源辐照度限值 E_B**。理由: 出瞳眼盒 **12×10 ~ 15×10 mm** 就在眼前, 角张**远大于 0.011 rad**; 面板本身 (10.783 mm 宽) 在 200 mm 观察距离处角张 = 10.783/200 = **0.054 rad > 0.011** ⇒ 两条路都是大光源 |
| **判据 ⑤-b (评估距离)** | **d = 出瞳面到角膜前表面 = 眼点距, 目标 15–20 mm**。⇒ 结构后果: **耦合光学出射面 → 波导出瞳面 的空间 = d**, 加上鼻梁区分光件 ⇒ **共同决定镜框上沿厚度** (见 `MECH/MECH_BUDGET.md` 的镜框光学腔体预算) |
| **判据 ⑤-c (测量窗口)** | 出瞳光谱测量一律加 **11 mrad 接受角**; 曝光时间按**实际使用形态**定: OD 检测场景是**间歇短时直视** ⇒ t_max 基准须按实际单次注视时长与频次写进 R5 |
| **数值来源** | ⑤-a: α 判据 0.011 rad `[媒体]`; ⑤-b: 18 mm `[媒体]`; ⑤-c: 0.011 / 0.1 rad `[媒体]` |
| **证据等级** | `[媒体]` (标准原文) + `[推算]` (面板角张 0.054 rad) |
| **怎么测** | ① 评估距离 = 实测眼点距 (样机装配后量); ② 光谱仪加 11 mrad 限孔 (或选带该接受角的光谱仪); ③ t_max 按使用形态统计 (R5) |

### ⑥ 波导散射后对观察者的等效辐亮度怎么折算

| 项 | 内容 |
|---|---|
| **判据公式 (主)** | ★**L_eye = Φ_in × η_total / (A_e × Ω_fov)** , 其中 **Φ_in = L_p × A_p × Ω_c** (面板出光面辐亮度 × 有效面积 × 耦合收集立体角) ⇒ **等价写法: L_eye = L_p × (A_p·Ω_c)/(A_e·Ω_fov) × η_total** (辐亮度传递式) |
| **符号** | L_p 面板出光面辐亮度 (cd/m²) · A_p 面板有效显示面积 (6.540×10⁻⁵ m²) · Ω_c 耦合光学收集的立体角 (sr) · A_e 波导眼盒/出瞳面积 (m²) · Ω_fov 波导出射立体角 (sr) · η_total 耦合光学+波导总效率 |
| **★ 判据只锚出瞳处** | **L_B,eye = Σ L_λ,eye · B(λ) · Δλ**, L_λ,eye 取**出瞳处实测光谱** ⇒ ★**中间链路的任何厂商口径 (如 "光利用效率 nits/lm") 一律不进判据** ⇒ 口径争议被吸收在公式里, 不落在合格判定上 |
| **散射带来的三条必须单列的效应** | ① **色散/彩虹纹**: 衍射把不同波长散到不同角度 ⇒ 蓝光被散到 FOV 内某个位置 ⇒ **要记录"用户实际看到蓝光的那个角度"**, 并把该角度的辐亮度纳入取最大; ② **正面漏光 (front / stray leakage)**: 波导内的光会从耦入区与出瞳区漏到环境 ⇒ **不进眼 ⇒ 不构成光生物安全风险**, 但影响**他人**与**图像对比度** ⇒ 单列为"漏光"判据 (我方设计目标: 漏光在暗背景下不可见); ③ **衍射效率对蓝光的额外衰减**: SRG 的刻蚀深度对短波长容差更敏感 ⇒ **实际入眼蓝光占比可能低于面板蓝光占比** ⇒ ★**这是有利项, 但不可当设计余量** (随刻蚀批次漂移) ⇒ 判据仍按**面板蓝光占比上限**算, 把"波导对蓝光的额外衰减"列为**待实测项** |
| **数值来源** | 公式为通量守恒 + 立体角关系 `[推算]`; A_p 来自视涯官方 `[官网]`; A_e / Ω_fov 来自公开在售波导规格 `[媒体]`; η_total 由 JBD 官网"3 lm → 4000 nits 入眼"反算 `[推算]` |
| **证据等级** | 公式 `[推算]` · 面板量 `[官网]` · 波导量 `[媒体]` · η 反算 `[推算]` (含 ±2× 不确定度) |
| **怎么测** | ① 面板裸屏: 光谱仪 + 11 mrad 限孔测 L_λ, 算 L_p 与蓝光占比; ② 出瞳: 同法测 L_λ,eye, 算 L_B,eye; ③ **η_total = L_eye / L_p 的实测比值** (用同一套设备, 消除标定差); ④ 扫出瞳面 5×5 点, 取最大; ⑤ 漏光: 暗房 + 积分球测耦入区/出瞳区正面的漏出光通量 |
| **查不到时的降级方案** | ★**η_total 与漏光率公开查不到** (JBD 未公开波导参数; 舜宇/Dispelix 公开的是厂商自定义 "nits/lm", 未给定义式) ⇒ ⇒ 降级三级: **一级** 用 §3.5 的自洽反算区间 (η = 1.8%–5%) 做设计输入; **二级** 用**出瞳实测**直接给出 L_eye, 不再依赖 η; **三级** 若连出瞳都定不了 (波导未定型), 用 **L_p × 0.05** 作 L_eye 的保守上限估计 (由 JBD 与舜宇两组公开数字反推的量级), 并按 **10× 余量**设计 ⇒ ★**三级是"设计阶段占位值", 不是判据, 一旦有出瞳实测就必须替换** |
