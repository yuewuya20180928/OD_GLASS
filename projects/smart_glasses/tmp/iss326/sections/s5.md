## §5 · ★★三种失效形态的逐条判据 ★★

★**判据枚举 (本单自定义, 供闸复用)**:
- ★**RED (红)** ★: 改名后脚本抛异常 / 断言失败 / 找不到必需文件 ⇒ **显式失败, 会被发现**。
- ★**SILENT (静悄悄不查了 / 假绿)** ★: ★**判据分支再也匹配不上** ⇒ 脚本仍 rc=0, 但该项没人查 ⇒ **最坏, 排在处置表最前面**。
- ★**SAFE (不受影响)** ★: 注释 / 历史脚本 / 与判据无关的散文引用 ⇒ 改了也不影响判据行为。

### §5-1 · ★**七条判定规则 (本单用的)** ★

| # | 规则 | 判据 | 归入 |
|---|---|---|---|
| ★**R1** ★ | ★**硬下标取键** ★ | 源码里有 `xxx["REF"]` 形态的硬下标, 且键来自改名位号 | ★**RED** ★ (KeyError) |
| ★**R2** ★ | ★**精确等值分支** ★ | 源码里有 `== "REF"` / `!= "REF"` | ★**SILENT** ★ (分支再也匹配不上) |
| ★**R3** ★ | ★**断言等值** ★ | `assert … "REF" …` | ★**RED** ★ (断言失败) |
| ★**R4** ★ | ★**集合被精确成员消费** ★ | `VAR = ["REF", …]` 且 `VAR` 被 `x in VAR` / `for x in VAR` 消费 | ★**SILENT** ★ |
| ★**R5** ★ | ★**正则前缀锚 (无 `$` / 无词边界)** ★ | `re.compile(r"^REF…")` ⇒ 改名加 `_1` 后缀仍命中 | ★**SAFE** ★ (语义变宽, 记 SAFE-前缀宽松) |
| ★**R6** ★ | ★**正则带 `$` 锚 / 词边界** ★ | `re.compile(r"^(REF\|…)" r"(?:…)?$")` ⇒ 改名后匹配不上 | ★**SILENT** ★ |
| ★**R7** ★ | ★**注释行 / 历史脚本** ★ | 行首 `#` 或在文档串内; 文件名匹配 `_apply_*` / `_frag_update_*` / `rebase_*` / `_append_handoff_*` | ★**SAFE** ★ (无功能影响 / 跑完即退) |

### §5-2 · ★**为什么 SILENT 必然比 RED 多 (本单最关键的一条机理)** ★

★**改名形态是统一的「追加后缀 `_1`」** (★实测: 218 真集里 186 条改名位号, **186/186 全部是 `old + "_1"`**; 32 条不动位号**一字不变**★) ⇒

| 判据写法 | 改名后 | 失效形态 |
|---|---|---|
| 精确等值 `== "R_SEL_D0_N"` | ★**匹配不上** ★ | ★**SILENT (假绿)** ★ |
| 硬下标 `fps["D_LED_G"]` | ★**KeyError** ★ | ★**RED (崩)** ★ |
| 前缀正则 `^CONN_CAM` | ★**仍匹配** ★ (`CONN_CAM_1` 也匹配) | ★**SAFE** ★ |
| `$` 锚正则 `^(J_CHG\|…)$` | ★**匹配不上** ★ | ★**SILENT (假绿)** ★ |

★**⇒ 结论: 改名这一件事对 MECH 侧的主要威胁不是「崩」, 是「静悄悄不查了」** ★ ⇒ ★**处置的优先级也就出来了: 先修精确等值分支与 `$` 锚正则, 再修硬下标** ★。

### §5-3 · ★**处置优先级 (给 main 的可执行顺序建议, ★不替老板拍板★)** ★

| 优先级 | 动作 | 命中行数 |
|---|---|---:|
| ★**P0** ★ | ★**先建 MECH 侧位号可达性闸 (设计稿见 §6) ⇒ 把「改名漂移」变成可观测项** ★ | ★**68 个位号会被引用** ★ |
| ★**P1** ★ | ★**修判据脚本里的精确等值分支与 `$` 锚正则** ★ (★SILENT 的根因★) | ★**82 行 / 8 个脚本** ★ |
| ★**P2** ★ | ★**修判据脚本里的硬下标** ★ (★RED 的根因★) | ★**79 行 / 6 个脚本** ★ |
| ★**P3** ★ | ★**改判据脚本在读的那几份 md 的机器块** (★§4-4 的 185 行★) | ★**185 行 / 3 份 md** ★ |
| ★**P4** ★ | ★**注释里的 ref / 历史脚本里的 ref: 一律不改** ★ | ★**31 + 164 行** ★ |
