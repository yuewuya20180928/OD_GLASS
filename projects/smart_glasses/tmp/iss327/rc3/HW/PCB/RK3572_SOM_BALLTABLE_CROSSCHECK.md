## 3. ★★顺带查出来的 2 条真发现 (★都要记账★)★★

### ★★★发现 A (★★重要★): `P2_7` 官方默认功能是 `PWM0_CH1_M0`, 我们拿它当 `UART_TX` 用 ⇒ ★**必须确认这是不是【引脚复用】的合法用法★★

- ★**官方**: `P2_7` = `PWM0_CH1_M0` / GPIO0_C3_d / 3.3V
- ★**官方**: `P2_9` = `UART0_RX_M0_DEBUG` / GPIO0_D5_u / 3.3V
- ★**我们**: `P2_7` → `UART_TX`, `P2_9` → `UART_RX`
- ⇒ ★**⇒ 官方把 UART0_TX 放在哪了? 本轮在官方手册里【只查到 UART0_RX_M0_DEBUG 在 P2_9】, 没在同一批表里查到 UART0_TX 的 P2_号 ⇒ ⇒ 【这可能是一个真问题, 也可能官方把 TX 放在 P2_7 复用】**

⇒ ★**⇒ 已登记为 need (★待 hw-lead 用官方 pinmux 表交叉核★) ⇒ ★**这正是"自己查"比"等回信"强的地方: 官网就能查, 且查出了别的问题★★
