## §0 · 一句话结论 (★先看这个★)

★**三件主板 MOS 的占位 pad 序 三样都不同 (`Q_AND` = D/S/G · `Q_PG` = S/D/G · `Q_ENVC` = G/S/D), 而 SOT-23 库引脚序只有一种 (G/S/D) ⇒ 只有 `Q_ENVC` 天然对上, `Q_AND` 与 `Q_PG` 必须人工改映射** ★
★**接反的后果不是"少一个功能", 是 `Vgs` 极性反 ⇒ 开机路径不通 (PG 低反而关机) ⇒ 这条归 G-2 缺口, 归落板批次执行** ★

### §1.3 · ★为什么"占位 pad 序"不是"库引脚序"★ (★机理, 免得下一批人再踩★)

★**板文件的占位 land 是按【网表行出现的顺序】画的, 不是按【器件库引脚序】画的** ⇒ ★**网表里 `Q_AND` 的三行依次是 RESET_N / GND / PG_AND, 于是占位 pad1/2/3 就依次是 D/S/G** ⇒ ★**换任何 SOT-23 器件都必须逐件重新核 pad↔pin 映射, 不能拿"SOT-23 就是 G-S-D"想当然** ★ (`[实测]` + `[推算]`)

### §2.2 · ★依据: 为什么"按 pad 序号机械接"会打死 `D_ESD_CAM`★

★**TI `TPD1E05U06DPYR` 是【单向件】: pin1 = I/O · pin2 = GND** (★官方数据手册 SLVSBO7O 引脚表, `[官网]`, 引自 ISS-241 矩阵 §3.1 ①) ★
⇒ ★**对 `D_ESD_DEMO` / `D_ESD_USB_D` (pad1=信号 / pad2=GND): 按序号接 = pin1(I/O)→信号 ✔ · pin2(GND)→GND ✔ ⇒ 对** ★
⇒ ★**对 `D_ESD_CAM` (pad1=GND / pad2=CSI_D0_CK_P): 按序号接 = pin1(I/O)→**GND 位** · pin2(GND)→**信号位** ⇒ ★**信号脚被短到地、I/O 脚接到地 ⇒ 器件不工作 (且信号被 ESD 器件直接对地钳位)** ★ ★**⇒ 必须二选一 (方案甲 / 方案乙), 一条不许代拍** ★

### §2.3 · ★两条改法 (★各带代价★)★

| | ★**方案甲: 落表时把两件的单向件换成双向件** ★ | ★**方案乙: 保留单向件 (TPD1E05U06DPYR)** ★ |
|---|---|---|
| **怎么做** | ★**`D_ESD_CAM` (以及可一并统一的 `D_ESD_DEMO` / `D_ESD_USB_D`) 改用双向件 `PESD5V0S1BA`** (Nexperia SOD-323, 2 lead, 1.3 mm pitch, 本体 1.7×1.25×0.95 mm) ⇒ ★**K1/K2 对称 ⇒ pad 序天然免疫, 三个件可以同料** ★ (`[官网]`: Nexperia 官方产品页 + 数据手册, 引自 ISS-241 矩阵 §3.1 ①) | ★**保留 TI 单向件 `TPD1E05U06DPYR`** (DPY X1SON 2-pin, 0.42 pF) ⇒ ★**落板批次对 `D_ESD_CAM` 的 land 做 pad1/pad2 对调** (★即 land 改成 pin1(I/O)→`CSI_D0_CK_P` 位、pin2(GND)→`GND` 位★) |
| **优点** | ★**pad 序问题从根上消失 ⇒ 落板批次不需要为这一件单独做"反向 land" ⇒ 三件 ESD 同料 ⇒ BOM 行数少 / 来料种类少 (量产备料成本)** ★ | ★**结电容 0.42 pF (typ) vs 双向件 `PESD5V0S1BA` 的 35 pF ⇒ 差 83 倍 ⇒ CSI 高速 lane 上结电容直接决定眼宽 ⇒ 电气上最优** ★ · ★**且 `D_ESD_USB_D` 也能同料 (USB 2.0 FS 0.42 pF 是过剩余量)** ★ |
| **代价 (★必须摆出来★)** | ★**① 结电容 35 pF 在 Gbps 级 CSI lane 上会吃掉眼宽 ⇒ 电气上是"判据级差异"不是价格差异 ⇒ CSI 侧是否接受, 属 main / 老板** ★ ★**② `PESD5V0S1BA` 的 VRWM 恰为 5.0 V ⇒ 对 5 V±5% (最高 5.25 V) 轨顶到边 ⇒ 对 `D_ESD_DEMO` (打在 VBUS 轨上) 要复核 IR 曲线 (ISS-241 矩阵 §3.1 ② 降级栏已登记)** ★ ★**③ SOD-323 的 1.3 mm pitch 与占位 2.30 mm 间距不重合 ⇒ 三个件都要落板批次重画 land (这条两个方案都要付, 不是甲的额外代价)** ★ | ★**① `D_ESD_CAM` 要单独做"反向 land" ⇒ 落板批次必须逐件核 pad 序号 ⇒ 人为出错概率高 (这正是本条存在的理由)** ★ ★**② DPY 是 X1SON 无引脚 0.5×0.5 mm ⇒ 必须上贴片机, 手工返修困难** ★ ★**③ DPY 官方 land 与占位间距不一致 ⇒ 同样要重画** ★ |

## §4 · 复现命令 (★B6 自证★)

```bash
cd /home/yuewuya/.openclaw/workspace/projects/smart_glasses

# ★★板文件实读: 三件 MOS + 三件 ESD 的 pad 号 / net / 尺寸 / 位置 (本表 §1.1 §2.1 的原始出处) ★★
python3 - <<'EOF'
import re
lines = open('HW/PCB/demo_mainboard.kicad_pcb', encoding='utf-8', errors='replace').read().split('\n')
starts = [i for i, l in enumerate(lines) if l.startswith('\t(footprint ')]

for si in starts:
    ei = si
    while ei < len(lines) and lines[ei] != '\t)':
        ei += 1
    txt = '\n'.join(lines[si:ei+1])
    m = re.search(r'\(property "Reference" "([^"]*)"', txt)
    if not m or m.group(1) not in T:
        continue
    print('==', m.group(1), '==')
    for pm in re.finditer(r'\(pad "([^"]*)" (\S+) (\S+)\s*\n\s*\(at ([^)]*)\)\s*\n\s*\(size ([^)]*)\)([\s\S]{0,300}?)\n\t\t\)', txt):
        nm = re.search(r'\(net "([^"]*)"\)', pm.group(6))
        print('  PAD %s at=(%s) size=(%s) net=%s' % (pm.group(1), pm.group(4), pm.group(5), nm.group(1) if nm else '-'))
EOF

# ★★网表真源 (引脚功能 = 漏/源/栅 的判据来自网表 note, 不是猜) ★★
grep -nE ",(Q_AND|Q_PG|Q_ENVC)," HW/netlist_v1.csv | cut -c1-200
grep -nE "^(Q_AND|Q_PG|Q_ENVC)\." HW/netlist_v1_pins.csv | cut -c1-200

# ★★受保护 md5 (板不许动) ★★
md5sum HW/PCB/demo_mainboard.kicad_pcb HW/PCB/demo_mainboard.kicad_pro
```
