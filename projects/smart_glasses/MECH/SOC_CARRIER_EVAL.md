## B1 结论摘要

1. **按任务书的字面提法「在镜框主板位置加一层载板」→ 结构侧判定：不值得。** 因为 `MECH/CLEARANCE_FIX.md` §3.5 解 D 已经判过
   「SoC+PCB 全部挪镜框」**镜框没位置、不可行**；载板化**不改变这个判定**（主板还是那块大板），却要付
   **+2.30mm 厚度 / +34% PCB 面积 / +2 件新增零件 / +3 道工序**。

2. **若改问「在镜脚主板位置加一层载板」→ 结构侧判定：不可能（几何超差）。** SoC 位前后叠层
   壁0.8+隔热0.5+空隙0.3+PCB0.8+**SoC0.85**+导热垫0.3+骨架1.0+壁0.8 = **5.35mm**，
   镜脚上限 7.30mm → 余量只有 **1.95mm**；B 档（BTB 载板）需 **+2.30mm** → **超 0.35mm**；
   C 档（FPC 载板）需 **+2.10mm** → **超 0.15mm**。→ **载板化强制 SoC 必须在镜框**。

3. **但载板化有一条硬的、且与「装在哪」无关的收益：它把主板长度从 76mm 压到 69mm，修掉镜脚长度超差。**
   A 直接焊：电池40.5+主板76+余量15 = **131mm** vs 镜脚内腔 130mm → **超 1.3mm**（hw-lead §7.2 ME-2 已标）；
   B 载板：40.5+69+15 = **125mm** → **余 5.2mm** ✅。→ **这才是载板化的真实结构价值，不是风险隔离。**

4. **载板化不解除对原厂的依赖。** 载板自己也要球位图才能画 → 球位图永远不来，载板一样做不出来。
   它只买到「球位图来了但我们把引脚→功能映射搞错了」这一种情形下，**重投的是 383mm² 小板而不是 910mm² 大板**。
   唯一真正解开依赖的是 **D 档（供应商模组）**：模组厂自己出版引脚定义表（ISS-083 正在做的）。

5. **兜底路线（用现成 AR9481/ARS45 模组做 EVT）必须拆成两问：台架 EVT ✅ 可行且是现成路径；眼镜形态 EVT ❌ 几何否决。**
   模组级参考 45×55mm（SOM3559C_A1 规格书 `[官网]`）→ 镜脚根部净高只有 **38mm**，**超 17mm**；
   镜框上沿单侧连续段只有 **43mm** < 45mm → 也否决。**⇒ 模组只能上台架，不能进眼镜。**

6. ★ **结构侧的方向（建议，非拍板）：先做 D 档台架（ISS-083 已在做），同时在主板上预留 60 位 BTB 载板接口
   （成本≈0：只多一块 16×16 空板位 + 一颗连接器焊盘）。这样 ISS-083 一旦拿到模组引脚表，主板不用重投。**

# 1. 前提：三档方案的物理定义

| 档 | 定义 | 球位图错时的重投对象 |
|---|---|---|
| **A 直接焊**（现状） | SoC 直接回流在主板上 | 整块主板（6 层 ~910mm²） |
| **B BTB 载板** | SoC + 逃线 + 就近去耦 放独立载板（4 层），载板用 60 位 0.4mm BTB **叠在**主板上 | 只重投载板（4 层 ~383mm²，面积 1/2.4） |
| **C FPC 载板** | SoC 放载板/刚岛，经 FPC 引出；FPC 可弯折 → **载板可以不在主板旁边** | 同 B，但 FPC 也要重投（打样周期比 PCB 长 + 需折弯治具） |
| **D 供应商模组**（兜底） | 买现成模组，模组自带 SoC+DDR+PMIC+连接器；主板只留接口 | 主板完全不动，换模组即可换 SoC |

> ⚠️ **前置事实（三条互相独立，共同决定架构）**：
> ① ISS-014 决策 5（老板 10-25 19:23 拍板）：**SoC + 充电板挪镜框**，镜脚只留电池；
> ② `MECH/CLEARANCE_FIX.md` §3.5 解 D：「SoC+PCB 全部挪镜框」→ **镜框没位置、不可行**（需变更流程）；
> ③ `HW/SCHEMATIC_V1.md`（hw-lead 10-27）：SoC 在**镜脚主 PCB**，充电板在镜框 → 与 ① 不一致。
> → **「镜框主板位」本身还没定**，所以下面所有结论都按情形给。

# 2. 面积账（板宽 / 板长 / 总 PCB 面积）

> 模型引自 `HW/PCB_FORM_FACTOR_RECHECK.md` §5.3：land 542 + SoC 逃线框 113 = 655mm² 占用，
> 所需板面积 = 占用 ÷ 利用率（双面贴 0.72）。连接器占位：本体 13.6×3.38 = 46mm²，含逃线扇出 ≈ 87mm²/侧 `[推算]`。

| 档 | 主板占用 | 主板需板面积 | 主板板长（宽 12mm） | 载板需板面积 | **总 PCB 面积** |
|---|---|---|---|---|---|
| **A 直接焊** | 655mm² | 910mm² | **76mm** | — | **910mm²** |
| **B BTB 载板** | 599mm² | 832mm² | **69mm** | 383mm²（~16×16） | **1215mm²（+34%）** |
| **C FPC 载板** | 578mm² | 795mm² | **66mm** | 347mm² | **1142mm²（+25%）** |

**⇒ 三个事实**：
1. **载板化不减总 PCB 面积，只是把 SoC 逃线区从主板搬到载板上**（B 档 +305mm² / +34%）。
2. **它确实让主板变短**（76→69mm）—— 这是它唯一真正的面积收益。
3. C 档相对 B 档**无本质面积优势**（1215 vs 1142mm²，且 C 还要多一块刚岛 + 更长的 FPC 打样）；
   C 的唯一差异是**载板可以不在主板旁边**（见 §3 情形 β）。

## 2.1 ★ 镜脚长度账（这才是载板化真正的结构收益）

| 档 | 组成 | 合计 | vs 镜脚内腔 130mm | 判定 |
|---|---|---|---|---|
| **A 直接焊** | 电池 40.5 + 主板 76 + 余量 15 | **131mm** | **超 1.3mm** | ❌ |
| **B BTB 载板** | 电池 40.5 + 主板 69 + 余量 15 | **125mm** | 余 5.2mm | ✅ |
| **C FPC 载板** | 电池 40.5 + 主板 66 + 余量 15 | **122mm** | 余 8.2mm | ✅ |

> ★ **A 直接焊在镜脚里是超长的**（hw-lead §7.2 ME-2 已标「加长到 60mm 撞镜腿长度已短 10-15mm」，
> 但没人把它算到"76mm 这个数本身就不够"这一步）。
> **载板化把它修好了** → 这是本单最硬的结构收益，**且与载板装在镜框还是镜脚无关**。

## 3.1 SoC 位前后叠层（逐项）

# 5. 热 —— 载板化不产生散热收益

| 项 | 数字 | 证据级 |
|---|---|---|
| 现状（镜腿内满载 0.90W） | 皮肤侧 **80.1°C**（主口径）/ 96.1°C（整机上界） vs 43°C 红线 | `[推算]`（MECH §2.6） |
| 载板化对这三个数字的影响 | **零** —— 发热功率不变 / 皮肤侧面积不变 / 43°C 红线不变 | `[推算]` |
| 镜脚只留电池时 | 皮肤侧 **37.5°C** ✅ | `[推算]`（MECH §2.3.1 降级方案 4） |
| 充电峰值 0.8W | 载板化不改变（充电板在镜框已定） | `[推算]` |

> ★ **「挪镜框」≠「解决散热」** —— 镜框侧（鼻梁 / 额侧）同样适用 ISO 13732-1 的 43°C 持续接触阈值。

## 5.1 载板位的两种装法

| 装法 | 热路 | 新增热阻 | 结温影响 |
|---|---|---|---|
| **装法 1**（推荐）载板背面压金属衬板/骨架 | SoC → 载板过孔 → 背面铜面/衬板 → 骨架 → 石墨 → 对流 | **0**（BTB 不在热路上） | **≈ 0°C** |
| **装法 2** 热必须穿过 BTB | SoC → 载板内横向扩散 → 连接器触点 → 主板 → 骨架 | 扩散 **3.39** + 界面 0.5 = **3.9 K/W** | **+3.5°C** @0.90W |

> 扩散段算式（薄膜环形扩散，Carslaw）`[推算]`：
> R = (1/(2π·k·t))·ln(r2/r1) = (1/(2π·400·35e-6))·ln(6.8/5.05) = **3.39 K/W**
> （r1 = SoC 8×10 焊盘等效半径 5.05mm；r2 = 连接器触点区等效半径 6.8mm；t = 35µm 铜箔）
> 对照基线 R(结→皮肤) ≈ 54.5 K/W → 新增仅占 **7.2%**。

> ★ **两条装法的差别不是「热行不行」，是「镜框要不要多一个金属件」**（装法 1 要，0.48g 机加工件；装法 2 不要）。
> 镜框现在是 3D 打印 PA-CF/PC-CF（k=0.2），**热路上不能有塑料隔断**（MECH §5.1：加进去 +94 K/W）。

# 7. 装配 / 零件 / 失效模式

| 档 | 工序 | 新增件 | 风险隔离收益 | 新增失效模式 |
|---|---|---|---|---|
| A | 1 次 SMT | 0 | 无（球位图错 → 整块主板重投） | 无 |
| **B** | 2 次 SMT + 1 次对插 = **3 道** | 载板 + BTB + 金属衬板 = **3 件** | 重投 383mm² 小板（1/2.4）✅ | 对插不良 / 载板翘曲（16×16 薄板 + SoC 集中载荷）/ 合缝方向限制装配顺序 |
| **C** | 2 次 SMT + FPC 折弯 + 对插 = **4 道** | FPC + 座 + 刚岛 + 衬板 = **4 件** | 同 B，但 FPC 也要重投（周期更长 + 需折弯治具） | 同 B + 弯折半径 ≥3mm 占空间 + 弯折疲劳 + **FCCSP 焊在 FPC 上的量产工艺先例 `[0数据]`** |
| D | 1 次 SMT + 模组对插 = 3 道 | 模组 (+散热片) = 2 件 | 主板完全不动 ✅ 最彻底 | 模组是黑盒（引脚/时序/ISP 参数全靠模组厂）/ 采购与版本锁定 / 体积重量不可控 |

## 7.1 ★ 装配顺序硬冲突（B/C/D 三档共同）

镜框/镜腿是 3D 打印**分体壳**（MECH §5.2 上下分壳）→ 主板 + 载板必须在**合壳之前**装进去 →
载板/连接器的装配方向必须与合壳方向一致 → 若载板挂在主板**上方**（SoC 朝上），合壳时会被压到、对插空间不足 →
**SoC 必须朝内（朝皮肤侧）或主板朝下贴骨架** → 这**直接翻转**现有「SoC 远离皮肤侧」的散热布局要求（MECH §2.4 对策 A）。

> ★ **这是本单最硬的一条装配结论：载板化不是「多一颗连接器」，是「改 SoC 的朝向」，而朝向已经被散热定死了。**

# 8. 结构侧判据与方向性结论（不拍板）

## 8.1 三条判据

**判据 A【载板化解决的是哪个风险?】**
- ISS-081 已自证：球数/封装**不是风险**（45-80 脚够，8×10 FCCSP 放得下）；真正卡住的只有**引脚→功能映射**。
- ★ **载板化不解除对原厂的依赖**：载板自己也要球位图才能画 → 球位图永远不来，载板一样做不出来。
- 它只买到：**「球位图来了但我们把功能映射搞错了」这一种情形下，重投的是 383mm² 小板不是 910mm² 大板**。
- → 载板化的**真实价值 = 一次小板的成本**，不是「项目可以不等原厂」。
- **唯一真正解开依赖的是 D 档**：模组厂自己出版引脚定义表（ISS-083 正在做的事）。

**判据 B【结构代价打在真约束上了吗?】**
- 厚度：+2.30/+2.10mm 打在镜脚 SoC 位（余量只有 1.95mm）→ **B/C 在镜脚里装不下**。
- 长度：A 直接焊**超 1.3mm** → **载板化修成余 5.2mm** ✅ ← **唯一硬收益**。
- 镜框平面：上沿单侧只有 43mm → 主板 69mm 仍塞不下。
- 总面积：910→1215mm²（+34%）→ **面积没省，只是搬家**。
- 重量：B +1.06g（可忽略）/ D +11.0g（形态否决级）。
- 镜框上沿厚度：载板位余量只有 **0.45mm**，无决策余量。

**判据 C【热与装配有没有被顺手解决?】**
- 载板化**不改变任何散热数字**（80.1°C / 43°C / 0.16-0.21W 上限全不变）。
- 载板位要走到金属件 → 镜框是打印件 → **必须新增 1 件金属衬板**（0.48g，机加工件）。
- 装法 2 结温 +3.5°C；装法 1 ≈ 0 → **代价落在「镜框多一个金属件」，不是落在温度**。
- ★ **装配顺序冲突**：载板化 = 改 SoC 朝向，与上下分壳 + SoC 不贴皮肤的既定布局矛盾。

## 8.2 方向性结论（**不是拍板**）

1. **按字面提法「镜框主板位加一层载板」（情形 α）：不值得。** 解 D 已判镜框没位置，载板化不改变这个判定。
2. **按「镜脚主板位加一层载板」（情形 γ）：不可能。** B/C 厚度超差 0.35/0.15mm。
3. **真正有价值的是第三条**：载板化把主板长度 76→69mm，**修掉镜脚长度超差 1.3mm** —— 与「载板装哪」无关。
4. **所以结构侧的方向是：值得做的不是「把 SoC 搬到镜框」，而是「把 SoC 从主板上拆下来做成载板」用来解决主板面积/长度；
   载板装镜框还是镜脚是被厚度和可靠性逼出来的结果，不是目的。**
5. **但性价比取决于两个现在都是 `[0数据]` 的数**：原厂球位图能不能来（决定 A-2）、ISS-081 引脚预算能不能缩到 50 脚以内
   （决定连接器 60 位还是 40 位 → 载板 16×16 还是 12×12）。
6. **建议动作（建议，非拍板）**：先做 D 档台架（ISS-083 已在做），同时在主板上**预留 60 位 BTB 载板接口**
   （成本≈0：只多一块 16×16 空板位 + 一颗连接器焊盘）→ ISS-083 一旦拿到模组引脚表，**主板不用重投**。
7. **本条不替项目总工/老板拍板** —— 请裁：(a) 主板位定镜脚还是镜框（解 D 走不走变更流程）(b) ISS-083 模组线是否升主线
   (c) u8 镜框截面口径。

# 9. 兜底路线初判 —— 用现成 AR9481/ARS45 模组做 EVT

## 9.0 ★ 先拆两件被混在一起的事

| | 验的是 | 结论 |
|---|---|---|
| **(i) 台架 EVT**（桌面台架，模组不戴在脸上） | 软件/协议链 | ✅ **可行，且是现成路径** |
| **(ii) 眼镜形态 EVT**（模组进眼镜） | 整机形态 | ❌ **几何否决** |

**(ii) 的几何否决算式** `[官方]` + `[推算]`：
- 模组级参考 **45×55mm**（SOM3559C_A1 规格书，BSH-060-01-L-D-A-TR 60pin 0.5mm）
- 镜脚内腔 130×38×7.30 → 模组高 **55 > 净高 38**，**超 17mm**
- 镜框上沿单侧连续段 43mm < 模组 45mm → 也否决
- → **模组只能上台架，不能进眼镜。**「用模组做 EVT 样机」这句话必须拆成两问。

## 9.1 (i) 台架 EVT：能验什么

| 项 | 内容 | 判定 |
|---|---|---|
| ISP 链路 | 模组自带 ISP + 驱动 → 曝光/增益/帧率/中断/DMA 全链可跑 | ✅ |
| OD 链路 | 模组自带 NPU runtime → yolov5s INT8 640×640 可跑，出框 + NMS | ✅ |
| 显示链路 | 若模组带 MIPI-DSI TX → 可直连走鹃Ⅱ；若只有 DP/HDMI → **仍需桥接芯片，这条验不到** | ⚠️ 看接口 |
| **★ 显示 TX 判定** | 模组规格书会写明视频输出接口类型 → **ISS-083（DSI TX 到底是哪一种）最直接的公开证据** | ✅✅ |
| **★ 引脚→功能映射** | 模组厂出版引脚定义表 + 原理图 → **直接绕开 ISS-081 的卡点** | ✅✅ |
| 功耗构成 | 分别关 ISP/NPU/显示测差值 → 给 sw-lead 一个**分项**功耗表（比整机 1.22W 有用） | ✅ |
| 端到端延迟 | 台架可测 ISP→OD→合成→出光 段；口径 A（曝光→出光）需高速相机 + 光电探头 | ⚠️ 需设备 |

## 9.2 (i) 台架 EVT：**要解决什么**

1. **模组选型**：必须能买到**引脚定义表公开**的 AR9481/ARS45 模组（ISS-083 正在找，我**不外联**）。
2. **显示输出口必须是 MIPI-DSI** 才能接走鹃Ⅱ；若只有 HDMI/DP → 台架也得加桥接板，验证价值打折。
3. **CSI 摄像头输入**：模组 CSI 口是否引出 + 能否驱动我们的 OV04C10/AR0234CS（可能得用模组自带 sensor）。
4. **ISP 调参**：模组 ISP 是给机器人/扫地机 sensor 调的；我们用鱼眼 120° → **LDC + 数字 shift 参数要在模组 SDK 上重做**。
5. **存储/启动**：模组自带 eMMC → 启动链 / rootfs 分区 / OTA 要按模组重做（`SW/FLASH_AND_VERSION.md`）。
6. **供电**：机器人模组是 5V/12V 输入，不是电池直供 → 台架要额外电源板；且测不出眼镜形态的电池账。
7. **散热**：模组必须配散热片（台架风冷）→ **测出的满载功耗不能外推眼镜形态**。

## 9.3 (i) 台架 EVT：**差在哪**（验不了什么）

- **形态**：尺寸 / 佩戴 / 配重 —— 全验不了（45×55mm 进不去眼镜）。
- **重量**：模组级 +11g vs 整机 30-40g 目标 → 没有可比性。
- **散热**：台架风冷 → 验不了镜腿 0.16-0.21W 上限 / 43°C 红线（现状皮肤侧 80.1°C）。
- **续航**：AR9481 ~1W（机器人预算）vs ARS45 <300mW → **台架功耗不能倒推电池档位**。
- **OD 延迟**：AR9481 8TOPS vs ARS45 6TOPS（tracker §2.1：640×640@60 ~11ms vs ~15ms）→ **台架值偏乐观，不能当 60ms 达标证据**。
- **ISP 画质**：模组 ISP 是机器人相机调的 → 我们的鱼眼 120° 畸变/LDC 要重调，调不动就证不了。
- **引脚映射**：模组引脚 ≠ SoC 球位 → **模组证不了 ARS45 的球位图**（只证平台可行）。
- **光学链**：走鹃Ⅱ / 一拖二分光 / 波导 与 SoC 无关，台架里挂不上 → 光学件仍全部 `[0数据]`。

## 9.4 兜底路线与 ISS-084 的关系（★ 本单最有价值的一句）

> **载板化 (B/C) 与 模组化 (D) 是同一个风险隔离机制的两端：**
> - **B/C** = 我们自己造那块「引脚图隔离板」→ 但**我们得有球位图才能造** → **死锁**
> - **D** = 别人造那块板，并附引脚表 → **死锁解开**
>
> ⇒ **先走 D（台架 EVT + 模组引脚表），再决定要不要为 D 做一块适配主板**；
> **不要**在球位图 0 数据时先做 B/C 载板 —— 那是在赌原厂会回信。
> ⇒ 若最终确实要用模组进眼镜（D 档），几何已否决 → 那时唯一可行的是
> **主板预留载板/模组接口**（B 档接口的主板），而不是把模组塞进眼镜。
