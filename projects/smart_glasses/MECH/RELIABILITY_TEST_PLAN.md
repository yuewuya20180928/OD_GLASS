## B0 一句话结论

```
1 台样机**能**做的: 12 类用例全部可以"跑一遍" (其中 8 类是整机级, 4 类用试样件) ——
但跑一遍的产出是**失效模式暴露**, 不是**寿命判定**。
真正能下"通过"结论的, 只有 2 项: ① 单次跌落的结构完整性 ② 化学介质不造成功能失效。
其余全部要在 3 台 + 试样 + 老化/振动/弯折设备的条件下, 由后续批次出结论。
```

### B2.3 相对判据原则 (1 台样机能不能用的关键)

1 台样机**没有群体基线**, 所以大部分判据必须写成**相对量** (相对自身基线快照 S0 的变化率), 而不是绝对规格:

| 判据类型 | 例子 | 为什么 |
|---|---|---|
| **相对量 (1 台可判)** | 接触电阻 ΔR ≤ +10 mΩ; 内阻 ΔR ≤ +20%; 电感 ΔL ≤ ±10%; MTF 衰减 ≤ 10%; 阻抗 ≤ ±10%; 残余变形 ≤ 0.3 mm | 有 S0 基线就能算, 不需要第二台 |
| **绝对量 (1 台也可判)** | 板弯 σ ≤ 板材许用×0.5; 点蚀深度 ≤ 0.05 mm; 焊点空洞率 ≤ 25%; 不得断裂/脱开 | 结构/工艺红线, 与样本量无关 |
| **群体量 (1 台不可判)** | 失效率、寿命余量、95% 置信下限、"3 台 30 次全过" | 需要多台 → 本文明确归到后续批次 |

> ⚠️ **这条原则直接决定 §B4 的样品分配**: 凡判据是群体量的用例, 本轮只标 "筛查", 不标 "验证"。

### B3.3 ★ 换件规则 (1 台做 12 类, 必然会坏)

1. **任何一次失败 → 立即停止该台的后续试验**, 转失效分析 (FA), 记录失效模式, **不得"换件继续"然后把结果算作通过**。
2. 若允许换件继续 (例: T-05 汗液浸泡后电路受潮), 必须: ① 在数据表上写明换件清单与时间戳 ② 该台从此标记为"**非出厂态**" ③ 换件后的数据只用于"后续用例", **不用于回溯判定前面的用例**。
3. **优先用试样件承载破坏性最强的项** (T-05 电芯、T-06 胶接、T-08 材料), 让整机留给耦合观察 (T-01 → T-10 → 化学 → UV 的**叠加失效**才是整机最有价值的产出)。

## B6 试验顺序与检查点 (1 台做 12 类, 顺序是方案的一部分)

> **排序三条原则**: ① 先无损/微损, 后破坏 ② 先机械, 后环境, 最后化学/UV (越不可逆越靠后) ③ 每一步前留**基线快照**, 保证"相对判据"有参照物。

### B6.1 为什么是这个顺序 (三条理由)

1. **T-05 汗液浸泡放在 T-01 跌落之后**: 目的是观察**耦合失效** —— 跌落造成的焊点隐裂 + 电解质 → 腐蚀加速 → 这才是"最恶劣组合"的真实风险。单独泡和单独跌落都看不到。
2. **T-10 温循紧跟 T-01 跌落**: 温循是**隐裂放大器** —— 跌落后 X-ray 看不出的焊点微裂纹, 经 50 次冷热循环后会扩展成可见裂纹 → 跌落"看起来没事"的风险被消除。
3. **UV 放最后**: 2,000 h UV 会改变材料状态 (黄变/脆化), 若 UV 在化学之前, 后面汗液/化妆品的区分度会下降; UV 放最后, 它的结果就是"整机在经历真实使用顺序后的最终状态"。

### B6.2 顺序的代价 (诚实说明)

- **总周期 ≈ 115 天** (其中 UV 占 83 天) → **UV 是关键路径**, 必须最早约设备, 否则最后卡住。
- **U1 只有一台**: 任一环节失败 → 后续用例全部作废 (失效分析优先)。→ **强烈建议: 把 T-03 的 FPC 试样段 (200,000 次) 与 T-12 振动在 U1 装配之前, 用试样先跑**, 用试样结果提前锁定设计, 减少 U1 被"试错"消耗的概率。
- **建议补样**: 若预算允许, 优先补 **打印件 R1 + 电芯 R3 + PCB 1 块**, 这三样是 U1 坏了以后唯一能"重启流程"的东西。
