### 1.2 算式与输入 (C-6 全部数的来源)

```
光束口径 D_e = sqrt(4 × A_e / π)          = sqrt(4×62/π)        = 8.8849 mm
面板等效直径 D_p = sqrt(4 × 65.40 / π)                             = 9.1252 mm
⇒ 中继比 M = D_e / D_p = 0.9737 ⇒ FOV 折减 = (1−M)×100% = 2.63 %

45° 平板所需对角 (严格矩形包含口径) = D_e × √3                    = 15.3890 mm
45° 平板所需对角 (宽松式)             = D_e / sin45°              = 12.5651 mm
⇒ 等效方边长 = D_e × √(3/2) = 10.8817 ⇒ 取可加工整数 **11 × 11 × 1.5**
  (对角 11√2 = 15.5563 ≥ 15.3890 ✔  竖向 11.0 vs 光束 8.8849 ⇒ 余 2.1151 mm)
转向棱镜入口口径 ≥ D_e = 8.8849 ⇒ 8×8 装不下 ⇒ **9 × 9 × 5** (入口余 0.1151 mm)

连续口径体积 = 10.8817² × 1.5 / 1000 + 2 × (8.9² × 5 / 1000)
             = 0.1776 + 2 × 0.3961                                      = 0.9697 cc
工程取值体积 = 11 × 11 × 1.5 / 1000 + 2 × (9 × 9 × 5 / 1000)
             = 0.1815 + 2 × 0.4050                                      = 0.9915 cc
Δ vs 旧 0.79 cc = +0.1797 (连续) / +0.2015 (工程)
W4 = 3-6 g × (0.9697 / 0.79) = 3.6825-7.3649 ⇒ 落表 **3.68-7.36 g** (Δ +0.68~+1.36 g)
正中区体积 = 0.18 (M5 旧占位) + 0.9697 + 装配 0.05                  = 1.1497 → 1.15 cc
整机合计   = 50.1+0.68 / 74.0+1.36 (387 mAh) = 50.78-75.36 g
             = 48.9+0.68 / 72.8+1.36 (315 mAh) = 49.58-74.16 g
```

## 3. 必做③ · C-8 ★ `t_s` 轴向口径自己实算 + 三档 T = 18/21/23 的后果重算

### 3.1 冲突的根因 (轴口径混用)

- §1.4.5 的 `t_s = 6.0 mm` 取自 §1.3 M6 的**包络第三维** (14×10×6) —— ★**M6 包络的「第三维」从来不是「前后向占位」的推导值, 只是旧器件 (走鹃Ⅱ 2.9 mm 光束) 的占位**;
- ★**45° 平板绕竖轴倾斜 (左右分光构型的唯一可能) ⇒ 平板的竖向投影 (11.0) 与前后向 (轴向) 投影是两个不同的量**;
- ISS-219 §2.5 取的是**竖向**投影 (11.0) 填进**轴向**预算 ⇒ ★**轴口径错误 ⇒ 它的「三档全废」是这个错误的产物, 不能当结论用**。

### 3.2 轴向投影的几何式 (任何左右分光构型都成立)

```
45° 平板 (边长 a = 11, 厚 t = 1.5) 绕竖轴 (Z) 倾斜 45°:
  平板在水平面内的边 (沿 u) 与前后轴 Y 的夹角 = 45° ⇒ 该边的 Y 向投影 = a·sin45°
  平板法向与 Y 轴的夹角 = 45° ⇒ 板厚方向对 Y 的贡献 = t·cos45°
⇒ 轴向 (前后向) 占位 t_s = a·sin45° + t·cos45°
                       = 11 × 0.707107 + 1.5 × 0.707107
                       = 7.7782 + 1.0607 = **8.8388 mm**
```

⇒ ★**这个值与光路怎么摆无关** (只要是左右分光, 平板就必须绕竖轴 45°); ⇒ **转向棱镜不计入 t_s** (前提: 棱镜**不串在正中区的前后向链上** —— §3.3 的 TS-5 行给出反证)。
