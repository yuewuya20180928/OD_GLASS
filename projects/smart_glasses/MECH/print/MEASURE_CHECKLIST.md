# M-PRINT 逐项测量清单 (P2S 打样件)

> **本清单是 M-PRINT 的执行书**。本机 (Linux 工作站) **无法打印也无法量测**:
> 打印机 `192.168.1.68` 与本机 `192.168.2.4/24` **不同网段, 不可达** (2026-10-25 12:2x 实测: ping 无响应,
> TCP 990/8883/6000/4000 全 closed); 本机**无切片器** (无 Bambu Studio / Orca / Cura), **无卡尺/千分尺/塞尺**,
> **无 USB 串口设备** (`/dev/ttyUSB*` 不存在) → 电子卡尺也接不上。
>
> 所以: **交付的是可直接下片的 STL + 这份逐项测量清单**, 谁执行谁按表填, 填完回填
> `state/measurements.yaml` (M-PRINT, kind=实测) 与 `MECH/MECH_BUDGET.md` §5.4。
>
> ⚠️ **不许拿推算值回填**。测量清单里每一行都必须写**实测数字 + 工具 + 日期 + 执行人**。

### 2.1 工具要求

| 量 | 用什么 | 分辨率 | 备注 |
|---|---|---|---|
| 孔径 / 外形尺寸 | **数显卡尺** (0.01mm) | 0.01mm | 电子卡尺可导出 CSV 最好 |

## 3. 回填规则 (填完怎么用)

1. **先填 `state/measurements.yaml`**: 新增一条 `id: M-PRINT`, `kind: 实测`, `value: <实测汇总>`,
   `by: <执行人>`, `when: <日期>`, `evidence: MECH/print/MEASURE_CHECKLIST.md 表格 + 照片文件名`。
   > `kind` **必须**写 `实测`; 写 `推算` 阶段门照样不认 (这是设计意图, 不是 bug)。
2. **回填 `MECH/MECH_BUDGET.md` §5.4**: 把"实测尺寸 ❌ [0数据] 一件都还没打"那一行改成实测值,
   并把相应行的证据等级从 `[推算]` 升到 `[实测]`。
3. **回填 v1.1 的公差结论**: 若 B1-B6 实测显示 FDM 做不出 0.10-0.15mm 间隙 →
   §5.4 "波导卡槽单边 0.10-0.15" 必须改成金属压条方案 (v1.1 §5.5 已规定, 实测只是补证据)。
4. **同时登记 `M-FIT`**: H4 (实物电池插入) 的结果 = M-FIT 的实物证据;
   把它填进 `measurements.yaml` 的 `M-FIT` (kind=实测) → **G2 阶段门这两项才真的能过**。
