## 2. 参考实现 (项目总工照着机械重生成)

> 坐标约定沿用现有生成器 (`gen_print_pack.py`):
> **X = 电池插入方向** (电芯从 -X 端插入, 端挡在 +X 端) · **Y = 电池厚度 = 镜脚 H 方向** ·
> **Z = 电池高度 = 镜脚 V 方向** (Z=0 = 检具底面)
>
> ⚠️ **本规格新增一条坐标定义** (Rev 0 没写, 导致"哪边深/浅"有歧义):
> **Y 负侧 = 皮肤侧 (外侧, 靠皮肤)** · **Y 正侧 = 顶板侧 (内侧, 朝镜腿内腔)**
> 下面所有"皮肤侧 / 内侧"都按这条。

| `pz` 座净高 (Z) | **23.80** (不变) | batt_v 23.5 + 2×clr 0.15 |

### 2.2 派生坐标 (照抄即可)

```
座底面 (皮肤侧内壁面)      Y = 0.80
电芯占位                   Y = 0.80 .. 5.40      (厚 4.60)
内侧间隙 (压垫工作间隙)     Y = 5.40 .. 5.55      (0.15)
顶板内侧面 (槽区以外)      Y = 5.55
顶板外侧面                 Y = 6.35              (厚 0.80)
压垫槽 (让位凹槽) 空腔     Y = 5.55 .. 5.95      (深 0.40, 从内侧面往板内挖)
   → 槽区的顶板内表面在 Y = 5.95, 槽区板厚 = 6.35 − 5.95 = 0.40   ⚠️ §6-P1
压垫槽区板厚               0.40                  ⚠️ §6-P1
电池段实体 Y 总范围        Y = 0.00 .. 6.35      (Rev 0 是 0.00..7.90)
```

**槽的性质 (容易搞反, 必须写明)**: 压垫槽是顶板内侧的 **让位凹槽** —— 材料从内侧面 (Y=5.55) **往板内** 挖到 5.95。
所以 **槽区的净宽比槽外大 0.40**: 槽外净宽 4.75 (座底 0.80 → 顶板内侧面 5.55), 槽内净宽 5.15 (座底 0.80 → 槽底面 5.95)。
⇒ 探针 #35 的算法 = **槽内净宽 − 槽外净厚 = 0.40** (不是相减反了号)。

**"非对称"的确切含义 (F1)**: 座净深 4.75 里, **皮肤侧间隙 0.00** (电芯被顶板上的硅胶压垫压向座底, 贴面) ·
**内侧间隙 0.15** (压垫工作间隙) —— 旧值 4.90 是**每边 0.15 的对称槽**, 新值是**单边 0 的定位槽**。

### 2.3 temple_cage_340 电池段 (A 段) 的精确盒体

> 全部用 `m.box(x0,y0,z0, x1,y1,z1)`, 纯加法, **不需要布尔运算** (现有生成器无布尔)。

```
# A1 槽底板 (Z 0..2.0) —— Y 上限由 6.90 收到 6.35
m.box(0, 0, 0, px+w, 6.35, w)
# A2 皮肤侧壁 (Y 0..0.80), Z 2.0..25.8, X 0..40.8
m.box(0, 0, w, px, skin_w, w+pz)
# A3 顶板基体 (Y 5.95..6.35, 满板)
m.box(0, 5.95, w, px, 6.35, w+pz)
# A4 顶板下边条 (Y 5.55..5.95, Z 2.0..5.75) —— 围出压垫槽的下沿
m.box(0, 5.55, w, px, 5.95, 5.75)
# A5 顶板上边条 (Y 5.55..5.95, Z 21.75..25.8) —— 围出压垫槽的上沿
m.box(0, 5.55, 21.75, px, 5.95, w+pz)
# A6 端挡 (X px..px+w), Y 0..6.35, Z 0..27.8
m.box(px, 0, 0, px+w, 6.35, w+pz+w)
# A7 顶盖 (Z 25.8..27.8), Y 0..6.35, X 0..px+w
m.box(0, 0, w+pz, px+w, 6.35, w+pz+w)
```

> A3+A4+A5 的效果 = 一块 0.80 厚的顶板, 中间被挖出一条 0.40 深 × 40.80 × 16.00 的槽 (槽区板厚剩 0.40)。
> **槽是敞口到尾端的** (X 0 侧开口) —— 硅胶压垫从尾端塞入, 不需要额外固定。

## 6. 风险 / 待确认 (P0 = 重生成前必须有结论)

### P0-1 压垫的"吸收量"比写的少 0.15 —— 差 0.05 就翻车

**算式 (全部 [推算], 可复算)**:

```
压垫预算 (能再压缩多少) = 压垫厚 0.40 − 名义内侧间隙 0.15 = 0.25
最坏需吸收量            = 座深最短 − 电芯最厚
                        = (4.75 − 0.25) − (4.60 + 0.15) = 0.25      ← 正好用完, 零余量
若电芯厚度公差按 ±0.15 → 需吸收 0.25, 预算 0.25 → **零余量** (差 0.05 就硬干涉)
若电芯厚度公差收紧到 ±0.10 → 需吸收 0.20, 预算 0.25 → **余 0.05** ✅
```

**问题**: `CLEARANCE_FIX.md` §3.1 写的是"差 0.30mm → 由 0.40mm 硅胶压垫压缩吸收" —— 但压垫在名义状态下**已经被压了 0.25** (占位 0.15), 实际只剩 **0.25** 的压缩余量, 不是 0.40。
另外 `fit_check.py` 把座深缩短按 **±0.30** (零件外形公差) 算, 而盲槽是**内部特征**, 按 ±0.25 算更合适 —— 两者不能混用。

**我的建议 (需 boss / 项目总工拍板)**: **座深保持 4.75 不变** (保住 H 链 6.35 → 名义余量 0.95 / 最坏 0.65 ✅), 同时:
1. **电芯厚度公差写进采购要求 ≤±0.10** (项目总工走 JBD / 电芯厂) ⇒ 需吸收量降到 0.20 ≤ 预算 0.25;
2. 座深内部公差按 **±0.25** 标注 (不是 ±0.30);
3. 原型阶段 (只做 1 台) 允许**配磨座底 0.05** 兜底。

**对比选项 (不推荐, 列出来是因为它会破规矩)**: 座深改 5.00 (电芯最厚 4.75 + 座深公差 0.25) ⇒ H 链 6.60 ⇒ 名义余量 0.70 ✅ 但最坏 (+0.30) 余量 **0.40 < 0.60 ❌** 破"2×单边公差"规矩 ⇒ 要走变更流程。**本规格不采用。**

### P0-2 "非对称"的方向是不是我写的这一条

`CLEARANCE_FIX.md` §3.1 的原话是"座深 4.75 (电芯 4.60 + 0.15), **定位面在电池段前端壁**"。
- 本规格按**厚度 (Y) 方向非对称**执行 (皮肤侧 0.00 / 内侧 0.15), 见 §2.2;
- 若"非对称"实际指的是**长度 (X) 方向** (电芯前端抵电池段前端壁、尾端留 0.15) ⇒ 产品件座净长应为 **40.65** 而不是 40.80, **检具 X 净长本规格保持 40.80 不变** (兼容两种电芯装法)。
⇒ **请确认按哪个方向执行**; 若改方向, 只需改产品件, 打印包检具的 X 尺寸不用动。

### P1-1 压垫槽区板厚只剩 0.40 (< FDM 最小壁 0.80)

顶板 0.80 厚, 挖 0.40 深的槽 ⇒ 槽区板厚 0.40, 低于 `MECH_BUDGET` §5.4 的 **0.8mm 最小壁**。
- **检具** (temple_cage): 0.40 壁可以接受 (只是检具, 受力小, 且它是**竖壁**不是水平薄顶) —— 本规格按 0.40 执行。
- **产品件** (下壳顶板): 0.40 厚的水平顶 + 40.80×16.00 跨度 ⇒ **FDM 必变形/必塌**。
  ⇒ 产品件的解法二选一: (a) 槽改浅到 0.20 (板厚 0.60, 仍 <0.8, 治标); (b) **顶板局部加厚到 1.20** (槽底留 0.80) ⇒ H 链 0.80+4.75+1.20 = **6.75** ⇒ 名义余量 **0.55 < 0.60 ❌** 破规矩。
  ⇒ **两条路都会破 2×公差规矩** ⇒ 需要 boss 裁决 (或改成"压垫贴在顶板表面, 不开槽" —— 那样不占厚度, 但压垫没有定位槽, 需背胶固定, 见 P0-1)。

### P1-2 打印方向: 电池段盲槽轴线必须水平

产品件下壳若把盲槽轴 (H) 竖着打, **0.80 顶板就是 40.80×23.80 的水平桥** ⇒ FDM 塌。
⇒ **产品件必须按"电芯从尾端水平插入、盲槽轴水平、V 向竖直"打印** (顶板 = 竖壁, 座底 = 竖壁, 无桥)。
⇒ 检具 (temple_cage) 的 Rev 0 几何本来就有 7.9mm 宽的水平顶盖 (Z 25.8..27.8), Rev A 不新增更宽的桥 ⇒ **检具仍可按现方向打**, 但要记录"顶盖是 42.8×6.35 的水平桥, 可能有下垂, 打印后先量 H1/H2".
