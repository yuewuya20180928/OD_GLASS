## 1. 打印机连通性 (跨网段不可达 —— **实测复现**)

```
$ ping -c 2 192.168.1.68
--- 192.168.1.68 ping statistics ---
2 packets transmitted, 0 received, 100% packet loss, time 1039ms

$ # TCP 端口 (拓竹常用: 990 / 8883 / 6000 / 4000)
990 closed
8883 closed
6000 closed
4000 closed
```

**本机网络接口 (完整)**:
```
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536
    inet 127.0.0.1/8 scope host lo
2: enp4s0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
    inet 192.168.2.4/24 brd 192.168.2.255 scope global dynamic noprefixroute
```
```
default via 192.168.2.1 dev enp4s0 proto dhcp src 192.168.2.4 metric 100
192.168.2.0/24 dev enp4s0 proto kernel scope link src 192.168.2.4 metric 100
```

⇒ **结论 [实测]**: 本机 `192.168.2.4/24`, 打印机 `192.168.1.68` 在 `192.168.1.0/24` ⇒
**不同网段, 网关只有 192.168.2.1 一条默认路由** ⇒ ICMP 不通、TCP 全 closed。
**这不是"打印机没开机"** —— 是 **网络层不通**。要打印必须满足三者之一:
① 本机接入 `192.168.1.0/24` (或路由器开子网互通) ② 打印机改接本机所在网段 ③ 走代打印服务。
