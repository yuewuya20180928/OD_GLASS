## 1. 空间预算表

### 1.1 第一个结论: **光学件不在镜脚里, 在镜框里**

这是本轮最重要的结构判断, 先说清楚, 否则整张预算表算错位置。

| 部件 | 实际归属 | 依据 |
|---|---|---|
| PCB (ARS45 + 电源) | 镜脚 | PROJECT_TRACKER §2.2 "PCB+电池+光机 集成到镜脚内部" — 但见下 |
| 电池 | 镜脚 | 体积决定, 镜框装不下 |
| 充电板 + Type-C | 镜脚 (末端) | §2.2 Type-C 外露 |
| **光机 (走鹃Ⅱ)** | **镜框正中 (鼻梁上方)** | 见 1.2 推导 |
| **一拖二分光件** | **镜框正中, 与光机同基准** | 见 1.2 推导 |
| **衍射光波导 ×2** | **镜框 (镜片位)** | 波导必须与镜片平行、贴脸, 物理上不可能在镜脚 |
| **摄像头模组** | **镜框** | §2.2 "摄像头 内嵌到镜框上" + §0 #31 横装 |

**为什么光机不能放镜脚** (推导):
1. 衍射光波导是**侧入射/边缘耦入**结构: 光束从波导边缘的耦入光栅横向注入, 在波导内全反射传播, 从耦出光栅射入眼 (JBD 蜂鸟Ⅰ 波导厚度/眼盒参数, CIOE 舜宇 LM3027 "侧入射投影方式")。
2. 因此**耦入点必须在波导的边缘**, 而波导在镜片位。
3. 一拖二需要**分光件把出射光分成两路分别射向左右眼波导** → 分光件必须在两片波导的中间, 即鼻梁区。
4. 若光机+分光件放镜脚, 分光后的两路光要横跨整个镜框 (~62mm 瞳距 + 鼻梁宽) 才能到对侧波导边缘 → 光路过长, 漏光/鬼影/合像误差不可控, 且要加转向棱镜增加体积。
5. 公开报道印证: 一拖二方案的通病是"眼镜中间部位不得不向后凸起", 光机 + 分光棱镜 + 光栅集中在中间区域 (`abvr360 一拖二技术难点分析`)。

> ⚠️ **这与 PROJECT_TRACKER §2.2 的 "PCB+电池+光机 集成到镜脚内部" 存在出入。**
> 结论: **光机 + 分光件放镜框正中**, 镜脚只放 PCB + 电池 + 充电板。
> 若老板坚持光机进镜脚, 则必须放弃"两片镜框波导", 改为**每侧镜脚各一个光机 (双光机方案)** — 但 §0 #22/#3 已锁死"1 光机 + 一拖二", 此路不通。
> → **此条需项目总工与老板确认 (见交接单 TBD-1)。**

### 1.2 一拖二 光路的结构后果 (R13 相关)

走鹃Ⅱ 官方参数 `[官网]`: 出瞳 **2.9mm**, 体积 0.18cc, 重量 0.5g, 800×600, 30° FOV, 6lm, 98mW, 480Hz, 虚像距离无限远。
JBD 蜂鸟Ⅰ 双目模组 `[官网]`: 眼动范围 **15mm × 10mm**, 波导重量 **~16g**, 300mW, 640×480。

| 环节 | 结构量 | 来源 |
|---|---|---|
| 光机本体 | 7.5 × 5.0 × 4.8mm (≈0.18cc) | **`[推算]`**: 官网只给 0.18cc/0.5g, 未给长宽高。参照 JBD 走鹃Ⅰ "光学总长 7.8mm (蜂鸟Ⅰ 为 11.99mm)" `[媒体]` (EET China 2025-12), 同 2.5μm MicroLED + X-cube 平台 → 假设走鹃Ⅱ 光学总长 7-8mm, 截面积 180/7.5 = 24mm² |
| 出瞳 | 2.9mm | `[官网]` JBD 走鹃Ⅱ 参数页 |
| 分光件 (1:2) | 需承接 2.9mm 光束 | 见下 |
| 波导耦入区 | 与 2.9mm 光束 + 眼盒 15×10mm 匹配 | 眼盒 `[官网]` JBD 蜂鸟Ⅰ; 具体耦入区尺寸 **未查到, 待 JBD / 波导厂** |

**分光件体积推算** `[推算]`:
- 直角半透半反平板: 出瞳光束以 45° 入射 → 所需对角 ≥ 2.9/sin45° = 4.1mm, 留装配余量 → 10×10×1.5mm 平板 (玻璃/胶合) = 0.15cc
- 转向棱镜 ×2 (把两路光转向 ±90° 对准左右波导): 8×8×5mm each = 0.32cc each
- **分光组件合计 ≈ 0.15 + 2×0.32 = 0.79cc** → **比光机本体 (0.18cc) 大 4 倍**
- ❌ **这是全机最大的单件体积项之一, 且完全是我推算的 — JBD 无现成双目光模组, 分光件要自研或买标准件**

**分光角度公差 (装配公差, 这是 R13 的结构落点)** `[推算]`:
- 分光件转角误差 Δθ → 左右两眼出射方向差 = 2Δθ
- 分光件位于鼻梁后 ~30-40mm 处, 臂长 L = 40mm
- 位置误差 = L·tan(Δθ): Δθ=0.25° → **0.175mm**; Δθ=0.5° → 0.349mm; Δθ=1° → 0.698mm
- **结论 (硬约束)**: 分光件与光机**必须共用一个定位基准** (一体件 或 金属夹具精定位), 不能各自用胶粘。单独 3D 打印件的角度公差实测 ±0.2~0.5°, 两个件叠加直接超标。
- **分光面不能用 3D 打印件的打印面** (FDM 层纹 Ra ≈ 10-30µm, 分光面平整度需 ≤5µm) → 镜框必须**预留一个加工/研磨平整的分光件安装位**, 分光件用螺钉+UV胶固定在打印件上。

#### 1.4.2 镜脚截面高度叠加 (AGENTS.md 硬性 check list 项)

**前后方向 (H) 叠层** — 电池与 PCB **必须沿长度串行** (电池 22mm + PCB 12mm = 34mm, 垂直方向勉强, 宽度方向不可能并排):

| 导热垫 (SoC → 骨架) | 0.3 | 只在 SoC 区域局部 |
| PCB | 0.8 | 4 层 FR4 |
| 电池 | 4.3 | 丰江 432243 |
| 外侧外壳内壁 | 0.8 | |
| **合计 (不含走线槽)** | **7.0 mm** | |
| + 走线槽 (沿电池侧面) | +2.0 | 走线槽放在电池的**垂直侧面**, 不占 H |
| **镜脚外厚需求** | **≈ 7.0 mm** | 对比华为 AI 眼镜镜腿厚 **6.25mm** `[媒体]` |

**垂直方向 (沿镜腿高度) 叠层**:
```
电池 22 (垂直) + PCB 12 (垂直) + 走线槽 3 = 37 mm  → 镜腿根部净高需求 ≥ 37 mm
```
> 普通全框眼镜镜腿根部高度 ≈ 镜框高度 (35-45mm)。**37mm 落在正常区间上限, 但没有余量。**
> 镜腿是**上宽下窄的锥形**, 电池 + PCB 只能放在**根部 60-80mm 长度段**, 末端 (镜腿 1/3) 只能是空的 (或放充电板)。

**长度方向占用**:
```
电池 43.5 + PCB 50 + 充电板 25 = 118.5 mm  (+ 连接器/弯折/插拔余量 15 mm) = 133.5 mm
```
> 华为镜腿长 151mm `[官网, 华为 AI 眼镜规格页: 52□20-151]` → 扣掉铰链区 (~15mm) 和末端弯折/插头 (~15mm), **内腔可用长 ≈ 120-125mm**
> → **133.5mm 需求 > 120-125mm 可用 → ❌ 长度不够, 差 10-15mm**

- 正中区 **≥11.8mm** ← **这是整机的第一厚度约束 (不是镜脚)**
- 上沿区 **≥10-12mm** (§1.5.2)
- 镜片区 ≥1.3mm
- 铰链区 ≥3.0mm
→ **镜框做不成"薄片式"** (华为 AI 眼镜 52□20 那种), 正中区要 ≥12mm → 外观形态与 30-40g 目标冲突, 需老板拍板 (TBD-2 同批)。

### 1.5 摄像头安装角度约束 (FOV 100-120°)

**几何推导** `[推算]`:
- 摄像头装**镜框上沿** (AI 眼镜主流做法), 镜头中心高于用户视线 h = 12-20mm, 镜片到眼点距离 d = 30-35mm (镜眼距 12-14mm + 镜片/镜框厚度)
- 俯角 = atan(h/d):
  - h=12, d=32 → **20.6°**
  - h=15, d=32 → **25.1°**
  - h=20, d=32 → **32.0°**
- **所以: 摄像头装镜框上沿, 俯角偏置 20-32° 是结构上不可回避的** (除非镜框上沿做到与瞳孔同高, 现实中做不到)

**FOV 对偏置的硬约束**:
| 镜头对角 FOV | 半对角 | 可接受的最大偏置 (留 10° 视场余量) | 20° 偏置是否覆盖正前方 |
|---|---|---|---|
| 100° | 50° | **≤ 40°** | ✅ 覆盖, 且正前方落在画面上半部 |
| 120° | 60° | **≤ 50°** | ✅ 覆盖, 余量更大 |

**结论 (给 sensor/镜头选型和镜框设计)**:
1. **对角 FOV ≥ 100° 不只是画质指标, 它是"偏置安装还能覆盖正前方"的必要条件**。若 FOV 收到 80°, 32° 偏置就吃掉大半视场, 正前方会掉出画面。
2. **偏置 20-32° 会让画面中心偏离用户正在看的方向** → 需要 ISP 做**数字 shift (几何变换)** 或镜头做 **optical shift**。
   - 数字 shift 代价: 边缘拉伸出黑边, **有效视场进一步缩水 10-20%**, 且要占 ISP 几何流水线预算 (与 §5.7 的 LDC 冲突)。
   - optical shift 代价: 模组贵 + 要原厂 ISP tuning + 周期长。
   - **建议: 优先选支持大 shift 的定焦广角模组 (舜宇"大广角 SLAM 视觉模组" / "低畸变 5P 高清采图视觉模组" `[展会]`), 跟模组厂明确 shift 需求。**
3. **畸变**: 广角 + 离轴 → 桶形畸变加剧 → ISP 必须做 LDC, 与 §5.7 的"LDC 占 pipeline 预算"叠加。
4. **机械后果 (硬)**: 广角镜头筒直径 + sensor 封装 (思特威 SC1200IOT 5.1×3.7mm `[官网]`) + AA 组装余量 → **镜框上沿需局部加厚到 10-12mm** 才能装下, 这影响外观和重量 (+1-2g)。

#### 1.5.1 ⭐ 镜框边框吃掉多少 FOV (回答 hw-lead 问题 3)

**先算 FOV 分解** (16:9 sensor, `[推算]`):

| 对角 FOV | 水平 FOV | 垂直 FOV | 垂直半 FOV |
|---|---|---|---|
| 100° | 92.2° | 60.6° | 30.3° |
| 110° | 102.4° | 70.0° | 35.0° |
| 120° | 113.0° | 80.7° | 40.3° |

**边框遮挡取决于摄像头是"齐平/凸出"还是"凹进"镜框上沿**:

| 安装方式 | 遮挡计算 | 遮挡量 (对角100°, 俯角25°, d=25-35mm) | 判定 |
|---|---|---|---|
| **凸出镜框上沿前表面** (AI 眼镜主流, 镜头罩凸起) | 无 (镜框与光轴共面) | **0°** | ✅ 最优 |
| 齐平前表面 | 上沿前缘距光轴 0-1mm | 0-2° | ✅ 可接受 |
| **凹进 1.5mm** | atan(1.5/30) | **2.9°** | ✅ 可接受 (占垂直视场 5%) |
| 凹进 3mm | atan(3/30) | 5.7° | ⚠️ 吃掉上半视场 19% |
| 凹进 5mm | atan(5/30) | 9.5° | ❌ 吃掉上半视场 31% |

**结构硬约束 (写给 hw-lead 和镜框设计)**:
> **摄像头不得凹进镜框上沿前表面超过 1.5mm。**
> 若为了外观必须内凹 → 镜框上沿要在摄像头位置**局部开天窗/抬高**, 或改用**凸包式镜头罩**。
> **另外**: 摄像头每凸出镜框上沿 1mm (d 从 32 减到 31), 俯角增加约 **0.7-0.8°** (h=15-20mm, d=32mm) → 凸出 3mm 时俯角从 25.1° 变成 **27.3°**, **要同时上调 FOV 要求或降低凸出量**。
> ⚠️ **【更正 2026-10-25 第二轮】** 上一版写 "凸出 1mm → 俯角 +1.8° → 凸出 3mm 时 25° 变 30°" 是**算错了** (用的是 Δθ≈Δh/d, 把"向前凸出"当成了"向上抬高")。真实值 **+0.7-0.8°/mm**, 凸出 3mm 只到 27.3°。**影响: 摄像头 FOV 要求不用因为凸出量上调这么多, 但"凸出越多俯角越大"的方向性结论不变。**
> **水平方向**: 摄像头装在镜框上沿**正中** (不靠铰链侧) 时, 水平视场只被鼻梁和镜框内侧限, 不受边框遮挡 → **又一条"装正中"的理由**。

#### 1.5.2 给硬件总工的摄像头角度约束 (写死)

- 光轴俯角 ≤ **25°** (推荐区间 15-25°)
- 光轴水平偏置 ≤ **10°** (即装在镜框上沿正中, 不靠铰链侧)
- 镜头到镜框外表面的凸出量 ≤ **2.5mm**; **凹进量 ≤ 1.5mm**
- 优先要求: **低畸变 (优先鱼眼/低畸) + 大 shift + 对角 FOV ≥ 100°** (与 §5.7 一级指标一致)
- 镜框上沿摄像头位置**局部加厚 10-12mm** (装镜头筒 + sensor 5.1×3.7mm + AA 余量)

2. **PCB 面积是真问题**: eMMC 16GB 的 150mm² 占 50×12mm PCB 的 **25%** → **PCB 必须加宽到 15mm 或加长到 60mm** → **镜脚长度需求 +10mm**。
   - 叠加 1.6.3 的挪充电板方案: 长度需求 106mm (340mAh) → **116mm**, 仍在 130mm 内 ✅
3. **给 hw-lead 的存储选型建议 (按空间从小到大)**:
   - 首选 **方案 A (SPI-NOR 64MB)**: 只存固件/引导, 体积和面积都可忽略。**前提是 ARS45 内置 boot storage + rootfs 有别的落脚点。**
   - 若 rootfs + yolov5 权重 + ISP/NPU 固件必须外挂存储 → **eMMC 8GB (68mm²) 优先于 16GB**; 16GB 需 PCB 加宽到 15mm。
   - 容量估算 (供 hw-lead 参考): Linux rootfs ~80-150MB + yolov5s INT8 ~12MB + ISP/NPU 固件 ~20-50MB → **128MB 就够, 512MB-1GB 有余量, 8GB 是安全余量** → **16GB/32GB 是浪费, 用 8GB 或 SPI-NOR 64MB 即可**。
4. **这条要尽快 close**: 如果 ARS45 内置 boot storage = 未知, 则 PCB 外形 (宽度 12 还是 15mm) 定不下来 → **PCB 开模/投板前必须定**。建议把"ARS45 是否内置 boot storage + rootfs 放在哪"列入给原厂的邮件问题。

### 2.3 热路径计算 (稳态, 贴皮肤镜腿)

**模型** `[推算]`:
```
发热功率 P 在镜腿内 → 结 Tj → (PCB + 铜箔 + 石墨) → 内骨架 → 外壳壁 → 分两路:
   (a) 传导到皮肤:  R_skin_path = R_壳壁 + R_皮肤界面
   (b) 对流到环境:  R_conv
稳态: P = (T - T_amb)/R_skin_path + (T - T_amb)/R_conv
→ 进入皮肤的热量比例 = R_conv/(R_skin_path + R_conv)
→ 皮肤侧温升 = P × R_skin_path × [R_conv/(R_skin_path+R_conv)]
```

> ⭐ **P 的口径 (ISS-064 S-1 同步, 2026-10-26): P = 镜腿内发热量, 不是整机功耗。**
> **光机 (走鹃Ⅱ, M5) + 摄像头模组 (M8) + 分光件 (M6) + 波导 (M7) 全在镜框 / 镜片位, 功耗不流经镜腿 → 不进镜腿的皮肤热路径** (§1.1 / §1.3 已证光学件不在镜脚里)。
> 下面保留的 "整机口径" 表 = 把镜框的热也算到镜腿上, 是**上界**; 对 "镜腿要做薄" 这个决策**过度保守**。
> **主口径改为 "镜腿内发热量"** (硬件总工 `HW/POWER_BUDGET_V2.md` §4.1; **结论不翻案**: 仍超 43°C 红线 30°C 以上)。

**结温侧校验**:
- Tj = 35 °C + P × R(结→皮肤). R(结→皮肤) ≈ 0.3 (焊球+PCB+铜+石墨) + 12.5 (壳壁) + 41.7 (皮肤) ≈ **54.5 K/W**
- P=1.22W (整机口径) → **Tj ≈ 101 °C** (接近 SoC Tj_max 125°C, 触发降频/保护)
- **P=0.90W (镜腿内口径满载) → Tj ≈ 84 °C** —— 芯片本身安全, 但皮肤侧 80.1 °C 不可接受 → **热必须从皮肤侧引走, 不能只降 Tj**
- P=0.8W → Tj ≈ 78 °C (安全)
- 加金属骨架 + 石墨把热导到**非接触面** (镜腿外侧/上侧) 后, R(结→皮肤) 可降到 15-25 K/W → Tj 降到 50-65°C ✅, 但**皮肤侧温升仍由 P 决定, 降不下来** → 所以**唯一有效杠杆是降功耗 + 把热源挪出接触区 + 加隔热层**, 而不是加强导热。

   > 要真正压到 **40°C**, 镜腿内功耗必须 **≤0.10W**。
2. **皮肤侧隔热 + 上壳对流** (对策 A/B/C 组合): 注意 §2.3 模型里**单加隔热会让"皮肤侧温升"略升** (热量堆在壳体节点上) → 隔热的作用是**把热挪到上表面靠对流带走**; 必须同时把对流面积从 150mm² 扩到 250-300mm² (R_conv 667 → 333-400 K/W) → 0.23W 时皮肤侧仍 **~47°C** → **隔热本身救不了 43°C, 降功耗才是**。
   > ⚠️ **前提条件 (ISS-064 S-3)**: 上面"必须同时扩对流面积"这句话**只在 "上下分壳" 方案下成立**, 别当成通用条款。
   > - **贴皮肤方案** (发热件直接贴皮肤): 扩对流面积 150 → 300 mm² **只值 +5~8%** (43°C 对应功耗 0.160W → 0.172W), 因为热阻主导项是 **R_skin_path (54.2 of 721.2), 不是 R_conv** → **贴皮肤方案下扩对流面积基本无用, 不要为它做结构改动**。
   > - **上下分壳方案** (发热件不贴皮肤, 靠上壳对流带走): 此时 100% 热量必须走对流路径, **R_conv 直接成为瓶颈** → **扩对流面积是必需条件 (不是可选优化)**。
3. **缩小皮肤接触面积** (320mm² → 150mm²): R_皮肤 41.7 → 88.9 K/W → 0.23W → 皮肤侧 **55.2°C** ❌ 反而更烫 (热量集中在一条线) → **❌ 不可行, 记在这里避免有人提这个方案**。
4. **把 SoC + 充电板挪出镜脚 (挪到镜框)** → 镜脚只剩电池 (待机 0.05W) → 镜腿皮肤侧 **37.5°C** ✅ → **这是唯一能同时满足"镜腿薄"和"皮肤温度达标"的方案**, 代价是镜框内 PCB 面积和散热空间 (§1.4.5 镜框厚度已到 11.8mm, 会更挤)。
   > ⚠️ **警告 (ISS-064 S-4): "挪到镜框" ≠ 安全。** 镜框正中 = **鼻梁上方** (光机 M5 + 分光件 M6 已占 11.8mm) → **鼻梁皮肤同样适用 43°C 红线** (ISO 13732-1, 持续接触) → 挪过去的热**没有消失, 只是换了个皮肤接触点**。
   > → **必须同时配三件事**: ① 鼻梁侧隔热 ② 顶部对流 (把热从镜框上表面引走) ③ **鼻梁侧温度实测** (样机贴片, 不能只测镜腿)。
   > **上/下分壳后镜腿皮肤侧只剩 3-5 mW** (电芯自放电 + BQ2970 + 2 MOS + 唤醒电路) → 皮肤侧 **35.1-35.3 °C** ✅✅ —— **与整机功耗无关, 任何功耗档位都成立**。

### 2.5 对 DVFS / 温控策略的限制 (给 sw-lead)

**前提: 皮肤侧没有传感器, 软件测不到皮肤温度。** 只能用 SoC 内部 Tj 或 PCB 上的 NTC 间接推算。
所以温控策略必须**建在结温上, 而不是皮肤温度上**。

| 结温 Tj (或等效热代理) | 皮肤侧推算 (按 R(结→皮肤)=20 K/W, 加对策 B 后) | 建议动作 |
|---|---|---|
| < 70 °C | < 40 °C ✅ | **全速**: NPU 640×640@60, ISP 1080p60, 显示 60fps, EIS 关 |
| 70-85 °C | 40-42 °C ⚠️ | NPU 降到 30fps 或换 yolov5n; 显示维持 60fps; 关闭 EIS; 降低显示亮度/APL |
| 85-95 °C | 42-44 °C ⚠️❌ | **OD 停止** (只保留显示 + ISP); NPU 降到 15fps; 提示用户 |
| > 95 °C | > 44 °C ❌ | **强制降频到最低档 + 关闭显示背光/显示模块供电**; 持续 10s 未降下来 → 系统进入保护态 |

**硬件侧要求 (给 hw-lead)**:
1. **PCB 上必须放 1 颗 NTC** (贴 SoC 背面或骨架), 走 I2C 到 SoC/PMIC。**没有这颗 NTC, 软件只能盲降频。**
2. SoC Tj 读取接口 (若 ART.Galaxy SDK 不提供) → 用 NTC 温度 + 标定曲线近似。
3. **DVFS 档位设计要留出 3 档以上** (全速 / 半速 / 仅显示), 不能只有开/关两档。
4. **软件必须能主动降显示亮度** (走鹃Ⅱ I2C 接口, JBD 清单 Q9 已问 I2C 用途) → 这是最省电的调节旋钮 (显示功耗与亮度近似线性)。

### 2.6 散热结论

1. **持续满载在贴皮肤镜腿里热学不可行** —— 皮肤侧 **80.1 °C (镜腿内主口径, 镜腿内发热 0.90 W)** / **96.1 °C (整机上界, 1.22 W 口径)** vs 红线 43°C。这是 **R11 的实质**, 且严重程度超过 tracker 里"🟢 低-中"的评级 — **建议把 R11 从"🟢 低-中"上调为"🔴 高"**。
2. **出路是降功耗, 不是加散热片。** 按需触发 (平均 0.23W) 同时解决 §1.4.3 的空间问题和本节的散热问题。
3. **必须做上下分壳 + 金属/石墨骨架 + 皮肤侧隔热**, 这是结构上不可省的三件套。
4. **充电场景 (0.8W+ 满载) 必须设计成"摘下充电"**, 且充电板要用铝屏蔽罩与皮肤隔断。
5. 上表 §2.5 的 4 个温控档位必须**同时**给硬件和软件, 否则只能等实测再改。
6. ⭐ **电池降容 (441 → 315/387 mAh) 不改变本节任何温度数字**: 容量档位改的是**形态** (镜腿 8.7-11.2mm → 7.3mm), 发热功率 (镜腿内 0.90 W) 一瓦没降 → 皮肤侧仍是 **80.1 °C** (主口径) / **96.1 °C** (上界)。**热只能靠降功耗 + 把热源挪离皮肤解, 加电池余量没用。**

### (b) 一拖二无双目光学模组 (R13 高风险) — 结构视角

**R13 现状**: 走鹃Ⅱ 无现成双目光学模组, JBD 只有蜂鸟Ⅰ 双目模组 (640×480 / 300mW / 0.4cc / 波导 16g) `[官网]`。

**结构上 R13 意味着 5 件事**:
1. **分光件是自研件**, 体积 ~0.79cc `[推算]`, 比光机本体大 4 倍 → **镜框正中要留出 14×10×6mm 的光学舱**
2. **分光件 + 光机必须共基准** (角度公差 0.25° → 40mm 臂长上 0.175mm) → 打印件不行, 必须共定位
3. **分光面不能用打印面** (需 ≤5µm 平整度) → 必须留研磨件的安装位
4. **"眼镜中间向后凸起"** `[媒体]` → 分光件 + 光机在鼻梁后, 会 (i) 向后凸出压迫鼻梁 (ii) **热量直吹鼻梁皮肤** (鼻梁是最敏感部位, 同样适用 43°C)
   → **对策: 用直角棱镜把光"折进"镜框厚度内, 把向后凸出量压到 ≤10mm; 分光舱做隔热**
5. **R13 一旦失败 (JBD 不给分光方案 / 耦合效率不够), 备选是"双光机"** (左右各一个走鹃Ⅱ) →
   - 体积: 2×0.18cc = 0.36cc (仍小), 但**功耗 2×98mW = 196mW**, **PCB 要 2 路 DSI, BOM +2 光机 (成本无所谓, 但 BOM ¥500-1000 目标要重算)**
   - 空间上双光机反而更简单 (各放一侧镜框, 无分光件, 无共基准公差问题) → **R13 失败时, 双光机是结构上的降级方案, 建议提前在心里留着**

> **给项目总工的判断**: 双光机 (2×走鹃Ⅱ) 在**空间和结构上比一拖二更简单**, 只在功耗 (+98mW) 和 BOM (+1 光机) 上有代价。
> 老板锁死了 "1 光机 + 一拖二", 我不推翻, 但**如果 JBD 的一拖二支持迟迟不来, 双光机应该是 Plan B 而不是死路**。

### (d) 衍射光波导的彩虹纹: 结构能做什么 / 不能做什么

> **证据等级: [0数据]** —— 我没有波导样片, 也没有拿到任何一家的彩虹纹 (rainbow / 应力彩纹 / 色差) 指标。
> 下面分"物理上确定的部分"和"必须等厂家数据的部分", **不猜**。

**先分清三种不同的"彩虹纹"** (经常被混为一谈, 处理办法完全不同):

| 现象 | 机理 | 归属 |
|---|---|---|
| **A. 视野里的彩色边缘/彩色鬼影** (用户看到画面边缘有彩色条) | 衍射光栅把白光按波长分开 → 入眼光谱本身带色; 大角度 + 大 FOV 下色散加剧 | **光学/波导设计问题** |
| **B. 镜片表面看到的彩色条纹** (从外面看镜片有彩虹纹) | 光栅周期不均 / 膜厚不均 / 基板应力双折射 → 反射光呈彩色 | **波导制造 (刻蚀均匀性 + AR 镀膜)** |
| **C. 装配后才出现的应力彩纹** (波导边缘一圈彩虹) | 卡槽压紧 / 胶固化收缩 / 温度不均 → 基板应力双折射 | **结构问题 (我能管)** |

**结构上我能做的 (只针对 C 类)**:
1. **波导卡槽用泡棉软压, 不用硬压** (§5.2 已写入) → 压紧力 <0.1MPa, 避免应力双折射彩纹; 硬压卡槽是彩纹的常见来源。
2. **平行度 ±0.3° 由金属压条保证, 不靠打印面** (FDM 面纹 ±0.2-0.5° 会直接变成应力彩纹)。
3. **不点胶固定波导本身** (只压不粘) → 避免固化收缩应力; 泡棉 + 压条即可定位。
4. **分光件安装位平整度 ≤5µm** (金属/研磨件) → 分光面不平会同时产生鬼影和彩纹。
5. **温度均匀性**: 导热骨架让波导区温度均匀, 避免局部受热造成膜厚/应力变化。

**结构上我做不到的 (必须写清楚, 避免被误认为结构能解决)**:
- ❌ **不能消除 A 类 (视野里的彩色边缘)** → 那是衍射光栅的光谱特性, 只能靠: 换窄谱光源 / 削减入射白光成分 / 波导厂的衍射效率设计 / 光学良化 (lens)。**结构侧无解**。
- ❌ **不能靠结构消除 B 类 (光栅工艺/镀膜导致的表面彩虹)** → 只能靠**波导厂**: 光栅刻蚀均匀性、AR 增透膜、基板应力管控。**我要的是厂家的彩虹纹指标 (亮度均匀性 / 色差 / 反射率规格)**, 已列入 §6 u11。
- ❌ **"选低反射膜" ≠ 解决 A 类** —— 反射低不等于色散小, 这两件事经常被混为一谈。

**给项目总工的提问项 (加进 JBD 清单, 走 PM)**:
1. 该波导的**出射光光谱宽度与色坐标 (u'v')** → 决定 A 类彩边严重程度。
2. 是否**镀增透膜 (AR coating)** + 反射率规格 → 决定 B 类表面彩虹。
3. **应力敏感度** (装配允许的应力上限 / 是否允许点胶) → 决定我的卡槽设计 (压紧力上限)。
4. 官方**亮度均匀性 / 色差 (rainbow) 指标** —— 现在是 [0数据]。

> **诚实结论**: **"彩虹纹"我只能解决 C 类 (装配应力), 手段是"少压、别粘、靠金属件保平行度"。**
> **A/B 两类不是结构能解决的**; 在拿到厂家指标前, **我对波导彩虹纹的判断是 [0数据], 不做"能解决"的承诺。**

### 5.5 原型打印件 vs 量产开模件 (只做 1 台, 但必须标清楚)

## 7. 结论摘要 (3-5 行)

> **2026-10-25 晚更新**: 补上了对 PM/硬件总工点名的电池档位 (340/575/675mAh) 和存储缺口 (HW-03) 的正式回话 → **§1.6**。
> **2026-10-26 (ISS-072)**: 电池容量换新口径 (**315 mAh 无桥 / 387 mAh 有桥**, 旧 441 mAh) → 镜腿厚度映射、散热温度口径、重量表同步落地 (§1.4.3 / §1.6.2 / §1.6.3 / §2.6 / §3)。

1. **空间: 装得下, 但有条件 —— 条件是"充电板不占镜脚长度"。** 挪走充电板后 (新口径): **315 mAh → Renata ICP582035PR-01 → 长度 105.5mm / 镜腿厚 7.3mm ✅**; **387 mAh → 丰江 432243 → 长度 108.5mm / 镜腿厚 7.3mm (名义 7.0) ✅** → **老板锁死的 7.3mm 镜腿一毫米不用改**; 旧口径的 "575-675 mAh → 镜腿 8.7-11.2mm (华为 1.8 倍) ❌" **已作废** (旧口径满载容量 441 mAh 落进 575-675 档)。
2. **最紧的 3 个**: ① **电池** (4.1-7.7cc, 占镜脚物料 70-80%, 直接决定镜腿厚度) ② **充电板** (25mm 长度, 是长度超标的唯一元凶 → 建议挪到镜框或并入主 PCB) ③ **一拖二分光组件** (0.79cc, 比光机大 4 倍, 带 0.25° 共基准公差, 是 R13 的结构落点)。**存储件 (HW-03) 不是体积问题, 是 PCB 面积问题** (eMMC 16GB 吃 25% PCB 面积 → PCB 要加宽到 15mm)。
3. **散热: 持续满载在贴皮肤镜腿里热学不可行 —— 皮肤侧 80.1 °C (镜腿内主口径, 镜腿内发热 0.90 W) / 96.1 °C (整机上界, 1.22 W 口径) vs ISO 13732-1 红线 43 °C**。**加散热片无效, 只能降功耗 + 把热源挪离皮肤。** 建议把 R11 从"🟢 低-中"上调为 **🔴 高**。**注意: 电池从 441 mAh 降到 315/387 mAh 只解形态, 不解散热 (发热功率没变)。**
4. **续航 1h 与镜脚空间的冲突, 真正的杠杆是 Q4 (续航口径)**: 若 1h 是"持续满载", **空间和形态都不输** (新口径 **315/387 mAh → 镜腿 7.3mm ✅**) **但热学上仍输** (皮肤侧 80.1 °C, 远超 43 °C); 若 1h 是"按需触发" (平均 0.23W), 电池只要 77-130mAh (1.8cc), **镜腿厚度可做到 5.5-6.0mm, 比华为的 6.25mm 还薄, 空间问题彻底消失** —— 但**散热问题只解决一半**: 0.23W 稳态皮肤温度推算 **46.5°C, 仍超 43°C 红线** (§2.3.1【更正】)。**旧口径的 675mAh 档实质是在为"持续满载"这个未经确认的假设买单 —— 新口径下它已不存在。**
5. **重量: 估算 48.9-74.0g** (315 mAh 配置 48.9-72.8 g / 387 mAh 配置 50.1-74.0 g; 第二轮更正 49-66g 是求和算错, 电池按新电芯重算后下限 -1.2g), **超 30-40g 对标 22-85%**, 做完减重措施 (换 SiC 波导 + 薄壁 + 金属件 + 电池降容) 约 45-60g。原型机预期 **45-60g**, 需要提前跟老板对齐。
6. **我需要谁给什么**: 项目总工 → **Q4 续航口径** + 镜腿截面拍板 + JBD 催"波导 2D 外形图 + 走鹃Ⅱ 长宽高" + 电池档位选哪档; hw-lead → PCB 外形 50×12mm (或 15mm, 取决于存储选型) 确认 + 器件发热分布 + NTC 需求 + **ARS45 是否内置 boot storage**; sw-lead → 实测功耗 (Tj + 整机瓦数, 用于倒推电池容量)。
