### 4.3 仲裁结论与依据

> **结论: 采纳套 A (P1(8,15) / P2(52,15) / S1(8,10) / S2(52,20))。套 B 否决。**

依据 (按强度排序):

1. **[实测] 打印包已经是套 A，套 B 会装不进。**
   本轮用纯 Python 解析 `MECH/print/temple_cage_revb.stl` (二进制 STL, 2112 三角面) 与 `MECH/print/fit_coupon_revb.stl`，按「同一圆上直径对点投票」反算孔心：
   - `temple_cage_revb.stl` 的 B 段「PCB 定位板」(X 0–60, Y 60–90, 板基线 Y=60) 内实测 **⌀2.4 让过孔 @ (8.00, 75.00) / (52.00, 75.00)** ⇒ 板坐标 **(8.00, 15.00) / (52.00, 15.00)** = P1/P2；
     **⌀1.6 让过孔 @ (8.00, 70.00) / (52.00, 80.00)** ⇒ 板坐标 **(8.00, 10.00) / (52.00, 20.00)** = S1/S2。⇒ **笼 = 套 A**。
   - `fit_coupon_revb.stl` 的 L 段「PCB 样板 60×30」(板基线 X=4, Y=84) 内实测 **⌀2.4 @ (12.00, 99.00) / (56.00, 99.00)** ⇒ 板坐标 (8.00,15.00)/(52.00,15.00)；**⌀1.6 @ (12.00, 94.00) / (56.00, 104.00)** ⇒ 板坐标 (8.00,10.00)/(52.00,20.00)。⇒ **样板 = 套 A**。
   ⇒ 若 PCB 按套 B 钻：**M1.2 螺钉与笼的 ⌀1.6 让过孔差 7.50mm** ⇒ 螺钉穿过实心板 ⇒ **板装不进骨架/笼**。打印包是**已经存在**的硬件，不是纸面方案。
2. **[实测] hw-lead 自己的三个产物都写套 A**，套 B 是**单点孤例**：
   `state/fragments/hw.yaml` 的 interface claim `pcb_mount_holes_xy` = `P1(8,15)P2(52,15)S1(8,10)S2(52,20)`；`HW/hw_week_20261101_check.py:55` 的 `exp` 同；`hw.yaml` 的 needs_from `iss118_pcb_holes_30mm_y` **明写规则**「Y 按中心线平移 (旧中心 7.50 → 新中心 15.00, **S 孔 ±5.00 不变**)」——这是 hw-lead 给结构侧的**书面口径**。套 B 只出现在 `HW/pcb60x30_check.py` 一张 `HOLES` 表及其导出的 json。
3. **[推算] 套 B 的边距余量不可接受**：S 孔壁距板边 1.80mm；再叠加 ISS-049 §5 强制要求的「隔热垫 2 处螺钉位开 ⌀3.0 让位孔」与 PCB 侧 M1.2 头座沉孔 ⇒ 让位孔边只剩 **1.00mm** ⇒ 破边/掉料，且 PCB 铣边公差 (±0.15) 下更紧。
4. **[推算] 套 B 会推翻 ISS-049 §4 的骨架接口**：该条写「其余段宽度 **≥10.00mm** (PCB 支撑 + 两个 M1.2 凸台)」。套 B 把 X=8 / X=52 处的特征组从 5.00mm 拉到 12.50mm ⇒ 非 SoC 段必须加宽 ⇒ 骨架增重 + 改接口 + 重出图。
5. **[推算] 套 B 的 Y 规则本身是已作废的老口径**：MECH_BUDGET §5.1 老口径就是「**孔心到板边 2.50**」。套 B 把它原样搬到 30mm 板上，等于复活已被机械复算判死的老方案边距规则（老口径的作废理由见 §4.4 与 `MECH/PCB_MOUNT_PIN_SET2.md`）。
6. **套 A 保留全部既有结论**：四孔相对几何与 15mm 板**逐字同构**（只是整体平移 +7.50mm），所以定位链 (≤0.046mm)、孔间中心距 5.00mm、孔壁间距 3.30mm、隔热垫/骨架接口、打印包契约**全部不变**。

## 5. 骨架 / 石墨 (30mm 口径, 重出结论)

口径: 板 60×30×1.00 / SoC RK3576 占位 X[15.00,32.20]×Y[6.95,23.05] / 逃线带 0.80/边 / 骨架厚 1.00 (备选 0.80) / 非 SoC 段宽 ≥10.00 / 铝 2.70 g/cc、铜 8.96、石墨 2.00 g/cc。

| 候选 | 体积 cc | g/侧 | g/对 | vs 骨架预算 (+1~3g/对) |
|---|---|---|---|---|
| A 满宽 60×30×1.0 | 1.800 | 4.86 | **9.72** | ❌ 超 6.72g |
| B 台阶 X15.00–32.20 满宽 30 / 其余 10 宽 ×1.0 | 0.944 | 2.549 | **5.10** | ❌ 超 2.10g |
| C 台阶 同上 ×0.8 | 0.755 | 2.039 | **4.08** | ❌ 超 1.08g |
| D 台阶 同上 ×0.8 铜 | 0.755 | 6.767 | **13.53** | ❌ 判死 (超 10.53g) |

★ **30mm 板宽的结构结论 (与 15mm 板时代不同, 必须上报)**:
1. **SoC 段骨架必须满宽 30.00mm** (16.10 + 2×6.95 = 30.00，横向扩散通道 **6.95mm/边**，比 15mm 板时的 3.50mm/边宽 1.99 倍)。满宽段长度 = SoC X 投影 **17.20mm**。
2. **所有金属骨架候选都超 `MECH_BUDGET` §2.4 B 的「+1~3g/对」预算** (最好候选 C = 4.08g/对, 超 1.08g) ⇒ **30mm 板宽下骨架截面必须重做**，这不再是「选 1.0 还是 0.8」的题，而是「金属满宽段还要不要」的题。
3. **石墨片也超 W11 预算**: 满板 60×30×0.30 → 1.08g/片 → **2.16g/对** > W11「1~2g/对」上限 0.16g ⇒ 要么缩石墨覆盖 (只铺 SoC 段+扩散带)，要么调 W11 预算。
4. **H 链不受板宽影响** (板宽走 V 不走 H): 外壁 0.8 + 骨架 1.0 + PCB 1.0 + 空隙 0.3 + 隔热垫 0.5 + 皮肤壁 0.8 = 4.40 (+石墨 0.30 = 4.70) vs 镜腿 7.30 ⇒ 余 **2.60mm** (骨架 0.8 时 2.80mm) ✅。
5. **热模型中间量 (口径: 骨架 SoC 段满宽 30.00×1.00 ⇒ A=30mm²，**这是上限口径**，非 SoC 段只有 10mm 宽 ⇒ 实际段热阻比此值更大)**:
   P1/S1 距 SoC 中心 15.60mm ⇒ R = **2.19 K/W**；P2/S2 距 SoC 中心 28.40mm ⇒ R = **3.99 K/W** (15mm 板口径为 5.06 / 7.31 K/W)。
