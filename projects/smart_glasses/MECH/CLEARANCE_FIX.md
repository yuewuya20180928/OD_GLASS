## B1 结论摘要

1. **基线确实不通过**: v1.1 原模型 (沿长度串行) 前后需求 **7.00mm** vs 可用 **7.30mm** → 名义余量 **0.30mm**; 判据是"余量 ≥ 2× 单边公差 = 0.60mm" → **0.30 < 0.60 = 临界 = 不通过**。ISS-017 的自判是对的, 不是保守。
2. **推荐解 A「隔热层局部化 + 电池段单件箱形」**: 前后需求 **6.35mm** → **名义余量 0.95mm**, **最坏情况 (对抗性公差栈) 余量 0.65mm**; 垂直余量 **8.50mm**; 长度余量 **24.50mm** → **三条全部 ≥ 2×公差 (0.60mm) ✅**。**镜腿仍 7.3mm, 一条已定前提都没动。**
3. **为什么能省下 0.65mm**: 不是把镜腿做厚, 是**把 0.5mm 隔热垫 + 0.3mm 空气隙从"全长"缩到"PCB/SoC 段"** —— 那一段本来就空 2.80mm (H), 而电池段没有热源, 那 0.8mm 隔热层在那里是**无效件**。同时把电池段从"两片壁夹着电芯"改成"**同一个打印件的盲槽 + 自带顶板**", H 尺寸链上从 **3 个打印件公差**降到 **1 个**。
4. **三个替代解也算了数**: 解 A-1 (最小改动) 名义余量 0.75mm 但**最坏情况只剩 0.05mm ❌** → 不能当主选; 解 B (换丰江 432243, 4.30mm 厚 / 420mAh) 余量 1.25mm 但**整机 +2.28g** (重量表已 50.1-74.0g 超标) → 不为空间买重量; 解 C (电池分置左右, 各 170mAh) 余量 1.55mm 但**跨铰链 1-2A 充电电流是可靠性新风险** → 不推荐; 解 D (SoC/PCB 挪到镜框) 散热最优但**镜框没位置** → 撞锁死前提, 需变更流程。
5. **三项条件性不通过全部闭环**: ① 叠放模型 **物理不可能** (要 8.10mm > 7.30mm 且 41.50mm > 38.00mm) → 裁决"沿长度串行"为准, 叠放分支作废; ② 充电板不移出 → **改排布**: 与主 PCB 在同一 L 段沿垂直方向并排, **长度余量 24.50mm 一分不占**; ③ ⌀2.0 H7 FDM 做不到 → **定位基准整体移到金属骨架** (机加工面 ≤5µm + H7 销), 打印件只做 ⌀2.4 间隙孔, **打印公差不进定位链**。
6. **散热热路不断**: 解 A 把隔热层缩到 PCB/SoC 段, 但**隔热层原封不动留在 SoC 与皮肤之间** → 皮肤侧温度数字不变 (§2.3.1: 0.23W → 46.5°C, 仍超 43°C 红线, **但那不是我这条改出来的**)。附带一条**新的硬约束**: **金属骨架 / 石墨不得延伸进电池段** (若延伸, 新增并联热路 4.50 K/W, 进皮肤的热量比例 92.5% → 95.7%)。

# 1. 为什么要重做 (判据)

**上轮的问题不是算错, 是判据缺失。** v1 只报 "余量 0.30mm", 读者无法判断这 0.30mm 是"够"还是"不够"。本件把判据写死:

```
判据:  名义余量 ≥ 2 × 单边公差          (FDM 单边 ±0.30mm → 阈值 0.60mm)
       且 最坏情况余量 (对抗性线性公差栈) ≥ 0.60mm
```

**为什么是 2×**: 一条公差链上, 两端各有一个零件, 各自的制造偏差都要被余量吸收; 余量 < 2×单边公差 时, 落在链上的一处偏差就能吃掉全部余量 → 装配从"能装"变成"看运气"。上轮 0.30mm = 1× 公差 → **临界 = 不通过**, 这条判据和 ISS-017 的自判一致。

**公差账** (证据: MECH_BUDGET §5.4 "装配间隙" 行 + §5.3 "打印精度风险"):

| 项 | 单边公差 | 来源 |
|---|---|---|
| 打印件 **外形尺寸** | ±0.30mm | [推算] §5.4 装配间隙行 (打印件↔打印件 单边 0.3) |
| 打印件 **特征间距离** (盲槽深/壁厚位置) | ±0.25mm | [推算] §5.4 |
| 合缝/装配间隙波动 | ±0.10mm | [推算] 本件假设 (v1.1 未给) |
| 电芯厚度公差 | ±0.15mm | ⚠️ **[0数据]** 原厂未公开, 按常规假设 |

**v1 → v2 的唯一口径修正**: 走线槽在垂直方向的占位取 **6.00mm** (MECH_BUDGET §5.6.2 表口径: 电池 23.5 + 走线槽 6 = 29.5; §1.4.2 正文写的 "3" 与 §5.6.2 的表不一致 → 取表口径 = 取保守值)。**这条修正让垂直方向从 11.50 变成 8.50mm, 不改变任何结论。**

# 3. 候选解 (4 个主解 + 1 个降级版)

## 3.1 解 A ——「隔热层局部化 + 电池段单件箱形」 ★推荐

**改什么 (3 条)**

1. **隔热层局部化**: 0.5mm 隔热垫 + 0.3mm 空气隙 从"镜脚全长"改为 **只保留在 PCB/SoC 段**。
   *依据*: 电池段**没有热源** (电芯自身发热 mW 级) → 那 0.8mm 隔热层在该段是**无效件**; 而 PCB/SoC 段本来就空 2.80mm, 隔热层放得下 (需求 4.50 → 仍 4.50, 余量 2.80 不变)。
2. **电池段改成下壳单件箱形**: 电芯坐在**下壳一体的盲槽**里, 该壳自带 0.8mm 顶板封口 → **这一段不再有上下壳合缝**。
   *依据*: v1 的电池被"皮肤壁 + 隔热垫 + 空隙 + 外壁"**四个零件夹在中间**, H 尺寸链上有 3 个打印件公差; 改成单件后, 链上只有 **1 个** FDM 外形公差 (±0.30)。
3. **电池座改非对称 + 顶部硅胶压垫**: 座深 **4.75mm** (电芯 4.60 + 0.15, 定位面在电池段前端壁), 顶板内侧贴 **0.4mm 硅胶压垫**。

**H 尺寸链 (解 A, 电池段)**

```
皮肤侧下壳壁   0.80   [打印, 同一件]
电池座盲槽深   4.75   [打印特征, 同一件]   ← 电芯 4.60 + 0.15 间隙
下壳自带顶板   0.80   [打印, 同一件]
────────────────────
名义需求       6.35   →  镜腿 7.30 → 名义余量 0.95mm
```

# 4. 推荐解与散热路径影响

## 4.1 推荐: **解 A**

**理由 (4 条, 每条都有数)**

1. **余量**: 前后 0.95mm (最坏 0.65mm) —— 是判据阈值 0.60mm 的 **1.6 倍 / 1.1 倍**; 垂直 8.50 / 长度 24.50 远超阈值。
2. **公差链最短**: 电池段 H 链上是 **1 个**打印件公差 (解 A-1 是 2 个, 最坏只剩 0.05mm) —— 这是本轮最重要的工程判断, 而不是"多留 0.2mm 余量"。
3. **代价最小**: +0.2g 整机 (0.1%), **不动镜腿 7.3mm / 不动镜框 11.8mm / 不动上下分壳 / 不动充电板挪出**; 不需要换料, 不需要改铰链。
4. **不牺牲散热**: 见 §4.2 —— 隔热层原封不动留在 SoC 与皮肤之间, 皮肤侧温度数字不变。

## 4.2 对散热路径的影响 (改结构不能把热路切断)

**解 A 之后, 镜脚里有两条热路, 一条没动, 一条变得更干净:**

| 热路 | 路径 | 解 A 后 |
|---|---|---|
| ① **主散热路** (SoC → 环境) | SoC → 0.3 导热垫 → **铝/铜骨架** → 石墨片 → 上壳外壁 → 对流 | **完全不变** (骨架与石墨都还在 PCB/SoC 段, 镜腿上表面 + 前端铰链侧的对流面一点没减) |
| ② **隔热路** (SoC → 皮肤) | SoC → **0.5 隔热垫 + 0.3 空气隙** → 皮肤侧下壳 → 皮肤 | **隔热层仍在 SoC 与皮肤之间, 原封不动** —— 只是从"全长"缩到"PCB/SoC 段", 而 SoC 本来就只在那段 |
| ③ 电池段 | 电池 (mW 级发热) → 顶板 → 上壳外壁 → 对流 | 取消隔热层后, 电池段与皮肤之间**没有热源**, 所以"少了一层隔热" = **没有少任何隔热作用** |

**⇒ 皮肤侧温度数字不变**: §2.3.1 主模型 0.23W → **46.5°C** (仍超 43°C 红线 3.5°C, **但那是功耗口径的问题, 不是结构余量的问题** —— 别把这两件事混在一起说)。

**⚠️ 解 A 带来一条新的硬约束 (必须写进加工图)**

> **金属骨架 / 石墨不得延伸进电池段。**

| 情形 | 纵向热阻 (R = L/kA, L=40.5mm, A=38×7.3mm) | 进入皮肤的热量比例 (§2.3: R_conv 667 / R_skin 54.2) |
|---|---|---|
| 维持打印件 (PA-CF k=0.2) | **730 K/W** | 92.5% → 92.5% (无影响) ✅ |
| 若骨架 (铝 1.0mm) 延伸进电池段 | **4.50 K/W** | 92.5% → **95.7%** ⚠️ |

*计算*: R_al = 0.0405 / (237 × 1.0e-3 × 0.038) = 4.50 K/W; 并联后 R_skin_path 54.2 → 30.0 K/W。
*诚实交代*: §2.3.1 已自报模型不确定性 **±14°C** (壳壁热阻算不算进皮肤侧的算法差异) → **这条约束只能当"禁止"的依据, 不能当"允许"的依据**。禁止它的理由是物理的 (金属会绕过隔热层直接灌到皮肤), 不是模型的。

**充电峰值 (0.8W)**: 充电板挪到镜框 (已定前提) → 镜脚不受影响。若按 §5.2 的兜底把充电板留在镜脚 → 必须**铝屏蔽罩 + 与皮肤隔断** (§2.4 E), 镜脚皮肤侧净高余量 **8.50mm** 放得下屏蔽罩 ✅。

# 5. 三项条件性不通过 —— 逐条解决

## 5.1 ① 叠放模型 (前后 +0.80mm / 垂直 +3.50mm)

**处置: 裁决"沿长度串行"为准, 叠放分支作废 —— 这是模型冲突, 不是"两个都要满足"。**

**三重证明 (叠放在 7.3mm 镜腿里物理不可能):**

| 证明 | 计算 | 结论 |
|---|---|---|
| A (H) | 叠放要求 0.8 + 0.3 + 0.8 + 4.6 + 0.8 + 0.5 + 0.3 = **8.10mm** > 镜腿上限 **7.30mm** (超 0.80mm) | 在 7.3mm 镜腿里**根本装不下** |
| B (V) | 叠放要求 23.5 + 12 + 6 = **41.50mm** > 根部净高 **38.00mm** (超 3.50mm) | 同样装不下 |
| C (L) | 串行只需 40.5 + 50 = **90.5mm** ≤ 内长 **130.0mm** (余 39.5mm) | **串行是唯一可行排布** |

**依据**: §1.3 主表 / §1.4.3 / §1.6.2 / §1.6.3 / §5.6.2 **全部**用串行模型; 只有 §1.4.2 的 H/V 表用叠放, 而那张表是按 **420mAh / 22mm 厚电芯**写的 (比现在的 340mAh 电芯还薄), 属于**过时模型**。
→ **本轮按串行 + 解 A 闭环, 不需要变更流程。**

**若老板坚持叠放** (备用): 镜腿厚必须 ≥ 8.10 + 2×0.30 = **8.70mm** = 比 7.3mm 厚 **+19%**, 是华为 AI 眼镜 6.25mm 的 **1.39 倍** → **走变更流程** (形态代价我已量化, 老板可据此拍板)。

## 5.2 ② 充电板不移出镜脚 (长度 +0.50mm)

**三条解法, 按优先级:**

| 优先级 | 做法 | 长度需求 | 长度余量 | 垂直需求 | 垂直余量 |
|---|---|---|---|---|---|
| **主 (已定前提)** | 充电板挪到镜框 (§1.6.3) | 105.50 | **24.50** ✅ | — | — |
| **次 (若必须留在镜脚)** | **充电板与主 PCB 沿垂直方向并排** (同 L 段) | 105.50 (**不占长度**) | **24.50** ✅ | max(12, 10) + 6 = **18.00** | **20.00** ✅ |
| 兜底 | PCB 50 → 45mm (需 hw-lead 确认 12×12 逃线区 + MIPI + SPI-NOR 68mm² 放不放得下) | 125.50 | 4.50 ✅ | 18.00 | 20.00 ✅ |

**次优解的布局要点**: 充电板 (25×10×0.8) 放在 **PCB 段的垂直空当**里 (PCB 宽 12 / 充电板宽 10, 取大值 12); Type-C 仍在尾端; 充电板到尾端的线走 **电芯上方的走线槽** (该槽 V 向占 6mm、H 向占 2mm, 位于电芯**上方**而不是侧面 —— 侧面 H 只剩 1.0mm, 放不下)。

## 5.3 ③ ⌀2.0 H7 定位销孔 FDM 做不到

**根因**: FDM ±0.30mm vs H7 ±0.010mm —— 差 **30 倍**, 不是"打印得仔细一点"能解决的。

**解法: 把定位基准从打印件整体移到金属骨架 (v1.1 §5.3/§5.5 已经规定用金属件, 本件把它写成可执行的接口):**

| 件 | 做什么 | 公差 |
|---|---|---|
| **金属骨架** (机加工 Al/Cu, §5.5 已有件, **不增加零件数**) | · PCB 安装面: 铣削平面, 平面度 **≤5µm**<br>· 2× M1.2 攻丝孔 → PCB 用 2 颗 M1.2 螺钉压紧<br>· 1× **⌀2.0 H7 销孔** (⌀2.0 销装在骨架上) → 负责**长向定位**, 防电池充放电微动 | 销孔 ±0.010 / 铣削面 ≤5µm |
| **打印件** | 1× **⌀2.4 间隙孔** (只让过, 不定位) + 2× ⌀1.6 螺钉过孔 | ±0.30 **完全可接受** (因为它不定位) |

**⇒ 打印公差不进定位链**: 定位链 = 骨架铣削面 (≤5µm) + H7 销 (≤0.01) → PCB 板面平行度 ≤0.05°, 满足 §5.1 的定位要求。
**代价**: 骨架多 2 个 M1.2 攻丝孔 + 1 个 H7 孔 (机加工, 件数不变, 单件 +0.2g 估算); **PCB 孔位要改 (M1.2, 孔心到板边 ≥1.5mm) → 需 hw-lead 点头** (已列入 §B5 卡点 2, 走项目总工转达)。
**打印包同步**: `temple_cage_340.stl` 的 ⌀2.0 配作孔 → **⌀2.4 间隙孔** (见 §6)。
