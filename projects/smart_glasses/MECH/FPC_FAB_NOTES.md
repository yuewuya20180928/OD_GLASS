## 0. 怎么用这份文件 (给加工方看这段)

- **§1** 是**不可协商项** (违反 = 器件报废或安全失效), 共 6 条。
- **§2** 是**载流专项要求** (只对 `J_CHG` 这条 FPC), 共 8 条。
- **§3** 是**弯折段专项要求** (所有 4 条 FPC), 共 7 条。

- **§5** 是**装配/固定要求** (固定夹与应力释放), 共 5 条。

## 1. 不可协商项 (6 条)

| # | 要求 | 理由 | 判据 | 证据 |
|---|---|---|---|---|
| **N-1** | **弯折段铜箔厚度 = 1oz (35µm)**; 固定段可用 2oz (70µm), 但**弯折段绝对不许 2oz** | 弯折段应变 ε = t/(2R) = 70µm/(2×3.0mm) = **1.167%** (1oz 只有 0.583%) → 应变翻倍 → 按疲劳寿命幂律 m≈4~6, **寿命掉到 1/16 ~ 1/32** | 弯折段任何位置的铜厚 ≤ 35µm | [推算] (几何) + [0数据] (幂律 m 值未核厂商数据) |
| **N-2** | **载流铜箔 (pin1/pin2/pin3/pin4) 从框侧到脚侧全程连续**, 中间**不得有任何过孔 / 焊盘 / 分支 / 焊点 / 补铜** | 载流路径上的过孔/分支会形成**应力集中 + 局部电阻升高** → 压降与温升都不可控, 且是弯折寿命的隐形杀手 | 弯折段与固定段的载流铜箔必须是同一张连续图形 | [推算] |
| **N-3** | **`L2`/`L3` 内层地平面在 pin1-pin4 触点区正下方做 keep-out (挖空)**, 范围 = pin1-pin4 触点区**及其正下方全宽**, 两侧各外扩 **≥0.5mm** | 4 层 FPC 的 L2/L3 是完整地平面 (截面 4.5mm×35µm, 31mm 段仅 **3.4 mΩ**), 远小于 pin3/pin4 的 0.3mm 铜箔 (50.8 mΩ) → 若不干预, 1A 回流会**部分走平面** → 载流/回流阻抗不对称、模型失真、接触区电流不均 → **局部热点** | keep-out 必须在加工图上**显式画出并标注** (见 N-4) | [推算] |
| **N-4** | **keep-out 必须在图上写明"有意为之, 不是漏铜"**, 并给出 keep-out 的**坐标/尺寸标注** | CAM/DRC 会把"不连铜"当成缺陷自动修复 → 漏改 = 阻抗和温升都变成"看运气" | 图上有一行注释 + 一个带尺寸的 keep-out 轮廓 | [推算] |
| **N-5** | **禁止上调充电终止电压做压降补偿** | 跨铰链压降方向是**压低上限** (CV 段电芯稳定在 4.20V − ΔV), 不是抬高下限 → 补偿 = 把真实电芯推过 4.2V = **过充方向**。SYS 下限 3.5V (R-F1 UVP) **完全不受影响** (SYS 不过铰链) | 接受 ~1% 容量损失, 保留 30-120 mV 安全裕量 | [推算] + `MECH/HINGE_POWER_CALC.md` §2.3 / M-7 |
| **N-6** | **`J_CHG` 的 pin10 必须走成"TS 专用回流"**, 与 pin8 (TS 信号) **成对相邻、等长 (长度差 ≤0.5mm)**, 中间**不得有任何平面/铜皮分流** | TS 是**安全门限功能** (BQ25896 据此停充)。若 pin10 与 pin8 不成对, TS 的参考地被 1A 回流抬高 **14-32 mV** → 折算 **0.44-0.99°C 温度偏差** → 停充门限失准。成对后偏差 **<0.01°C** | pin8/pin10 相邻 + 等长 ≤0.5mm | [推算] + `MECH/HINGE_POWER_CALC.md` M-4 |

## 2. 载流专项要求 (只对 `J_CHG` 这条 FPC)

**工况锚点** (供加工方理解为什么要这么严):

| 项 | 值 |
|---|---|
| 充电电流 `ICHG` (R_ILIM 390Ω, max 档) | **0.822 A** |
| 分布 | **pin1 与 pin2 并联**, 每 pin **0.411 A** |
| 回流 | **pin3 与 pin4 并联**, 每 pin 0.411 A |
| 其余 | pin5/6/7/8 ≤1mA; pin9 预留; pin10 TS 回流 ≤0.5mA |
| 跨铰链段长度 (标称) | 31 mm (ISS-085 §4.2 下限口径) |
| 弯折半径 | R ≥ 3.0 mm |

| # | 要求 | 理由 | 判据 | 证据 |
|---|---|---|---|---|
| **P-1** | **固定段铜厚 2oz (70µm)**, 弯折段 1oz (35µm) —— 即**分段铜厚** | 固定段不弯折, 2oz 把载流铜箔电阻减半 (0.3mm 宽: 50.8 → 25.4 mΩ); 弯折段必须 1oz (见 N-1) | 两段铜厚在图上分别标注 | [推算] |
| **P-2** | **载流铜箔 (pin1-pin4) 线宽 0.4mm** (不是 0.3mm) | 电阻 R = ρL/(w·t): 线宽 0.3→0.4 只减 25%, 而铜厚翻倍减 50% → **先加厚再���宽**; 0.5mm pitch 下 0.4mm 线宽留 0.1mm 间隙 (需厂商确认最小间隙能力) | 载流 4 根铜箔净宽 ≥0.40mm | [推算] + [0数据] (厂商最小间隙) |
| **P-3** | **载流铜箔的相邻间隙 ≥0.10mm**; 信号铜箔 (pin5-pin8) 线宽 ≥0.15mm、间隙 ≥0.15mm | 0.5mm pitch 下 0.5mm 线宽 = 间隙 0 → **不可能**, 不要提 | 图上标最小间隙 | [推算] |
| **P-4** | **不做额外的散热铜箔/铺铜** | 铰链段发热仅 15-127 mW, 铜箔自身温升 <1°C (轴向热阻极低), 聚酰亚胺导热 k≈0.3 W/m·K → 垂直温差 <0.1°C → **加散热铜箔不解决任何问题, 反而增加弯折应变** | 弯折段无额外铺铜 | [推算] |
| **P-5** | **pin1/pin2 的载流铜箔全程等宽 (0.4mm), 不得中途收窄** | 收窄 = 局部阻抗集中 + 应变集中 | 全程等宽 | [推算] |
| **P-6** | **pin3/pin4 (回流) 与 pin1/pin2 (载流) 必须相邻排布, 不许在中间插信号脚** | 环路面积最小 → 辐射噪声与压降耦合最小 (这个 pin map 是对的, 不用改) | pin 顺序: 1-2 载流 / 3-4 回流 / 5-8 信号 / 9 预留 / 10 TS 回流 | [推算] |
| **P-7** | **固定段两端各 ≥8.0mm**; 其中**紧邻固定夹的直线段 ≥5.0mm** | 固定段太短 → 弯折应力直接传到连接器焊点; 应力释放段不足 → FPC 在固定夹处反复受折 | 图上标固定段长度 | [官方-项目内] (ISS-085) |
| **P-8** | **分段铜厚的过渡处用 ≥1.0mm 的斜坡** (阶梯蚀刻/多次压合), 过渡段位置**必须落在固定段内**, 距弯折弧起点 ≥3.0mm | 铜厚台阶是**硬应力集中点**; 台阶落在弯折段 = 寿命直接归零 | 图上标过渡段位置与长度 | ★**本轮自发现** (§7 A) |

## 3. 弯折段专项要求 (4 条 FPC 通用)

| # | 要求 | 理由 | 判据 | 证据 |
|---|---|---|---|---|
| **B-1** | 弯折半径 **R ≥ 3.0mm** | 1.27mm 排线达不到 R3.0 的弯折寿命; 0.5mm pitch FPC 的铜箔应变与寿命匹配 | 图上标 R3.0 最小弯折半径 | [官方-项目内] (ISS-085) |
| **B-2** | 弯折段**只允许连续铜箔**: 无过孔 / 无器件 / 无焊点 / 无分支 / 无胶 / 无卡扣压点 | 任何非铜箔特征都是应力集中 + 局部阻抗升高 | 弯折段图形必须是纯走线 | [官方-项目内] + [推算] |
| **B-3** | 弯折段**禁止贴胶带/泡棉/补强板** (除 N-1 允许的 PI 基材本身) | 补强板会限制弯折并把应力转到基材/铜界面 → 沿界面分层 | 图上禁止该区域任何贴附 | [推算] |
| **B-4** | 弯折段**建议增加一层 PI 承载 (载流铜箔 + PI + PI + PI 结构, 铜箔在中间层)** | 铜箔在中间层 → 弯曲时中性面靠近铜箔 → 铜箔应变最小 | 图上标明层叠顺序 | [推算] |
| **B-5** | **固定夹夹持面夹 FPC 背面 (无器件面)**, 夹持边倒角 **R ≥ 0.3mm** | 夹器件面会压伤器件/焊点; 锐边会割伤 PI → 起裂源 | 夹具图纸要求 | [官方-项目内] (ISS-085) |
| **B-6** | **固定夹允许滑移 ≤0.1mm** (不硬锁死) | FPC 要能吸收热胀冷缩与铰链开合位移; 硬锁死 → 应力全部转进 FPC | 装配图纸要求 | [官方-项目内] (ISS-085) |
| **B-7** | **对接面之间无相对转动** —— FPC 在中段弯折, 两端座分别固定在框/脚上 | 若对接面相对转动 → 微动磨损 (fretting) → 接触电阻漂移 | 装配顺序: 先固定框侧 → 弯折 → 再固定脚侧 | [推算] (ISS-091 §5.2) |

## 6. 电气上"不要做"的事 (4 条 —— 都是加了更糟)

| # | 不要做 | 为什么 | 证据 |
|---|---|---|---|
| **X-1** | **不要在充电路径 (BAT_CHG) 上加 π 滤波 / 共模扼流圈** | 会破坏 BQ25896 的充电环路稳定性 (网表已明确"充电路径上不装 π 滤波") | [官方-项目内] (`HW/netlist_v1.csv` P10 页注记) |

## 7. ★ 我自己发现的要求 (4 条, 任务要求 ≥3 条)

### ★ A-1: **分段铜厚的过渡段必须落在固定段内, 且要有 ≥1.0mm 斜坡**
- "固定段 2oz / 弯折段 1oz" 这个要求本身就引出一个**没人提过的工艺问题**: 两段铜厚不同 ⇒ 成品厚度不同 (1oz 段 0.20mm / 2oz 段 0.24-0.25mm) ⇒ 存在一个**厚度台阶**。
- 台阶是**硬应力集中点**; 若台阶落在弯折弧上, 寿命直接归零。
- ⇒ **要求**: 过渡段位置**距弯折弧起点 ≥3.0mm** (落在固定段内), 过渡用 **≥1.0mm 斜坡** (阶梯蚀刻 / 多次压合), 图上标注位置与长度。
- ⇒ 附带: **固定段成品厚 0.24-0.25mm** ⇒ 铰链区**径向**余量 1.00 → **0.80mm** (高度方向 0 影响) —— 已在铰链区预算里, 这里只提醒加工方: **固定段会比弯折段厚 0.04-0.05mm, 固定夹的夹持面要按厚段设计**。

### ★ A-2: **PCB 端载流焊盘必须做加长型 (否则 0.40mm 载流铜箔接不上 0.30mm 焊盘)**
- 0.5mm pitch 下, PCB 焊盘带宽上限 ~0.30mm (留 0.2mm 间隙)。
- 而 FPC 载流铜箔按 P-2 要 **0.40mm** 宽。
- ⇒ 焊盘必须是**长孔型** (长轴沿走线方向, 长 ≥0.80mm), 让 FPC 的 0.40mm 铜箔有足够的搭接长度。
- ⇒ **这条是 P-2 的必要配套**, 漏了 = 载流路径阻抗不连续 + 焊点承载不足, 而且**图上不写清楚, 板厂默认给你 0.30mm 方形焊盘**。
- ⇒ 同时是 **15mm 板宽带来的正面收益**: 板宽 15 → 焊盘区两侧各有 4.5mm 扇出区, 加长焊盘有地方放 (12mm 板时只有 3.5mm)。

### ★ A-3: **铰链段总长有下限 25.5mm, 现标称 31mm 只有 5.58mm 余量**
- 最小需求 = 固定段 8.0 + 弯折弧长 π×3.0 = 9.42 + 固定段 8.0 = **25.42mm**
- 现标称 **31mm** → 余 5.58mm
- ⇒ **要求写进图纸**: 铰链段长度标称 ≥25.5mm, **建议 31mm**; 若某个版本把铰链段压到 <25.5mm, **必须同时缩短的是应力释放直线段, 而不是固定段** —— 因为应力释放段短到 <5.0mm 就直接违反 S-1。
- ⇒ 这条把"31mm 是标称下限"这个数字**从口头约定变成图纸标注**。

### ★ A-4: **FPC 端的 FPC 厚度上限要写进图 (0.30mm), 别让加工方按 0.20mm 常规做**
- `J_CHG` 座选 Hirose FH12 类 (支持 **0.18 ±0.05mm**, 即 0.13-0.23mm) —— **但固定段 2oz 时成品厚 0.24-0.25mm, 超了 FH12 的 0.23mm 上限!**
- ⇒ ★ **这是一个真冲突**: **固定段 2oz (0.24-0.25mm) 可能超出所选 ZIF 座的可插 FPC 厚度范围。**
- ⇒ **要求**: 图上明确 **固定段成品厚 0.24-0.25mm / 弯折段 0.20mm**, 并且**选型时必须向厂商确认该座可插的最大 FPC 厚度 ≥0.25mm** (或选支持 0.3mm FPC 的座型) —— **这一条已列入 `HW/J_CHG_SELECTION.md` §2.2 待查清单**, 但**必须写进 RFQ 的硬判据**, 否则会出现"图做对了、件插不进去"。
