## ISS-181 · demo 主板自动布线轮 (hw-lead)

### 交付
- `state/gen_pcb_routing.py` —— ★**可复用网格路由器** (本轮核心资产):
  网格 0.25mm A* · 3 信号层 L1/L3/L5 · 差分对走廊捆绑 · 电源宽铜+过孔阵列 ·
  L2/L6 完整 GND 平面 + 焊盘下拉通孔 · BTB 密集焊盘"出脚直道" · 几何后处理。
  ★**必须由 `state/gen_pcb_netlist_board.py` 调用** (板是脚本生成的 ⇒ 手改 .kicad_pcb 会被冲掉)。
- `HW/PCB/ROUTING_REPORT.md` —— 规格 + 实测数字 + ★4 条投板前必修。
- `HW/PCB/.layout_done.json` —— `{unconnected, drc_violations, at}`, 阶段门靠它判 G1。

### 实测 (不是估计)
unconnected **349 → 101** · DRC violations **0** · 网表↔板逐焊盘等价 482/482 不变 ·
19161 走线段 / 484 过孔 / 6401mm 铜 · F.Cu 10182 + In2.Cu 5292 + In4.Cu 3687。

### ★踩过的坑 (下轮别再踩)
1. **栅格原点必须全局一致** —— 焊盘栅格化与路径索引必须同一个原点,
   否则焊盘铜摊到 3 个单元 ⇒ **焊盘出不来线** (症状: 所有网 0 段)。
2. **KiCad 区域填充要"存盘后重读再填"** —— 同会话加的走线/过孔还没进连通性缓存
   ⇒ 填充器以为平面没连东西 ⇒ 孤岛删除模式**把整个平面删空** ⇒ 过孔全变 via_dangling。
3. **通孔 (F.Cu↔B.Cu) 能同时接上 L2 与 L6 两个平面**; SMD 焊盘接不上内层平面 ⇒ 必须过孔下拉。
4. **没分配网络的焊盘 (SoM 400 脚有一半没网) 同样是障碍** —— 不登记 ⇒ 布线直接压过去 ⇒ 短路。
5. **离网格的"出脚直道"落铜后要再查一次已布走线** —— A* 障碍图避让不了"后来才出现的直道"。
6. 净距余量: 栅格中心采样会吃 ~半格 ⇒ 余量必须 ≥0.125 (本轮用 0.20)。
7. 过孔中心距 ≥0.58mm (孔到孔 0.25 制造规则) ⇒ **A* 选换层点时就要查**, 不能只在落铜时查
   (否则规划的换层点根本放不下过孔 ⇒ 层间过渡段悬空 ⇒ track_dangling)。

### ★投板前必修 (本轮查出来的, 不是推测)
1. **SoM BTB (0.4mm pitch / 0.2mm 焊盘) 出脚物理上只能 0.2mm 线宽**
   ⇒ `LAYOUT_RULES` 写的"SOM 输入 ≥0.5mm 铜宽"在出脚处**做不到** ⇒ 0.5mm 只能在出脚后的
   开阔区用 L3 铜皮 + 过孔阵列实现。
2. **J_USB_C 用的是通用 8 脚假封装** (网表 footprint 写的是 GCT USB4105 16p)
   + **fp 中心 x≈130 不在板边** ⇒ 机械上插不了 USB 线 ⇒ 投产前必须换真封装 + 挪到板边。
3. 差分长度差口径: TP 分支让两条线总线长天然不等 ⇒ 0.13mm 口径只对**主干段**成立。
4. MIPI 差分对长度差还没配平 (CSI_D0_CK_P/N Δ=32.4mm, DSI_D0_CK_P/N Δ=16.5mm)。

### 纪律
★**阻抗不给结论**: 差分对最小中心距 0.25mm 只是网格量化结果, 90Ω/100Ω 是否达标
必须由板厂阻抗计算器按**实际叠层**算 (STACKUP 的介质厚度还是草案) ⇒ 没有实测/仿真依据前
**不说"已达标"**。
