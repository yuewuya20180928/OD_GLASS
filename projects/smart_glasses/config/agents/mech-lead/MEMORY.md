| M3 | **675mAh 形态否决** (镜腿 11.2mm) | 兜底: 拆左右镜脚各 ~337mAh |

| M5 | **一号杠杆 = Q4 续航口径** | 按需触发 (平均 0.23W) → 电池 77-130mAh (1.8cc) → 镜腿可做到 **5.5-6.0mm**, 空间+散热同时消失。675mAh 是在为"持续满载"这个未确认假设买单 |
| M6 | **重量 49-66g**, 超 30-40g 对标 23-65% | 做完减重到 36-45g。原型预期 45-55g |
| M7 | **HW-03 存储是 PCB 面积问题不是体积问题** | eMMC16GB 11.5×13 = 150mm² = 50×12mm PCB 的 25% → PCB 宽度定不下来 → 投板前必须 close |
| M8 | **摄像头装镜框 → 俯角偏置 20-32° 不可回避** | 对角 FOV ≥100° 是"还能覆盖正前方"的必要条件。约束: 俯角 ≤25°, 水平偏置 ≤10°, 镜框上沿局部加厚 10-12mm |

| M13 | **Type-C 面板开孔 9.5×3.6mm** | 母座本体 8.94×3.26 (USB Type-C 规范); 镜腿末端壁厚留 ≥1.5mm |

### 我发现的 tracker 数据问题 (已走 TBD, 我不改 tracker)
1. §3.4 续航倒推 **漏算 DC-DC 效率 (~90%) 和 DoD (~90%)** → 电池容量要 **+23%**
2. §3.4 "光机 200-500mW" → 应为 **98mW** [官网]
3. §2.2 "PCB+电池+光机 集成到镜脚" → 光机+分光件应在**镜框**
4. R11 "🟢 低-中" → 建议 **🔴 高**
5. 电池档位应由 **Q4 续航口径**反推, 不该由功耗上界反推

### 教训
- **别用 "应该能放下" 这种话**。电池 675mAh → 镜腿 11.2mm 就是"放不下", 要直接说形态否决。
- **三维尺寸推算要给输入和公式**, 老板反感没依据的推断。我的每个 `[推算]` 都标了公式和输入值。
- **热学结论要用标准锚** (ISO 13732-1 的 43°C), 不能拍脑袋说"会烫"。
- **等 tracker 被别人并发更新** — 10-25 晚 PM 和 hw-lead 同时在改 tracker, 我写完文档后必须重新 grep 一遍关键段 (电池/光机/R11), 否则交接单会漏掉别人刚提的问题。

### 我发出去的结构约束 (已进交接单, 等 hw-lead 落进原理图)
- PCB: 长条 50×12mm (或 15mm, 取决于存储选型; **板宽跟着 FCCSP pitch 走**) | 0.8mm(4层)/1.0mm(6层) | 2×M1.2 螺钉 + 1×⌀2.0 H7 定位销 | 器件距板边 ≥0.8mm | **SoC 下方必须有铝/铜骨架** | **SoC 放远离皮肤侧** | **必须加 NTC** | 不做无线 → 禁布铜区
- 镜框/镜腿: 波导 U 形卡槽 (平行度 ±0.3°, 泡棉软压) | 分光件独立加工件安装位 (≤5µm, 螺钉+UV胶) | 光机与分光件共一体托架 (3 点定位, ≤0.25°) | **上下分壳** | 镜腿厚 ≥7.3mm / 净高 ≥38mm / 内长 ≥110mm | 充电板铝罩隔断 | **摄像头不得凹进上沿前表面 >1.5mm**
- 散热路径: SoC 焊盘 → 0.3mm 导热垫 → 铝/铜骨架 → 石墨 → 镜腿上表面+铰链侧 → 对流。**路径里不得有塑料隔断**
- Type-C 面板开孔 **9.5×3.6mm**, 末端壁厚 ≥1.5mm
- 3D 打印边界: 外壳仍一体打印, 但 **~6 件小型机加工件 (铝/铜) 承担所有关键定位 + 散热** (打印件 Ra 10-30µm vs 分光面需 ≤5µm; FDM 定位 ±0.2-0.3mm; 角度 ±0.2-0.5°)

### 已回复 hw-lead 交接单里的 4 个问题
1. 镜脚空间预算 + PCB/电池/光机分配 → 给了需求下限 + 分配方案, 并指出**光机应在镜框不在镜脚**
2. PCB 外形 + 最大厚度 → 50×12mm, 0.8/1.0mm, **板宽跟着 pitch 走**
3. 摄像头窗口位置朝向 + 边框吃多少 FOV → 俯角≤25°, 装上沿正中, **凹进≤1.5mm** (算了遮挡角)
4. 散热接触路径 + Type-C 开孔 → 给了完整热路径和 9.5×3.6mm
