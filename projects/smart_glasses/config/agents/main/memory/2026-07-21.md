### 关键坑（已加 MEMORY.md）
- **【铁律】yolov5 binary 是 PIE (ET_DYN), glibc 2.34+ 拒绝 dlopen**
  - 报错: `cannot dynamically load position-independent executable`
  - 修法: 用 SDK 源码编 shared lib (`g++ -shared -fPIC`), 不要 dlopen 那个 binary
  - build 命令 8 行, 板端 30 秒
- **【优化】awnn_init / awnn_create 复用到 __init__ 阶段**
  - 一开始每次 predict 都 init+create, 浪费 ~10ms
  - 改成 lazy + amortized: 第一次 predict 时 init, 后续复用, close() 时释放
  - `with A733ODModelDirect() as m:` 自动 close
