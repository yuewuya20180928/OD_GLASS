### 根因
- 板端 .nb 是 416x416 input 重导的 (output 52x52, 26x26, 13x13)，但 .nb 推上去了 .so 没重编
- yolov5_post_process.cpp:237-238 hardcoded `letterbox_rows = 640; letterbox_cols = 640`

- generate_proposals 按 640/8=80 stride 遍历，但 NBG output 实际是 52 宽
- → 越界读 garbage FP32 数据 → sigmoid 全 1.00 → 25200 anchor 全进 NMS → NMS 巨慢
