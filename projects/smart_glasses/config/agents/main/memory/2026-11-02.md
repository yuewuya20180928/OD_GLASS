## 3. ★★★ 今天抓到的三个真技术发现 (都写进网表/文档了)

### 3.1 P0: 9 路电源 IC 的 EN 脚全没画 ⇒ 投板后整板不上电
- **TPS7A20 / TPS62130A 都有 EN 脚**, TPS7A20 内部 **500kΩ 下拉** ⇒ datasheet 原文 "keeps the LDO disabled even when the EN pin is left floating" ⇒ **EN 悬空 = 关断**; 门限 VEN(LOW)≤0.3V / VEN(HIGH)≥0.9V
- ⇒ 原网表 **7 LDO + 2 DC-DC 全无 EN 网络** ⇒ 投板后 9 路全灭 = 2~4 周返工; ★**好在 BOM footprint/opn 全"待定" ⇒ 改成本≈0**
- **已修**: 除 SENSOR_AVDD 外 EN 直连 RAIL_SYS; **SENSOR_AVDD 的 EN 走 RC 延时** (R 100k + C 1µF, t≈83ms) ⇒ **AVDD 最后上电 ⇒ 满足 IMX415 DVDD→OVDD→AVDD** ⇒ **ISS-152 闭环 (不换 LDO 家族)**

### 3.2 `rk3572` 不是任何已发布版 rknn-toolkit2 的合法 target
- 实测 **2.3.2 与最新 2.5.0 都抛 `ValueError: Invalid target_platform 'rk3572'!`**; `rk3576` rc=0; 目标列表 (含编译后 .so) 里 rk3572 命中 0
- ⇒ **不存在"升级 toolkit 就有 rk3572"** ⇒ **只能用 `target_platform='rk3576'` 转** (同代 RKNPU v2, 算力 4 vs 6 TOPS ⇒ [推算], 板端须实测) ⇒ **ISS-155**
- ★**正确核法 = 直接 `config()` 试** (属性 `RKNN.RKNN_TARGET_PLATFORM` 在 2.3.2 不存在)

### 3.3 面板 init code 不用问厂家
- ★Rockchip 内核 79 个 panel 驱动里**确实有** ST7701 / ST7703 / ST7789V / ILI9881C / NV3052C / OTM8009A / HX8394 / RPi-TC358762; ★**EK79007 / EK73217 / NV3049 内核里没有**
- ★`rk3576-evb.dtsi` 里有 **1080×1920 / 4-lane / RGB888 的完整 panel-init-sequence** (与视涯屏分辨率最贴)
- ⇒ ★**面板这条路起点是"抄内核现成 dts", 不是"问厂家"**

### 3.4 其它已查实 (公开渠道, 零对外通信)
- **AR0234CS**: 功耗 Typ 372.6 / Max 646.4 mW @120fps (Table 16 p.18) · ★**VIN abs-max = VDD_IO+0.3 = 3.1V ⇒ 3.3V I2C 上拉违规 (整机阶段改 2.8V)** · ★**CRA 有 0°/28° 两个 PN 变体 (Table 1 p.1 + Figure 19 p.23)** · 供电 **5 组含 VDDIO_PHY 1.8V only (Note 10) ⇒ 我们网表缺这条轨 + CONN_CAM 18p 已满 ⇒ ISS-154**
- ★**onsemi 官网 PDF 被 Akamai 403 ⇒ 走 LCSC + Sunnywale 两个授权分销镜像拿到原厂 datasheet** (Rev 3 / Rev 0, 同一 Publication Order Number) ⇒ **"不发邮件"照样拿得到**
- **IMX415**: DVDD1 1.00~1.20V typ 1.10 (250mA max) / OVDD 1.70~1.90V typ 1.80 (3mA) / AVDD1 2.80~3.00V typ 2.90 (156mA) ⇒ ★**网表 SENSOR_VDD_IO 2.8V→1.8V (TPS7A20-18)**, CORE 1.2V 保持 (250mA), AVDD 2.8V 保持 (156mA); **I2C_A 上拉 4.7k→2.2k** (IOL≤3mA ⇒ R≥967Ω), 上拉电压仍 3.3V (VI≤3.3V 合法) ⇒ ★**TBD-05 对 IMX415 不成立**
- ★**IMX415 出 1080p60 = sensor 侧 2/2 行 binning (不是 crop ⇒ 不违反 10-25 禁 ROI)**, BSP `imx415.c` 已带该模式, 60fps 只需改 VMAX (0x0C5D→0x062E) ⇒ **零移植**; 现成 IQ 锁死 3840×2160 ⇒ 1080p 档需补 mesh + AE 表 (1~2 人日)
