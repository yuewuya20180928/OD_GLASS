## 根本 bug（**重要！**）

### Bug 1: losses.py fg_mask 错误（**最致命**）
**修改前**（错误）：
```python
fg_mask = tf.cast(cls_targets == 1, tf.float32)
```
**修改后**（正确）：
```python
fg_mask = tf.cast(cls_targets > 0, tf.float32)
ignore_mask = tf.cast(cls_targets == -1, tf.float32)
valid_mask = 1.0 - ignore_mask
```

**影响**：cls_targets 实际是 0-80（-1=ignore, 0=bg, 1-80=各类前景），原代码只把 class 1 (person) 当前景，其他 79 个类全当背景。模型只学到"person vs 背景"，mAP=0。

### Bug 2: ignore 样本未排除
- `tf.maximum(cls_targets, 0)` 把 -1 当 0（背景）
- 修法：加 valid_mask，在 focal loss 计算时屏蔽 ignore 样本

### Bug 3: evaluate.py GT 框坐标空间错配
- GT 是原图归一化坐标，预测是 320×320 像素坐标
- 修法：在 evaluate.py 给 GT 套上 letterbox 变换到 input_size 空间
- 涉及 `labels["original_shape"]` + letterbox scale + padding

### Bug 4: evaluate.py class ID 偏移
- TFRecord 存 1-80（COCO id），模型输出 0-79（去 background 后）
- 修法：在 evaluate.py 给 GT 减 1，对齐到 0-79 空间

### Bug 5: evaluate.py `.numpy()` 调用错误
- `det.predict()` 返回 numpy 数组，不需要再 `.numpy()`
- 修法：用 `np.asarray()` 替代
