## 01:30 — 老板反馈"框的位置不准确"

### 老板的诉求
- 框覆盖真人但偏下 + 偏大
- 头部在画面中上部, 但 NPU box 中心在画面下部

### 调试 v38d2 (v38 + BOXES debug)
停 service, 跑 25s, 看 NPU top-1 真实输出:
```
sc=0.47 [230,358,447,480] center(338,419)
sc=0.68 [295,423,428,480] center(361,451)
sc=0.58 [248,357,440,480] center(344,419)

sc=0.59 [82,292,570,480] center(326,386)
sc=0.62 [0,317,368,480] center(184,399)
```

### 根因分析 (3 层)
1. **Box y2 总是 480 (画面最底)**: yolov5s COCO person 训练含全身 (头到脚), 老板画面只拍腰部以上, NPU 按全身预测 → box 底部永远顶到画面底
2. **Box 中心 y 在 386-463**: 偏离头部实际位置 (~240) ~150px
3. **conf 最高 0.68 平均 0.58**: 坐姿 + 戴眼镜 + 低头, yolov5s 训练数据少, 模型没信心
4. **temporal voting 不修坐标**: 只决定画不画, 不修正位置

### 修复方案
- A: box 位置约束 (5 min)
- B: box aspect filter (5 min)
- **C: anchor 重新训练 (老板选这个)** - 半天+
- D: 接受现状

- `mux=mp4` 要求 H.264 + AAC audio

- std mux 拒绝 → 文件损坏
- 修法: `mux=matroska` (mkv 不需 audio) 或 transcode
