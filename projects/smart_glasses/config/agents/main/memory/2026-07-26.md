## 关键发现 (新增铁律)

### 铁律: Allwinner pegasus 转换工具不在 PC 端
- PC 端有 `rknn-toolkit2` (Rockchip RKNN 格式) 但板端 SDK 用 Allwinner VIPLite NBG (VPMN magic)
- awnpu_model_zoo scripts_model_convert 需要 `ACUITY_PATH` 环境变量指向 pegasus binary
- pegasus binary 在 Allwinner 客户服务平台下载 (Docker 镜像形式)
- PC 端没有,意味着 .nb 重转这条路需要先装 pegasus 工具链 (30-60min)

### 铁律: Allwinner .nb "uint8" 命名只描述 input quantization
- `yolov5s_rt_uint8_a733.nb` 的 input 是 int8 (data_format=2), output 默认 fp32 (data_format=0, none-quant)
- 改 .nb 重转必须显式设置 output 量化 (peg export ovx_nbg 加 `--output-quant` 之类)
- 当前 SDK awnn_lib.c 不支持 runtime 改 output format

### 铁律: vip_map_buffer alias 后 post_process 涨 9ms (NPU device memory cache miss)
- alias NPU buffer 到 user_output_buffers 跳过 memcpy 省 9.9ms
- 但 post_process_bgr 读 NPU device memory 触发严重 cache miss, post 涨 9.4ms
- net zero, FPS 不变
- 软件 prefetch / NEON 帮不了, NPU device memory cache behavior 是 hardware 决定
