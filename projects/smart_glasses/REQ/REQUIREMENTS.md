## 3. 三条验收标准 (v0.1 里"待填"的部分, 现在有答案)

### 3.1 端到端延迟怎么测
| 口径 | 测法 | 需要的设备 | 现状 |
|---|---|---|---|
| **口径 A (曝光→出光)** ★承诺口径 | 曝光起点只有图像传感器知道 → 需外部设备; 或用已知曝光时间推算 (**标 [推算]**) | 高速摄影 ≥240fps / 示波器 ≥100MHz + 光电探头 | 老板 19:23 定: **改主观眩晕验收 (M-DIZZY) 补充**, 数字部分待设备 |
| 口径 C (读出完成→出光) | **纯软件打点** | 无 | ✅ 现在就能测 |
| **M-NPU (纯硬件耗时)** | 软件打点, **计时点夹紧** (前后处理在时间轴上天然不重叠 = 结构性排除; 不许用减法) | 无 | ✅ 现在就能测, 且**决定 60fps 成败** |
| 主观验收 (M-DIZZY) | 佩戴连续快速转头/走动/视线切换 5 分钟 | 无 | 老板 19:23 定, 零设备 |

> ★ 老板的"目测感官"决定**没有挡住关键路径**: 决定 60fps 的 M-NPU 不需要任何外部设备。

### 3.2 精度怎么验收
- ONNX vs 板端: **top-1 框坐标误差 ≤3px / 类别一致 / conf 误差 ≤0.05**
- 逐类阈值回归 (80 类各跑一遍)
- ★**鱼眼专项** (ISS-053): 不裁剪 + 鱼眼 → 检测框在图像上是弯的 → 必须做"检测框反投影到真实方位角", 框龄用方位角差而非像素行差; 同时评估不做 LDC 对边缘目标检测精度的影响

### 3.3 续航怎么测
| 口径 | 测法 | 判据 |
|---|---|---|
| **按需触发 (Q4 已拍板)** ★承诺口径 | 触发 1s / 停 10s 的循环, 计时到没电 | **≥60min** |
| 持续满载 | OD 常开, 计时到没电 | 记录值 (必然发烫, **不是承诺口径**) |
| 待机功耗 | 触发后进入 idle, 测电流 | **<0.05W** (硬约束) |
