# 顶层需求与拆解 (草稿 — 项目总工维护, 各总工补子模块)

> 状态: 草稿, 待 4 个 agent 首轮对齐后定版

## 顶层需求 (来自老板锁死变量, 见 PROJECT_TRACKER §0)
1. 形态: 一体式智能眼镜整机
2. 类别: 80 类 COCO (YOLOv5 通用, 不做场景定制)
3. 显示: 双目同源 (1 光机 + 1 DSI + 分光 → 2 波导)
4. 主控: 酷芯微 ARS45 (AR9481 备选)
5. DDR: 512MB 内置, 不外挂
6. 输入: 单路 MIPI-CSI, ≥1920×1080@60fps
7. OD: 640×480@60 (优先) 或 1280×960@15
8. EIS: 硬件预留, 软件可关, 基线按关 EIS
9. 端到端: **< 60ms (硬指标)**
10. 续航: **≥ 1 小时**
11. 样机: **先出 1 台**
12. 无线: 第一款不上
13. 电源: 电池供电 + Type-C + 充电保护
14. BOM: 原型 ¥500-1000 / 量产 ¥300-800
15. 重量: 消费 AR 参照 30-40g

### 软件 (sw-lead)
> ✅ 2026-10-25 首轮已填。**完整内容见 `../SW/SW_REQUIREMENTS.md`** (8 模块 + 验收标准 + 延迟预算表 + 内存规划 + A7S 复用清单)。摘要:

**8 个模块**: M1 BSP/驱动 · M2 ISP 调参 · M3 NPU runtime · M4 模型转换 · M5 OD 应用 · M6 显示合成 · M7 电源管理 · M8 调试升级通道

**端到端延迟 (< 60ms) 分段预算** (目标值 / 证据等级):
| 段 | 目标 ms | 证据等级 |
|---|---|---|
| sensor 曝光+读出 | 16.7 | 推算 (sensor 未选型) |
| ISP + 缩放 | 8.0 | 官方口径 (合计 <10ms) |
| OD 预处理 | 1.0 | 推算 (A7S 实测类比) |
| **NPU 推理 (纯 NPU)** | **16.0** | **公开横评 + 推算 (最大未知数)** |
| NPU 输出后处理 (反量化) | 2.0 (目标) / 9.3 (若强制 FP32) | 推算 (A733 实测外推) |
| decode + NMS | 3.0 | 实测 (A733, 口径不同) |
| 画框叠加 | 1.0 | 推算 |
| 显示 TX | 3.0 | 媒体二手 (走桥接芯片则作废) |
| 光机 | ≤ 5.0 | **没数据** |
| 框龄 (age) | 0 / 16.7 / 33.3 / 50.0 | 推算 (台阶项) |

⚠️ **三种口径 × 三种流水线模式的完整矩阵见 `SW/SW_REQUIREMENTS.md` §10.4**。严口径 (曝光→出光) 下: 显示等 OD 方案 55.7ms 达标但显示降到 ~25.6fps; 异步 60fps 方案 67.0ms 超预算。

**内存 (512MB)**: 静态 + 峰值 ~178MB (乐观) / ~191MB (悲观), 余量 ~320MB → **内存不是瓶颈**, 但需确认 NPU SDK workspace 与 CMA 预留。

**软件侧验收标准 (摘要)**:
- 端到端延迟: 分段打点, 每段 min/avg/max + 采样帧数; **纯 NPU 耗时与 SDK 总耗时分开报**; 框龄 (age) 单独打点
- 端到端物理测量: 高速摄影法或示波器法 (光机出光无法用软件打点)
- 精度: ONNX vs 板端 top-1 框坐标误差 ≤3px / 类别一致 / conf 误差 ≤0.05; 逐类阈值回归
- 续航: 待 Q4 答"OD 持续跑还是按需触发"后定义测试条件
- 稳定性: 连续跑 ≥2h 无 OOM / fd 泄漏
