## 三、当前选型结论 (10-29 19:20 口径)

- **基线 = 瑞芯微 RK3588** (9 项总分 79, 全候选第一); **RK3576 (74) = 可机械触发的翻转后手**
- **翻案条件 (机械判定)**: T1 SoC 域功耗实测 >400mW · T2 纯 NPU S5 >20.33ms · T3 板端 INT8 F1 <0.30 · T4 30mm 板宽摆不下 ⇒ 任一命中 ⇒ 立即切 RK3576 (只改 157 行网表 + 5 页图, 不动结构)
- **设计上为 RK3588 预留、为 RK3576 留后手**: 板框 60×30 + 留小封装落位区 · 电源树 6A 级 · 散热按大封装铜箔 · DP+DSI 双出口位 · **SoC 不挪镜框正中** (挪进去鼻梁侧 50.1°C 超红线) · DDR 按 64-bit 布层叠
- **桥接芯片原则上不做** (12 款过线候选里 10 款原生带 MIPI-DSI TX) ⇒ 前置 = JBD 给出走鹃Ⅱ 的 DSI lane/时序/分辨率
- **ARS45 / AR9481 正式不再考虑** (10-29 19:20) ⇒ 代理线与原厂草稿全部作废不发

## 五、★铁律清单 (最该带走的部分)

**工作方式**
1. **收到老板的任务, 第一件事是落盘, 第二件事才是干活** (总表 + issue + 快照, 三条都做完才算接住)
2. **token 用完之前先记录进展和待办**; 恢复后从 GitHub 拉回继续 ⇒ `state/token_watch.py` + cron「token 守护」(每 15 分钟)
3. **写死的数字必然过期** —— 所有数字实时读
4. **失败必须显式暴露** —— `>/dev/null 2>&1` 会把错误吞掉
5. **幂等检查串必须和写入串是同一个常量**
6. **收活先查 mtime** —— `status: failed` 不等于"它没干"
7. **重派别照抄原任务书** —— 要写"上次为什么 0 产出" + 补上盲区

**派活**
8. ★**先落 `fixing` 再 spawn** (反了会留窗口让下一轮重复派同一 agent ⇒ 10-29 撞了 3 例)
9. ★**一个 agent 同时只开一个写会话**; spawn 报 "file lock stale" ≠ 没派出去 (用 `subagents list` 核对)
10. ★**任务书不能一次塞 6 件事**; 要拆成"出规格"与"出文件"两步
11. ★**派活别把话说满** —— 写"至少覆盖 X", 留出子总工发现你没要求的东西的余地
12. ★**别让子总工整篇读文档** —— 把结论列给它, 不确定标"待确认"问我

**验收**
13. ★**自己产的文档关单时 `verify_by` 不能填自己** (我连犯 3 次, 机械门禁抓到的)
14. ★**交卷 ≠ 状态推进** —— owner 交卷时必须自己把 status 推到 `fixed` 并落 `fix_ref`
15. ★**给老板的数必须引子总工的核算原文**, 不自己心算
16. ★**子 agent 自推 `fixed` 会覆盖项目总工的 `verified`** ⇒ 验收后要复查

**工程**
17. ★**查芯片接口要查 TX 侧和 RX 侧两边**, 并区分"芯片级"与"方案级"证据
18. ★**别把工程约束当一票否决** —— 先问"这个东西不解决是**项目起不来**, 还是只是**难做**?" 难的降级成风险项
19. ★**结构约束可以拿量产先例来解** —— 先问"市面上有没有同形态的量产件?"
20. ★**口径混用要抓**: 对角半角 vs 垂直半视场 / 厚度 vs 直径 / 叠放 vs 串行 / 跨口径相减
21. ★**降额要分层**: L1 绝对最大红线 / L2 推荐工作区 / L3 系统占用率 + J1 额定直比 / J2 降额 / J3 规范值
22. ★**皮肤 43°C 红线** (ISO 13732-1) ⇒ 镜腿可持续功耗只有 0.15-0.2W ⇒ 满载 1.22W 与眼镜形态不相容 ⇒ 靠按需触发 + 把热源挪离贴皮肤面
