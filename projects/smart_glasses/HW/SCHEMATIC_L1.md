## 2. 光机连接器引脚表 (CONN_LIGHT) —— **定死, 不许改**

> **为什么定死**: 光机在镜框、SoC 在镜脚, DSI 必然跨铰链。连接器一旦定错 (lane 数 / 电源 / 脚序), 整条显示链重画 + 铰链排线重做。
> **做法**: 按**最大可能**定义 (4 lane + 双电源 + 独立 DDC), 用 0Ω/DNP 把"用不上的"摘掉。**这样原厂答 2-lane 或 4-lane 都不用改连接器。**

### 2.1 连接器规格

| 项 | 值 | 证据 |
|---|---|---|
| 类型 | 板对板 / FPC 混合座, **0.5mm pitch, 40 pin** (跨铰链, 需 ≥3mm 弯折半径) | `[推算]` (依 `MECH_BUDGET.md` §1.3 M9 "BTB ×3 + FPC 折弯槽 ≥3mm") |
| 位置 | 镜框 ↔ 镜脚 铰链处 | `[官方]` MECH §1.3 M9 (华为 AI 眼镜同款 BTB 做法 `[拆解]`) |
| 屏蔽 | 必须带接地壳 / 金属屏蔽, 接地过孔 ≥2 个直连机壳地 | `[推算]` EMC R-01/R-02 |
| ESD | 连接器出口侧 ≤3mm 内放 ESD 阵列 | `[推算]` EMC R-03 |
| 差分对数 | **4 lane 全定义** (2 lane 用, 2 lane DNP 预留) | `[推算]` 800×600@60 RGB888 = 691Mbps 载荷 → 2 lane 足够 (§3.3) |
| 状态 | **引脚表 v1.0 = 冻结** | — |

## 3. 显示链双出口预留 (方案 A / 方案 B 互斥, 不锁死任何一条路)

### 3.1 两条路

| | **方案 A** (主) | **方案 B** (fallback) |
|---|---|---|
| 路径 | ARS45 **原生 MIPI-DSI TX** → CONN_LIGHT | ARS45 **DP TX** → **桥接芯片** → DSI → CONN_LIGHT |
| 触发条件 | 原厂答"有 DSI TX, ≥800×600@60" | 原厂答"只有 DP TX, 无 DSI TX" |
| 选路开关 | `R_SEL_DSI_*` (0Ω) **装** | `R_SEL_DSI_*` **全部 DNP**, 改装 `BR_DSI_*` (0Ω) |
| 桥接芯片 | **不装** (位保留) | **装** (型号见 `state/outbox/bridge_chip_rfq.md`) |
| 电池档位影响 | 无桥接 → 340-575mAh | 有桥接 → 575-675mAh (675mAh 形态已否决) |
| 采购周期 | 0 | **4-8 周** → 并行询价, 不等原厂 |

### 3.3 为什么 2 lane 就够 (算式, 可复现)

```
800×600 @60fps RGB888 (24bpp) = 800×600×24×60 = 691.2 Mbps 载荷
含 ~10% 协议开销 ×1.1         = 760.3 Mbps
÷ 2 lane                      = 380.2 Mbps/lane
```
→ DSI-2 HS 单 lane 上限 2.5Gbps, **余量 6.6×** → **2 lane 足够, 4 lane 纯预留** `[推算]`。

### 3.4 DP 侧的隐藏坑 (现在就要占位, 否则将来加桥接芯片要改板)

| 项 | 要求 | 依据 |
|---|---|---|
| DP 主链路 | 4 lane 差分 (A0-A3) 全部从 ARS45 引出并预留 | `[推算]` 卡点 A 第 4 点 |
| **DP AUX** | 2 pin (AUX_P/AUX_N) 差分 → **DNP 端接 100Ω 对地 + 磁珠** | EMC R-02 (单端/半差分辐射效率高于差分) |
| **DP HPD** | 1 pin → **DNP 端接 100Ω 对地** | 同上 |
| **Redriver / Retimer 位** | 预留 4 对串阻 (0402) + 4 个对地电容位 + 接地环 | EMC R-02 ③ (多数 DP→DSI 芯片需重驱动才过眼图) |
| 桥接芯片去耦位 | 1µF + 100nF×2 + 10nF 四档, 就近接地环 | EMC R-02 ③ |
| 桥接芯片屏蔽罩安装孔 | 预留螺钉柱 + 接地弹片孔位 (成本≈0, 留选项) | EMC R-02 ④ |

### 4.3 DC-DC 额定电流怎么定 (NPU 突发, 算式)

```
NPU 640×640 INT8 单帧 ≈ 15ms, @60fps → 占空比 = 15/16.67 = 90%
   → 不是"突发稀疏", 是"近乎连续 + 每帧一个电流台阶"
SoC 域功耗推算 0.9W (tracker §3.4 区间 0.75-1.22W 取中)
   @V_core=0.8V → I_avg = 0.9/0.8 = 1.125A
   峰值裕量 ×1.5            = 1.688A
   → DC-DC 额定 ≥ 2.0A  → 选 3A 档 (TPS62130A)
```

> ⚠️ **"用输出电容吸收电压跌落" 这句话是错的 (必须纠正)**:
> 若指望电容扛住帧内 1.667ms 的空档 (15ms 推理 + 1.667ms 空档, 60fps 下算式):
> `C = ΔI × Δt / ΔV = 0.3A × 1.667ms / 50mV = **10.0 mF**` —— 陶瓷/钽电容都做不到这个量级。
> **正确做法**: ① DC-DC 选型时把 **"负载阶跃动态电压偏移"** 当硬指标写进去 (不是只看静态效率); ② 输出电容 = SoC 球位正下方 2×22µF 0402/0603 (高频去耦) + 1×47µF 0805 X5R + 1×100µF 聚合物/钽 (bulk), **作用是吸收环路响应(µs 级)量级的台阶, 不是帧周期量级**; ③ 环路带宽 fc≥100kHz 时 22µF 的阻抗压降已 ≤22mV `[推算]`。
> **给 PCB 厂的约束**: 核心轨 DC-DC **额定 ≥2A**, 且 **负载跃变响应指标必须在选型时被写入** —— 否则表现为"静态功耗达标, 一跑 OD 就掉电重启"。

### 4.4 电源域的 4 条硬规则 (画图时照抄)

1. **每个外部模块的电源都从 SYS 域来, 不许从 SoC 域的某条轨直接串接** → 防止一个模块的浪涌把 SoC 拉崩。
2. **所有对外连接器 (sensor / 光机 / Type-C) 的 GND 单点汇流到机壳地**, 差分对下方地平面完整, 禁止割裂。
3. **未使用引脚接地或标 NC**。
4. **每条轨都要有 1 个 TP (测试点) + 1 个 对地 10nF+100nF 就近去耦 + 1 个 磁珠/π 滤波入口**。
