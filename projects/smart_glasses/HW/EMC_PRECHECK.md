## 1. 结论摘要 (B1 式, 每条带数字)

1. **列出 12 个 EMC 风险点** (R-01 ~ R-12), 覆盖任务书点名的 6 个方向: MIPI-CSI 高速差分对 (R-01) / Type-C 端口 (R-03) / 镜腿金属件天线效应 (R-04) / NPU 时钟谐波与电源纹波 (R-05) / 光机电源域 (R-06) / ESD 防护 (R-07), 另加 6 个项目特有项 (显示链双出口 DNP 天线 R-02 / 分板互连共模 R-08 / sensor 供电耦合 R-09 / 悬空引脚与地平面割裂 R-10 / 上下分壳屏蔽闭合 R-11 / 手机近场 RF 免疫 R-12)。
2. **判定方式三分**: 只能实测关闭 **4 个** (R-04 金属件天线 / R-07 ESD / R-11 屏蔽闭合 / R-12 近场 RF 免疫) / 混合类 (设计可预评估 + 必须实测复判) **8 个** / 设计阶段可判定 **1 个** (R-10)。→ 全文 12 个风险点**全部含必须实测项**。
3. **本项目 EMC 的第一风险不是"超标", 是"ESD 打穿充电板导致 1S 锂电在佩戴者脸上起火"** —— 眼镜是**贴皮肤佩戴物 + 可触摸物**, 镜腿内有 1S Li-po (丰江 432243, ≥420 mAh `[官方]` 转引 `INTERFACES.md` 硬件↔结构表), 放电路径与人体接触路径重叠。**这条把 ESD 从" EMC 指标"升级成"安全问题"**, 优先级高于所有发射类项。
4. **两个跨模块 EMC 交叉点必须现在定, 晚了就是改板**:
   - **跨铰链高速线**: 摄像头在镜框、SoC/PCB 在镜脚 (镜脚长度需求 106~110 mm `[推算]` 转引 `MECH_BUDGET.md` §1.6.3/§1.6.5) → **MIPI-CSI (R-01) 与 MIPI-DSI (R-02) 两组高速差分都必须跨铰链**; 铰链 = 金属件 + 弯折 + 线束换向 = 三重耦合热点。
   - **板宽压缩会挤掉 EMI 布局余量**: `INTERFACES.md` 已登记"eMMC 16GB 吃 25% PCB 面积 → 板宽 12→15 mm"; 反过来板宽收到 12 mm 时, **机壳地环 / 滤波位 / ESD 位 / 大电流铜箔必须保留** → 需写进 PCB 设计规则 (§8 规则 16)。
5. **"首款不上无线"≠"没有 EMC"**: 无 intentional radiator (`PROJECT_TRACKER` §0 #11 锁死) 只免掉发射许可, **不免掉 ① 数字谐波辐射 ② 手机近场 RF 免疫 (R-12) ③ 人体 ESD (R-07)**。R-12 是佩戴场景下最可能被用户投诉的故障 (手机来电 → 眼镜花屏/重启), 与 EMC 直接相关。
6. **必须在画板前做, 不能板子回来后补**: 依据 = `FRAMEWORK_SCOPE.md` H3-06 (依赖 H3-03 PCB layout) + `PROJECT_TRACKER` §10.14 "EMC 预评估只做预评估不做实测" 的裁剪结论。**下面 16 条硬约束 (§8) 必须进 PCB 设计规则与审图 checklist, 否则 layout 阶段没有裁决依据。**

## 6. 风险点详卡

### R-01 MIPI-CSI 高速差分对: 辐射与跨铰链耦合

| 项 | 内容 |
|---|---|
| 等级 | 🔴 高 |
| 判定方式 | **混合类**: 阻抗/长度/回流路径可在 layout 前算 + coupon 预测试; 辐射发射与眼图必须整机实测 |
| 证据 | 机理 = `[推算]`; lane 数/速率/voltage 域 = `[0数据]` (datasheet 未到); 100 Ω ±10% = 项目接口取值 (非实测) |

**风险机理**
MIPI-CSI-2 D-PHY 是高速差分 (1080p@60, lane 数待定 `[0数据]`)。差分线在阻抗失配 (PCB 厂阻抗偏差 + 连接器/FPC 引入的不连续) 时发生**差模→共模转换**, 共模电流流过机壳/金属骨架 → 形成电偶极 (线天线) + 磁偶极 (环路天线) 辐射。本项目的**放大因素有三条**:
1. **跨铰链长距离**: 摄像头在镜框上沿, SoC/PCB 在镜脚 → MIPI-CSI 要从镜框走到镜脚, 走线长度受镜架几何支配 (镜脚长度需求 106~110 mm, 加上镜框段, **跨铰链段大概率 ≥ 100 mm `[推算]`**)。高速差分走线越长, 共模阻抗越大 → 辐射效率越高。
2. **铰链是三重耦合热点**: 金属铰链件 + FPC 弯折 (阻抗不连续) + 线束换向 → 一次把差模扰动、共模注入、结构耦合全叠上。
3. **同束并存**: MIPI-CSI (入) 与 MIPI-DSI (出) 两条高速线都要过铰链, 若在同一束 FPC 里平行走 → 串扰 + 共模互激励。

**可能表现**
- 辐射发射在 lane rate 整数倍处出现尖峰 (近场扫描可见), 30 MHz~1 GHz 段被 100 Ω 失配强烈激励。
- 摄像头图像出现**横向条带/滚动条/闪点** (共模耦合进 sensor AVDD 或 MCLK, 见 R-09) —— 最容易被误判为"软件 bug"。
- 充电时或 OD 满载时图像劣化 (电源噪声叠加, 见 R-05)。

**整改预案**

| 维度 | 措施 | 量化判据 | 证据 |
|---|---|---|---|
| 布局 | ① 差分对全程 100 Ω 差分 (已登记接口取值); ② **lane 内等长差 ≤ 0.1 mm, lane 间差 ≤ 0.5 mm**; ③ MIPI 走外层, L2 保持**完整连续 GND 参考面**, 任何层分割/走线不得跨分割; ④ 过铰链段前后各留 3 mm 直线段再进 FPC 弯折; ⑤ 与 MIPI-DSI 在同一束内**间距 ≥ 5 mm 且不平行长距并行**, 或分束 | 等长差值 / 参考面连续 / 间距 | `[推算]` (工程通用做法) |
| 滤波 | ① **源端 (SoC 侧) 每 lane 串 100 Ω** 端接 (放 SoC 引脚近端, 不放接收端, 不破坏阻抗平衡); ② 接收端 (sensor 侧) 不加端接电阻, 改由 sensor 内部匹配 (待 datasheet 确认, 现 `[0数据]`); ③ 预留共模扼流圈位 (连接器侧, 低 DCR, 插损可接受时再装) | 100 Ω ±1% / 位置 | `[推算]` |
| 接地 | ① 连接器/座子的 GND 引脚**多颗并联 + 过孔阵列直下 L2**; ② 走线两侧铺 GND 并**每 5 mm 加地缝合过孔 (stitching via fence)**, 把共模电流就近短路; ③ MIPI 区域**禁止与电源/数字信号共用回流路径** | 缝合间距 ≤ 5 mm | `[推算]` |
| 屏蔽 | ① 跨铰链的 FPC 走**屏蔽层 (带接地导线的 FPC)** 或在铰链处加金属压条压住并接地; ② **不要让 MIPI 走线贴着铝骨架** (金属会集中电场并改变阻抗) → 间距 ≥ 3 mm; ③ 传感器模组座优先选带金属屏蔽罩的 | 间距 ≥ 3 mm | `[推算]` |
| 器件 | ① MIPI 连接器处 **ESD 阵列** (容值 ≤ 0.5 pF, 见 R-07); ② 连接器选带 GND 弹片/屏蔽壳型号 | 容值 ≤ 0.5 pF | `[推算]` |

**设计阶段可预评估**
- 用叠层 (L1 信号 / L2 GND / L3 信号 / L4 电源 / L5 信号 / L6 GND, 6 层目标) + 目标阻抗算线宽/线距 → **layout 前即可定**。
- 用走线长度预算表算跨铰链段长度 → 决定是否需要同轴 FPC / 是否必须 sensor 模组自带屏蔽。

**必须实测 (整机, 板后)**
| 测什么 | 怎么测 | 判据 |
|---|---|---|
| 辐射发射 | 近场探头扫描 (先定位)+ 暗室/EMC 箱复测 30 MHz~1 GHz | 无明显尖峰, 且低于对标限值 (方法见 §3) |

### R-02 显示链双出口: DNP 方案的天线与 DP AUX 单端

| 项 | 内容 |
|---|---|
| 等级 | 🔴 高 |
| 判定方式 | **混合类** (端头处理可预评估; 方案切换后的辐射差异必须实测) |
| 证据 | 双出口对策 = `[推算]` (我自己在 `HARDWARE_BREAKDOWN.md` §2 卡点 A 提的); DSI TX 有无 = `[0数据]` (媒体二手, `PROJECT_TRACKER` §5.8 已降级) |

**风险机理**
原理图上 SoC 侧**同时引出 DSI_TX 与 DP_TX 两组, 各带 0 Ω/DNP 选择位** (`HARDWARE_BREAKDOWN.md` §2 卡点 A 对策)。EMC 侧的隐患是: **PCB 上的铜箔、过孔、器件焊盘在"方案 B 不用"时仍然全部存在**。一段没有端接的高速差分走线 = 一根天线; 一根没有端接的 DP AUX/HPD 单端线 = 一根更糟的天线 (单端辐射效率高于差分)。第二个机理: DP 侧除 4 lane 主链路外还有 **AUX (2 pin) + HPD (1 pin)**, 且多数 DP→DSI 芯片需要重驱动/均衡 (redriver/retimer) 才能过 SI —— 这些位现在就得在 PCB 上占位 (`HARDWARE_BREAKDOWN.md` §2 卡点 A 第 4 点), **占位器件的寄生与未端处理同样要管**。

**可能表现**
- 样机 (走方案 A) 辐射合格, 量产 (走方案 B) 辐射超标 → 差异不在元件, 在 PCB 上多出来的那段铜箔。
- DP AUX/HPD 单端线拾噪 → 桥接芯片工作异常 (表现为"桥接芯片偶发不工作"), 容易被当成芯片质量问题, 实际是 PCB 端头问题。
- 桥接芯片周边滤波位未预留 → 事后加 π 型滤波要改板。

**整改预案**

| 维度 | 措施 | 量化判据 | 证据 |
|---|---|---|---|
| 布局 | ① 两套方案的差分对**都**按 100 Ω 差分 + 完整 GND 参考 + 缝合过孔布; ② DNP 走线的**末端紧邻 DNP 位**, 不允许"绕过半个板子再回来"; ③ 桥接芯片位预留: 电源 4× 去耦 (1 µF + 100 nF ×2 + 10 nF) + 周边接地环 + π 型滤波位 (0402 串阻 + 0402 对地电容); ④ redriver 位预留 (含其参考电源去耦) | 预留位尺寸 ≥ 芯片+滤波网络 | `[推算]` |
| 滤波 | ① **DNP 方案差分对两端各加 100 Ω 对地 (DNP)** —— 不能留开路; ② **DP AUX / HPD 单端必须 100 Ω 对地 + 磁珠 (DNP)**, 不允许悬空走线; ③ 桥接芯片输入端预留 π 型滤波 (串阻 + 对地容) | 100 Ω ±1% | `[推算]` |
| 接地 | DNP 器件的接地脚走**短粗过孔到 L2 参考面**, 不用"就近随便一个地" | 过孔 ≤ 2 个 | `[推算]` |
| 屏蔽 | 桥接芯片位若在主板 → 在其正上方预留**可选金属盖板安装孔位** (螺钉柱 + 接地弹片), 成本 ~0, 留选项 | 预留孔位 | `[推算]` |
| 器件 | DNP 电阻/磁珠选 0402 (易手工补装); 端接电阻精度 ±1% | 0402 | `[推算]` |

**设计阶段可预评估**: 端头处理、滤波位预留、DNP 器件位布点 —— **全部在原理图 + layout 阶段可关闭**。

**必须实测**: ① 最终选定方案的辐射发射; ② DNP 端头是否真的把"未用方案"变成低辐射 (近场扫描对比: 焊 DNP vs 不焊); ③ 若走方案 B: DP 主链路 + AUX 的眼图。
> ⚠️ **只有 1 台样机** → 无法做 A/B 两块板对比 → **只能对最终选定方案实测**。这是"先出 1 台"策略在 EMC 上要付的代价, 据实记录。

**卡点**: Q16 显示 TX 结论未回 (`[0数据]`, `PROJECT_TRACKER` §5.8); 桥接芯片未选型 → 其 EMI 指标与滤波需求无数据。

### R-03 Type-C 端口: ESD 入口 + 传导噪声入口 + 适配器线缆共模

| 项 | 内容 |
|---|---|
| 等级 | 🔴 高 |
| 判定方式 | **混合类** (器件与布局可预评估; ESD 等级/传导发射/适配器兼容性必须实测) |
| 证据 | Type-C 开孔 9.5×3.6 mm `[推算]` 转引 `INTERFACES.md`; 充电 IC 0.8 W 耗散 `[推算]`; 适配器噪声谱 = `[0数据]` |

**风险机理** —— 五条通路叠在同一个 9.5×3.6 mm 的洞上:
1. **ESD 入口**: 连接器金属壳直接暴露, 用户插拔时手指/金属插头可能同时接触外壳与引脚。
2. **传导噪声入口**: 用户自备的 Type-C 适配器与线缆 (不是我们配套的), 其共模噪声经 VBUS/GND 反灌进板。**1 m 线缆在 75/150 MHz 附近谐振** → 正好落在辐射发射测量频段内 → 线缆自己就是天线。
3. **充电 IC 是开关电源**: 0.8 W 耗散 @1 A, 开关节点电压高、dv/dt 大 → 沿排线共模辐射。
4. **USB 2.0 差分**: D+/D- 90 Ω 差分, 480 Mbps, 与 MIPI 的 100 Ω **不是同一套阻抗模板** (混用会导致其中一路失配)。
5. **金属壳与铝框**: Type-C 开口边按结构要求加铝框防刮 (`MECH_BUDGET.md` §5.1) → 又一个金属体 + 一个缝隙。

**可能表现**
- 插拔瞬间设备死机/重启/摄像头异常 (最常见)。
- 充电时整机辐射发射抬升, 换一个适配器表现就变 (用户反馈"有时会花屏")。
- 充电时摄像头/显示受干扰, 与 R-06 叠加。

**整改预案**

| 维度 | 措施 | 量化判据 | 证据 |
|---|---|---|---|
| 布局 | ① ESD 阵列放在**连接器出口侧 3 mm 内** (连接器与被保护 IC 之间, 靠连接器一侧); ② 泄放脚用**短粗过孔 (≥2 个 ⌀0.3 mm, 或大面积) 直连机壳地铜**, 不经过数字地路径; ③ CC1/CC2 下拉 Rd 就近放, 走线短 (< 5 mm); ④ D+/D- 90 Ω 差分, 参考面完整 | ESD 距连接器 ≤ 3 mm | `[推算]` |
| 滤波 | ① VBUS 入口 π 型滤波: **磁珠 (≥ 600 Ω @100 MHz) + 100 Ω + 1 µF**; ② 充电 IC 输入加 **共模扼流圈 + Y 电容 (1 nF / 2 kV)** (插拔噪声与充电器共模的主要泄放点); ③ 电池充电路径加 TVS + 100 Ω 限流 | 磁珠阻抗 ≥ 600 Ω @100 MHz | `[推算]` |
| 接地 | ① Type-C **金属壳直连机壳地 (chassis GND)**, 至少 2 个接地过孔, 间距尽量大 (降低寄生电感); ② 机壳地与数字地**单点汇流 + 多点高频电容**; ③ 充电板与主板地: 单点汇流 + 1 nF/10 nF 多档电容搭接 | 壳地过孔 ≥ 2 | `[推算]` |
| 屏蔽 | ① 连接器 shell 与充电板**铝屏蔽罩搭接** (导电泡棉/铝箔), 搭接宽度 ≥ 5 mm, 缝隙 ≪ λ/20; ② 罩体排线进出口开槽处用导电泡棉封堵; ③ 罩与主板 GND 用**接地弹片**搭接, 不靠螺钉金属接触 | 搭接 ≥ 5 mm | `[推算]` |
| 器件 | ① Type-C ESD 阵列: **D+/D- 容值 ≤ 1 pF; CC/SBU/VBUS 容值 ≤ 3 pF; VRWM ≥ 24 V** (VBUS 含 PD 高压); ② 选带 IEC 61000-4-2 系统级认证的器件 (系统级等级, 不是器件级 ±15 kV 那种) | 容值 / VRWM | `[推算]` |

**设计阶段可预评估**: 器件选型、走线顺序、壳地搭接拓扑 —— 全部可预评估。
**可预测试**: **充电板 (M3, 25×10 mm) 是独立板 → 可以单独先投板先测** (见 §8-2): 在主板还没画完时就能做 ESD 摸底与传导噪声摸底。这是本项目唯一能"板前测 EMC"的机会。

**必须实测 (整机)**
| 测什么 | 怎么测 | 判据 |
|---|---|---|
| ESD 抗扰 | 接触放电 (金属壳/铝框/骨架外露面) + 空气放电, 逐点加严 | 建议目标: 接触 ±4 kV / 空气 ±8 kV 下无功能失效 (`[推算]` 对标值) |
| 传导发射 | 充电工况 + 适配器, LISN 150 kHz~30 MHz | 无超标尖峰 |
| 适配器兼容性 | 至少 3 种常见适配器 + 1 条第三方线缆 | 各工况辐射表现一致, 无"换充电器就花屏" |

**卡点**: 适配器/线缆型号不定 (采购未定) → 传导发射的实测条件不可复现; 结构外露金属面清单未给 → ESD 施加点不完整。

### R-04 镜腿金属件天线效应

| 项 | 内容 |
|---|---|
| 等级 | 🔴 高 |
| 判定方式 | **只能实测** (谐振与辐射强度取决于最终结构件尺寸/公差/装配状态, 设计阶段只能给接地拓扑约束) |
| 证据 | 金属件清单 = `[推算]` 转引 `MECH_BUDGET.md` §1.3/§5.1/§5.2; **无任何辐射实测** = `[0数据]` |

**风险机理**
镜腿里的金属不是一个件, 是**一组**: 铝/铜散热骨架 (SoC 正下方, 纵向延伸)、石墨膜 (面内扩展)、充电板铝屏蔽罩、金属压条 (波导平行度)、Type-C 开口铝框、螺钉与螺柱。长度接近镜脚量级 (100 mm 量级 `[推算]`) 的金属结构 + SoC 内部 DDR/NPU 时钟 = 典型的**无意天线**。三条机理:
1. **单极子谐振**: 110 mm 金属体对地作为单极子, 一阶谐振约在 λ/4 ≈ 680 MHz, 全波约 1.36 GHz `[推算]` (工程估算) → SoC 时钟谐波谱在这个区间必然有能量。
2. **磁偶极回路**: 骨架 + PCB 地平面 + 屏蔽罩若形成闭合回路 → 环面积 × 回路电流 → 辐射效率远高于单极子。**这是最坏情况, 也是最容易犯的错**: 想"多点接地更稳", 结果造出一个大环。
3. **石墨不是导体**: 石墨膜各向异性导电, **不能当接地路径** → 若设计时误以为"石墨会把电荷导走", 会得到一个既不接地又会辐射的金属体。

**接地拓扑的三选一 (必须明确选一种, 不能含糊)**
| 方案 | 做法 | 后果 |
|---|---|---|
| ❌ 悬浮 | 金属件完全不接 PCB | 金属件成天线, 收集环境噪声; 触摸时电荷无处可去 → 放电直接打在内部信号上 (与 R-07 叠加) |
| ❌ 多点接地 | 骨架与屏蔽罩各接一次地 | 形成地环路 → 承载共模电流 → **辐射 + 地弹** (最坏) |
| ✅ **单点低阻抗搭接** | 全部金属件在**一个位置**通过接地弹片/导电胶垫接到 PCB 的机壳地铜 | 金属件成为屏蔽体延伸, 共模电流就近短路; 触摸金属件时电荷走机壳地, 不进内部 |

**可能表现**
- 辐射发射与金属件强相关, **改结构就变数** → 换一批打印件/换一副骨架, 发射水平漂移 → 测试不可复现。
- 佩戴者头部方向场强集中 (体佩戴, 极低功率, 但值得在 R-12 一起测)。
- 触摸金属件时设备异常 (与 R-07 同一根因)。

**整改预案**

| 维度 | 措施 | 量化判据 | 证据 |
|---|---|---|---|
| 布局 | ① PCB 上划出**连续不割裂的机壳地环 (chassis GND)**, 沿板边一圈, 宽 ≥ 3 mm; ② 骨架搭接点布置在**靠近 SoC 与电源区**的一侧, 且位于信号稀疏区; ③ 金属件与 MIPI/高速线间距 ≥ 3 mm | 机壳地环 ≥ 3 mm 宽, 不被信号切割 | `[推算]` |
| 滤波 | 机壳地与数字地之间: **单点直流连接 + 高频电容多档搭接 (1 nF + 10 nF + 100 nF 并联)**, 位置靠近单点汇流处 | 电容档位 | `[推算]` |
| 接地 | ① 骨架/屏蔽罩/压条/铝框 → **一律单点搭接到机壳地**, 禁止两点接地; ② 搭接方式: 接地弹片 (导电镀金弹片) 或导电胶垫, 目标搭接阻抗 **< 1 Ω**; ③ 搭接面保持金属裸露, 不做绝缘涂层 (涂层会同时恶化热阻与搭接) | 搭接阻抗 < 1 Ω | `[推算]` |
| 屏蔽 | ① 充电板铝屏蔽罩覆盖 Type-C + 充电 IC + 保护器件, 并与主板搭接成闭合围腔; ② 上壳内部用金属盖板 + 导电泡棉闭合 SoC 区 (见 R-11) | 围腔闭合 | `[推算]` |
| 器件 | 接地弹片选**低接触电阻 + 抗振**型号; 不依赖螺钉金属通电 | 选型 | `[推算]` |

**设计阶段可预评估**: 金属件清单与接地拓扑 (设计约束)、谐振频率估算 (仅数量级)。
**必须实测 (全部)**: ① 整机辐射发射 (近场扫描定位 + 暗室); ② **金属件搭接前/后的对比扫描** (拆掉一根弹片 vs 装上, 看辐射差) —— 这一条能直接验证接地拓扑是否有效; ③ 不同结构批次的一致性 (至少 2 副骨架)。

**卡点**: ① 外露金属面清单与搭接位需 mech-lead 确认 (走项目总工转达, 见 §9); ② 石墨膜的电导率与接地可能性未确认 (`MECH_BUDGET.md` 只说"石墨只做面内扩展"); ③ 是否全部金属件都能做到单点接地, 取决于结构装配方式 → 结构一变, EMC 结论作废。

### R-05 NPU/DDR 时钟谐波、电源纹波与负载台阶

| 项 | 内容 |
|---|---|
| 等级 | 🔴 高 |
| 判定方式 | **混合类** (拓扑与选型条款可预评估; 纹波/跃变/辐射峰必须实测) |
| 证据 | 整机 0.85~1.52 W `[推算]`; DC-DC 额定 ≥ 均值×1.5 = 项目接口取值 (非实测); **SoC 内部时钟频率/电源域 = `[0数据]`** |

**风险机理**
1. **谐波源**: 内置 512 MB DDR (数百 MHz 量级时钟) + NPU + ISP 的 PLL → 谐波谱延伸到 GHz `[推算]`; 具体基频落点 **未知** `[0数据]`。
2. **纹波源**: 核心轨在 OD 满载时是**突发负载**。sw-lead 已确认 OD = 连续推理、100% 占空比、**无空闲窗口** (已登记 `interface_claims.dc_dc_overshoot` 注) → **不存在"按占空比折算平均值"这条退路** → 每帧一个电流台阶 (60 Hz 基频的调制 + 宽带毛刺)。
3. **开关电源自身**: 若核心轨用开关型 DC-DC, 其开关频率及谐波会**直接落在 30 MHz~300 MHz 的发射敏感区**。
4. **耦合路径**: 纹波经共用回流阻抗 (电源/地平面阻抗) 串扰进 MIPI 差分对 → 模式转换 → 辐射; 也串扰进 sensor AVDD (R-09)。

**可能表现**
- 辐射发射谱上出现**尖锐的开关频率及其谐波峰** (最容易被判超标的一类, 且加滤波会引入新的谐波)。
- 相机横条 / 显示抖动 (与 R-06、R-09 叠加, 三个成因容易混淆 → 诊断顺序见 §7-诊断顺序)。
- "静态达标、动态不达标": 待机功耗合格, 一跑 OD 就掉压重启 (`HARDWARE_BREAKDOWN.md` 卡点 C 结论 C-2 已预警过这条)。

**整改预案**

| 维度 | 措施 | 量化判据 | 证据 |
|---|---|---|---|
| 布局 | ① 电源区与高速差分区**分区**, 电源回流不得穿越差分参考面; ② 大电流路径铜箔宽度/过孔数按**峰值电流** (待 datasheet 电流上限, 现 `[0数据]`); ③ 每个 SoC 电源球就近去耦, **多档容值并联 (1 nF + 10 nF + 100 nF + 1 µF)**, 数量按电源球数定 | 多档去耦; 峰值路径 | `[推算]` (待 datasheet) |
| 滤波 | ① DC-DC 输出端**两级滤波**: 一级 LC 二阶 (≥ 10 µH + ≥ 10 µF), 二级 磁珠 + 1 µF; ② **DC-DC 选型条款必须写死"负载跃变响应"指标** (不是只看额定电流), 并要求**开关频率或其谐波避开 30~300 MHz 敏感区**, 或选展频 (spread-spectrum) 型号降低单点峰; ③ 核心轨与 NPU 供电分开一级 | 跃变响应指标写进选型条款 | `[推算]` |
| 接地 | ① 功率地与信号地在**电源入口处单点汇流**; ② 每一级 DC-DC 的输入电容直接接本级地平面, 不跨层借地; ③ 去耦电容的接地过孔**就近下到本层参考面**, 不与其他过孔共用 | 单点汇流 | `[推算]` |
| 屏蔽 | SoC 所在区域上方预留**可选金属盖板** (若结构允许), 抑制 SoC 噪声向上耦合到骨架/机身 | 预留孔位 | `[推算]` |
| 器件 | ① DC-DC 选型: 额定电流 ≥ 均值 ×1.5 (已锁), **+ 瞬态响应指标 + 开关频率 + 展频选项**; ② 若用 LDO 做后级: 注意 LDO 压差 → 压差 × 电流 = 自身发热 (贴皮肤侧 = 43 °C 红线, 见 `MECH_BUDGET.md` §2.2), **发热轨优先用开关电源** | 见左 | `[推算]` |

**设计阶段可预评估**: 滤波拓扑、开关频率选型条款、纹波预算表、布局分区规则 —— **全部可在画板前关闭**。
**必须实测**: ① 各轨纹波 (示波器 + 弹簧地/同轴探头, 带宽限制 20 MHz 以免被开关噪声淹没 —— 测纹波必须先关带宽限制); ② OD 满载瞬态跌落 (示波器 + 触发在负载台阶); ③ 辐射谱上开关频率峰的实测值; ④ 图像/显示在满载下的表现。

**卡点**: **SoC 电源域表/电流上限/开关频率全未知** (`HARDWARE_BREAKDOWN.md` 卡点 C 结论 C-3) → 纹波预算表与滤波参数现在写不出具体数值, 只能写"待 datasheet"。

### R-06 光机电源域: LED 驱动开关噪声 + 480 Hz 调制 + DSI 供电耦合

| 项 | 内容 |
|---|---|
| 等级 | 🟡 中 |
| 判定方式 | **混合类** (隔离供电与滤波可预评估; 实际噪声贡献与画面表现必须实测) |
| 证据 | 走鹃Ⅱ 98 mW / 480 Hz / 800×600 / MIPI+I2C = `[官方]` (JBD 官网, 转引 `PROJECT_TRACKER` §0 #21); **光机内部 LED 驱动拓扑/开关频率/输入纹波要求 = `[0数据]`** |

**风险机理**
光机在这个系统里是**双重身份**: ① 污染源 (内部 LED driver 是开关电源, 恒流驱动 + PWM 调光) ② 受污染方 (DSI 差分与电源同束传输)。三条通路:
1. **光机电源反灌**: 光机电源线与 DSI 差分对在同一连接器同一束 → 光机侧开关噪声沿电源线进入主板 → 污染 SoC 轨 (与 R-05 叠加)。
2. **480 Hz 帧同步/调光调制**: 480 Hz 的功率调制 → 频谱上是 480 Hz 及其谐波的低频包络 → 若与电源纹波中的 60 Hz 分量拍频 → 在图像/显示上表现为**低频横纹或亮度抖动**。
3. **跨铰链**: 光机在镜框, SoC 在镜脚 → 供电与 DSI 都要跨铰链 → 共模路径长 (同 R-01 的放大因素)。

**可能表现**
- 画面出现与 480 Hz / LED 驱动相关的横纹、闪烁、亮度抖动。
- ⚠️ **与结构应力的"彩虹纹"混淆**: `MECH_BUDGET.md` §5 已讨论彩虹纹 (装配应力成因)。**两种成因的表现不同 (应力彩虹纹是固定位置的彩色条纹, 噪声横纹是随时间滚动/随工况变化), 诊断时必须先分清** → 否则会拿着 EMC 结论去改光学件, 或拿着光学结论去改电路。
- 充电时更明显 (叠加 R-03/R-05)。

**整改预案**

| 维度 | 措施 | 量化判据 | 证据 |
|---|---|---|---|
| 布局 | ① 光机供电**独立一路 DC-DC 或独立 LDO**, 不与 SoC 核心轨共用; ② 光机连接器上 **DSI 差分对与电源线之间用地线隔断 (ground guard)**; ③ 光机地与 SoC 地在**连接器处单点汇流**, 不形成跨板地环路 | 独立供电 + ground guard | `[推算]` |
| 滤波 | ① 光机电源入口: **磁珠 + LC 二阶**; ② 跨铰链的光机电源线上加**阻尼网络 (磁珠 + 100 Ω, 靠近源端=光机)**, 100 Ω 放在磁珠之后; ③ DSI 差分线上**不加大电容** (会破坏眼图) —— 需要滤波时改用小容值共模扼流圈 + 短 stub | 阻尼网络顺序 | `[推算]` |
| 接地 | 光机供电地回流走独立路径, 不与 MIPI-CSI 地共用 | 独立回流 | `[推算]` |
| 屏蔽 | 光机座金属件若存在 → 接到机壳地单点搭接 (同 R-04 规则) | 单点 | `[推算]` |
| 器件 | 磁珠选**低 DCR、自谐振频率高于开关频率**的型号 (否则磁珠变成电容, 谐振更难查) | SRF > 开关频率 | `[推算]` |

**设计阶段可预评估**: 供电隔离拓扑、滤波网络、ground guard —— 全部可预评估。
**必须实测**: ① 光机单独工作/整机工作两种工况的画面差异 (高速摄影或逐帧比对, 注意光机逐帧延迟本身也是 0 数据, 见 `measurements.yaml` M-OPTIC); ② 光机电源纹波实测 (示波器在光机输入端); ③ 频谱上 480 Hz 及其谐波的能量分布。

**卡点**: **光机供电电压范围/峰值电流已在 JBD 清单里 (`jbd_zoushe_dsi_spec`), 但"输入纹波/开关频率/是否需要外部 π 滤波"没问** → 需追加一问, 经项目总工转达 JBD (我不外联, 见 §9)。

### R-07 ESD 防护全局: 人体触摸路径 + 锂电点火次生风险

| 项 | 内容 |
|---|---|
| 等级 | 🔴 **高 (含安全后果)** |
| 判定方式 | **只能实测** (ESD 抗扰是整机 + 实际结构 + 实际放电点的测试, 结构未定前测了也没意义) |
| 证据 | 人体模型/触摸路径 = `[推算]`; 电池 1S Li-po ≥420 mAh 装在贴皮肤镜腿 = `[官方]` 转引 `INTERFACES.md`; **无任何 ESD 实测** = `[0数据]` |

**风险机理**
眼镜是**可触摸佩戴物** —— 这条与常规工设的根本差别: 人体本身就是持续存在的 ESD 源 (人体电容 ~100 pF 量级 `[推算]`, 接触金属可积累 kV 级电位)。触摸路径:
1. 金属镜腿 / 骨架外露面 / 金属压条 / Type-C 开口铝框 (若外露)。
2. Type-C 插拔时手同时接触外壳与引脚。
3. **充电时同时接触 Type-C 与金属件** → 放电电流被迫穿过内部走线。

🔴 **次生安全风险 (比"死机"严重一个量级)**: 镜腿内是 1S 锂聚合物电池 (丰江 432243, ≥420 mAh `[官方]`)。ESD 电流若泄放到**电池排线 / 保护板 (DW01A+双 MOS 类, `HARDWARE_BREAKDOWN.md` HW-06)**, 保护 MOS 击穿 → 电池短路 → 发热/起火。**眼镜是贴脸佩戴物, 起火直接烧脸** → 这条把 ESD 从"EMC 指标"升级为"安全问题", 也解释了为什么它的优先级高于所有发射类项。

**可能表现**
- 设备死机/重启/摄像头异常 (最常见, 也是最容易被忽略的"偶发故障")。
- 电池保护异常、鼓包 (极端: 起火)。
- 金属件与塑料件接触时"啪"一声伴随数据丢失。

**整改预案**

| 维度 | 措施 | 量化判据 | 证据 |
|---|---|---|---|
| 布局 | ① **外露金属件全部等电位**: 骨架/压条/铝框/Type-C 壳 → 同一机壳地网络, 且该网络与电池、敏感信号之间有明确泄放路径 → 摸金属件时电荷走外壳, 不进内部; ② 电池排线加**防反插/防呆**连接器; ③ NTC (I2C, 贴 SoC 背面) 的走线若经金属骨架 → 也纳入保护 | 金属件单一接地路径 | `[推算]` |
| 滤波 | ① 电池主路径加 **TVS + 100 Ω 限流 (或磁珠)**, 防止 ESD 直接灌进电池/保护板; ② 任何引到外露金属件的信号线加磁珠 + 100 Ω 串阻 + 下拉 | 限流 100 Ω | `[推算]` |
| 接地 | ① 机壳地 = 金属件的**唯一泄放路径**, 必须**低阻 (< 1 Ω @ 接触点)**; ② 机壳地与数字地单点汇流; ③ **泄放电流不得穿越 MIPI/DSI 差分对回流** | < 1 Ω | `[推算]` |
| 屏蔽 | 外露金属件边缘做**绝缘包边/涂层** (仅边角, 内部搭接面保持裸露) → 降低人体直接接触概率 | — | `[推算]` |
| 器件 | ① ESD 器件: **MIPI 连接器处 ≤ 0.5 pF; Type-C D+/D- ≤ 1 pF; CC/SBU/VBUS ≤ 3 pF; VRWM ≥ 24 V**; ② 选**系统级 IEC 61000-4-2 认证**器件 (系统级 ±4 kV 接触 / ±8 kV 空气), 不要只看器件级 "±30 kV" 那种 (那是钳位电压测试, 不是系统抗扰); ③ 电池保护板选带**过压/过流/短路自恢复**的组合 | 容值 / VRWM / 认证等级 | `[推算]` |

**设计阶段可预评估**: 泄放路径拓扑、器件选型、布局规则 —— 可预评估 (这是本项目 ESD 能不能达标的关键)。
**必须实测 (全部)**: ① 接触放电 (金属壳/铝框/骨架外露面) + 空气放电逐点加严; ② 充电工况下的 ESD (最容易漏: 充电时人同时摸金属件); ③ 放电后功能与电池状态检查 (有无一键关机/需重插电池); ④ **电池保护板在 ESD 冲击后的存活测试** (直接量保护板 MOS 的 Vds 是否击穿)。

**卡点**: ① 外露金属面清单与位置未给 (mech-lead) → ESD 施加点无法穷举; ② 结构未定 → 整机 ESD 测试没有意义 → **必须排在结构冻结之后**; ③ 电池保护板未选型 (`HARDWARE_BREAKDOWN.md` HW-06 状态 ⬜ 未选)。

### R-08 充电板 ↔ 主板 分板互连的共模电流

| 项 | 内容 |
|---|---|
| 等级 | 🟡 中 |
| 判定方式 | **混合类** (互连与滤波可预评估; 共模电流实测必须做) |
| 证据 | 充电板 25×10×0.8 mm + 铝屏蔽罩 = `[推算]` 转引 `MECH_BUDGET.md` §1.3; 互连排线形式与长度 = `[0数据]` |

**风险机理**
充电板 (Type-C + 充电 IC + 保护 + NTC) 与主板 (SoC + PMIC + 连接器) 是**两块独立 PCB**, 由排线/FPC 互连 (`MECH_BUDGET.md` §1.3 M1/M3 + §5.2)。分板的代价:
1. **排线是共模电流的天然通道**: 两块板的地平面不连续, 排线地线的回路阻抗大 → 共模电流在上面流过时产生共模电压 → 排线自己当天线 (1 m 线缆在 75/150 MHz 附近谐振, 排线短一些但同样成立)。
2. **充电 IC 的开关尖峰**沿排线进主板 → 主板辐射 + 主板电源被污染。
3. **两块板各自的地"浮"在排线两端** → 若两端各自接了机壳地 → 形成**跨板地环路** (第二根天线)。
4. 充电板必须在镜脚末端以外 (挪出长度, `MECH_BUDGET.md` §2.1 B) → 排线更长。

**可能表现**
- 充电时整机辐射发射抬升; 充电时相机/显示受干扰 (与 R-03/R-05/R-06 叠加)。
- 充电时的故障被误判为"软件问题"。

**整改预案**

| 维度 | 措施 | 量化判据 | 证据 |
|---|---|---|---|
| 布局 | ① 排线**地-电源-地-电源交替**排布 (每根电源线配地线), 共模回路面积最小; ② 排线连接器选**带 GND 触点且触点交错**的型号; ③ 两块板尽量**共面平行, 间距 < 5 mm**, 中间加一层地 (或用双面贴装让地平面靠近) | 地/电源交替 | `[推算]` |
| 滤波 | ① 排线上加 **共模扼流圈 (CM choke)** + 每根电源 **磁珠**; ② 电池路径 (两板共有的) 加 100 Ω 限流 + TVS; ③ 充电板输出端加 π 型滤波 | CM choke | `[推算]` |
| 接地 | ① 两板地**只在一处汇流** (优先在靠近主板电源入口处), 禁止两端都接机壳地; ② 若必须两端都接 → 中间加**隔直电容 (1 nF × 4 并联)** 阻断直流环路 | 单点汇流 | `[推算]` |
| 屏蔽 | ① 充电板铝屏蔽罩覆盖电子部分; ② 排线从罩内引出 → 罩上开槽用**导电泡棉**封堵; ③ 罩与主板 GND 用弹片搭接 | 罩体闭合 | `[推算]` (结构侧由 mech 落实) |
| 器件 | CM choke 选**低 DCR、直流可过 ≥ 2 A** (充电电流峰值), 注意 DC 偏置下电感值下降 | ≥ 2 A | `[推算]` |

**设计阶段可预评估**: 互连排布、滤波、汇流点 —— 可预评估。
**可预测试**: 充电板独立先投 (§8-2) → 可先测这块板自身的辐射与 ESD。
**必须实测**: ① 整机充电工况辐射发射; ② 近场探头定位排线是否为主辐射源 (把排线换成短线对比, 差值即排线贡献); ③ 充电时图像/显示表现。

**卡点**: 排线的实际形式 (FPC/线束/几芯/多长) 未定 → 滤波选型与排布规则无法定稿。

### R-09 sensor 供电 / MCLK 耦合 → 图像噪点

| 项 | 内容 |
|---|---|
| 等级 | 🟡 中 |
| 判定方式 | **混合类** (供电拓扑可预评估; 图像上的实际表现必须实测) |
| 证据 | sensor 型号未定 → AVDD/MCLK 细节 `[0数据]`; 机理 `[推算]` |

**风险机理**
sensor 是整机里唯一的模拟前端, 对电源噪声最敏感:
1. SoC 电源纹波经共用回流阻抗串进 sensor AVDD → 图像**横向条带**。
2. **MCLK** (数 MHz~数十 MHz 方波) 与 sensor 电源/地线并行 → 容性串扰 → 图像闪烁/横条。
3. sensor 地与 SoC 地若多点连接 → 地环路 → 同上。
4. 模组座下方地平面被 MIPI 走线切开 → 参考不连续 → 噪声耦合路径。

**可能表现**
- 图像出现随电源状态 (待机/满载/充电) 变化的横条、竖条、斑点。
- ⚠️ **诊断陷阱**: 这类现象与"ISP tuning 没做好"、"sensor 坏"、"软件 bug" 三者外观相近 → **必须先做排除法** (§7 诊断顺序) 再去动软件或光学。

**整改预案**

| 维度 | 措施 | 量化判据 | 证据 |
|---|---|---|---|
| 布局 | ① **MCLK 单独包地**, 与 sensor 电源/地并行长度 ≤ 5 mm, 间距 ≥ 3 mm; ② MCLK 不与电源并行走; ③ 模组座下方地平面保持完整, MIPI 走线不得从座下穿过 | 间距 ≥ 3 mm | `[推算]` |

### R-10 悬空引脚 / 地平面割裂 / 长走线 / 测试点 = 天线

| 项 | 内容 |
|---|---|
| 等级 | 🟡 中 |
| 判定方式 | **设计阶段可判定** (纯几何与拓扑, 审图逐条可关; 但残余发射仍需整机复测) |
| 证据 | 机理 `[推算]`; 已列于 `HARDWARE_BREAKDOWN.md` §1.6 HW-26 (未使用引脚处理) |

**风险机理**
1. **悬空引脚 = 单极子天线 + 不确定行为**: CMOS 输入悬空会拾取噪声 → 随机翻转 → 对 BOOT/RESET 键来说 = **眼镜自己重启** (佩戴场景下的"产品事故", 不是 EMC 指标问题但成因是 EMC)。
2. **地平面割裂 = 缝隙天线**: 任意电源/地分割都在地平面上切出缝隙, 缝隙 Q 值高 → 强辐射; 且跨越分割的高速信号回流路径被迫绕行 → 辐射与串扰同源。
3. **长走线 + 测试点/排针**: 测试点、调试排针引出的短线是单极子; 复位/BOOT 长线拾噪。

**整改预案**

| 维度 | 措施 | 量化判据 | 证据 |
|---|---|---|---|
| 布局 | ① 任何电源/地分割**对称且最短**, 禁止高速信号跨分割; ② 分割处用地缝合 + 电容; ③ 复位/BOOT/按键走线尽量短 (< 20 mm), 测试点集中在板边**一处**并用地包围 | 对称最短 | `[推算]` |
| 滤波 | 按键/复位加 **10~100 kΩ 下拉 + 100 nF 到地 (RC 抗扰)**, 按键额外加 ESD 器件 | RC 值 | `[推算]` |
| 接地 | 悬空引脚按 SoC 手册接地或标 NC; **禁止悬空** (已列 HW-26) | 逐脚核对 | `[推算]` |
| 屏蔽 | 测试点/排针区加 ESD 阵列 + 磁珠 | — | `[推算]` |
| 器件 | 上拉/下拉电阻靠近接收端 (≤ 5 mm) | ≤ 5 mm | `[推算]` |

**设计阶段可预评估**: ✅ 完全可预评估 (审图 checklist 已覆盖, `AGENTS.md` 原理图 checklist 明确要求"未使用引脚处理")。
**必须实测**: 仅残余辐射复测 (整机), 不需要专门测项。

**卡点**: 无 (纯设计纪律)。

### R-11 上下分壳缝隙 + 隔热垫 → 屏蔽不闭合

| 项 | 内容 |
|---|---|
| 等级 | 🔴 高 |
| 判定方式 | **只能实测** (屏蔽效能取决于最终装配的缝隙/搭接/公差) |
| 证据 | 分壳方案 (0.5 mm 隔热垫 + 0.3 mm 空气隙) = `[推算]` 转引 `MECH_BUDGET.md` §5.2; 屏蔽效能无数据 = `[0数据]` |

**风险机理**
镜腿**上下分壳** (上壳: PCB/SoC/骨架/石墨; 下壳: 电池, 贴皮肤), 中间 0.5 mm 隔热垫 + 0.3 mm 空气隙 (`MECH_BUDGET.md` §5.2)。这对 EMC 意味着:
1. **缝隙长度才是关键, 不是宽度**: 0.8 mm 的缝宽在 30 MHz~1 GHz 不是主要泄漏路径 (λ/20 @ 1 GHz ≈ 15 mm), **但沿缝方向的长度 (接近镜脚长度, 100 mm 量级) 远大于 λ/2 的谐振条件** → 长条形缝隙本身就是缝隙天线, 会把 SoC 区噪声耦合到皮肤侧与外界。
2. **隔热垫不是导电垫** → 屏蔽在整条缝上断开。
3. **冲突**: 想用导电泡棉跨缝闭合屏蔽 → 会同时把热从 SoC 区导到贴皮肤的电池区 → 与 `MECH_BUDGET.md` §2.3 的热路径账 (皮肤侧 43 °C 红线) 冲突。**这个冲突必须由结构侧裁决, 不能由硬件单方面决定。**

**可能表现**
- 辐射从镜腿缝隙泄漏 → 发射超标; 佩戴者头部场强 (体佩戴, 极低功率, 但值得测)。
- 上/下半壳之间出现电位差 → 触摸时放电 (与 R-07 同一根源)。

**整改预案**

| 维度 | 措施 | 量化判据 | 证据 |
|---|---|---|---|
| 布局 | PCB 侧: 上壳内的金属件 (骨架 + 屏蔽罩) 在**上壳内部**形成闭合围腔 → SoC 被金属包住; 围腔在 PCB 上的投影区不放高速信号引出 | 围腔闭合 | `[推算]` |
| 滤波 | 跨壳引出的信号 (电池/充电板排线) 加磁珠 + 100 Ω; 尽量少跨壳 | — | `[推算]` |
| 接地 | ① 上壳金属件之间用**导电泡棉/铜箔桥**在**金属-金属**处搭接 (壳体内侧), 形成闭合回路; ② **不要跨越隔热垫搭接** (会导热到皮肤侧) | 金属-金属搭接 | `[推算]` |
| 屏蔽 | 金属盖板 + 导电泡棉封闭 SoC 区上方 (上壳内侧); 充电板铝屏蔽罩与主板搭接成围腔 (见 R-08) | 缝隙 ≪ λ/20 | `[推算]` |
| 器件 | 导电泡棉选**低压缩永久变形、高导电率**型号 (PED 镀碳) | — | `[推算]` |

**设计阶段可预评估**: 屏蔽围腔的拓扑方案 (可预评估, 需结构配合)。
**必须实测 (全部)**: ① 整机辐射发射 (这是唯一判据); ② **有/无导电泡棉的对比扫描** (差值即缝隙贡献); ③ 上下壳之间的电位差测量 (静电探头, 高阻表)。

**卡点**: ① 导电泡棉搭接方案需与 mech-lead 的热路径一起裁决 (走项目总工); ② 泡棉压缩量与隔热垫厚度的空间冲突未知。

### R-12 手机近场 RF 免疫 (佩戴距离 5~15 cm)

| 项 | 内容 |
|---|---|
| 等级 | 🔴 高 |
| 判定方式 | **只能实测** (近场场强需按实际佩戴距离标定, 无法用标准距离替代) |
| 证据 | 机理 `[推算]`; 手机实际发射功率/近场场强 = `[0数据]` |

**风险机理**
首款不上无线 (`PROJECT_TRACKER` §0 #11) 只说明**我们不发射**; 不影响**我们必须不被别人的射频打挂**。佩戴场景的特殊性: **用户的手机就在眼镜旁边 5~15 cm** → 近场场强远高于标准试验条件 (3 V/m @ 30 cm) 在该距离下的场强。三条机理:
1. **射频经高速线耦合**: 手机 RF 经 MIPI/DSI/电源线容性耦合进 SoC → 数字误动作 (ISP 死机、摄像头花屏、NPU 结果错)。
2. **非线性整流**: ESD 器件/结电容的二极管效应把 RF 整流成直流偏置 → 触发复位/锁存。
3. **电源轨整流 → 掉压**: RF 在电源/地平面阻抗上整流出电流 → 供电跌落 → 硬重启。

**可能表现**
- 用户戴眼镜时手机来电/发短信/开热点 → 眼镜花屏、黑屏、重启。
- **这是佩戴场景下最可能被用户投诉、且最容易被归咎给"软件不稳定"的故障** → 若在 G3/G4 才发现, 排查成本极高。

**整改预案**

| 维度 | 措施 | 量化判据 | 证据 |
|---|---|---|---|
| 布局 | ① 所有外露/长走线 (MIPI/DSI/电池/I2C) 均视为**天线**, 逐条处理; ② I2C (sensor + 光机 + NTC 三方共用一路) 上拉**用 2.2 kΩ 而非 1 kΩ** (降低驱动强度与辐射), 串 100 Ω + 就近 10 nF | 上拉 2.2 kΩ | `[推算]` |
| 滤波 | ① **每个 SoC 电源引脚就近去耦 + 铁氧体/磁珠 (5~10 nF 或 600 Ω @100 MHz)**; ② 电池路径加磁珠 + 100 Ω; ③ 复位/BOOT 加 100 nF + 10 kΩ 下拉; ④ **ESD 器件本身是整流源** → 靠近连接器放, 且不要让 RF 直接打到 ESD 器件的信号脚后串扰到 IC | 见左 | `[推算]` |
| 接地 | 机壳地把 RF 电流就近短路 (同 R-04 单点搭接) | — | `[推算]` |
| 屏蔽 | SoC 区金属围腔 (同 R-11) | — | `[推算]` |
| 器件 | 磁珠选自谐振频率高于干扰频段 (手机 0.8/1.8/2.4 GHz 及 5G → 需要覆盖 2.4~6 GHz 的宽带磁珠或铁氧体) | 覆盖 2.4~6 GHz | `[推算]` |

**设计阶段可预评估**: 滤波拓扑与选型 —— 可预评估。
**必须实测 (全部)**: ① RF 源 (信号发生器 + 功率放大器 + 近场探头) 在**实际佩戴距离**注入, 逐频扫描找敏感频点; ② 手机实机 (2G/4G/5G/Wi-Fi/蓝牙) 在 5/10/15 cm 三档距离下的功能与画面表现; ③ 找出系统最敏感频点后, 把该频点写进回归测试用例。

**卡点**: ① 无 RF 测试设备 (信号源 + 功放 + 近场探头) → 需项目总工决定外委或租借; ② 手机发射功率为 `[0数据]` → 近场场强无法预估 → **不能用"标准 3 V/m"糊弄**。

### 7.3 诊断顺序 (防止把 EMC 故障当成光学/软件故障去乱改)

当出现"画面异常 / 抖动 / 重启"类现象时, **按下面顺序排除**, 不要跳步:

1. **工况相关性**: 是否随 待机 / 满载 / 充电 变化? → 变 = 电源耦合 (R-05/R-06/R-08/R-09); 不变 = 光学/结构 (如彩虹纹, `MECH_BUDGET.md` §5) 或 ISP tuning。
2. **位置性**: 条纹是**随时间滚动** (噪声) 还是**固定位置** (结构应力)? → 滚动 = EMC; 固定 = 光学/装配。
3. **RF 相关性**: 是否只在手机附近出现? → R-12。
4. **ESD 相关性**: 是否只在触摸/插拔后出现? → R-07。
5. **以上全否** → 才去查 ISP tuning / 模型 / 光学件。

> 这条顺序写进 `SW_REQUIREMENTS.md` 与 G3 联调计划更合适 → 已列入 §9 转交项 (走项目总工)。

## 9. 板子回来前能做的预测试计划 (与 §7 的"必须实测"区分)

> 目的: 把能在画板阶段暴露的风险, 挪到板子回来**之前**暴露。**这是本项目唯一能"提前做 EMC"的窗口**, 因为没有 devkit (R9)。

|---|---|---|---|---|---|
| **PT-1** | **阻抗 coupon** | 与最终 PCB 同叠层同批次, 额外投一块测试板: 100 Ω 差分 ×2 + 90 Ω 差分 + 50 Ω 单端 + 地 stitching 结构 | PCB 厂阻抗控制能力; 规则 1/2/3/4 是否可行 | 几乎为零 (拼板加一块) | 主板回来才发现阻抗不对 → **改板 = 2~4 周 + ¥4~8K** (`PROJECT_TRACKER` R10) |
| **PT-2** | **充电板单独先投** | 充电板 (M3, 25×10 mm) 独立投板: Type-C + 充电 IC + 保护 + 铝屏蔽罩 | Type-C 端口 ESD 摸底; 壳地搭接有效性; 屏蔽罩效果; 传导噪声 | 一块小板, 无系统依赖 | ESD 问题只能等整机 → 迭代周期 ×N |
| **PT-3** | **DC-DC 评估** | 用评估板/评估模块测: 开关频率实测、负载跃变响应、输出纹波 (关带宽限制) | 开关频率落点 (→ R-05 谐波落频); 滤波方案定型 | 需一块评估板 + 示波器 | 只能拿到板子后才发现开关频率在敏感区 → 换芯片 = 改板 |

> **PT-1 与 PT-2 建议合并到第一次投板一起下单** (拼板), 边际成本几乎为零, 但能把两个最高风险 (阻抗 + Type-C ESD) 提前 2~4 周暴露。
