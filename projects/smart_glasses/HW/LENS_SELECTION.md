## B1 结论摘要

1. **推荐档位 = 对角 120°** ✅。但**必须同时锁一条结构条件: 光轴俯角 ≤25°** (ISS-047 收口)。理由: 120° 是三档里**唯一**在俯角 25° 与 32° 两种工况下正前方都留在画面内、且 25° 时还有 +15.3° 余量的档位 `[推算]`。
2. **在 1/3"~1/2.6" 靶面上, "120° 对角" 这个数有两种完全不同的含义** —— 这是本轮最要紧的一条。**直行 (rectilinear) 口径**下 120° 需要 f=**1.78mm** (OV04C10) / **1.96mm** (AR0234CS), 垂直半视场 **40.3°**; **等距鱼眼 (equidistant) 口径**下同一个"120° 对角"需要 f=**2.95mm**, 但垂直半视场只有 **29.5°** —— **俯角 32° 时正前方直接掉出画面** `[推算]`。**镜头的投影模型必须和 FOV 数字一起写进 RFQ, 否则报价回来的东西大概率是鱼眼, 而结构拿到的余量是错的。**
3. **物理上能量产的是鱼眼, 不是直行 120°**。直行 120° 的量产镜头 (1.1" 靶面级) 缩到 1/3" 靶面后焦距 1.78mm、等效光圈要缩到 ⌀0.6-0.7mm (等效 f/2.6-3.0) `[推算]` → 弱光信噪比不可接受。**→ 路线定为: 鱼眼 (等距/等立体角) + 对角 120° + 不做 LDC**。
4. **畸变代价 (老板已接受, 不构成否决)**: 等距鱼眼 120° 的边缘桶形畸变 **角落 -39.5% / 水平边 -29.4% / 垂直边 -9.0%** `[推算]`。**反向收益**: 不做 LDC → ISP 几何流水线省掉畸变校正重采样 → 缓解 tracker §5.7.1 "LDC 占 pipeline 预算"; 且鱼眼的角分辨率**均匀** (0.0389°/px), 而直行 120° 角落比中心粗 **4.0 倍** `[推算]` → 对边缘目标检测, 鱼眼反而更好。
5. **结构侧要跟的数 (三档之间只差 ≤0.9mm, 可以不等镜头定档就开模)**: 镜筒外径 **⌀6.0-6.5mm**、镜头总高 **3.7-4.6mm**、模组沿光轴总高 **5.0-5.9mm**、窗口通光 **⌀4.5mm**、前组通光口径 **≥4.0mm** `[推算]`。**前镜片顶点必须齐平或凹进 ≤1.0mm** → 感光面凸出 0.6-1.4mm, 满足 MECH "凸出 ≤2.5mm" `[推算]`。
6. **一个必须写进 ISP 需求的副作用**: 老板拍板"后级只缩放、不裁剪" ⇒ 画面保持鱼眼原始形状 ⇒ **检测框在图像上是弯的**。SW 侧必须做"检测框反投影到真实方位角"这一步, 否则框位置/框龄全部带系统性误差。→ 已写进 §B6.4 RFQ 第 9 条 + §B7 卡点 6。

### 2.3 ★ 投影模型依赖 —— 本轮最关键的一条

**"对角 120°" 不是一个自洽的数。** 它只在明确了投影模型时才有意义:

| 投影模型 | 映射关系 | 对角 120° 所需 f (OV04C10) | **垂直半视场** | 俯角 25° | 俯角 32° |
|---|---|---|---|---|---|
| **直行 (rectilinear)** | r = f·tanθ | **1.781 mm** | **40.45°** | +15.45° ✅ | +8.45° ✅ |
| **等距 (equidistant)** | r = f·θ | **2.946 mm** | **29.53°** | +4.53° 🟡 | **−2.47° ❌ 掉出画面** |
| (参考) 等立体角/正交 | r = f·sinθ 系 | 3.561 mm | ~25.3° | −0.3° ❌ | ❌ |

**三档在两种投影下的完整对照 (OV04C10)**:

| 对角 FOV | 直行 f | 直行 垂直半视场 | 直行 俯25 | 直行 俯32 | 鱼眼 f | 鱼眼 垂直半视场 | 鱼眼 俯25 | 鱼眼 俯32 |
|---|---|---|---|---|---|---|---|---|
| 100° | 2.589 | 30.40° | +5.40° | −1.60° ❌ | 3.535 | 24.61° | −0.39° ❌ | −7.39° ❌ |
| 110° | 2.160 | 35.11° | +10.11° | +3.11° 🟡 | 3.214 | 27.07° | +2.07° 🟡 | −4.93° ❌ |
| **120°** | **1.781** | **40.45°** | **+15.45°** ✅ | **+8.45°** ✅ | **2.946** | **29.53°** | **+4.53°** 🟡 | **−2.47°** ❌ |

**结论 (必须写进 RFQ 和结构对齐单的一句话)**:
> **在 1/3"~1/2.6" 靶面上量产的 120° 镜头是鱼眼, 它的"120° 对角"对应的垂直半视场只有 29.5° (OV04C10) / 31.8° (AR0234CS 16:10), 不是基线表里的 40.3°。** → 走鱼眼路线时, **俯角必须 ≤25°** (OV04C10 余量 +4.5°) / **≤28°** (AR0234CS 余量 +6.8°)。

## B3 120° 镜头的代价量化 (验收 2)

以下按 **OV04C10 (主选靶面) + 对角 120°** 给出; AR0234CS 的对应值在括号里。

### 3.1 边缘畸变量级 (barrel / pincushion, %)

畸变定义: `D% = (r_实际 − r_理想)/r_理想`, 理想 = 同焦距直行投影 `r_理想 = f·tanθ` (行业标准口径)。

| 位置 (角位置) | **直行 120° (理论)** | **等距鱼眼 120° (计算值)** |
|---|---|---|
| 画面角落 (对角, θ=60°) | 0% (针孔定义) → **设计残差目标 ≤15% 桶形** `[推算·工程目标]` | **−39.5% 桶形** |
| 水平边中点 (θ=56.45°) | 0% → 残差 ≤10% | **−29.4% 桶形** |
| 垂直边中点 (θ=40.45°) | 0% → 残差 ≤6% | **−9.0% 桶形** |
| 视场 50% 处 (θ=30°) | 0% → 残差 ≤2% | −5.7% 桶形 |

- 直行路线的 "0%" 是**理想针孔的理论值, 不是可交付值** —— 真正的交付指标是**残差**, 写进 RFQ: **角落 ≤15% 桶形, 且厂商必须随货提供标称畸变曲线** `[0数据]`。
- 鱼眼路线的 −39.5% 是**投影本身决定的, 改不掉** (等距投影的固有属性, 与靶面尺寸无关) `[推算]`。
- **老板已明确"先接受畸变"** → 上述量级**不构成否决**; 但必须让 SW 侧知道: **画面边缘的直线会明显弯曲, 检测框在图像上不是矩形** (见 §B1 第 6 条)。

### 3.2 边缘清晰度 (角分辨率 + MTF)

**角分辨率 (每像素对应的场景角度, °/px)** —— 由 `dθ/dr` 乘像元尺寸得到:

| 路线 (120°) | 画面中心 | 水平边 | 角落 | 中心/角落比 |
|---|---|---|---|---|
| **直行** (f=1.781) | **0.0643°/px** | 0.0327°/px | **0.0161°/px** | **4.0×** (角落分辨率是中心的 4 倍) |
| **等距鱼眼** (f=2.946) | **0.0389°/px** | **0.0389°/px** | **0.0389°/px** | **1.0× (完全均匀)** |

*(AR0234CS @ 3.0µm: 直行 中心 0.0877 / 角落 0.0219 °/px; 鱼眼 均匀 0.0530 °/px)*

**读法 (对 YOLO 检测的直接含义)**:

- **直行 120°**: 角落像素比中心像素"看得更远" (0.0161 vs 0.0643 °/px) —— 看着像好事, 实际是**同一个目标在画面边缘被径向拉长 ~4 倍**, 检测框的**长宽比和真实形状严重失真**, 且角落 MTF 很难做上去 (边缘像差最大) → **边缘目标的位置/尺寸估计不可信**。
- **鱼眼 120°**: 角分辨率均匀 → **画面中心与边缘的检测能力一致**, 代价是边缘目标像素数与中心相同 (不会更少), 这正是 AI 眼镜需要的 (视野边缘不能"糊")。

**具体量化示例 (2m 外, 人肩宽 450mm → 角宽 12.85°)**:
- 鱼眼 120°: 12.85/0.0389 = **330 px** (全画面一致)
- 直行 120° 中心: 201 px · 直行 120° 角落: **798 px 但径向拉伸 4× (框失真)**

**MTF 指标 (交付要求, 当前 0 数据)**:
- 要求厂商提供**标称 MTF 曲线**, 验收线: **角落 MTF ≥ 中心 MTF 的 30% @ Nyquist 频率** `[推算·工程目标]`
- 鱼眼 120° 在 f/2.0-2.8 光圈下的角落 MTF 实测值 = `[0数据]` → 必须向模组厂索取 (见 §B7 卡点 2)

### 3.4 亮度 / 暗角 (直行 vs 鱼眼, 差别很大)

**相对中心照度 (rectilinear 系统的 cos⁴ 律)**:

| 位置 | 直行 120° 理论 (cos⁴) | 备注 |
|---|---|---|
| 角落 (60°) | **6.3%** | 实际因渐晕更差 → 必须 ISP 阴影校正 (SHPC) |
| 水平边 (56.45°) | **9.3%** | 同上 |
| 垂直边 (40.45°) | **33.6%** | 同上 |

**鱼眼 120° 的边缘亮度衰减显著慢于 cos⁴ 律** (鱼眼的有效 f-number 随视场角增长远慢于 cos⁴), 典型边缘相对照度 **40-70%** `[推算·行业经验, 厂商亮度曲线 0数据]` → **SHPC 负担远低于直行路线**。

> 这条是"直行 120°"被否掉的第二个硬理由: 角落只有中心亮度的 6% → 增益拉高 → 噪声爆炸 → 对 YOLO 小目标召回是直接伤害。

### 3.5 ISP 预算影响 (LDC 开关)

| 方案 | ISP 几何流水线 | 量化 |
|---|---|---|
| **鱼眼 120° + 不做 LDC** (老板拍板"后级只缩放") | **省掉畸变校正重采样** | 相对做 LDC 省 **~30-50% 的几何流水线负载** `[推算]`; 且**没有黑边** (数字 shift 的 10-20% 视场缩水也一并省掉) |
| 鱼眼 120° + LDC 校正到直行 | 重采样 | ⚠️ **等效直行对角只剩 92.6°** (`2·atan((d/2)/f_equi)`) —— 比基线 100° 档还窄 → **鱼眼 + LDC 与"要 120°"自相矛盾, 老板的"不裁剪/接受畸变"正好绕开这个矛盾** |
| 直行 120° + LDC | 轻量校正 (残差 ≤15%) | 缩放系数 1.0-1.15×, 负载小; **但镜头不可量产** |

> **老板"暂接受畸变、后级只缩放"的决定, 在光学上是自洽的**: 它正好避免了"鱼眼做 LDC 缩水到 92.6°"的死结。代价由 SW 侧承担 (检测框需反投影, 见 §B1 第 6 条)。

### 4.3 凸出 / 凹进 与俯角的耦合 (结构必须跟的数)

**几何**: 摄像头装镜框上沿、光轴俯角 φ → 前镜片顶点比感光面**低** `Δz = 镜头总高 × sin φ`。若前镜片顶点相对镜框上沿外表面**凹进 r mm**, 则感光面**凸出** `= Δz − r` mm。MECH 硬约束: 凸出 ≤2.5mm, 凹进 ≤1.5mm。

| 档位 | 镜头总高 | 俯角 25°: 顶点凹进 0 / 0.5 / 1.0 / 1.5mm → 感光面凸出 | 俯角 32°: 同 |

| 100° 直行 | 3.70 | 1.56 / 1.06 / 0.56 / 0.06 ✅ | 1.96 / 1.46 / 0.96 / 0.46 ✅ |
| 110° 直行 | 3.95 | 1.67 / 1.17 / 0.67 / 0.17 ✅ | 2.09 / 1.59 / 1.09 / 0.59 ✅ |
| 120° 直行 | 4.50 | 1.90 / 1.40 / 0.90 / 0.40 ✅ | 2.38 / 1.88 / 1.38 / 0.88 ✅ |
| 100° 鱼眼 | 4.25 | 1.80 / 1.30 / 0.80 / 0.30 ✅ | 2.25 / 1.75 / 1.25 / 0.75 ✅ |
| 110° 鱼眼 | 4.40 | 1.86 / 1.36 / 0.86 / 0.36 ✅ | 2.33 / 1.83 / 1.33 / 0.83 ✅ |
| **120° 鱼眼 ★** | **4.55** | **1.92 / 1.42 / 0.92 / 0.42 ✅** | **2.41 / 1.91 / 1.41 / 0.91 ✅** |

**结构结论 (直接可执行)**:
- ✅ **三档 × 俯角 20-32° × 凹进 0-1.5mm 的全部组合都满足 MECH "凸出 ≤2.5mm"** —— 最坏情况 (120° 鱼眼 + 俯角 32° + 顶点齐平) = **2.41mm**, 余量只剩 **0.09mm**。

- ⭐ **这条与 FOV 档位基本无关** (三档差异 ≤0.4mm) → 结构侧现在就可以定"凹进 1.0mm"这个安装基准, 不必等镜头定档。
- ⚠️ **反过来说: 凹进 1.5mm 是上限不能再加** —— MECH 已算 "凹进 5mm 吃掉上半视场 31%" (atan(5/30)=9.5°), 与本文件的镜头账相互印证。

## B6 推荐档位 + 理由 (验收 5)

### 6.1 推荐

> ### ★ 推荐: **对角 120° 档**
> **路线: 鱼眼 (等距/等立体角) + 全画幅不裁剪 + 不做 LDC**
> **硬条件: 光轴俯角 ≤25°** (由 ISS-047 收口; AR0234CS 可放宽到 ≤28°)
> **配套靶面: OV04C10 (豪威, 16:9) 或 AR0234CS (1/2.6", 16:10 原生全画幅, 垂直余量更大 +2.1°)**

**理由 (四条, 每条带数)**:

1. **它是三档里唯一在俯角 25° / 32° 两种工况都把正前方留在画面内的档位**。100° 档在俯角 32° 时差 1.6° (掉出), 110° 档只剩 3.1° (不够稳) —— 120° 档即使在鱼眼口径下俯角 25° 也有 +4.5°/+6.8° 余量, 直行口径下更达 +15.5°/+17.5° `[推算]`。
2. **畸变代价老板已接受** —— 前提写在下面 §6.2, 因此 −39.5% 角落桶形**不构成否决**; 且鱼眼路线**免掉 ISP 的 LDC 重采样**, 反而给几何流水线减负 (省 ~30-50%) `[推算]`。
3. **在 1/3"~1/2.6" 靶面 + 6mm 模组高度内, 鱼眼是唯一能量产的路线**。直行 120° 需要 f=1.78mm + 等效 f/2.8 的小光圈 → 角落照度掉到中心的 6.3% → 弱光噪声不可接受 → **直接否掉** `[推算]`。
4. **镜筒/窗口尺寸三档只差 ≤0.9mm** → 结构侧可立刻按 §B4.4 的预留开加厚区, **镜头定档不阻塞结构开模**; 且"前顶点凹进 1.0mm"这条安装基准与档位无关, 现在就能定。

### 6.2 前提标注 (**老板已接受畸变** —— 本推荐成立的前提)

> **本推荐建立在老板 2026-10-25 19:33 的明确决定之上**:
> **"sensor 输出先不裁剪, 由后级模块缩放到目标分辨率, 暂时先接受畸变, 后继看效果"**
> (`PROJECT_TRACKER.md` §0 变量 40)
>
> 具体含义: ① 用全画幅有效阵列, **不裁剪**; ② 后级只做**等比缩放**到目标分辨率; ③ **不做畸变校正 (LDC)**, 边缘桶形畸变 (-39.5% 角落) **暂时接受**; ④ 效果后继看, 必要时再换镜头/开 LDC。
>
> **若老板推翻这条 (例如要求画面必须"正"、必须 LDC 校正、或必须 32° 俯角), 本推荐立即失效, 走 §6.3 回退路径 B/C。**
