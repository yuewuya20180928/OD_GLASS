## 二、我自己发现的问题 (不是子 agent 交的, 是画的时候撞出来的)

1. **跨铰链被短接** (C7) —— 最严重的一处: 画 P9 时发现 USB 差分从 SoC 直连 Type-C, 而两块板根本不在一块板上。**这不是笔误, 是"网表里没有板级概念"的必然结果** → 加 `board` 列才是根治。
2. **电池过温保护漏画** (C3) —— V1 只画了 SoC 侧温度计, 充电链的 TS 脚空着。安全项漏画。
3. **供电器件输入侧漏画** (C5) —— 9 颗 IC 的输入脚没接任何东西, "来源"判据形同虚设。
4. **`U_BRIDGE` 一颗芯片两个定位** (C8) —— P4/P6 说法冲突, BOM 必错。
5. **ISS-082 的前提是错的** (C11) —— "可编程 TPS7A20" 不存在 (该系列只有固定输出)。**正确解法比原方案更便宜**: ① LDO 全系列同封装 X2SON → 换料不换板 ② DC-DC 用引脚可选输出 → 落在档内换料、档外换同封装可调型号 ③ 监督器分压位 → 任何电压轨都能映射到监控窗口。**三步都不需要改板。**

## 五·补、★V1.2 (2026-10-27 09:0x) —— 电池位置裁决 (跨域冲突, 只有画图才能撞出来)

- **触发**: 结构总工 ISS-085 抛出 **MECH-B7** —— "电池在镜框还是镜脚, 两边假设互斥" (netlist 标充电板侧=镜框, 而 `MECH_BUDGET` 写 "电池 4.12cc **镜框装不下** → 镜脚")。
- **裁决 (项目总工, 按体积硬约束)**: **电池 + 电池保护 IC (BQ2970 + 2×MOS) 装镜脚主 PCB**; 充电板 (Type-C + ESD + π + BQ25896) 仍按 ISS-014 决策 5 在镜框 ⇒ **SYS 在镜脚本地产生, 不过铰链** ✅
- **代价 (讲清)**: 跨铰链的大电流从 SYS 0.55A 变成 **充电电流 1.0-1.5A** → `J_CHG` 改 1×10 (pin1/pin2 双 pin 载流 + pin3/pin4 双 pin 回流) + `TP_BAT_CHG` 测铰链段压降
- **充电路径上不装 π 滤波** —— 会破坏 BQ25896 环路稳定性; 只做双 pin 并联 + 载流核算 (ISS-091)
- **可回退分支 (跟 Q4 续航口径挂钩)**: 若拍板"按需触发 130mAh" (体积 1.8cc), 电池可能装进镜框 → 跨铰链大电流降回 SYS 0.55A ⇒ `J_CHG` 留了 3 个预留位, 两种形态都能落板
- 依据写入 `DECISIONS.md` (2026-10-27 条)

## 七、★V1.4 (2026-10-27 09:0x-09:35) —— 独立复审 (ISS-088) 挖出 3 类真缺陷 + 我自查出 KiCad 导出件是坏的

**这轮的由来**: 我把 V1.2/V1.3 派给 hw-lead 独立复审 (自己产的必须别人验)。它**超时 0 落盘** (40 分钟, 回执只有半句话) —— 但分析有效, 我独立复核后全部坐实并修掉。

## 八、★V1.5 (2026-10-27 09:35-09:50) —— 充电板规格交卷 → 又查出 4 处缺陷 + 7 条裁决 + P10 页开工

**触发**: 充电板整页规格任务交卷 (`HW/CHARGE_BOARD_SPEC.md` 691 行, USB-IF Type-C Spec 2.0 + TI BQ25896 datasheet 一手核对)。**它在我的网表里查出 3 个硬缺陷**, 我独立复核全部坐实:

| # | 缺陷 | 后果 | 修法 |
|---|---|---|---|
| **D8** | **Type-C GND 只接了 A1+A12** | USB-IF 16p 的 GND 是 **A1/A12/B1/B12** → B1/B12 悬空 = **USB 回流路径减半** | 补 B1+B12 |
| **D9** | **TS 不在 `J_CHG` pin map 里** | V1.2 把电池/NTC 搬到镜脚后, NTC 在镜脚而 BQ25896 在镜框 → **TS 必须跨铰链, 但我漏画了这一段** | 补 `J_CHG pin8` + 补画 TS 跨铰链行 |
| **D10** | **TS 分压值错** (10k NTC + 10k 下拉) | BQ25896 是**三件式**: RT1 5.24k (REGN→TS) + RT2 30.31k (TS→GND) + **103AT NTC ∥ RT2** (datasheet 0°C→73.25%, 60°C→34.375%) → 原来的分压比完全不对 | 按 datasheet 重画 |
| **D11** (我自查) | **11 行 `board` 误标 CHG_BOARD** (RAIL_SYS / RAIL_BAT) | V1.2 把电池搬镜脚后, 板级归属没同步 → 装配/备料会按错板 | 修 board 规则 |

**7 条裁决 (进 `DECISIONS.md`)**:
1. **充电板不上 PD 控制器 (TPS25730)** —— 充电板无 3.3V 轨 (VIN_3V3 abs max 4V) + 25×10mm 放不下 QFN-38; ★而且 **PD 5V/2A 不会把 2A 灌进铰链** (铰链走 ICHG ≈ 0.822×IIN)
2. **R_ILIM 300Ω 必装** (IINLIM 复位默认 2048mA → 不装铰链吃 ~1.68A) → ICHG 0.88-1.07A; 换 390Ω → 0.67-0.82A (**换料不换板**)
3. **J_CHG 定稿 1×10p@0.5mm** (加 TS, 铰链区堆叠仍 26.5mm, 余 10.5mm)
4. **充电 IC 的 I2C 不跨铰链** (靠 R_ILIM 硬件限流 + CHG_STAT/PG GPIO 兜底; pin9/10 预留)
5. **电池位置锁镜脚** ("放镜框"的回退分支与本 pin map **不兼容**, 布局前不得切换)
