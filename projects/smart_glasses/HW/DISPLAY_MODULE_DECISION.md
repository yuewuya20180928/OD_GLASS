## 0. 一句话结论

主控 RK3572 的同时, **显示件从「JBD 走鹃Ⅱ 彩色光引擎 (800×600/30°/0.18cc/6lm/98mW/480Hz)」换成「视涯科技 0.49 英寸 1920×1080 硅基 OLED 微显示屏 (SiOLED/OLEDoS)」**。
★**这是架构级变更, 不是换料**: 走鹃Ⅱ 是**光引擎** (自带准直光输出, 直接耦合进波导), 硅基 OLED 是**显示面板** (自身发光的成像面) ⇒ **中间必须多一级耦合光学**。
★**接口是唯一的好消息**: 0.49" 1920×1080 模组口径为 **MIPI DSI + I2C** ⇒ 与走鹃Ⅱ 同接口 ⇒ SoC 侧网表 `CONN_LIGHT` 基本可复用。

## 2. ★★ 三条机械后果 (按影响排序)

### 2.1 「光机」这个器件类别消失了 ⇒ 必须补一级耦合光学 (★工作量最大的一条)

- **旧链**: SoC --MIPI DSI--> 走鹃Ⅱ (光引擎, 自带准直输出) --> 波导耦合 --> 衍射光波导 --> 眼
- **新链**: SoC --MIPI DSI--> SiOLED 面板 (成像面, 屏面视场角仅 ~35°) --> **【新增】耦合光学/准直镜** --> 波导 --> 眼
- ★**面板本身视场角只有 ~35°** (模组厂口径: 白色亮度衰减到 50% 的角度) ⇒ **FOV 全靠耦合光学放大** ⇒ 30° 垂直半视场 / 对角 120° 的目标要靠这一级扛
- ★**两条出路**:
  - **(A) 买视崖的光机模组 (推荐)** —— 视涯本身就把 Micro OLED + 光学封装成光机模组 (CIOE 2025 首展 "**极光·无界**" 1.3" + 折叠光路 95°FOV / PPD 37.4; "**极光·锐影**" 0.6BB 光机模组), 且官网光学方案线明列 **See-through: Birdbath / Waveguide** ⇒ ⇒ **架构可以不变 (仍是"光机 + 波导"), 只是一颗换成另一家的**
  - (B) 买屏自己做耦合光学 —— 非球面 + 波导入瞳匹配设计, 无光机经验不现实
  ⇒ ⇒ **问询草稿必须直接问 (A): 0.49" 1920×1080 + 波导耦合的整套光机模组报价/交期/外形**
- ★**结构后果**: `optical_cavity_size = 14×10×6mm` (镜框内光学腔体) 与 `splitter_volume = 0.79cc` (分光器) **两条都要按新光机重算** ⇒ 新开 **ISS-133**

### 2.2 分辨率 800×600 → **1920×1080** ⇒ 三处预算全变

| 维度 | 变化 | 影响 |
|---|---|---|
| **端到端合成/缩放** | 像素量 0.48M → **2.07M (×4.3)** | RK3572 的缩放/合成能力要重算 (ISS-124/125 问询口径再改一次); ★**与 RK3572 的 4 TOPS 叠加 ⇒ 60ms 更紧** |
| **DSI 带宽** | 1920×1080@60 RGB888 ≈ **2986 Mbps** payload; @90Hz ≈ 4480 Mbps | 4-lane D-PHY 2.5Gbps **够** ⇒ 不强制要 DSC ⇒ 但要确认 **RK3572 的 DSI 控制器是否支持 DSC** (面板支持不等于 SoC 支持) · ★**依据 (ISS-186 订正)**: payload = 1920×1080×24×60 = 2985.98 Mbps ⇒ 与 `HW/e2e_budget_rk3572.py` §⑥ 同口径 (TX 下限 7.776ms = 2986 Mbps ÷ 60fps ÷ 6400 Mbps 有效带宽, 即按这个 payload 算) |
| **FOV 映射 (ISS-063)** | 走鹃Ⅱ 30°FOV/800px → 0.49" 屏/120°对角 | ★**ISS-063「120°→30° 映射方式」的前提全部作废** ⇒ 重新定义 |
| **PPD** | 800px/30° ≈ 26.7 PPD/° → 1920px/120° ≈ **16 PPD/°** | ★**分辨率涨了, 但 PPD 反而降** ⇒ 画框最小线宽判据要重定 (1px 在 120° FOV 下会被光波导 MTF 吃掉) |
| **显示分辨率 claim** | `display_resolution = 800x600` (sw.yaml) | **必须同步改** (否则 STATE 挂过期基线) |

### 2.3 JBD 的角色从「光机供应商」收窄为「波导供应商」 ⇒ 问询对象变了

- 老板锁死表 **#19「MIPI-DSI 输入的光机由 JBD 的蜂鸟提供」** 与 **#21「光机型号 = JBD 走鹃Ⅱ」** ⇒ **本条作废**
- ★**JBD 问询草稿要改**: 原来问走鹃Ⅱ 的长宽高 (ISS-016) / 光生物安全参数 (ISS-048) / 关联的波导 (ISS-004/013) ⇒ 现在:
  - ISS-016 (走鹃Ⅱ 尺寸) ⇒ **作废**, 换成问视崖的光机模组外形
  - ISS-048 (光生物安全) ⇒ ★**口径整个变了**: 走鹃Ⅱ 是 **LED 光源**, 问的是波长/亮度/光通量/辐亮度; 硅基 OLED 是**面光源自发光**, 且蓝光 (~460nm) 在衍射波导里散射 ⇒ **要问视崖**: 出光面辐亮度/光谱/蓝光占比/工作温度下的亮度衰减/波导耦合后的出射角
  - ISS-004/013 (波导选型) ⇒ **仍需要**, 但判据变了: 波导不再"配走鹃Ⅱ 的准直光", 而要"配 0.49" 面板 + 视崖耦合方案"的入瞳/出瞳/耦合角 ⇒ **波导到底还问 JBD 还是另找, 也要重新定**
- ⇒ 新开 **ISS-134** (JBD 角色收窄 + 问询草稿改写 + 波导供应商重定)

## 3. ★★★ 决定性未知项: **0.49" 1920×1080 是单色还是全彩?** (这题决定产品定义, 必须先问)

**为什么这是决定性的**: 项目的显示内容是 **OD 检测框 + 检测结果**。若 0.49" 1920×1080 只有**单色 (黄/绿)**, 则
① 检测框不能上色 (绿色单色能出, 但红色/多类别区分要靠纹理/位置) ⇒ **产品"彩色显示"卖点要改**;
② 单色 SiOLED **成本大幅低于全彩**, 且**发光面积只有 1/3 ⇒ 同亮度功耗更低** ⇒ **对 ISS-130 (670mW 热学) 是正面消息**;
③ 全彩 0.49" 1920×1080 属**贵价件** ⇒ BOM 与报价要重算。

**现有线索 (都指向"要直接问")**:
- 视崖招股书把 **0.49" 与索尼 0.44"、京东方 0.49" 并列在 "0.4-0.49 英寸级别"**, 三家分辨率都是 1920×1080 ⇒ 这个尺寸档是业界"高分辨率 AR 单色"的主战场
- 视崖 CIOE 2025 新闻稿重点推的是 **0.6" (全彩 6000 nits / 30~120Hz)**, 并称它是"继**爆款 0.49 英寸**之后的**全新一代**" ⇒ ★**暗示 0.49" 是上一代/走量款 (大概率单色或低规格全彩), 0.6" 才是新一代全彩**
- 视崖有"强微腔、串扰截断、**高光效叠层全彩**"技术 ⇒ 全彩能力存在, 但在哪个尺寸档未公开
⇒ ⇒ **必须直接问视崖, 不能猜** (新增 **ISS-132**)
