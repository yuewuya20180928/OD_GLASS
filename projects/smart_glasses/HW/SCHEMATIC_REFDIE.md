## §3 同 Die 的 6 条关键推论 (含 1 条**负面结论**)

> 这 6 条是本文的技术内核。**每条都标了它解锁了什么、没解锁什么。**

### §3.1 ✅ 推论 1: 同 Die 的 ARS45 **一定有 MIPI CSI RX 控制器** —— 解锁卡点 #3 的**存在性**

- 依据: AR9481 支持 4-8K 视频输入、最多 6 路甚至 >10 路 `[媒体 M2]`; 4 核 CPU + RISC-V MCU + DSP + 机器视觉处理器 `[官网brief O1]`。
- 推论: 同 Die 的 ARS45 必然含 MIPI CSI RX 控制器, 且很可能**不止一组** → 参考版预留 **S75 (第 2 组 CSI) + S76 (热成像专用输入)** 两个预留组。
- **解锁**: 卡点 #3 的"有没有 CSI RX" → **有** (✅)。所以我们板级不用再纠结"要不要自己加 CSI 接收器"。
- **没解锁**: lane 数 / 每 lane 速率 / 电压域 / AC 耦合是否内置 / 球号 → **全卡**。

### §3.2 ✅ 推论 2: 同 Die 的 ARS45 **有 I2C 控制器**, 但**"第 2 路 / DDC 独立通道"仍不确定** —— 卡点 #9 仍卡

- 依据: 机器人 SoC 必须挂摄像头/雷达/麦克风/温感从机 `[媒体 M2 + 推算]`。
- 推论: 至少 1 路 I2C (总线 A) ✅; **第 2 路 (总线 B / DDC) 是否独立** 无法从同 Die 推出 → 仍按 v0.1 的"两种都留焊盘"处理。
- **重要副作用**: 总线 A 上要给 sensor / NTC / 桥接 / 充电IC / 光机(兜底) 共 5 个从设备 → **I2C 控制器数量要 ≥1, 最好有 2**。若原厂只有 1 路 → 总线 B 走 DDC 复用 GPIO 也能成立 (v0.1 §4.3 已兜底)。**不影响板子**。

### §3.3 ✅ 推论 3: **视频编码器 (H.264/265) 在同一 Die 上** —— 第一台样机不投板, 但有 2 个后果

- 依据: AR9481 集成 H.264/265 编码器 `[媒体 M7]` → 同 Die 的 ARS45 大概率也有。
- 后果 ①: 编码器与 NPU 共用 DDR 带宽 → **我们后面若加"录像"功能, 必须重估 DDR 带宽和功耗** (第一台样机不做录像, 所以**不加编码器相关电源域**)。
- 后果 ②: 同 Die 意味着 **DDR 控制器一样** → AR9481 的 DDR 方案对我们有参考价值, 但 AR9481 的 DDR 容量未公开 `[0数据 Z3]` → 卡点 #6 仍卡。

### §3.4 ⚠️ 推论 4: **V_CORE 不能按 0.8V 假设** —— 这是本文**唯一改动选型约束**的一条

- 依据: AR9481 "**最低工作电压可以到 0.65V**" `[媒体 M3]`, 且"工作电压上提供了更高的范围" `[媒体 M8]`。
- ⚠️ **这条最容易被人误用**: 0.65V 是**机器人产品标称的最低工作电压**, **不等于** ARS45 的 V_CORE 标称值 (0.65V ~ 1.0V 是"能工作"的低端, 机器人满载 NPU 用的一定更高)。
- **工程结论 (参考版唯一新增的选型改动)**: DC-DC (TPS62130A 类) 的**输出电压范围要按 0.6-1.0V 覆盖来选**, **反馈分压电阻留 2 挡焊盘** (0.6V 挡 / 0.8-0.9V 挡), 等原厂给了标称电压再焊死其中一挡。
- **额定电流不变**: 仍 **≥2A** (算式不变, 见 `SCHEMATIC_L1.md` §4.3), 因为电流由功耗决定, 不由同 Die 参考改变。

### §3.5 ✅ 推论 5: **4 个片上 scaler** → 我们的"800×600 显示"从 ISP 内部取, 不需要外挂 scaler

- 依据: "ISP 子系统集成**四个独立的片上缩放器** (支持 1/64 至 2 倍)" `[官网brief O5]`。
- 推论: 800×600@60 的缩放由片内 scaler 做 → **板级不需要外挂 scaler 芯片** (省面积 + 省功耗 + 少一颗待确认器件)。
- 副作用: "辅以两个外部 1 进 4 出缩放器" `[官网brief O5]` 是**芯片外**的器件, 说明官方参考设计里有多路显示输出的诉求 → **侧面支持"显示 TX 存在"的可能, 但不是证据** (见 §3.6)。

### §3.6 ⛔ 推论 6 (**负面结论**): **同 Die 参考完全没有解锁显示接口** —— 卡点 #4 一字未动

这是本文最重要的一条, 也是最容易被"乐观派"漏掉的一条。

| 检查项 | 结果 |
|---|---|
| 官网 AR9481 产品页有没有提显示接口? | **没有**。只写 4K@60fps 输出 / 8Tops / 4核64bit CPU / RISC-V MCU / 机器视觉处理器 `[官网brief O1]` —— "输出 4K@60fps 视频"指的是 **ISP 输出视频流**, **不是** "芯片有一个 DSI/DP 显示输出接口" |
| 官网 ARS45 产品页有没有提显示接口? | **没有** (与 ISS-054 的结论一致) |
| 官网"智能图像处理"页提显示接口了吗? | **没有**。只提延迟 <10ms (传感器输出→显示渲染)、4K60fps 处理、4 个片上 scaler、CV ISP 双通道单色输入 `[官网brief O3~O6]` |
| **结论** | **官网从头到尾没有给出任何 SoC 的显示接口类型** → 同 Die 参考 **不能** 解锁卡点 #4 |
| ⚠️ **不能做的推论** | "AR9481 是扫地机 SoC, 扫地机不需要显示 → 所以 AR9481 没有显示 TX → 所以 ARS45 也没有" —— **这是错的**。扫地机/无人机普遍带 HDMI/DSI 输出小屏/图传, 且 O5 的"外部 1 进 4 出缩放器"反而暗示多路输出需求。**没有证据 = 不知道, 不是"没有"** |
| **本文怎么做** | 双出口 0Ω 选路矩阵**原样保留** (`R_SEL_*` 装 / `BR_*` 装, 互斥), 并且 **DP AUX (1 对) + HPD (1 脚) 单独占位** (v0.1 只在 A-21 一行里带过) → 收到 Q16 答案只改 BOM, **不改板** |
