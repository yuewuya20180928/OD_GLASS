## 0. 字段定义与填表规则

| 字段 | 含义 | 规则 |
|---|---|---|
| **ID** | 本表行号 (`A-`/`B-`/`C-` 前缀) | 后续引用一律用 ID, 不写网名 |
| **信号名** | 网名 | 命名规则: `<域>_<器件>_<功能>` (如 `CSI_D0_CK_P` / `LIGHT_3V3` / `KEY_PWR`) |
| **方向** | 相对**主 PCB (M1)** 的方向: `SoC→外设` / `外设→SoC` / `双向` / `电源` / `地` | 所有跨域连接必须写死方向 |
| **电平** | 数字信号写电压, 模拟/电源写轨名 | ARS45 侧电平一律标 **`[待原厂]`** |
| **阻抗** | 高速差分写差分阻抗; 单端写上升时间/负载; 电源写最大电流 | 差分 **必须写 100Ω / 90Ω + ±10%** |
| **连接器** | 物理落点 | 跨铰链的必须标 "跨铰链" |
| **测试点** | 有/无 + TP 编号 | **高速差分与关键状态信号必须有 TP** |
| **责任人** | 谁最终对这个值负责 | `hw-lead` / `mech-lead` / `sw-lead` / `main` / `vendor` |
| **DNP** | 是否默认不装 | 见 `SCHEMATIC_L1.md` §3.2 互斥规则 |
| **版本** | 本行取值版本 | 与本表版本号同步 |

> ⚠️ **本表是"接口契约", 不是"愿望清单"**: 凡写不出两端引脚的行, 一律标 `[待原厂]` 并进 `SCHEMATIC_L1.md` §6 对照表, **不猜**。

### 4.3 ⭐ 兜底: DSI DDC 通道不独立怎么办 (原厂问题 1-4)

> 原厂问询明确问了 "DSI TX 的 I2C 通道是独立的还是与 DSI 共用" (`state/outbox/vendor_round2_email.md` 问题 1-4)。**两种答案都必须成立**:

| 情形 | 光机 I2C 落点 | 地址是否冲突 |
|---|---|---|
| **原厂答: DDC 独立** (正常) | 总线 B, 地址 0x72 | ❌ 不冲突 (与总线 A 完全隔离) |
| **原厂答: DDC 不独立 / 共用** | 光机挂到**总线 A**, 地址 **0x72** | ❌ **仍不冲突** —— 故意的: 总线 A 上 **0x72 已被预留给光机**, 总线 A 现有 0x36 / 0x48 / 0x50 / 0x6B, **无一与之冲突** |

> ✅ **结论: 光机地址在两条总线上都预留 0x72, 两种原厂答案都不需要改板。** 这就是"接口先定死"的收益。

### 4.4 总线 A 完整地址表 (供软件建库)

| 7-bit 地址 | 器件 | 10-bit 写法 |
|---|---|---|

| 0x36 | sensor OV04C10 | 0x6C |
| 0x48 | NTC TMP117 | 0x90 |
| 0x50 | DP→DSI 桥接芯片 | 0xA0 |
