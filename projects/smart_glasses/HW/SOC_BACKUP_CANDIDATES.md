## 0. 背景与"资料充足"的机械判据

**背景**: 酷芯微 (Artosyn) 代理渠道已联系但暂时联系不上 ⇒ boss 定: **以半个月 (至 2026-11-12) 为期**, 期限内拿不到 ARS45 的关键资料 ⇒ 切到"资料充足"的备选芯片。

**为什么必须机械判据**: 换过去还是照样开不了机 = 只是把"等原厂"换成"等另一个原厂"。

| # | 判据 (5 条全满足才算候选, 任一条不满足 = 不算) |
|---|---|
| J1 | **公开可得的完整引脚表 / 球位图** (不是只有营销页 —— 必须能据此画原理图) |
| J2 | **公开可得的 datasheet + 硬件设计手册** (含参考原理图 / PCB / 布局指南) |
| J3 | **公开可得的 NPU 模型转换链 + 算子支持清单** (我们跑 YOLOv5 INT8) |
| J4 | **公开可得的 Linux/SDK 支持 + 至少一个真实量产产品的公开资料或拆解** |
| J5 | **功耗与封装量级能进眼镜**: SoC 域 ≤300mW 级 / 封装 ≤10mm 级 |

**J5 为什么是硬门槛**: 很多资料齐全的芯片功耗是眼镜的 10 倍, 装了也过不了皮肤 43°C。
