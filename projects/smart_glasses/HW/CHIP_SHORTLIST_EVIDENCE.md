**小结 (瑞芯微 5 款)**

- **RK3588** — 最强: ①**VO 全都有 (DP1.4×2 + HDMI2.1×2 + DSI 4-lane×2)** ⇒ 直接消解桥接芯片问题 ②6 TOPS + RKNN 生态最成熟 ③64-bit DDR 带宽最足 ④官方 datasheet 齐全。**硬伤: 封装/功耗均 [0数据]** —— 手机级 SoC, 预估 SoC 域功耗与封装尺寸都偏大 (风险项 R-01/R-04, **不否决**)。
- **RK3576** — 最强: ①**同款给了 DP1.4 + HDMI2.1 + MIPI-DSI + 并行输出, 四路 VO 齐备** ②8nm/6 TOPS/RKNN 成熟 ③官方 Brief Datasheet 把封装都写明了 (FCCSP698L 16.1×17.2mm)。**硬伤: 封装宽度 16.1mm vs 板宽 15mm** ⇒ ★**风险项 R-03** (不否决): 化解路径 = 放宽镜腿/镜框到 ≥17~18mm (老板 18:55 明确允许), 见 §5.2。
- **RK3568** — 最强: ①VO 接口全 (HDMI2.0 + DSI×2 + eDP) 无 DP ②32-bit DDR ③官方 datasheet 齐全 ④量产最稳。**硬伤: NPU 仅 0.8-1 TOPS, 1080p60 + YOLOv5 INT8 端侧实时性存疑**; 22nm + 4×A55@2.0GHz ⇒ 预估功耗偏高 (**风险项 R-01**, 3.6 打 5 分, 不否决)。
- **RK3566** — 最强: 同 RK3568, 少一路 GMAC/PCIe 降级, 更便宜。**硬伤: 同 RK3568 (22nm 功耗) + NPU 1T 偏低 + 无 DP** —— 在同厂内属"缩水版", 相对 RK3568 无增益。

## §3 ★ 对 ISS-003 / ISS-005 的直接结论 (老板 3.8 项 "DP 优先于 MIPI-DSI" 怎么解)

> **背景**: ISS-003/ISS-005 卡了两周 —— "ARS45 到底有没有原生 DSI TX, 要不要加桥接芯片 (4-8 周采购周期)"。

| **RV1126B** | 无 [官方] | **有, 4-lane DSI 1080p@60** [官方] | 直接 DSI 接光机 | **❌ 不用买** |
| **CV186AH** | 无 [媒体] | **有, DSI + LVDS + 数字 RGB 双屏** [媒体] | 直接 DSI 接光机 | **❌ 不用买** |
| **RK3568 / RK3566** | 无 [官方] | **有, DSI TX0&TX1 (4-lane 各)** [官方] | 直接 DSI 接光机 | **❌ 不用买** |
| **K230 / K230D** | 无 [官方] | 有, DSI 1080p@60 [官方] | — | (已因 V5 淘汰) |

**三条硬结论**:

1. ★**"桥接芯片"这条采购路径可以整体取消** —— 因为本轮 12 款过线候选里, **原生带 MIPI-DSI TX 的有 10 款** (只有 CV186AH 的 DSI 参数来自方案商口径需复核)。**只要选定其中任意一款, 双目光机直接吃 SoC 的 DSI, 不需要任何 DP→DSI 桥接芯片 ⇒ ISS-003/ISS-005 卡住的 4-8 周采购周期直接归零。**
2. ★**"DP 优先"这条, 在 12 款过线候选里只有 RK3588 / RK3576 同时满足** (既有 DP1.4 又有 DSI)。**注意 DP 的真正价值不是"接光机"** —— 衍射光波导光机 (micro-OLED/MicroLED) 实际吃的是 DSI/RGB/并口, **DP 的价值是 (a) Type-C 调试口同时出 DP Alt Mode 视频 (b) 给"必须接 DP sink"的外接场景留退路**。所以 **DP 是加分项, 不是接光机的必要条件**。
3. ★**真正的卡点从"有没有 DSI"变成了"光机到底吃什么接口"** —— 我**没有**光机输入接口的原始规格 (JBD/光机厂资料未到)。**若光机只吃 DSI, 上面 10 款直接可用; 若光机只吃并口 RGB, 则要挑并口/DSI 双出的片 (RK3576 有并口输出, T527 有 2×RGB)**。**这一条必须走接口请求给项目总工 → 转 JBD/光机厂确认, 我不能替结构总工猜光机接口。**
