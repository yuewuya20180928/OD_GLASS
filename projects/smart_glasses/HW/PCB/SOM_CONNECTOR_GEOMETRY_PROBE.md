| 结论 | 证据 |

| 每个座是 **2 排 × 50 = 100 脚**; **奇数脚 = 一排, 偶数脚 = 另一排** | 手册 §2.6.2: 8 张表 = 4 座 × (Odd 表 + Even 表); 且 §2.6.1 的 4 张引脚原理图上, 左列 = 1,3,5…99, 右列 = 2,4,6…100 |

|---|---|

### (b) ★最可靠且可自证: 买 1 片 SoM + 1 个 DF40C-100DS, 万用表实测 (推荐)

**原理**: 手册 §2.6.2 的表给出每个座 pin1/pin2 的功能, 挑一个 **pin1 与 pin2 功能差别最大** 的座, 在 SoM **底面 (针头侧)** 用万用表对 GND 打通, 直接判出哪一排是 pin1 排。

**推荐用 P2** (手册 §2.6.2 表):
- **P2 pin 1 = I2C2_SDA_M0** (SoC ball Y32, 3.3V 信号, 接进 SoC 球)
- **P2 pin 2 = GND** (SoM 地)
- ⇒ 在 SoM 底面, 对准 P2 座 **△ 标记端**的两根针头, 用万用表电阻档一端接 SoM 地 (或 SoM 上任意 GND 焊盘):
  - **读数 ≈0Ω 的那根 = pin2 = 偶数排**
  - **读数不通/高阻的那根 = pin1 = 奇数排**
- 再把"哪一根在 y 大的一侧 / y 小的一侧"读出来 ⇒ **奇数排归属即刻确定**
- ⚠️ 读的是 **底面**: y 方向**不镜像**(镜像的是 x), 所以底面上"上/下"排 = 顶视上的"上/下"排, 直接换算; 只有 x 方向要注意镜像
- 备选座: **P4** (pin1 = GPIO0_C5_d @ball 1T21, pin2 = NC) —— 差别也很干净, 但 GND 打不通法不如 P2 直白

**为什么这套能一锤定音**: 手册 §2.6.2 是 Forlinx 官方表, P2 的 pin1/pin2 定义明确 (I2C2_SDA_M0 vs GND), 万用表读的是**物理接触**, 与任何图形/符号解读无关 ⇒ 结论就是物理事实。

### (c) 兜底: Hirose 原厂件 + 3D 模型

- Hirose 产品页提供 **3D model (STEP) / 2D3D model (IGES)** 免费下载 (需注册登录): https://www.hirose.com/en/product/p/CL0684-4033-4-51 ⇒ 导入 EDA 量排距, 并看模塑的 cavity identification 记号在哪一端
- 买 1 个 DF40C-100DS + 1 个 DF40C-100DP, 用体视显微镜看模塑的**防呆位 (cavity identification)** 与 HRS logo 分别在哪一端, 与 Forlinx 底面图的 △ 端对上
- 若仍不确定, 走 Hirose 官方 **Engineering Drawing** 申请 (DF40 资料首页明确写 "Please request the Engineering Drawing for the most current and accurate design information") —— 这是唯一能给到带脚号接触排布的官方文件

### (d) 打样前的机械兜底 (即便 (a)(b) 做了, 仍建议加一道)

做一个 **1:1 打印 (或激光打印缩放校准) 的 SoM 轮廓 + 4 座位置校验治具**: 板上打出 68×50 轮廓、4 个 φ2.1 孔、4 个 22.6×3.2 座框 + pin1 三角 + 两个排的候选位置 (排 A / 排 B)。实物 SoM 压上去对位, 就能一眼看出"哪一排是奇数排", 且顺带复核 §2 的 17.0/51.0/3.5/46.5 坐标。**成本近乎为零, 但能在投板前抓出 100% 的几何错**。

## 7. 给下游 (demo 主板) 的直接可执行结论

1. **4 个母座中心** (以 SoM 轮廓左下角为原点): **P1 (51.0, 3.5) / P2 (51.0, 46.5) / P3 (17.0, 3.5) / P4 (17.0, 46.5)**, 长轴沿 x, 外形 22.6×3.2, 行内脚位跨距 19.6 (首末焊盘中心 x = 中心 ±9.8)。
2. **pin1 端**: 一律取 **+x 端** —— P1/P2 在 x=60.8 (朝板右外缘), P3/P4 在 x=26.8 (朝板中心)。脚号沿 −x 递增。
3. **待办 (阻塞项)**: **奇/偶排归属 = 无定论**, 走 §5(b) 的 P2 万用表实测 (或 §5(a) 索取载板 Gerber), **在这条闭环之前不要冻结载板 Gerber**。风险量级: 错一排 = 该座 100 根网络全对调 = 板子白打。
4. **焊盘**: 按 Hirose 母座推荐图做 (§4), 并同时把 "2.38 的两种解读" 用 §5 手段定死 (解读 A ⇒ 两排焊盘中心距 3.08mm; 解读 B ⇒ 2.38mm)。
5. 若 demo 主板把 SoM **旋转 90° 装** (照抄官方 OK3572-C 载板摆法), 按 §2.4 的映射表旋转坐标即可, **位号不变**。
