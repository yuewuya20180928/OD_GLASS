## 2. §2.6.1 四张原理图读数（逐张，4× 放大）

四张图都是 EDA 符号，**不是几何视图**。读数（逐张裁剪放大确认，4 个符号结构完全相同）：

```
          P1 符号顶            P2/P3/P4 符号顶
      ┌───────────────┐      ┌───────────────┐
  1 ──┤ 1          2 ├── 2      左列: 1,3,5,7,…,99
  3 ──┤ 3          4 ├── 4      右列: 2,4,6,8,…,100
  5 ──┤ 5          6 ├── 6      pin1 在符号"顶端"
  …  ──┤ …          … ├── …
 99 ──┤99         100├──100
      └───────────────┘
      左列 = ODD(奇)   右列 = EVEN(偶)
```

实测要点（每张图各自确认）：

| 图 | 符号左列 | 符号右列 | pin1 位置 | 器件名 |
|---|---|---|---|---|
| P1 | 1,3,5,…,99（外部网络名也挂在奇数脚） | 2,4,6,…,100 | 左上角 | DF40C-100DP-0.4V(51) |
| P2 | 同上 | 同上 | 左上角 | 同上 |
| P3 | 同上 | 同上 | 左上角 | 同上 |
| P4 | 同上 | 同上 | 左上角 | 同上 |

**结论（符号层面）**：
1. 物理上**奇数脚全部在一排、偶数脚全部在另一排**；
2. **pin1 属于奇数排**；
3. 符号顶端 = pin1 端，脚号沿符号向下递增；
4. 四张符号**没有任何一张是镜像或旋转画法** ⇒ 四个座的约定天然一致。

> 符号只给出"奇/偶"和"哪一端是 pin1 端"，**不给绝对方位**（哪个物理排是奇排、哪一端朝 +x）。
> 这两个必须靠 §3/§4 的物理图来定。

## 3. ★ 关键前置判定：底面尺寸图到底是不是镜像？

任务前提说"底面尺寸图 = 镜像视图，水平翻转 = 顶视"。**我判定：几何上不成立**，只对文字成立。

### 3.1 判定方法与三条独立证据

底面图板框像素定标（自动检测长直线）：板框 x = 239…1540 px，y = 202…1158 px ⇒ **19.132 px/mm**（x、y 一致）。
顶面图板框：x = 257…1329 px，y = 236…1024 px ⇒ **15.765 px/mm**。

**证据 A（文字反显 ⇒ 是"从顶面看底层"）**
底面图上的底层丝印文字全部反显：`P5` 显示成 `ꟼ5`（见 `/tmp/fx/txt_rohs.png`、`/tmp/fx/labels.png`）。
物理含义：底层丝印的字形在 CAD 里就是**反字存储**的（为了从板底看过去是正的）。
⇒ 底层图是**从板顶往下看**画出来的 ⇒ **板框方位 = 顶视方位（x 不翻转），只有字形反了**。
（若图是"把板翻过来看底面"，字形应当是正的；实测不是。）

**证据 B（BGA 过孔阵列的 x 位置，量化）**
- 顶面图 CPU BGA 焊球阵列：左右竖边在 x = 610/611 px 与 835/836 px ⇒ **mm 22.40 … 36.66，中心 29.53 mm**
- 底面图同一片区的过孔场：密集列从 x = 722 px 起 ⇒ **mm 25.20 …**，中心 ≈ **29.25 mm**
- 两者中心差 **0.28 mm**（板宽的 0.4%）⇒ 底图 x = 顶图 x，**未翻转**。
- 反证：若底图 x 被翻转，该过孔场应落在 **mm 34.6…42.8**（= 68−33.4…68−25.2），与顶面 BGA 阵列基本不重合。实测不是。

**证据 C（元件密集区同侧）**
顶面图右侧 x 40…66 mm 是小元件密集区；底面图右侧 x 48…66 mm 同样是密集区，左侧则是 BGA/LPDDR 过孔场。两侧同侧 ⇒ 未翻转。

### 3.2 由此得到的 3 个坐标事实

| # | 事实 | 依据 |
|---|---|---|
| F1 | 底面图的**板框与几何**与顶面图同向（x 不翻转，y 不翻转） | §3.1 A/B/C |
| F2 | 底面图上**丝印位号 P1/P2/P3/P4 的真实物理位置**（把字形水平翻转后读出，字是 P1…P4） | `/tmp/fx/labels.png` |
| F3 | 底面图上 4 个座的 **△ pin1 标记**在**同一相对位置**：**x 小的一端**、**y 小的一侧** | `/tmp/fx/conn_A..D.png`、`/tmp/fx/mm_A..D.png` |

### 3.3 F2 的直接读数（★与任务给定几何的对照）

把底面图的文字水平翻转后读出位号（`/tmp/fx/labels.png`）：

| 底图位置 (mm) | 丝印位号（翻转后读出） |
|---|---|
| x 5.75…28.28, y 44.5…48.5（左上） | **P2** |
| x 39.78…62.25, y 44.5…48.5（右上） | **P4** |
| x 5.75…28.28, y 1.5…5.5（左下） | **P1** |
| x 39.78…62.25, y 1.5…5.5（右下） | **P3** |

**这 4 个 x 区间（5.8…28.3 / 39.8…62.3）与任务给定的 17.0 / 51.0 完全吻合**（±0.3 mm），说明**任务给定的几何是对的**。

唯一需要说清的是 **x 的朝向**：
- 任务给定坐标系 S = "把底面图水平翻转后的图"，所以 **x_S = 68 − x_底图 = 68 − x_顶视**。
- 即：**任务给的 P1(51,3.5) 指的是"底面侧视图"里的 x**（严格意义的 SoM 顶视里 P1 在 x≈17）。
- **但 y 完全不受影响**（y_S = y_顶视），所以 **① 的答案（y 小排）在任务坐标系 S 与真实顶视里是同一个答案**。
- ②/③（"+x 端"、"沿 −x 递增"）在**任务给定坐标系 S 里成立**（已复核，下面 §4 给出论证）。

> ⚠️ 这一条建议记到项目备忘：**以后再读这张底面图，别再翻转了**；位号 P1 在顶视里是**左下角**那个座。

## 4. ★ 推理链（逐座）

### 4.0 通用链条（4 个座完全适用）

```
[底面尺寸图]  每个 BTB 座 = 矩形焊盘区, 内含 2 排各 50 个 0.4mm 焊盘,
              4 个方形 anchor 焊盘; 矩形外侧靠 x 小的一端、靠 y 小的一侧
              有一个丝印 △ (pin1 标记)。
              ── 实测 (mm, 底图坐标): △ 位于座左端内 1.1~1.7mm, 座下沿外 0.3~1.1mm,
                 且正对 y 小的那一排焊盘 (下排焊盘带 y 1.83~2.51 / 44.79~45.37)。
[符号]        奇数脚全部在一排; pin1 = 奇数排; 脚号沿符号向下递增 ⇒ pin1 在一端, 99/100 在另一端。
[合成]        △ 标的就是 pin1 ⇒ pin1 落在 "y 小的那一排" 的 "x 小的那一端"。
              ⇒ ODD 排 = y 小排; EVEN 排 = y 大排;
                pin1 端 = 座内 x 小端 (真实顶视) = 坐标系 S 的 +x 端;
                脚号自 pin1 端向另一侧递增 = 坐标系 S 的 −x 方向。
```

### 4.1 逐座结论

坐标系 S（任务给定）：x 0…68 自左向右，y 0…50 自下向上，原点左下。

座外形（矩形 = footprint 外框）：长 22.5mm（x 5.75…28.28 / 39.78…62.25），高 ≈4.0mm。
两排焊盘带（mm，S 系 y）：P1/P3 为 y 1.83…2.51（y 小排）与 y 4.39…5.12（y 大排）；P2/P4 为 y 44.79…45.37 与 47.41…48.03。

| 座 | 座外形 (S 系) | △ 位置 (S 系) | △ 所在排 | **pin1 排** | **pin1 端** | **脚号方向** |
|---|---|---|---|---|---|---|
| **P1** | x 39.8…62.3, y 1.5…5.5 | x ≈ 60.6…61.1, y ≈ 0.4…1.2 | y 小排 (下排) | **y 小排** | **+x 端** | **沿 −x 递增** |
| **P2** | x 39.8…62.3, y 44.5…48.5 | x ≈ 60.6…61.1, y ≈ 43.5…44.2 | y 小排 (下排) | **y 小排** | **+x 端** | **沿 −x 递增** |
| **P3** | x 5.8…28.3, y 1.5…5.5 | x ≈ 26.5…27.2, y ≈ 0.4…1.2 | y 小排 (下排) | **y 小排** | **+x 端** | **沿 −x 递增** |
| **P4** | x 5.8…28.3, y 44.5…48.5 | x ≈ 26.5…27.2, y ≈ 44.0…44.7 | y 小排 (下排) | **y 小排** | **+x 端** | **沿 −x 递增** |

### 4.2 ②/③ 复核：为什么"+x 端 / 沿 −x 递增"与本报告自洽

- 底图上 △ 在**x 小端** → 真实顶视里 pin1 在**x 小端**；
- 任务坐标系 S 的 x = 68 − x_顶视 ⇒ 真实顶视的 x 小端 = **S 系的 x 大端 = "+x 端"** ✔ 与已定结论一致；
- 符号里脚号自 pin1 端向另一侧递增 ⇒ S 系里脚号自 +x 端向 −x 递增 ✔ 与已定结论一致。

**⇒ ②③ 复核通过，不推翻。**（三条独立读法：符号 pin1 在顶端 / 底图 △ 在 x 小端 / 任务既定 +x 端，三者互相闭合。）

### 4.3 另一条独立交叉验证（符号画法约定）

把底图座形旋转到"pin1 在上"并**从顶面看**（这是画 EDA 符号时最自然的视角）：
令 pin1 端朝上 ⇒ 需把顶视转 90° CCW；此时 **S 系里 y 小的一排出现在符号左侧**。
而符号左侧 = 奇数排 ⇒ **奇数排 = y 小排**，与 §4.0 从 △ 直接读出的结论一致。
⇒ 两条互不依赖的路径（①△的物理位置 ②符号的旋转约定）给出**同一个答案**。
