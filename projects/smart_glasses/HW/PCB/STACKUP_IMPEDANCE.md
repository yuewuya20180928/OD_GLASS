## 3. 阻抗目标 (投板前必须复核)

| 链路 | 网名 (节选) | 目标差分阻抗 | 允许偏差 | 依据 |
|---|---|---|---|---|
| USB 2.0 D+/D− | `NET_USB_D_P_TYPEC` / `NET_USB_D_N_TYPEC` | **90Ω** | ±10% | USB 2.0 |
| MIPI DSI (4 lane, 面板) | `DSI_D0_D*_P/N` | **100Ω** | ±10% | MIPI DSI-2 |
| MIPI CSI-2 (sensor) | `CSI_D0_D*_P/N` | **100Ω** | ±10% | MIPI CSI-2 |
| I2C / SPI / GPIO | `I2C_*` / `*_CLK` / `*_RES*` | 单端 50Ω | — | 非关键 |

★**复核方式 (必做, 不能跳)**:
1. KiCad 里打开板 → **板设置 → 叠层编辑器** → 选中差分网络类 → 读 KiCad 算出的 Zdiff
2. 把目标阻抗写进**网络类 (net class)** 的 `Diff Pair Impedance` 字段
3. 若 KiCad 算出的 Zdiff 偏离目标 ⇒ **改线宽/间距** (本板当前线宽 0.25mm / 净距 0.20mm) ⇒ 重新布线

★**当前还没做**: 网络类里的阻抗字段还没写, KiCad 也没法在本机跑 (BOARD_STACKUP 未暴露给 Python API)
⇒ ⇒ **这一项留到布线定稿 (赢家轮落盘) 之后做**, 不阻塞布线

## 4. 其它投板要求 (同一批要写进下单备注)

- 最小线宽 / 间距: 0.20mm / 0.20mm (本板 DRC 规则), 成品板厂按 4mil 能力做即可
- 过孔: 0.60mm / 0.30mm 钻 (常规), 0.50/0.30 (小焊盘过孔)
- ★**大电流等效铜厚 (`RAIL_DEMO_5V` → SoM 的 7 个 DCIN 脚, ≥2A)**:
  实测走线本身只有 0.25mm (★USB-C 座焊盘只有 0.3mm 宽 ⇒ 出脚只能这么细),
  ★**但已叠同网铜皮 (state/add_power_pour.py, F.Cu 铜皮 + 0.20mm 净距 + 热焊盘)** ⇒
  ⇒ ★**下单时请注明"5V 干道已叠铜皮, 请按等效铜厚 ≥0.5mm 核算, 不要按 0.25mm 走线核算"**
  ⇒ ★同网铜皮由 KiCad 填铜自动避让别的网 (实测加铜皮后 DRC 违规数不变)
- 阻抗控制: ★**需要板厂开阻抗控制选项** (差分线对不额外加价的话, 至少要保证叠层一致)
- 表面处理: ENIG (沉金) —— 高密度 BTB 焊盘 (0.4mm pitch) 必须 ENIG, 否则有焊接不良风险
- 阻焊桥: 本板出现过"阻焊桥"类 DRC 违规 ⇒ ★**要求板厂按 IPC-7351B 最小阻焊桥标准**
- 阻抗测试: ★要求板厂随货提供 **TDR 阻抗测试报告** (差分对抽测 ≥ 10%)
