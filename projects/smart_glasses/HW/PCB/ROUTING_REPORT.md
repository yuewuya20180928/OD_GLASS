## 1. 路由器规格 (★全部来自 `HW/PCB/LAYOUT_RULES.md` + `HW/PCB/STACKUP.md`)

| 项 | 实现 | 依据 |
|---|---|---|

| 信号层 | **L1 (F.Cu) → L3 (In2.Cu) → L5 (In4.Cu)**, 层偏好代价 0 / 0.6 / 1.8 | STACKUP: L2/L6 是完整 GND 平面 ⇒ 不走信号 |
| 换层 | 只在**相邻信号层**间换 (F↔In2 / In2↔In4) ⇒ 过孔只跨一层平面 | ★不跨 GND+电源双平面 (回流路径不断) |
| 线宽 | 信号 0.25mm / 电源 0.5mm / **BTB 出脚 0.2mm** | LAYOUT_RULES: SOM 输入 ≥2A ⇒ ≥0.5mm |
| 净距 | 0.20mm (KiCad 默认) + **0.07mm 栅格量化余量** | 单元中心采样 ⇒ 实际净距会少 ~半格 |
| 过孔 | 0.6mm 盘 / 0.3mm 钻 (环宽 0.15mm = KiCad 最小环宽) | — |
| 多焊盘网 | Prim 最小生成树排序, 逐个并入 (目标 = **最近的已连焊盘** ⇒ 启发式紧) | — |
| 差分对 | 先布 P ⇒ 建距离图 ⇒ N 在 P 的**走廊**里布 (软代价 0.45/格) ⇒ 同层同间距 | LAYOUT_RULES 差分 90Ω/100Ω |
| 长度配平 | 短的那根加**三角蛇形** (底边 ≤8mm) | 长度差 ≤0.13mm |
| GND | **L2 + L6 完整平面** (不分割) + 每个 GND 焊盘一根**下拉通孔** | ★L2/L6 不得在差分对下方被分割 |
| 密集焊盘出脚 | SoM BTB (0.4mm pitch / 0.2mm 焊盘) ⇒ **沿焊盘中心线的直线出脚** 1.2mm 后才允许横向偏 | 0.25mm 网格做不出 0.4mm pitch 出脚 |

### ★关键实现坑 (★下一轮直接复用, 别再踩)
1. **栅格原点必须全局一致** —— 焊盘栅格化与路径索引必须用同一个原点,
   否则焊盘的铜会摊到 3 个单元上 ⇒ **焊盘出不来线** (本轮踩过, 症状: 所有网 0 段)。
2. **KiCad 区域填充要"存盘后重读再填"** —— 同会话里加的走线/过孔还没进连通性缓存
   ⇒ 填充器以为平面"没连上任何东西" ⇒ 孤岛删除模式把**整个平面删空**
   ⇒ 焊盘的过孔全变 `via_dangling`。
3. **KiCad 区域填充实测**: 通孔 (F.Cu↔B.Cu) 能同时接上 **L2 与 L6** 两个平面
   (同层的 SMD 焊盘则接不上内层平面 ⇒ 必须靠过孔下拉)。
4. **没分配网络的焊盘 (SoM 400 脚里有一半没网) 同样是障碍** —— 不登记成障碍
   ⇒ 布线直接压过去 ⇒ 短路。
5. **离网格的"出脚直道"落铜后要再查一次已布走线** —— A* 的障碍图只避让新走线,
   避让不了"后来才出现的直道"。

## 3. ★投板前必须知道的 4 条 (★本轮查出来的, 不是推测)

### ① SoM BTB (0.4mm pitch) 的出脚物理上只能 0.2mm 线宽
- 焊盘 0.2mm 宽、0.4mm 间距 ⇒ 相邻焊盘间只剩 **0.2mm** ⇒ 任何 >0.2mm 的线都过不去。
- ⇒ **`LAYOUT_RULES` 写的"SOM 输入 ≥0.5mm 铜宽"在 BTB 出脚处做不到**:
  0.5mm 只能在**出脚之后的开阔区**用铜皮/并联铜条实现 (L3 局部电源铜皮 + 过孔阵列) —— **本轮未做**。
- ⇒ 本轮 `RAIL_SOM_DCIN` 出脚用 0.2mm, 其余段 0.5mm。

### ② USB-C 座 (J_USB_C) 现在用的是**通用 8 脚假封装**, 不是 GCT USB4105
- 网表里 footprint 写的是 "GCT USB4105 (16p)", 但板生成器画的是**单排 8 脚 0.5mm 间距**的通用封装。
- ⇒ 真实 USB4105 是 **2 排 × 8 列**, D+ = A6/B6 一列、D- = A7/B7 一列 —— 本板画不出这个逃线结构。
- ⇒ 本轮为此把 `J_USB_C` **旋转 90°** (焊盘排变成沿 Y 的一列) 让 D+/D- 能成对逃出;
  **★真投产前必须换成真实 USB4105 封装** (否则 D+/D- 阻抗/间距不可控)。
- ⇒ ★★**J_USB_C 不在板边** (fp 中心 x≈130.6, 板边 x=160) ⇒ **机械上插不了 USB 线** ——
  这是投板后必然返工的项, **需要 MECH 一起定板边位置**。

### ③ 差分对长度差本轮只做到 **~0.98mm** (口径 ≤0.13mm)
- 原因: `NET_USB_D_P_TYPEC` 与 `NET_USB_D_N_TYPEC` 各自还挂着**测试点 (TP)** 分支,
  两个 TP 相距 4.4mm ⇒ 两条线的**总线长**天然不等; 蛇形配平只能补到主干段。
- ⇒ 要达标 0.13mm: ① 把两个 TP 挪成对称位置; ② 或者只按**主干 (座→串阻)** 报长度差。

### ④ MIPI CSI/DSI 差分对本轮**基本没布出来** (可下轮继续)
- 卡点同上 (BTB 出脚) + 差分走廊没生效 (P/N 各自跑了很长的独立路径)。
- ⇒ 下轮: 打开"出脚直道"后重跑 + 给 CSI/DSI 对指定**主干焊盘对** (像 USB 那样)。
