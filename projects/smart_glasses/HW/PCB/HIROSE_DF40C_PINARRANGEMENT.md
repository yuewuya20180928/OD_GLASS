# Hirose DF40C-100DS/100DP 原厂资料核查 —— 脚号排布 + 推荐焊盘图

> **背景**: 我们板上的 4 组 100pin BTB 座 = **Hirose DF40C-100DS-0.4V(51)** (载板侧插座), 与 SoM 侧
> **DF40C-100DP-0.4V(51)** (针头) 配对。脚号排布与焊盘几何错一次 = 板子白打 ⇒ 逐项核到原厂件。
> ★**取证方式**: ① 原厂 **2D 产品图** (drawing_2d.pdf) ② 原厂 **3D STEP 模型** (逐点解析) ③ 原厂 **DF40 Series Guideline**
> (ETAD-H1015-00) ④ 原厂 **DF40 系列目录** —— 四份互证。

## 1. ★★ 推荐 PCB 焊盘图 (Recommended PWB pattern) —— **已定案, 两路互证**

| 量 | 值 | 来源 |
|---|---|---|
| 焊盘宽 (pitch 方向) | **0.2 ± 0.02 mm** | 原厂 2D 图直接标注; 目录同 |
| **两排焊盘内缘距** | **2.38 mm** (0/−0.05) | 原厂 2D 图直接标注 |
| **两排焊盘外缘总宽** | **3.78 mm** (+0.05/0) | 原厂 2D 图直接标注 |
| ⇒ **焊盘长 (跨排方向)** | **(3.78 − 2.38) / 2 = 0.7 mm** | 由上两行推出 |
| ⇒ **两排焊盘中心距** | **(3.78 + 2.38) / 2 = 3.08 mm** | 由上两行推出 |
| Pitch | **0.4 ± 0.02 mm** | 原厂 2D 图 / 目录 |
| 焊盘阵列总长 (100 位) | **C = 19.6 mm** | 原厂 2D 图 (49×0.4) |
| 禁布区 | 阴影区 (1.5 MAX 高度) 内禁走线 | 原厂 2D 图 / Guideline §1.2.1 |
| 连接器本体宽 | **3.38 mm** | 目录 "Width: 3.38mm"; 3D 模型 x∈[−1.69, +1.69] |

**★ 3D 模型独立互证** (`DF40C-100DS_step.zip` 逐点解析, 13454 个 CARTESIAN_POINT):
- 焊脚焊接面 (y≤0) 的 x 分布: **±1.39 与 ±1.69** 各含 100 个不同 z 值 ⇒ **端子在跨排方向宽 0.30mm, 外缘 = 3.38 (= 本体宽)**
- ⇒ 推荐焊盘覆盖端子且各留 0.2mm ⇒ 焊盘中心在 **±1.54** ⇒ **排中心距 3.08mm** ⇒ **与 2D 图完全一致** ✔✔

> ★★**我们此前把 "2.38" 当成了排中心距 —— 错了**。2.38 是**内缘距**; 真正的中心距 **3.08mm**。
> ⇒ **错这个值 ⇒ 连接器对插不上 / 焊盘对不上焊脚** ⇒ 已改 `HW/PCB/som_btb_params.json`
> (`row_pitch` 2.38 → **3.08**, `pad_l` 1.4 → **0.7**) 并重出板、重跑全部门禁 (DRC 仍 0)。

## 2. ★ 脚号排布 (pin arrangement)

| 项 | 结论 | 证据等级 |
|---|---|---|
| **pin1 在哪一端** | 四个座的 pin1/pin2 在各自座的 **+x 端**; 脚号沿 **−x 递增** (1/2 → 99/100, 跨距 19.6mm) | **Forlinx 官方手册底面尺寸图** (每座带 △ 丝印, 实测 △ 在 x=60.8 / 60.8 / 26.8 / 26.8) + 官方 OK3572-C 载板图 4 座位号在"逆时针 90°"下**唯一**对上 ⇒ 四重交叉验证 |
| **pin1 在哪一排** | **奇数脚 = y 小的那一排** (偶数脚 = y 大排) | **Forlinx 手册 §2.6.1 的 4 张引脚原理图** (EDA 符号: 左列 = 奇 1,3,5…99 / 右列 = 偶 2,4,6…100) + 底面尺寸图的 △ 落在 y 小侧 ⇒ 三重交叉验证, **4 个座结论完全一致** |
| **厂商怎么标 pin1** | ★**原厂 2D 产品图的俯视图左侧有三角形标记** (index 5 指向) ⇒ **Hirose 就是用 △ 标 pin1** | **原厂 2D 图** (产品图, 非包装图) |

> ★★**残余风险 (仍要实测一次)**: 原厂图上**有 △ 但没有用数字指出哪一脚是 1** ⇒ "△ = pin1" 与 "哪一排是奇数" 的组合
> 目前由 **Forlinx 官方手册两处 (底面尺寸图 + §2.6.1 引脚原理图) 的 4 座一致性** 支撑, 而不是原厂图直接标注。
> ⇒ ★**投板前必须实机验证一次**: 买 1 片 SoM, 在**底面**对 △ 端的第一根针打 GND (pin2 = GND ⇒ 0Ω 那根是偶数排),
> 再用万用表量 "SoM 的 pin1 ↔ 载板焊盘 1" 是否导通。**错一排 = 该座 100 根网络全部对调。**

## 3. ★ 两条必须显式化的前提

① ★**SoM 在主板上的摆放方位**: 现按 **0° (不旋转, SoM +x = 主板 +x)** ⇒ 才有"SoM 的 y 小排 = 主板的 y 小排"。
   ★**若改成旋转 90° 装** (像 Forlinx 官方 OK3572-C 载板那样), **排向必须跟着转**, 否则整座网络对调。
② ★**焊盘几何一律取 Hirose 原厂图 / 原厂 3D 模型**, **不得**用 Forlinx 底面尺寸图反推
   (底面图的外框实测 22.46×4.13mm 与 Hirose A×C 不符, 图上脚距 0.42mm 是栅格加粗)。
