## 4. 结论 (给老板的三条)

1. **按总分, 第一名是 RK3588 (瑞芯微, 79 分)**, 第二 RK3576 (74 分)。★但两者都卡在同一处: **封装进不了 15mm 板宽** ⇒ 走老板 18:55 授权的 "放宽结构宽度" 这条化解路径。
2. ★**如果只有一款能进镜腿, 那是 RV1126B (封装 14×14mm)**, 但它算力只有 3 TOPS 且无 DP ⇒ 端到端 [推算] ~68ms (容差内) + 只能走 DSI ⇒ **它是"形态派"而不是"性能派"**。
3. ★**必须先补的实测 (决定排名能不能定)**: ①买 RK3576 核心板打 S5 (≤20.33ms) 与 SoC 域功耗 ⇒ **同时解掉 3.5 和 3.6 两项的 [推算]/[0数据]** ②向原厂书面确认 1080P@60 与 JBD 光机的 DSI/DP 匹配。
