## B1 结论摘要 (每条带数字)

1. **充电 IC 必须是开关型 (buck), 不能用线性** —— 线性方案在 VBUS 5V / VBAT 3.5V / 1A 下耗散 **(5.0-3.5)×1.0 = 1.50W > 0.8W 上限**; 要压到 0.8W 以内, 线性充电电流上限只有 **0.533A** (< 1A 指标) `[推算]`。→ 选 **TI BQ25896** (1S 开关 buck 充电, 3A 能力, I²C 可编程, 集成 11mΩ BATFET) `[官方]`。
2. **Type-C PD sink 必须独立加一颗无固件 PD 控制器** —— 只挂 Rd 5.1k 时, 电流由**源端 Rp** 决定 (500mA/900mA/1.5A/3.0A), **≥1A 不可控** → 选 **TI TPS25730** (PD3.1, **sink-only, 无需固件开发**, 引脚 strap 配置, 内置 20V/5A 电源通路, 支持 dead-battery) `[官方]`。
3. **电池保护用 BQ2970 + 2 颗外部 N-MOS** —— BQ2970 是 1S 保护控制器, OVP 阈值可选 **4.275V** (最接近 1S 标准 4.25V), 带 OCD/SCP, **Iq 4µA**, 6 脚 DSE 1.5×1.5×0.75mm `[官方]`。
4. **SoC 域 DC-DC 额定 ≥2A** —— 0.9W ÷ 0.8V × 1.5 = **1.69A** → 选 **TPS62130A** (3A, 3-17V in, 0.9-6V out, 3×3 QFN-16, DCS-Control, Iq 17µA) `[官方]`。
5. ⚠️ **"用输出电容吸收电压跌落" 这条要做不了** —— 要扛住帧内 **1.667ms** 的空档需 **C = 10.0 mF**, 陶瓷/钽都做不到 → **必须靠 DC-DC 的动态负载指标 + 环路带宽, 加电容无解** `[推算]`。
6. **外设域 LDO 用 TPS7A20** —— 噪声 **7µVrms**, PSRR **60dB@100kHz**, 300mA, 固定输出 0.8-5.5V 共 27 档, X2SON 封装 `[官方]`。选它的理由是**噪声指标** (sensor 电源纹波 → 图像横条, EMC R-09), 不是电流。
7. ★ **sensor 拍板: 豪威 OmniVision OV04C10** —— 唯一有**官方功耗数**的候选 (active **155mW**), 且 **120° 鱼眼镜头包络装得下** (镜头总高 **4.55mm ≤4.6**, 模组沿光轴 **5.85mm ≤5.9**); AR0234CS 同 FOV 需镜头总高 **5.01mm >4.6** → **机械硬否决** `[推算]`。
8. **Type-C 母座**: 16P 沉板型, 本体 **8.94×6.5×3.16mm**, 4 脚插板, 10000 次插拔 (HANGHONG 航宏, 沉板深度 0.8/1.0/1.6/2.10 四种) `[官方 厂商页]`; 面板开孔 **9.5×3.6mm** (MECH) → **沉板深度 ≤ 壁厚-1.5mm**, 需结构给壁厚定值。

**3.1.1 为什么不能用线性充电芯片** (南芯 SC70563 线性充电芯片 VIN 4.5-6V `[官方]` 就是被这条排除的)

```
线性充电: P_IC = (VBUS - VBAT) × I_CHG
  最坏工况 (电池刚接上, VBAT=3.5V):
    I=0.5A → 0.750W  (刚好不超)
    I=1.0A → 1.500W  ❌ 超 0.8W
  要满足 P≤0.8W: I ≤ 0.8/(5.0-3.5) = 0.533A  ❌ 达不到"≥1A"
  只有 CV 末期 (VBAT→4.2V) 才降到 0.800W —— 那是充电快结束的时候, 没有意义
```
→ **开关型是唯一解**。

**3.1.2 开关型的耗散账**

```
η=90% (典型):  P_IC = 5V × I × (1-η)
   I=1.0A → 0.500W  ✅ (余量 0.30W)
   I=1.5A → 0.750W  ✅ (余量 0.05W, 太贴边)
   I=2.0A → 1.000W  ❌
η=92%:          I=1.5A → 0.600W  ✅ (余量 0.20W)
```
→ **推荐充电电流 1.0A (P=0.5W), 上限 1.5A 且按 η≥92% 选型**。留 0.3W 余量给充电板 (25×10mm 小板, 散热面积小)。

**3.1.3 充电时间 vs 电池档位** (假设 CC 段恒流 + CV 段约 0.5h)

| 电池 | @1.0A | @1.5A | 空间后果 |
|---|---|---|---|
| 340mAh | 0.34+0.5 = **0.84h** | 0.73h | 镜腿 7.3mm ✅ |
| 575mAh | 0.58+0.5 = **1.08h** | 0.88h | 镜腿 8.7mm ⚠️ |
| 675mAh | 0.68+0.5 = **1.18h** | 0.95h | 镜腿 11.2mm ❌ **形态否决** |

→ **1.0A 充电 + 575mAh 电池 = 1.08h 充满**, 体感可接受; **1.5A 只能省 12 分钟, 却把耗散从 0.5W 推到 0.75W** → **推荐 1.0A**。

**4.1 额定电流怎么定** (算式)

```
NPU 640×640 INT8 单帧 ≈15ms @60fps → 占空比 15/16.67 = 90%  (近乎连续, 非稀疏突发)
SoC 域功耗推算 0.9W (tracker §3.4 区间 0.75-1.22W 取中)
  @V_core=0.8V → I_avg = 1.125A
  峰值裕量 ×1.5        = 1.688A
  → 额定 ≥2.0A → 选 3A 档 (TPS62130A)
```

**4.2 ⚠️ "输出电容吸收电压跌落" 不成立 —— 必须纠正这条常见说法**

```
若指望电容扛住帧内空档:
  NPU 推理 15ms, 帧周期 16.667ms → 空档 1.667ms
  C = ΔI × Δt / ΔV = 0.3A × 1.667ms / 50mV = 10.0 mF   ← 陶瓷/钽都做不到
=> 电容只能吸收【环路响应时间(µs 级)】的台阶, 扛不住【帧周期(ms 级)】的负载变化

阻抗压降核算 (ΔV ≈ ΔI / (2π·fc·C)):
  fc= 50kHz: 22µF→43mV ✅  47µF→20mV ✅  100µF→10mV ✅
  fc=100kHz: 22µF→22mV ✅  47µF→10mV ✅  100µF→ 5mV ✅
  fc=200kHz: 22µF→11mV ✅  47µF→ 5mV ✅  100µF→ 2mV ✅
=> 正确做法:
  ① DC-DC 选型时把【负载阶跃动态电压偏移】写成硬指标 (如 "2A→0A 阶跃, ΔV<50mV")
  ② 输出电容: SoC 球位正下方 2×22µF (0402/0603 高频去耦) + 1×47µF (0805 X5R)
                + 1×100µF (聚合物/钽 bulk)
  ③ 核心轨铜箔用平面层 + 过孔阵列, 不逐球走线
```

### 6.4 镜头配套算式 (120° 鱼眼 / 等距) —— 可复现

```
等距鱼眼: r = f·θ  →  f = (d/2)/θ,  θ = 60° = 1.047198 rad
垂直半视场 = (H/2)/f
前组通光口径 y_c = f·θ/2

OV04C10  (2688×1520 @1.998µm):  W=5.3706 H=3.0370  d=6.1698
   f = 3.0849/1.047198 = 2.9459mm
   垂直半视场 = 1.5185/2.9459 = 29.53°      俯角 25° 余量 +4.53° / 28° +1.53° / 32° -2.47°
   y_c = 2.9459×1.047198/2 = 1.542 (⌀3.08, 取 ⌀4.0-4.5)
   镜头总高 = 4.55 × (2.9459/2.9459) = 4.55mm   ≤4.6 ✅
   模组沿光轴 = 4.55 + 1.3(封装占位) = 5.85mm   ≤5.9 ✅ (≤ S3 硬要求 6.0 ✅)

AR0234CS (1920×1200 @3.000µm):  W=5.7600 H=3.6000  d=6.7925
   f = 3.3963/1.047198 = 3.2432mm   (长 10.1%)
   垂直半视场 = 1.8000/3.2432 = 31.80°      俯角 25° 余量 +6.80° / 28° +3.80° / 32° -0.20°
   y_c = 3.2432×1.047198/2 = 1.698 (⌀3.40, 取 ⌀4.0-4.5)
   镜头总高 = 4.55 × (3.2432/2.9459) = 5.01mm   > 4.6 ❌
   模组沿光轴 = 5.01 + 1.3 = 6.31mm   > 5.9 ❌  (> S3 硬要求 6.0 ❌)
=> 同一 FOV、同样的镜头结构, AR0234CS 的镜头比 OV04C10 高 0.46mm —— 结构给的高度包络装不下
```

**结构包络出处** `[推算]`: `HW/LENS_SELECTION.md` §B4.3 / §B4.4 —— 镜筒外径 ⌀6.0-6.5mm、镜头总高 3.7-4.6mm、模组沿光轴 5.0-5.9mm (S3 硬要求 ≤6.0mm)、加厚区净空 ⌀7.5mm × 轴向 ≥6.5mm。
