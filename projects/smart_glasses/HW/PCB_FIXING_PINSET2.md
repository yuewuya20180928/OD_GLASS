## 2. 为什么必须改 (机械复算)

### 2.1 基准数据

| 特征 | 值 | 依据 |

| 板框 | 60.00 × 15.00mm (6层 1.00 / 4层 0.80) | [决策] ISS-105 / 老板 10-27 |
| SoC 封装体 (FCCSP 8×10mm) | X∈[21.00, 31.00], Y∈[3.50, 11.50] | [官网] 8×10mm + 板居中 |
| **SoC 逃线带** (外扩 0.80/边) | **X∈[20.20, 31.80], Y∈[2.70, 12.30]** | [推算] `HW/SOC_PIN_BUDGET.md` (ISS-081) |
| 器件带 (每边) | 2.70mm | [推算] (15 − 8)/2 − 0.80 |
| 器件距板边 | ≥0.80mm | [既有] MECH_BUDGET §5.1 |
| J_CHG 座体 keep-out | X∈[0.00, 3.00], Y∈[4.25, 10.75] | [推算] 10p 排线居中 Y=7.50 ±3.25; 座体 A/B/C 尺寸页 **未核** [0数据] |

### 2.2 老口径失效复算 (3/3 孔压带)

> 复算脚本 `HW/pinset2_check.py` ②节。老口径只给了「孔心到板边 2.50mm」没给 X, 我按**最有利假设** (老孔就落在 SoC 的 X 段内, 因为 v1.1 的骨架/散热垫都在 SoC 下方) 复算:

| 老孔 | 位置 | 孔径 | 压逃线带 X | 压逃线带 Y | 重叠面积 | 判定 |
|---|---|---|---|---|---|---|
| M1 (M1.2 螺钉) | (25.00, 2.50) | ⌀1.4 | 1.40mm | **0.50mm** | 0.70mm² | ❌ |
| M2 (M1.2 螺钉) | (25.00, 12.50) | ⌀1.4 | 1.40mm | **0.50mm** | 0.70mm² | ❌ |
| D0 (⌀2.0 H7 销) | (25.00, 7.50) | ⌀2.0 | 2.00mm | 2.00mm | 4.00mm² | ❌ 完全落在带内 |

**结论**: 15mm 板宽把老孔从「完全不可放」变成「勉强放、仍压 0.50mm」——**加宽不解这个问题** ⇒ 必须沿板长 (X) 移出 SoC 段。

### 2.3 ★ 定位链: 打印公差不进链 (解 A 的核心)

```
定位链 = 骨架铣削面 (平面度 ≤5µm) + ⌀2.0 H7 销 (⌀2.0 h6, 径向间隙 0.008-0.041mm)
        ⇒ PCB 相对骨架的位置重复性 ≤ 0.041mm + 5µm ≈ 0.046mm
打印件 (FDM ±0.30mm) 只提供 ⌀2.4 间隙孔 (销头让过) + ⌀1.6 螺钉过孔 ⇒ **不进定位链**
```

> ★ **为什么 P2 用菱形销而不是圆销**: 两个 ⌀2.0 H7 圆孔同时约束 X = **过定位** (装配时销与孔的微小干涉会把板顶歪, 或把销压进板里)。标准做法: 主销圆 (定 X+Y+θz), 副销菱形 (对边 1.94 ⇒ X 向单边让位 0.030-0.041mm, 只定 Y)。**菱形销不增加 PCB 任何成本** (孔还是圆孔), 只改骨架上那颗销的形状。
> **降级方案 (若骨架加工方不接菱形销)**: P2 孔改成 **⌀2.0 + X 向 0.10mm 长圆孔** (腰形孔, 腰长 0.10) ⇒ 同样消除过定位, 但 PCB 要多一道腰形铣孔工序。

### 3.4 ★ 装配顺序 (与热路强相关, 必须写进工艺卡)

1. 骨架压装 **2 颗 ⌀2.0 H7 销** (P1 圆销 / P2 菱形销, 压装孔 ⌀2.0 H7, 销肩埋入骨架 ≥1.5mm, 露头 ≥3.0mm);
2. 骨架加工 **2× M1.2 攻丝孔** (或自攻底孔), 位置与 S1/S2 对位;
3. PCB 套销 (P1 定位 → P2 定 Y);
4. **2 颗 M1.2 螺钉从皮肤侧穿入**: PCB ⌀1.4 过孔 → 骨架攻丝孔; 螺钉头落在 **PCB 皮肤侧 ⌀2.4×0.6 沉孔** 内, **只压 PCB 皮肤侧面**;
5. 装 0.3mm 导热垫 (SoC 投影) + 石墨片 + 上壳 (上壳 **2×⌀2.4 + 2×⌀1.6** 让过孔, 销头由上壳限位防脱);
6. 隔热垫 (**2 处 ⌀3.0 让位孔** 给螺钉头) → 下壳合上。

> ★ **第 4 步是本单的热学硬约束**: 螺钉头**必须**落在 PCB 皮肤侧的沉孔里, **严禁**压在皮肤侧下壳或任何承力面 —— 一旦金属直接跨过 0.50 隔热垫 + 0.30 空气隙, 就等于给"骨架 → 皮肤"加了一条零阻抗旁路, 与 ISS-042 解 A 刚立的「骨架不得进电池段」是同一类错误 (92.5%→95.7% 那种)。

> ★ **骨架形状硬约束 (我给 mech 的输入)**: 骨架在 SoC 段必须满板宽 15.00mm (横向扩散通道), 但**不能整条 60mm 都满宽** —— 那要 4.86g/对, 整机重量账 (48.9-74.0g) 直接崩 ⇒ **必须做台阶形或 U 形/槽形截面**。这是结构侧的形状决策, 我只给"哪一段必须多宽"的硬约束。
