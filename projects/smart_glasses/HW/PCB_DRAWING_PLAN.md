## 3. ★★ D3 叠层与阻抗规则（F6 的定案 —— 打样前必须定）

**定案：6 层**（依据：公开 RK357x 载板设计通则 + 本板只跑 1×MIPI-CSI(2-lane) + 1×MIPI-DSI(4-lane) + 电源 + USB-C + 调试）

| 层 | 用途 |
|---|---|
| L1 | 信号（元件面） |
| L2 | **GND（完整平面）** |
| L3 | 信号 + 局部电源（1.2/1.8/2.8V 分区） |
| L4 | **电源平面（3.3V / 5V 分区）** |
| L5 | 信号 |
| L6 | **GND（完整平面）** + 丝印 |

**阻抗规则（写进 D3 + D4 的 net class）**:
| 网络 | 目标 | 约束 |
|---|---|---|
| **MIPI CSI（camera）/ MIPI DSI（screen）** | **100Ω 差分** | ★**差分对内间距固定**（按板厚/介质算），★**对间 ≥3× 线宽**，★**两侧下方 L2/L6 必须是完整 GND 平面**（不跨分割） |
| USB 2.0 (Type-C) | 90Ω 差分 | 同上原则 |
| I2C / MCLK / RESET | — | 常规；★**MCLK 与 CSI 时钟对**分开走，避免串扰 |
| 电源 | — | ★**3.3V/5V 大电流路径按载流量算宽**（SOM 输入 ≥2A ⇒ ≥0.5mm 铜宽或加过孔阵列） |

★**为什么必须在画图前定**: ★**层数与介质一改 ⇒ 阻抗全变 ⇒ MIPI 差分跑不起来 ⇒ 板子白打**（这就是 F6 的性质，和 EN 同级）。
