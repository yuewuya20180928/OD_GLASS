## §1 (a) SoC 侧最小引脚集 —— 逐项列出功能 → 数量 → 依据

### §1.1 先说结论: **45-50 脚够用, 而且是"宽裕地够用"**

| 配置 | 定义 | **需要的球数** | 其中 信号+电源 | 其中 GND | 相对 45-50 目标 |
|---|---|---|---|---|---|
| **C-min** | 最省: 单一显示路径 + 内置启动存储 + 内部 RC 时钟 + 1 键 1 灯 | **41** | 35 | 6 | ✅ **41 ≤ 45 → 够** |
| **C-base** | **设计基线 = 我们真的会投板的那一版**: 双显示路径 (DSI / DP+桥接) 都留焊盘 0Ω 二选一 | **57** | 49 | 8 | ⚠️ 57 > 50 → 见 §1.4 选型条款 |
| **C-max** | 最坏: 双显示 + 外挂 SPI-NOR + 外置晶振 + 4 键 3 灯 + 全预留 + 双 I2C | **91** | 79 | 12 | ❌ 91 > 50 → 见 §1.4 |

> ★ **一句话**: **"45-50 脚"这个目标在 C-min (41) 下成立, 且 C-base (57) 距离它只有 7 球 —— 这 7 球就是"双显示路径 hedge"的代价, 一颗桥接芯片换 11 个 SoC 球, 换来的是"原厂不回信也能开机"**。
> 91 球 (C-max) **不是我们要做的板子**, 它是"什么都不砍、什么都不省"的数学上界, 用来划定**选型条款的球数下限**。

### §1.3 为什么 C-base (57) 也能过 —— 双显示路径 hedge 的成本账

**问题**: 原理图按 `AGENTS.md` 硬件评审 checklist 硬要求, 必须**同时兼容"原生 DSI"和"DP + 桥接芯片"两种接法**。这两条路在 SoC 侧是不是要 6 + 11 = **17 个显示球**?

**答**: **是的, 但这 17 个球不是"我方需求", 是"原厂球位"** —— 我方在 `HW/SCHEMATIC_REFDIE.md` §4.2 已经把两条路设计成**互斥** (0Ω 选路)。所以:

- **SoC 侧显示球数**: 取决于 SoC **有没有** DP TX。若只有 DSI → **6 球** (2-lane); 若只有 DP → **11 球**; 若**两者都有** → 17 球。
- **我方无法选择这一项** → 只能把它当**选型条款** (要求 ≥ 72 球, 见 §1.4), 而不是当"我方需求"去砍。
- ★ **这 17 球里有 11 球 (DP) 是"保险费"**: 交 11 个球的封装空间 + 一颗桥接芯片 (QFN 6×6 + 周边 ≈ **52mm²** 板面积, `HW/PCB_FORM_FACTOR_RECHECK.md` §5.3), 换"原厂不回信 / Q16 无结论时仍能出图开机"。**在 ISS-081 的背景下 (原厂失联预案) 这笔保险值得买**; 若 Q16 在 10-29 前回信并确认原生 DSI, **立刻可以省 11 球 + 52mm² 板面积**。

### §1.3b ★ hedge 的真实代价不只是"球数 + 板面积" —— 它还加功耗, 而功耗已经是红线超标项

| 成本项 | 数值 | 依据 |
|---|---|---|
| SoC 侧球数 | **+11 球** (DP TX 4-lane + AUX + HPD) | 本文 §1.2 第 7 行 |
| 板面积 | **+52mm²** (QFN 6×6 + 串阻/AC 耦合周边) | `HW/PCB_FORM_FACTOR_RECHECK.md` §5.3 `[推算]` |
| **额外器件** | **+1 颗桥接芯片** | 同上 |
| **★ 额外功耗** | **+100-300mW** (桥接芯片) | 本人上一轮答复 (`state/fragments/hw.yaml` `pcb_outline_confirm`) `[推算]` |
| 现状功耗基线 | 满载 **1.22W** (SoC 500-900mW + 桥接 100-300mW + 其余) | `MECH/MECH_BUDGET.md` §2.6 `[推算]` |
| **皮肤侧后果** | 现状 **96.1°C** vs ISO 13732-1 红线 **43°C**; 且 **43°C 红线只允许贴皮肤镜腿持续 0.16-0.21W**; 方案 C (0.23W) 仍 **46.5°C** 超标 | `MECH/MECH_BUDGET.md` §2.6 `[推算]` |
| 板厚后果 | 6 层 **1.0mm** vs 4 层 0.8mm → **镜腿厚度 +0.2mm** | 本文 §2.2 Q2 + `MECH/MECH_BUDGET.md` §2.2 `[推算]` |

> ★ **诚实结论**: **买 hedge = 多 11 球 + 52mm² + 一颗芯片 + 100-300mW**, 而**散热侧已经是 ❌ 不达标** (96.1°C vs 43°C 红线)。
> → 所以 B5.1 的 PM 裁决**不是纯粹的"买保险"**, 它是**在"能出图"和"更超红线"之间做取舍**。我仍建议买 —— 因为**没有板就没有样机, 没有样机就没有实测散热数据**, 而现在纠结的 100-300mW 是推算值; 但**这条必须让 PM 知道, 不能只算球数不算功耗**。
> → 反过来也支持 §5.1 请求 1 (**板宽 15mm**): 15mm 让 SoC 横向热扩散通道 **2mm → 3.5mm (+75%)** (`HW/PCB_FORM_FACTOR_RECHECK.md` §5.2) → **同一个动作同时缓解逃线容差和散热**, 是一石二鸟。

## §2 (b) 8×10 FCCSP 球数上限 + 逃线可行性 (pitch 0.3 / 0.4 / 0.5 三档)

### §2.1 球数: 我方需求 vs 封装能提供

> ★ **先纠正一个可能的误解**: **封装球数不是我能选的, 是厂商定的**。所以"8×10 FCCSP 能放多少球"只能给**上界区间**, 不能给结论。真正的问题应该反过来问: **"我方需要 41 / 57 / 91 球, 8×10 FCCSP 至少有多少球?"** —— 答案见 §1.4 的 P-2。

| pitch | 满阵列 (理论上界) | 外围 3 圈 + 中心稀疏 | 外围 2 圈 | **外围 1 圈 (最保守)** | vs C-base 57 | vs C-max 91 |
|---|---|---|---|---|---|---|
| **0.50mm** | 16×20 = **320** | 180 | 128 | **68** | ✅ 够 | ❌ 不够 |
| **0.40mm** | 20×25 = **500** | 234 | 164 | **86** | ✅ 够 | ❌ 不够 |
| **0.30mm** | 26×33 = **858** | 318 | 220 | **114** | ✅ 够 | ✅ 够 |

`[推算]` (脚本: 满阵列 = floor(8/p)×floor(10/p); 圈层 = 逐层扣内圈)

| 结论 | 数字 |
|---|---|
| **最保守封装排布 (p=0.5 外围 1 圈) = 68 球** | 68 |
| C-min **41** 球 vs 68 | ✅ **装得下**, 余量 1.66x |
| C-base **57** 球 vs 68 | ✅ **装得下**, 余量 1.19x |
| C-max **91** 球 vs 68 | ❌ 装不下 → 必须走选型条款 P-2 (≥112 球) |
| 满阵列 p=0.5 上界 320 vs C-max 91 | 余量 **3.5x** |

> ★ **球数结论: 封装/球数是【非风险】**。理由是**双向**的:
> ① **下界方向**: 我方最省 41 球, **任何**合理的 8×10 FCCSP 排布 (哪怕只有外围 1 圈 68 球) 都装得下 → **不存在"球不够"**;
> ② **上界方向**: 满阵列 320 球 (p=0.5) 远大于 C-base 57 球 → **球多是厂商的事, 不是我方的约束**; 多出来的球对我们是**好事** (多 GND / 多散热 / 多备用 GPIO), 不是风险。
> ③ **唯一例外**: 若坚持 C-max (91 球, 什么都不砍) → 需选型条款 P-2 兜住。

### §2.2 逃线可行性: 需要 via-in-pad 还是交错? 6 层够不够?

#### 逃线模型 (与 `HW/PCB_FORM_FACTOR_RECHECK.md` §5.1 同一套几何)

```
逃线带/边 (从封装外廓量起) = p/2 + 0.05(阻焊桥余量) + L(短走线长)
                             + (R-1) × 行距 + 过孔盘半径
    R    = 过孔排数 (单排放不下就加排)
    行距 = 过孔盘直径 + 0.05 (径向行间电气间隙)
同排相邻过孔中心距 = 球心距 p  ->  同排净间隙 = p - 过孔盘直径
```

#### 三档结论

| pitch | 工艺 | 同排过孔净间隙 | **via-in-pad?** | 单排逃线带/边 | **6 层够不够** |
|---|---|---|---|---|---|
| **0.50mm** | 常规机械钻 0.20mm | 0.100mm ✅ | **不需要** → 交错 dog-bone 即可 | **0.80mm** | ✅ **够** (6 层舒服, 4 层勉强) |
| **0.40mm** | 常规机械钻 0.15mm (需厂确认良率) | 0.100mm ✅ | **不需要** → 交错 dog-bone 即可 | **0.70mm** | ✅ **够, 但只能取 6 层** (4 层无解, 见下) |
| **0.30mm** | 激光微孔 HDI + 树脂填孔/盖帽 | 0.100mm ✅ | ★**被迫需要** | **0.55mm** | ❌ **不满足** —— 层数数字够 (1+N+1=6) 但**工艺类别破了**: HDI 单价 2-3x、交期 +1-2 周、需激光微孔+树脂塞孔产线 → **破"4-6 层常规刚性板"锁死** |

#### ★ 直接回答任务里的三个问

**Q1: 0402 / 0603 (焊盘 1.0-1.6mm) 需要 via-in-pad 还是交错?**
> **答: 交错 (staggered dog-bone), 不需要 via-in-pad** —— 前提 **pitch ≥ 0.40mm**。
> - 几何依据: 同排相邻过孔中心距 = 球心距 p, 净间隙 = p − 过孔盘直径 = **0.100mm** (三档都是), **≥ 0.075mm 最小电气间隙** ✅ → 单排过孔阵列放得下, 交错即可分流。
> - 过孔占用率 (C-base 57 球): p=0.5 → 逃线带 28.8mm², 过孔占 **7.8mm² = 27%**; p=0.4 → 25.2mm², 4.4mm² = **17%** → **阵列有空间, 不需要塞 via-in-pad**。
> - **via-in-pad 只在 p=0.30mm 被迫需要** —— 而那时已经因为 HDI 被一票否决了。**所以"via-in-pad"不能进我们的设计前提, 它是选型条款 P-1 的排除依据。**

**Q2: 6 层够不够?**
> **答: 够, 但 6 层是目标, 4 层不是安全下限。** (与 `HW/PCB_FORM_FACTOR_RECHECK.md` §6.3 结论一致, 本文用最新 netlist 重算)
>
> **实测** (`HW/netlist_v1.csv`, 347 数据行): 触到 SoC 的 net **62** 个 / 全板 **152** net / 器件 146 颗 + ~42 未画入 = **~190 颗**。高速差分 **4 组**: CSI **12** (含 MCLK/RESET/上拉) · DSI **10** · DP **8** · USB2 **2**。
>
> | 叠层 | 信号层 | 高速怎么分 | 电源逃线 | 判定 |
> |---|---|---|---|---|
> | 4 层 L1sig/L2GND/L3PWR/L4sig | 2 | 4 组挤 2 层 → DSI 只能与 CSI 共层 → 长度匹配/串扰无余量 | 电源球 L1→L3 要盲孔 (4 层盲埋孔贵且少厂做) 或割裂 L2 地平面 (伤回流) | ❌ 不推荐 |
> | 4 层 L1sig/L2GND/L3GND/L4sig | 2 | 同上 | 无电源平面 → 2A 级大电流只能走粗线 | ❌ 电源完整性不合格 |
> | **6 层 L1sig/L2GND/L3sig/L4PWR/L5GND/L6sig** | **3** | DP→L1 (SoC 旁短距) · CSI→L3 (ref L2) · DSI→L6 (ref L5) · USB2→L1/L3 局部 | 电源球 L1→L4 盲孔 (6 层盲孔 = **常规工艺** ✅) · 地球过孔阵列打到 L2 | ✅ **目标叠层** |
>
> ★ **4 层只有在"砍掉 DP 出口 (少 1 组高速) + 无 USB PHY (再少 1 组) + 存储外移"同时成立时才可能** —— 而这三条全都取决于 Q16 / 卡点 #10 / 卡点 #6, **都不在我手上**。所以**先锁 6 层**, 等 Q16 回来再决定要不要为成本降到 4 层。6 层板厚 1.0mm (vs 4 层 0.8mm) → **镜腿厚度 +0.2mm** (需报 mech-lead, 见 B4)。

**Q3: 器件带还放得下 0402 / 0603 吗?**
> **答: 12mm 板宽下放得下 0402 (两种朝向都行); 0603 只能长轴平行于逃线带摆, 垂直放不下。**
> ★ **去耦电容容量够**: 0402 按 1.0mm 间距沿封装周长 (**2×(8+10) = 36mm**) 单排最多可放 **36 颗**; 而 SoC 电源球只需 **5-8 颗** → 每球配 1×0402 0100 + 1×10nF (规则 R5) 需要 **10-16 颗** → **单排就够, 不用翻底面** `[推算]`

| pitch | 排数 (C-base 57 球) | 逃线带 | 12mm 板宽余带 | 0402 (0.5mm 深) | 0603 平行 (0.8mm 深) | 0603 垂直 (1.6mm 深) |
|---|---|---|---|---|---|---|
| 0.50mm | 1 排 | 0.80mm | **1.20mm** | ✅ | ✅ | ❌ |
| 0.40mm | 1 排 | 0.70mm | **1.30mm** | ✅ | ✅ | ❌ |
| 0.30mm | 1 排 | 0.55mm | **1.45mm** | ✅ | ✅ | ❌ |

> ★ **但这不是本文认为的真风险 —— 真风险是 C-max (91 球) 触发第二排过孔**:

| 情形 | 排数 | 逃线带 | 12mm 板宽余带 | 0402 | 0603 平行 | 0603 允许的逃线带误差上限 |
|---|---|---|---|---|---|---|
| C-base 57 球 @ p=0.5 | 1 | 0.80mm | 1.20mm | ✅ | ✅ | +0.20mm |
| C-base 57 球 @ p=0.4 | 1 | 0.70mm | 1.30mm | ✅ | ✅ | +0.30mm |
| **C-max 91 球 @ p=0.5** | **2** | **1.25mm** | **0.75mm** | ✅ | ❌ | **−0.25mm (已经不够)** |
| **C-max 91 球 @ p=0.4** | **2** | **1.05mm** | **0.95mm** | ✅ | ❌ | **−0.05mm (已经不够)** |
| C-max 91 球 @ p=0.3 | 1 | 0.55mm | 1.45mm | ✅ | ✅ | +0.45mm |

> → **12mm 板宽对逃线带的误差容忍度只有 0.20-0.30mm** (p=0.4/0.5, C-base)。这就是 §3 里说的**真风险在"板宽/面积"轴, 不在"球数"轴**的直接证据。
> → **15mm 板宽下**余带 2.25-2.80mm, 误差容忍度 **+1.25mm** → 宽裕。

## §3 (c) 明确结论: 封装/球数/逃线 是风险还是非风险? 真正剩下的风险是什么?

### §3.1 判决

| # | 维度 | 判决 | 依据 |
|---|---|---|---|
| 1 | **封装尺寸 (8×10 FCCSP)** | 🟢 **非风险** | 我方需求 41-57 球 vs 最保守封装 68 球 → **装得下** (§2.1) |
| 2 | **球数** | 🟢 **非风险** | 满阵列上界 320 球 vs 需求 41-91 → 余量 3.5x~7.8x; **球多是厂商的事, 对我方是好事** (§2.1) |
| 3 | **逃线 (p≥0.4)** | 🟢 **非风险** | 交错 dog-bone 足够, **不需要 via-in-pad / 不需要 HDI**; 12mm 板宽下 0402/0603 都放得下; 逃线过孔占用率仅 17-27% (§2.2) |
| 4 | **逃线 (p=0.30)** | 🔴 **风险 (但已被选型条款 P-1 排除)** | 被迫 HDI → 破"4-6 层常规刚性板"锁死 → 一票否决。**结论: p=0.30 不接受, 换 SoC** |
| 5 | **层数 6 层够不够** | 🟡 **够, 但 4 层不是安全下限** | 4 组高速 + 62 个 SoC net + ~190 器件 → 4 层无解, **先锁 6 层**, 成本 +0.2mm 板厚 (§2.2) |
| 6 | **12mm 板宽对逃线带误差的容忍度** | 🟠 **真风险 (量级小)** | 只有 **0.20-0.30mm**; 若逃线带比模型宽 0.3mm 以上, 0603 就放不下 → **落选 15mm 板宽比加器件面积便宜** (§2.2) |

### §3.2 ★ 真正剩下的风险 (排完序, 前 3 条与 ISS-081 无关, 是继承来的)

| 序 | 风险 | 性质 | 为什么 ISS-081 解决不了 | 归谁 / 怎么解 |
|---|---|---|---|---|
| **R-1** | **引脚 → 功能的映射 (球位图)** | 🔴 **阻塞, 不可自证** | **本文给的是"需要几个球", 不是"哪个球是哪个功能"**。79 个 Sxx 功能位号至今无一有真实球号 → **原理图 L4 画不了, PCB 布不了, 投不了板** | **原厂** (球位图 + 引脚表) → 邮件已发 → **经项目总工**。**结构手段兜底**: 改用 **ISS-084 SoC 载板化** (把 SoC + 逃线搬到独立载板, 载板可重投而不动主板) + **ISS-083 模组线** (模组厂出版引脚定义表 → 直接绕开球位图依赖) |
| **R-2** | **显示 TX 类型 (Q16)** | 🔴 阻塞 | 决定 ① 用不用桥接芯片 (11 个 SoC 球 + **52mm² 板面积**) ② 6 层能不能降到 4 层 (省 0.2mm 板厚) ③ 高速组是 4 组还是 3 组 | **原厂** → 经项目总工 |
| **R-3** | **电源域划分 / 电流上限 (TBD-02)** | 🔴 阻塞 | 决定电源球数 (本文 5-8 球是**估计**) + **每个电源球的去耦电容数** (直接决定 SoC 周围的器件带占多宽 → 与 §2.2 的 1.20mm 余带抢空间) | **原厂** → 经项目总工 |
| **R-4** | **板宽 12mm 的余量只有 0.20-0.30mm** | 🟠 中 | 逃线带宽度是 `[推算]`, 误差带未标定 → **12mm 板宽经不起一次"球位图到手后发现电源球布局更挤"** | **hw-lead + mech-lead**: 要么锁 **15mm 板宽** (余量 +1.25mm, 但镜腿根部净高 +3mm 顶上限), 要么**第一台样机直接上 6 层 + 0201 化 + 砍 BOM** 换板长 |
| **R-5** | **p=0.30 被排除 → SoC 选型池可能没有了** | 🟠 中 | 原厂**只给 ARS45 一颗** (8×10 FCCSP 是官网唯一封装信息) → p≤0.3 的话不是"换料"而是"换 SoC" | **项目总工**: 若 p≤0.3 → **ISS-084/083 升主线**, 换模组/换 SoC 平台 (球数 ≥72 球 + pitch ≥0.4 + 原生 DSI 三条一起当选型条件) |
| **R-6** | **本文所有 SoC 内部几何都是 `[推算]`** | 🟡 低 | ARS45 真实 pitch / 球数 / 球位 / 散热焊盘形状 = 全 `[0数据]` | **原厂** → 经项目总工 (已在邮件问题清单第 1 问) |

### §3.3 一句话给项目总工

> ★ **"封装 / 球数 / 逃线" 三项在 p≥0.4mm 下全部是【非风险】, 可以从"一票否决项"降级为"选型条款"(P-1 pitch ≥0.4 / P-2 球数 ≥72 / P-3 显示出口不焊死)。**
> ★ **真正卡住投板的只有一件事: 引脚 → 功能的映射 (球位图)** —— 这件事**不可自证**, 只能靠 **① 原厂回信 ② ISS-084 载板化 (让"球位错"只报废载板, 不报废主板) ③ ISS-083 模组线 (模组厂出引脚定义表)** 三条腿走。**这就是 ISS-081 的价值: 把"以为的 3 个风险"缩成"1 个真风险 + 2 个已消掉的假风险"。**

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
SOC_PIN_BUDGET 计算器 (ISS-081) —— HW/SOC_PIN_BUDGET.md 附录 A, 文中所有数字的唯一来源
跑法: 把本段存成 .py 后 `python3 <file>.py`   (或直接用 B6 命令从本文抽出运行)
纪律: 本脚本只做几何/计数; **不含任何 ARS45 真实球位号** (球位图 = [0数据])
"""
from __future__ import annotations

import math

# ======================================================================
# (a) 引脚预算 —— 分组 -> 数量 x 3 种配置
#     C-min  = 最省 (单一显示路径 + 内置存储 + 内部RC + 1键1灯)
#     C-base = 设计基线 (双显示路径都留焊盘 0Ω 二选一 = 我们会投板的那一版)
#     C-max  = 最坏 (双显示 + 外挂SPI-NOR + 外置晶振 + 全键全灯 + 全预留)
# ======================================================================
GROUPS = [
    ("MIPI-CSI RX 2-lane", 6, 6, 6),
    ("MIPI-CSI RX 4-lane 预留", 0, 0, 4),
    ("MCLK_OUT", 1, 1, 1),
    ("CSI_RESET_N", 1, 1, 1),
    ("显示出口 - DSI TX 2-lane", 6, 6, 6),
    ("显示出口 - DSI TX 4-lane 预留", 0, 0, 4),
    ("显示出口 - DP TX 4-lane + AUX + HPD", 0, 11, 11),
    ("I2C A (主控总线)", 2, 2, 2),
    ("I2C B / DDC", 0, 0, 2),
    ("充电状态回读 CHG_STAT + PG", 2, 2, 2),
    ("ADC 采样 VBUS_DET + BAT_DET", 2, 2, 2),
    ("FSIN 帧同步", 0, 0, 1),
    ("RESET_N + BOOT_N", 2, 2, 2),
    ("LED 驱动", 1, 1, 3),
    ("按键输入 KEY_PWR/VOL+/VOL-/CAM", 1, 2, 4),
    ("板型编码 ID_DETECT0/1", 0, 0, 2),
    ("光机握手 DSI_RESET_N_OUT + LIGHT_PG", 1, 2, 2),
    ("JTAG 调试 TCK/TMS/TDI/TDO", 4, 4, 4),
    ("UART 调试 TX + RX", 2, 2, 2),
    ("USB 2.0 Device D+ + D-", 0, 0, 2),
    ("USB VBUS 检测", 0, 0, 1),
    ("电源球 - V_CORE", 2, 2, 4),
    ("电源球 - V_IO 组 (3.3/1.8/1.2)", 2, 3, 3),
    ("电源球 - V_PHY", 0, 0, 1),
    ("GND 球", 6, 8, 12),
    ("XTAL 晶振 IN + OUT", 0, 0, 2),
    ("启动存储 SPI SCLK/CSn/MOSI/MISO", 0, 0, 4),
    ("PGOOD / 上下电时序", 0, 0, 1),
]
CFG = (("C-min", 1), ("C-base", 2), ("C-max", 3))


def budget():
    return {c: sum(g[i] for g in GROUPS) for c, i in CFG}


def io_only(i):
    return sum(g[i] for g in GROUPS if g[0] != "GND 球")


def gnd_only(i):
    return sum(g[i] for g in GROUPS if g[0] == "GND 球")


# ======================================================================
# (b) 8 x 10 mm 封装球数
# ======================================================================
PKG_W, PKG_H = 8.0, 10.0
PERIM = 2 * (PKG_W + PKG_H)
PITCHES = [0.50, 0.40, 0.30]


def full_array(p):
    c, r = int(PKG_W / p), int(PKG_H / p)
    return c, r, c * r


def ring(p, k):
    c, r = int(PKG_W / p), int(PKG_H / p)
    t = 0
    for i in range(k):
        w, h = c - 2 * i, r - 2 * i
        if w <= 0 or h <= 0:
            break
        t += 2 * w + 2 * (h - 2)
    return t


def req_pkg_balls(n, margin=1.15):
    """要求封装提供的球数 (向上取整到 8 的整数倍, 便于对标标准球数档)"""
    return int(math.ceil(n * margin / 8) * 8)


# ======================================================================
# (c) 逃线
#     逃线带/边 (从封装外廓量起) = p/2 + 0.05(阻焊桥) + L(短走线) + (R-1)*行距 + 过孔盘半径
#     R = 过孔排数; 行距 = 过孔盘直径 + 0.05 (电气间隙余量)
#     同排相邻过孔中心距 = 球心距 p -> 同排净间隙 = p - 过孔盘直径
# ======================================================================
ESCAPE = {
    0.50: dict(ball_pad=0.25, trace=0.30, via_pad=0.40, via_drill=0.20,
                tech="常规机械钻 0.20mm", cls="常规 4-6 层 OK"),
    0.40: dict(ball_pad=0.20, trace=0.30, via_pad=0.30, via_drill=0.15,
                tech="常规机械钻 0.15mm (需厂确认良率)", cls="常规 4-6 层, 只取 6 层"),
    0.30: dict(ball_pad=0.15, trace=0.25, via_pad=0.20, via_drill=0.10,
                tech="激光微孔 HDI + 树脂填孔/盖帽", cls="HDI -> 破 4-6 层锁死"),
}
MIN_ELEC_CLEAR = 0.075
ROW_CLEAR = 0.05


def band(p, rows=1):
    e = ESCAPE[p]
    row_pitch = e["via_pad"] + ROW_CLEAR
    return (p / 2 + 0.05 + e["trace"] + (rows - 1) * row_pitch + e["via_pad"] / 2)


def via_row_capacity(p):
    """单排沿周长能放多少过孔 (中心距 = p)"""
    return int(PERIM / p)


def rows_needed(p, n_balls):
    cap = via_row_capacity(p)
    return max(1, math.ceil(n_balls / cap))


def residual(board_w, p, rows):
    return (board_w - PKG_W) / 2 - band(p, rows)


def fits(resid, depth, margin=0.20):
    return resid >= depth + margin


def via_fill(p, n_balls, n_pwr):
    e = ESCAPE[p]
    area_band = band(p) * PERIM
    va = n_balls * math.pi * (e["via_pad"] / 2) ** 2 + n_pwr * math.pi * (e["via_pad"] / 2) ** 2
    return area_band, va, va / area_band


def main():
    b = budget()
    print("=" * 92)
    print("(a) SoC 侧引脚预算 (球数 = 功能位号数; 不含包内 NC / 多余球)")
    print("=" * 92)
    print(f"  {'组':38s}{'min':>5s}{'base':>6s}{'max':>5s}")
    for g in GROUPS:
        print(f"  {g[0]:38s}{g[1]:5d}{g[2]:6d}{g[3]:5d}")
    for c, i in CFG:

          f"C-base {b['C-base']} {'OK' if b['C-base'] <= 50 else 'NG (>50)'} | "
          f"C-max {b['C-max']} {'OK' if b['C-max'] <= 50 else 'NG'}")

    print()
    print("=" * 92)
    print("(b) 8x10mm 封装球数: 我方需求 vs 封装可提供 (球数由厂商定, 我方只能给区间)")
    print("=" * 92)

    for p in PITCHES:
        cc, rr, fa = full_array(p)

                  f"{'够' if n >= b['C-max'] else '不够'}")

    print("=" * 92)
    print("(c) 逃线 (12mm 板宽 -> SoC 8mm -> 每侧 2.00mm)")
    print("=" * 92)

            resid = residual(12.0, p, rows)

                  f"0603 允许的逃线带误差上限 = {resid - 0.8 - 0.2:+.2f}mm")

    print("=" * 92)

    print("=" * 92)
    worst = min(ring(p, 1) for p in PITCHES)
```
