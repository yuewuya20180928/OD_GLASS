# MECH/BOARD_GEOM_30MM.md —— 结构侧权威表 (60×30mm 板)

> **交卷人**: 结构总工 (mech-lead) · **日期**: 2026-11-11 · **关联**: ISS-192 (本单) / ISS-118 (板宽 30 拍板) / ISS-107+ISS-049 (PIN-SET-2)
>
> ★ **本表是结构侧 (MECH) 对 60×30mm 现行板的唯一权威几何口径**。
> 凡本域其它文档/脚本/分片与本表冲突 ⇒ **以本表为准**；凡外部产物 (HW/ 网表、板、原理图、生成器) 与本表冲突 ⇒ **由对应 owner 改** (见 §6 影响面)。
> ★ 本单**没有改过任何 HW/ 文件**；所有待改项都登记成 `needs_from` (见 §6 / `state/fragments/mech.yaml`)。

## 0. 证据分级与本表口径声明 (先读这一节)

| 标记 | 含义 |
|---|---|
| **[实测]** | 本轮实跑脚本/解析实物文件得到的数 (可复现) |
| **[官方]** | 官网/原厂规格 或 已生效的**决策** (老板/项目总工拍板) |
| **[推算]** | 由上两类按公式复算得到的设计态几何 (非物理实测) |
| **[0数据]** | 无数据 / 未核 (占位) |

★ **凡给出任何统计数必须同时给出口径**。本表的默认口径:
- **板宽 30mm / 板长 60mm / 板厚 1.00mm (6 层)** —— 现行板框;
- **主控 RK3576** (FCCSP698L, 17.20×16.10mm) —— 现行 SoC;
- **PIN-SET-2 套 A** (Y 按中心线平移, S 孔 ±5.00 不变) —— 本单仲裁结论 (见 §4);
- **打印包口径 = Rev B** (`MECH/print/gen_print_pack_revb.py` + `temple_cage_revb.stl` / `fit_coupon_revb.stl`)。
- ★ 凡与上述口径不同 (如 12mm / 15mm / 板长 76 / 板长 50 / RK3588 8×10 封装) 的数，**都是死值**，见 §7。
