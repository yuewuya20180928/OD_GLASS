================================================================================
金属骨架截面形状 + 重量口径 + 石墨 H 链 —— 结构侧独立复算 (ISS-049 两问的答复)
★ ISS-192 迁版: 60×15 / RK3588 8×10 ⇒ **60×30 / RK3576 17.20×16.10**
================================================================================

★ 口径: 只做**算术复算 + 几何判定**; **不出新的皮肤侧温度数** (要完整热模型重算, U-3); **不拍板**。

【1】V 向覆盖需求 (决定截面形状的硬约束) —— 30mm 板
--------------------------------------------------------------------------------
  30mm 板: SoC 沿板宽 16.10 + 两侧横向扩散带各 6.95 = 30.00mm = 板宽 30.00 → SoC 段骨架必须**满宽 30.00mm**
  横向热扩散通道 3.50 → **6.95mm/边** (×1.99) —— 板宽翻倍的**结构收益**
  SoC 满宽段 X 长度 10.00 → **17.20mm** (X 15.00..32.20)

【1b】非 SoC 端段的 Y 跨度需求 (孔位口径的机械后果)
--------------------------------------------------------------------------------
  套 A (S1 Y=10.00 / S2 Y=20.00): 前段 10.00mm / 后段 10.00mm → 与 ISS-049 §4「其余段 ≥10.00mm」恰好相容 ✅
  套 B (S1 Y=2.50 / S2 Y=27.50): 前段 17.50mm / 后段 17.50mm = 1.75× 口径 ⇒ 套 B 推翻骨架接口 ❌ (故否决)

【3】石墨片 (0.30mm, 铺在骨架与 PCB 之间)
--------------------------------------------------------------------------------
  体积 0.540cc · 1.08g/片 · 2.16g/对
  重量归账: MECH_BUDGET §3 W11 (石墨散热膜+导热垫+隔热垫 1-2g) —— **不是** §2.4 B 的骨架预算
  ⚠️ 15mm 板时代 60×15×0.30 = 0.54g/片 (1.08g/对, 落在 W11 内); 30mm 板 60×30×0.30 = 1.08g/片 (2.16g/对) => 超 W11 上限 +0.16g ⇒ 要么缩石墨覆盖 (只铺 SoC 段+扩散带), 要么调 W11 预算

【4】PCB 段 H 链 (含石墨) —— ★与板宽无关 (板宽走 V 向)

  骨架 1.0: 4.40 -> +石墨 4.70mm  余 2.60mm
  骨架 0.8: 4.20 -> +石墨 4.50mm  余 2.80mm   (可用 7.3, 规矩 ≥0.6)

【5】整机重量影响
--------------------------------------------------------------------------------
  cand_B: 骨架 5.10g/对 -> 整机推算 48.9-74.0g 变成 54.0-79.1g (目标 30-40g, 仍超)
  cand_C: 骨架 4.08g/对 -> 整机推算 48.9-74.0g 变成 53.0-78.1g (目标 30-40g, 仍超)

【判定】
--------------------------------------------------------------------------------
  ✅ V_cover_need_30mm: 30mm 板: SoC 沿板宽占 16.10 + 两侧横向扩散带各 6.95 = 30.00mm = 板宽 30.00 -> **骨架在 SoC 段必须满宽 (30.00mm, 即满板宽)** (★15mm 板时代是 8.00 + 2×3.50 = 15.00, 通道 3.50mm/边; 现通道 6.95mm/边)
  ✅ transverse_spread_channel_widened: 横向热扩散通道 3.50 → **6.95mm/边** (×1.99) (SoC 沿板宽 8.00 → 16.10, 板宽 15 → 30.00; 通道宽 = (板宽−SoC宽)/2)
  ✅ escape_band_inside_board: SoC 逃线带 Y 跨度 17.70mm ≤ 板宽 30.00mm (余 6.15mm/边)
  ✅ seg_span_setA_fits_10mm_spec: ★套 A (S1 Y=10.00 / S2 Y=20.00): 端段须覆盖 Y 跨度 前 10.00mm / 后 10.00mm → 与 ISS-049 §4「其余段宽度 ≥10.00mm」**恰好相容** (无富余但也不冲突)
  ✅ seg_span_setB_breaks_10mm_spec: ★套 B (S1 Y=2.50 / S2 Y=27.50): 端段须覆盖 Y 跨度 前 17.50mm / 后 17.50mm = **1.75×** ISS-049 §4 的 10.00mm 口径 ⇒ 套 B 会**推翻骨架接口** (端段须加宽到 17.50mm)
  ✅ cand_A_full_width_dead: 满宽 60×30×1.0 = 9.72g/对 (15mm 板时代是 4.86g/对, 翻倍), 超骨架预算 +6.72g -> 判死
  ✅ cand_B_step_1mm_mass: 台阶形 t=1.0 = 5.10g/对 (15mm 板时代 3.62g/对), 超骨架预算 +2.10g
  ✅ cand_C_step_0_8mm_mass: 台阶形 t=0.8 = 4.08g/对 (15mm 板时代 2.89g/对, 当时落进 +1-3g), ★30mm 下**最好候选也超预算 +1.08g** => 骨架截面必须重做 (不再是「选 1.0 还是 0.8」的题)
  ✅ cand_D_copper_heavy: 铜台阶形 t=0.8 = 13.53g/对, 超预算 +10.53g (比铝候选 C 重 +9.46g/对) -> 导热好但重量代价大, 1 台样机阶段不建议
  ✅ all_candidates_over_budget: ★**30mm 板宽下 4 个候选全部超 §2.4 B 的 +1~3g/对 预算** (最好 4.08g/对); 根因: 满宽段宽度 15.00 → 30.00 且长度 10.00 → 17.20mm ⇒ 满宽段体积 ×2.0 => ★属**预算裁** (项目总工), 本脚本只报数不拍板; 结构侧可选项: 满宽段只到 SoC 投影 / 横向扩散改由石墨承担 / 骨架改材料分段 —— 三个选项的重量账待下一轮
  ⚠️  graphite_in_W11: 石墨 1.08g/片 = 2.16g/对 vs W11 的 1.0-2.0g => ★**超上限 +0.16g** (板宽翻倍 ⇒ 石墨片重量也翻倍)
  ✅ H_chain_margin_t1.0: 骨架 1.0 + 石墨 0.30: PCB 段 H 链 = 4.70mm vs 可用 7.30 -> 余 2.60mm (≥0.60 规矩 ✅)
  ✅ H_chain_margin_t0.8: 骨架 0.8 + 石墨 0.30: PCB 段 H 链 = 4.50mm vs 可用 7.30 -> 余 2.80mm ✅
  ✅ skeleton_stops_at_pcb_rear_edge: 硬约束: 金属骨架/石墨止于 PCB 段后缘 (板坐标 X=60.00). 若延伸进电池段: 纵向热阻 730 -> 4.50 K/W, 皮肤侧热路被旁路 -> 进皮肤热量比例上升 (CLEARANCE_FIX §4.2 报 92.5% -> 95.7%). 理由是物理的 (金属绕过隔热层直接灌到皮肤), 不是模型的.
  ✅ weight_still_over_target: 整机推算 48.9-74.0g 已超 30-40g 目标 (MECH_BUDGET §3.1); 骨架增量候选 B 5.10g / 候选 C 4.08g -> 两候选都救不了整机超重, 只能少加重 (薄壁化/金属件替打印加强件)

★ 结论 (建议, 不拍板 —— 最终由项目总工裁):
  ① 截面形状 = **台阶形** (SoC 段 X15.00–32.20 满宽 30.00 / 其余段 10.00) —— 唯一满足横向扩散带覆盖 (30.00 = 满宽) 又不像满宽那样被判死的方案
  ② ★**30mm 下重量全线超支**: 台阶 t=1.0 = 5.10g/对, t=0.8 = 4.08g/对 (仍超 +1-3g 预算 +1.08g) ⇒ **骨架截面必须重做** (满宽段只到 SoC 投影 / 横向扩散交给石墨 / 材料分段) —— 属预算裁, 报项目总工
  ③ 石墨 0.30 **铺在 PCB 内侧 (骨架与 PCB 之间)**, 与板同长同宽 -> PCB 段 H 链 +0.30; H 链余量仍 ≥0.60 (骨架 0.8 时余 2.80mm)。★但石墨片 1.08g/片 = 2.16g/对 **超 W11 (1-2g)** ⇒ 缩覆盖或调预算
  ④ 骨架/石墨**止于 PCB 段后缘** (X=60.00) —— 延伸进电池段 = 金属绕过隔热层直灌皮肤
  ⑤ ⚠️ 换 0.80mm 的**热学代价必须并进 U-3 一起算**: 铝的导热面积/截面都小 → Tj 会升, 而 §2.3.1 的 46.5°C (0.23W) 已经超 43°C 红线 —— **只看重量不看热学会翻车**
  ⑥ 整机超重 (48.9-74.0g vs 目标 30-40g) **两个候选都救不了**, 只能靠减重措施, 不靠骨架选型
  ⑦ ★**孔位口径**: 套 A 的端段 Y 跨度需求与 ISS-049 §4 的 ≥10.00mm **恰好相容**; 套 B 会把端段要求拉到 17.50mm ⇒ 推翻骨架接口 ⇒ 结构侧否决套 B (详见 MECH/BOARD_GEOM_30MM.md §4)
