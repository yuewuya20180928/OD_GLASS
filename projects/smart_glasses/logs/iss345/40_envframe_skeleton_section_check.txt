【判定】
--------------------------------------------------------------------------------
  ✅ V_cover_need_100mm: 100mm 板: SoM 承载区沿板宽占 46.78 + 两侧横向扩散带各 26.61 = 100.00mm = 板宽 100.00 -> **骨架在 SoM 段必须满宽 (100.00mm, 即满板宽)** (★本档为台架板帧: 无 15mm 产品板沿革可比; 通道 = (板宽−承载区宽)/2 = 26.61mm/边)
  ✅ transverse_spread_channel_widened: 横向热扩散通道 3.50 → **26.61mm/边** (×7.60) (SoM 承载区沿板宽 46.78, 板宽 100.00; 通道宽 = (板宽−承载区宽)/2)
  ✅ escape_band_inside_board: SoM 逃线带 Y 跨度 48.38mm ≤ 板宽 100.00mm (余 25.81mm/边)
  ✅ seg_span_setA_fits_10mm_spec: ★本帧口径不适用: 端段 Y 跨度需求由【PIN-SET-2 套 A 四孔的板坐标】推导 (PIN_Y / SCREW_Y_SET_A / SCREW_Y_SET_B) ⇒ 那是【60×30 套A 帧】专有坐标; 台架板 160×100 盘上无这四个孔 ⇒ 本档不跑本判据 (不假装跑通)
  ✅ seg_span_setB_breaks_10mm_spec: ★本帧口径不适用: 同上 (套 B 是被否决口径, 与板框无关 ⇒ 但其 Y 坐标也是 F30A 帧坐标)
  ✅ cand_A_full_width_dead: 满宽 160×100×1.0 = 86.40g/对 (★台架板帧无 15mm 产品板沿革可比), 超骨架预算 +83.40g -> 判死
  ✅ cand_B_step_1mm_mass: 台阶形 t=1.0 = 36.20g/对 (★台架板帧无 15mm 沿革可比), 超骨架预算 +33.20g
  ✅ cand_C_step_0_8mm_mass: 台阶形 t=0.8 = 28.96g/对 (★台架板帧无 15mm 沿革可比), ★100mm 下**最好候选也超预算 +25.96g** => 骨架截面必须重做 (不再是「选 1.0 还是 0.8」的题)
  ✅ cand_D_copper_heavy: 铜台阶形 t=0.8 = 96.09g/对, 超预算 +93.09g (比铝候选 C 重 +67.14g/对) -> 导热好但重量代价大, 1 台样机阶段不建议
  ✅ all_candidates_over_budget: ★**100mm 板宽下 4 个候选全部超 §2.4 B 的 +1~3g/对 预算** (最好 28.96g/对); 根因: 满宽段宽度 → 100.00 且长度 → 56.70mm ⇒ 满宽段体积 ×6.7 => ★属**预算裁** (项目总工), 本脚本只报数不拍板; 结构侧可选项: 满宽段只到 SoM 承载区投影 / 横向扩散改由石墨承担 / 骨架改材料分段 —— 三个选项的重量账待下一轮
  ⚠️  graphite_in_W11: 石墨 9.60g/片 = 19.20g/对 vs W11 的 1.0-2.0g => ★**超上限 +17.20g** (台架板 160×100 板面 ⇒ 石墨片重量按板面计)
  ✅ H_chain_margin_t1.0: 骨架 1.0 + 石墨 0.30: PCB 段 H 链 = 5.30mm vs 可用 7.30 -> 余 2.00mm (≥0.60 规矩 ✅)
  ✅ H_chain_margin_t0.8: 骨架 0.8 + 石墨 0.30: PCB 段 H 链 = 5.10mm vs 可用 7.30 -> 余 2.20mm ✅
  ✅ skeleton_stops_at_pcb_rear_edge: 硬约束: 金属骨架/石墨止于 PCB 段后缘 (板坐标 X=160.00). 若延伸进电池段: 纵向热阻 730 -> 4.50 K/W, 皮肤侧热路被旁路 -> 进皮肤热量比例上升 (CLEARANCE_FIX §4.2 报 92.5% -> 95.7%). 理由是物理的 (金属绕过隔热层直接灌到皮肤), 不是模型的.
  ✅ weight_still_over_target: 整机推算 48.9-74.0g 已超 30-40g 目标 (MECH_BUDGET §3.1); 骨架增量候选 B 36.20g / 候选 C 28.96g -> 两候选都救不了整机超重, 只能少加重 (薄壁化/金属件替打印加强件)

★ 结论 (建议, 不拍板 —— 最终由项目总工裁):
  ① 截面形状 = **台阶形** (SoM 承载区段 X13.65–70.35 满宽 100.00 / 其余段 10.00) —— 唯一满足横向扩散带覆盖 (100.00 = 满宽) 又不像满宽那样被判死的方案
  ② ★**100mm 下重量全线超支**: 台阶 t=1.0 = 36.20g/对, t=0.8 = 28.96g/对 (仍超 +1-3g 预算 +25.96g) ⇒ **骨架截面必须重做** (满宽段只到 SoC 投影 / 横向扩散交给石墨 / 材料分段) —— 属预算裁, 报项目总工
  ③ 石墨 0.30 **铺在 PCB 内侧 (骨架与 PCB 之间)**, 与板同长同宽 -> PCB 段 H 链 +0.30; H 链余量仍 ≥0.60 (骨架 0.8 时余 2.20mm)。★但石墨片 9.60g/片 = 19.20g/对 **超 W11 (1-2g)** ⇒ 缩覆盖或调预算
  ④ 骨架/石墨**止于 PCB 段后缘** (X=160.00) —— 延伸进电池段 = 金属绕过隔热层直灌皮肤
  ⑤ ⚠️ 换 0.80mm 的**热学代价必须并进 U-3 一起算**: 铝的导热面积/截面都小 → Tj 会升, 而 §2.3.1 的 46.5°C (0.23W) 已经超 43°C 红线 —— **只看重量不看热学会翻车**
  ⑥ 整机超重 (48.9-74.0g vs 目标 30-40g) **两个候选都救不了**, 只能靠减重措施, 不靠骨架选型
  ⑦ ★**孔位口径**: ★台架板 160×100 盘上无 PIN-SET-2 四孔 ⇒ 端段 Y 跨度判据**本档口径不适用** (★先例 MECH/board_frame_feasibility.py:108 `pinset_applicable: False`★)
