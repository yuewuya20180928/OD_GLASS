  ── 解 A 【隔热层局部化 + 电池段单件箱形】 ★推荐

【3】三项条件性不通过 —— 逐条解法 (含计算)

  ① 叠放模型 (前后 +0.80mm / 垂直 +3.50mm) —— **裁决: 锁「沿长度串行」, 叠放物理不成立**
     证明 A (H): 叠放要求 8.10mm > 镜腿上限 7.30mm, 超 0.80mm → 在 7.3mm 镜腿里**根本装不下**
     证明 B (V): 叠放要求 41.50mm > 根部净高 38.00mm, 超 3.50mm → 同样装不下
     证明 C (L): 串行只需 90.5mm ≤ 内长 130.0mm (余 39.5mm) → **串行是唯一可行排布**
     处置: §1.4.2 的 H/V 表是 **过时模型** (它按 420mAh/22mm 电芯算), §1.3/§1.4.3/§1.6.2/§1.6.3/§5.6.2 全用串行 → 以串行为准, 叠放分支作废
     若老板坚持叠放: 镜腿厚必须 ≥ 8.10 + 2×0.30 = **8.70mm**
             = 比 7.3mm 厚 +19% (华为 AI 眼镜 6.25mm 的 1.39 倍) → **走变更流程**
     ⟹ 本轮: ①按「串行 + 解A」闭环, 不需要变更

  ② 充电板不移出镜脚 (长度 +0.50mm) —— **解法: 充电板与主 PCB 沿垂直方向并排 (不占长度)**
     前提方案 (已定): 充电板挪到镜框 (§1.6.3) → 长度需求 105.5mm, 余 24.5mm ✅
     若坚持留在镜脚且必须沿长度串行: 需求 130.50 > 130.00 → 干涉 0.50mm ❌
     ⟹ 改排布: 充电板 (25×10×0.8) 放到 **PCB 段的垂直空当** (与 PCB 同 L 段, 沿 V 并排):
        长度需求不变 = 105.5mm → 余量 **24.5mm** ✅
        该段垂直需求 = max(PCB宽12, 充电板宽10) + 走线槽6 = 18.0mm ≤ 净高 38.0 → 余量 **20.0mm** ✅
        (Type-C 仍在尾端; 充电板→尾端的线走 **电芯上方的走线槽**, 该槽在 V 向占 6mm, 在 H 向占 2mm, 位于电芯上方而非侧面)
     兜底: PCB 50→45mm (需 hw-lead 确认 12×12 逃线区 + MIPI + SPI-NOR 68mm² 能否放下) → 长度需求 125.5 → 余 4.5mm ✅

  ③ ⌀2.0 H7 定位销孔 FDM 做不到 —— **解法: 定位基准整体移到金属骨架, 打印件只让过不定位**
     金属骨架 (机加工 Al/Cu, §5.5 已有件, **不增加零件数**):
        · PCB 安装面: 铣削平面, 平面度 ≤5µm (§1.4.5/§5.5 同款要求)
        · 2× M1.2 螺纹孔 (攻丝) → PCB 用 2 颗 M1.2 螺钉压紧 (★PIN-SET-2: 板坐标 S1 (8.00,2.50) / S2 (52.00,12.50), 纯压紧零定位)
        · 2× ⌀2.0 H7 定位销孔 (⌀2.0 销装在骨架上, 销孔 H7) → 负责 **全部定位**, 防电池充放电微动 (★PIN-SET-2: P1 (8.00,7.50) 配圆销=全基准 / P2 (52.00,7.50) 配菱形销对边1.94=只定Y ⇒ 消过定位)
     打印件侧: 1× **⌀2.4 间隙孔** (打印公差 ±0.30 完全可接受 —— 它只让过, 不定位) + 2× ⌀1.6 螺钉过孔
     ⟹ 打印公差 **不进定位链**: 定位链 = 骨架铣削面 (≤5µm) + H7 销 (≤0.01) → PCB 板面平行度 ≤0.05°
     代价: 骨架多 2 个 M1.2 攻丝孔 + 2 个 H7 销孔 (机加工, 件数不变, 单件 +0.2g 估算); PCB 孔位已由 hw-lead ISS-049 定版 PIN-SET-2 (2×⌀2.0H7 销孔 + 2×⌀1.4 压紧孔, 板坐标 P1(8.00,7.50)/P2(52.00,7.50)/S1(8.00,2.50)/S2(52.00,12.50))
     ⚠️ 打印包要改一处: temple_cage_340.stl 的 ⌀2.0 配作孔 → ⌀2.4 间隙孔 (已列入 §6 打印件影响)
     ⚠️ 打印包**尚未跟改 PIN-SET-2** (改版授权在 PM 手上): M1.2 让过孔仍是老口径 (孔距 40.00, X=6/X=46); PIN-SET-2 要求孔距 44.00 (S1 X=8.00 → S2 X=52.00)

【4】对散热路径的影响 (解 A)
  热路 ①  主散热路 (不变): SoC → 0.3 导热垫 → 铝骨架 → 石墨 → 上壳外壁 → 对流
  热路 ②  隔热路 (不变):   SoC → 0.5 隔热垫 + 0.3 空气隙 (在 PCB/SoC 段) → 皮肤侧下壳 → 皮肤
  ⟹ 解 A 只把 0.5 垫 + 0.3 空隙从「全长」缩到「PCB/SoC 段」, **热路 ② 的隔热层原封不动留在 SoC 与皮肤之间** → 皮肤侧温度不变 (§2.3.1: 0.23W → 46.5°C ❌ 仍超 43°C, 但**不是我这条改的**)
  电池段没有热源 (电芯自身发热 mW 级) → 取消该段隔热层 **不切断任何热路**

  ⚠️ 新增硬约束 (量化): **金属骨架 / 石墨不得延伸进电池段**
     若骨架(铝 1.0mm)延伸进电池段 → 新增并联热路 R = 4.50 K/W
        并联后 R_skin_path: 54.2 → 30.0 K/W, 进入皮肤的热量比例: 92.5% → 95.7%
        (按 §2.3.1 的 ±14°C 模型不确定性, 这条只能当「禁止」的依据, 不能当「允许」的依据)
     若维持打印件(PA-CF k=0.2)纵向导热 → R = 730 K/W, 与皮肤路径 54.2 K/W 并联后几乎无影响 ✅
     ⟹ 解 A 的散热结论: **热路不断**; 附带代价 0 (隔热垫数量不变); 但必须写进加工图: 骨架止于 PCB 段后缘
  充电峰值 (0.8W): 充电板挪到镜框 (已定前提) → 镜脚不受影响; 若按解 ② 留在镜脚, 必须铝屏蔽罩 + 与皮肤隔断 (§2.4 E), 镜脚皮肤侧净高余量 8.5mm 放得下屏蔽罩 ✅

★ 结论 (镜脚侧 / 340mAh 档 / 充电板挪出镜脚 / 沿长度串行 / Q4 锁死镜腿 7.3mm)
====================================================================================================
  基线 (v1.1 原模型): 前后名义余量 0.30mm < 2×公差 0.60mm → **临界 = 不通过** (ISS-017 自判, 已闭环)
  推荐解 A: 前后 **余量 0.95mm** (最坏情况 0.65mm) / 垂直 **余量 8.50mm** / 长度 **余量 24.50mm**
          判据: 前后 0.65mm ≥ 2×0.30 = 0.60mm → **是**
  三项条件性不通过: ① 裁决为串行 (叠放在 7.3mm 内物理不可能, 已给 H/V/L 三重证明) ② 充电板沿 V 与 PCB 并排, 长度余量 24.50mm 不变 ③ 定位基准移到金属骨架, 打印件只做 ⌀2.4 间隙孔
  散热: 热路不断 (隔热层仍在 SoC 段); 新增硬约束 = 金属骨架/石墨不得延伸进电池段 (否则并联热路 4.50 K/W)
  镜框侧: 仍 **未验** (缺 JBD 走鹃Ⅱ 三维尺寸 u1 + 波导 2D 外形图 u4 + 镜框截面 u8)
