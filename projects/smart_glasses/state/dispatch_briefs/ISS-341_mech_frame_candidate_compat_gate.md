### ★§0.2 现在 U-1 的建议默认值是怎么来的 (★你要审的对象★)

★**出处**: `state/fragments/pm.yaml` 的 `iss310_main_board_frame_u1_decision` (ISS-310, main 11-18 05:5x 汇总) ★
★**建议默认值 = 60×30 (F30A) 且板厚 ≤ 1.00** ★, 理由逐字是: ★**「36 档里唯一在结构判据上全绿的一档 + 开口能落在板末端 0.59mm; 台架板 V链−68.00/L链−85.50 与板厚无关地全红 + 板重 47.36g = 整机预算 65~97% + 开口距板端 100.59mm; 60×15 套A四孔不成立 ⇒ 整档作废」** ★

★**★main 指出这批理由的【口径分层问题】(★你本单要正面回答它·别绕★)★**:
★**那 36 档判的是【结构外形判据】(腔体净空 / 开口落位 / 板重 / 板厚档位) ⇒ 结论是「台架板装不进眼镜」—— 而台架板本来就是【台架板】(demo 评测板, 不装电池 · Type-C 供电 · 板上只有这一块, 见 ISS-169) ★**
★**⇒ 「装不进眼镜」≠「这一趟画不了」★ ⇒ ⇒ 「36 档里唯一全绿 ⇒ 这一趟该画 F30A」这个推理【跳了一步】★**
★**⇒ 你要产出的相容性矩阵, 必须把【两层问题】分开写**: ★**① 这一趟画哪块物理产品 (上位) ⇒ ② 那一块板用哪个框/层数/板厚 (下位, U-1)★**

## §1 交付物 (★4 件, 每件 = 一次独立 write 调用★)

### D1 · ★新建★ `MECH/check_board_frame_candidate_compat_gate.py` (机器判定闸本体)

★**只读闸** ⇒ ★**不许写板 / 不许写 HW/ / 不许改任何既有 MECH 文件** ★
★**读什么**:
- 板: `HW/PCB/demo_mainboard.kicad_pcb` ⇒ Edge.Cuts 包围盒 / 铜层数 / `(general (thickness))` / footprint 数 / **全部 186 封装的占位并集** / **J_SOM_P1..P4 承载区 bbox** (★按 pad 中心 + pad 尺寸算, 别只算中心★)
- 帧: `HW/PCB/BOARD_FRAME_CALIBER.md` §2 ```json cal:FRAMES``` ⇒ `B160x100` / `F30A` / `P60x15` 三帧的 width/height/layers/thickness/current
- 结构侧口径: `MECH/BOARD_GEOM_30MM.md` §1 (板厚/层数/主控型号) ★**只读**

★**判什么 (逐帧输出)**:
1. **装得下吗**: 该帧矩形 vs 现役板占位并集 / vs J_SOM 承载区 ⇒ **相容 / 不相容 + 差多少 mm** (宽/高各给差值)
2. **层数/板厚一致吗**: 帧 layers/thickness vs 板实测铜层数/thickness ⇒ 一致 / 不一致
3. **主控形态一致吗**: 帧隐含形态 (F30A/P60x15 = RK3576 SoC 直上板; B160x100 = RK3572 SOM 承载区) vs 现役板形态 ⇒ 一致 / 换架构
4. ★**最终判决 (机器可判的那一句)**: 该候选 = ★**「这一趟改现役板一次」** ★ 还是 ★**「这一趟 = 重画一块新板, 现役板的 186 封装/45 条未连接/作业包 S1~S13 全部作废」** ★

★**`--selftest` ≥ 6 用例**, 至少含:
- 正向: B160x100 对现役板 ⇒ 相容 ⇒ 判决「改一次」
- 反向 A: ★**把 F30A 的板高改成 60 (在沙盒里改副本) ⇒ 该帧变成装得下 ⇒ 闸的判决必须跟着变** ★ ⇒ ★**证明闸在读盘面, 不是把答案写死** ★
- 反向 B: 把现役板的 J_SOM 承载区高度读数改小 ⇒ F30A 判定必须翻转
- 反向 C: 把某帧 layers 从 8 改成 6 ⇒ 「层数不一致」必须报出来
- 反向 D: 把 `cal:FRAMES.current_frame` 改成 F30A ⇒ 「现役帧」相关判据必须翻转
- 反向 E: ★**删掉/改名 186 封装里任意一个 ⇒ 闸不许崩, 必须给出可读报错** ★
★**末行必须逐字 `ALL TESTS PASS`, rc=0** ★ (★沿用 ISS-339 的 selftest 规矩★)
