## 1. 病症（全部实测，非推测）

`CONN_LIGHT` (30,62) 焊盘行 y=60.15（盘高 1.30 ⇒ **59.50..60.80**），DSI 差分脚 **x=26.25..34.75**。

| 方向 | 堵它的件 | 净空 | 结论 |
|---|---|---|---|
| **上** | `C_AC_CSI_D0_CK_P` (24.15–27.00) / `C_AC_CSI_D0_CK_N` (28.95–31.80) / `C_AC_CSI_D0_D1_P` (33.75–36.60)，全在 y 57.95–59.05 | **0.45 mm** | 0.25 线 + 0.2 净距 = 0.45 ⇒ **零余量** |
| **下** | `TP_CSI_CK_N` (29.15–30.65, 60.95–62.45) / `R_SER_CSI_MCLK` (26.55–29.40, 61.95–63.05) / `R_PU_I2CA_SDA` (31.35–34.20, 61.95–63.05) | **0.15 mm** | **物理堵死** |
| **侧** | 0.5 mm pitch，0.30 宽盘 ⇒ 盘间 0.20 mm | 0.20 mm | = 净距下限 ⇒ **不能侧逃** |

⇒ **差分脚只有"上"或"下"两条路**，两条都被封。

## 2. 为什么挪过孔解决不了（已实测）

- v32_R（halo 精确 0.625mm）+ v33_S（`CONN_CAM` 逃逸走廊禁放 GND 下拉孔）⇒ ★**DSI 的 10 对全部毫无变化**
- ⇒ **DSI 侧的堵是"器件"不是"过孔"** ⇒ ★**必须走摆放臂**

## 3. 候选方案（都算过账）

| 方案 | 动作 | DSI 收益 | CSI 代价 | 评价 |
|---|---|---|---|---|
| **A** | 搬**全部 10 个** `C_AC_CSI_*` 到左下空地 (x 12–77, y 72–100，实测 65×28 全空) | 上方走廊全开 | ★**10 对 CSI 第二跳要一起从 y=72 爬回 y=51，全挤 x=57–77 过道 + y≈56.5 走廊** ⇒ **直接抵消 v32_R/v33_S 的成果** | ✘ 排除 |
| **B** | 只搬**挡路的 3 个**（CK_P / CK_N / D1_P） | 上方走廊 x=25.5–35.5 开出 **3.5 mm 高**通道 | 只影响 3 对（6 条线）⇒ 代价小 | ★**首选** |
| **C** | 搬 3 个电容 **+** 下方 `R_SER_CSI_MCLK` / `R_PU_I2CA_SDA` | 上下两条路都开 | 同 B | 备选（若 B 实测不够） |
| **D** | 搬 `R_SEL_*` 到右侧过道 | 无 | 无 | ✘ **已证伪**：SoM_P3 与 CONN_LIGHT 分居模块两侧 ⇒ 摆哪都要绕 ⇒ 链长不变 |

## 4. 方案 B 的落位（已按空闲栅格算过）

- 搬走：`C_AC_CSI_D0_CK_P`、`C_AC_CSI_D0_CK_N`、`C_AC_CSI_D0_D1_P`（3 个，各 2.85×1.10）
- 连带自动搬走：`TP_CSI_CK_P`、`TP_CSI_CK_N`、`TP_CSI_D1_P`（TP 的"贴伙伴"逻辑会自动跟过去 ⇒ 顺带清掉压在 DSI 脚上的 `TP_CSI_CK_N`）
- 候选空地（实测）：`x 12–77, y 72–100` / `x 43–50, y 64–100` / `x 57–77, y 48–100`
- ★**落位必须避开 x 40–78 / y 55–59 那条 CSI 走廊** ⇒ 只能落在 y ≥ 64 或 x ≤ 39

## 5. ★为什么必须等两臂先落盘（依赖）

1. **归因依赖**：v34 若建在"赢家臂"之上 ⇒ 相对赢家是 +1 变量 ✔；若两臂判负 ⇒ v34 需重跑（env 门控 ⇒ 重跑便宜）
2. **★★更硬的依赖**：★**搬走那 3 个电容 = 把它们从 y=58.6 的 CSI 走廊下沿挪走**
   ⇒ **v32_R / v33_S 修好的正是这条走廊**（x 40–78 / y≈56.5，3 mm 宽带，10 对 CSI 共用）
   ⇒ ⇒ **现在不知道两臂把走廊用到什么程度，就不知道搬电容的代价有多大**
   ⇒ ⇒ ⇒ **顺序错了会把刚修好的东西拆掉**
3. 成本对比：两臂距落盘仅 ~1–3 分钟（v32_R 已在 TIME 收尾阶段）⇒ **等一等几乎不花钱**

## 7. ★★★探针实测结果 (19:12–19:13, 只摆不布, ~20 秒/次)

★★**决定性教训**: ★**"搬迁几个件"根本不管用** —— 排版是**行式装箱流** ⇒ 搬走挡路的件 ⇒ **后面的件立刻补位**
- 探针 A (搬 CK_P/CK_N/D1_P → 左下 (12,72)) ⇒ **DSI 上走廊仍有 3 个件** (`D0_P`/`D0_N`/`D1_N` 补进来) ⇒ **一点没腾出来**
- 探针 B (搬 → (43,64)) ⇒ **同样没腾出来**
⇒ ⇒ ★**唯一有效手段 = 禁放框 (keep-out)**: 把走廊圈起来 ⇒ 撞框的件**同排右移**绕开

### ★探针 C = 成功方案（一个 env 搞定, 不动路由器一行）

```
PCB_KEEPOUT="24.0,56.1,35.6,59.6"
```

| 指标 | 基线 (v31_Q) | 探针 C |
|---|---|---|
| **DSI 上走廊 (x24–35.6, y56.1–59.6)** | **3 个件压着** (CK_P/CK_N/D1_P) | ★★**0 个 —— 空的** ✔ |
| DSI 下走廊 (y60.9–64.2) | 3 个 (TP_CSI_CK_N / R_SER_CSI_MCLK / R_PU_I2CA_SDA) | 2 个 (换成 C_KEY_VM / R_KEY_VM) |
| CSI 走廊件数 | 11 | 11（**成分变了，见下**） |
| 掉件数 | — | **0** ✔ |
| 异网焊盘搭接 | — | **0**（自检 ≥0.20mm 全过）✔ |
| parity | — | **全过（板↔网表 100% 一致）** ✔ |

★★**意外收获（比预期好）**: 禁放框把**整排电容右移** ⇒
`CK_P 25.9→40.3` · `CK_N 30.7→45.1` · `D1_P 35.5→49.9` · `D0_P→58.7` · `D0_N→63.5`
⇒ ⇒ **CSI 第二跳的起点整体离 CONN_CAM 更近（最远那对近 14mm）** ⇒ **走廊更短、交叉更少**
⇒ ⇒ ★**这一刀可能同时改善 CSI**（不只修 DSI）
⇒ 另: `TP_CSI_CK_N` 跟着电容走到 (44.5,55.2) ⇒ **不再压着 `CONN_LIGHT` 的 DSI 脚** ✔
