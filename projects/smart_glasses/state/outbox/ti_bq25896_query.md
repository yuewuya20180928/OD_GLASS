# 发给 TI (BQ25896) 的技术澄清 — 3 条 (草稿, 待老板批准后发)

**收件人**: Texas Instruments (BQ25896 充电 IC 团队 / 技术支持)
**主题**: 【设计澄清】BQ25896 在"电池与负载分处两块板 (中间跨柔性连接器)"场景下的 3 个问题 (IINLIM / VSYS / TS)

---

您好:

我们正在设计一副 1S 锂电的智能眼镜: **充电板 (Type-C + BQ25896) 在镜框, 电池 + 负载 (SoC 主 PCB) 在镜腿, 两块板之间用柔性连接器跨铰链**。充电电流 (典型 1.0A, 上限约 1.5A) 必须过这段柔性连接器。有 3 个点想请贵司确认, 我们都按贵司数据手册理解, 但有把握不足的地方:

## 1. IINLIM 电阻: 我们这样算对吗?

我们用 `IINMAX = KILIM / RILIM` 估算输入电流上限, 取 **R_ILIM = 300Ω** → IINMAX ≈ 1.07-1.30A (按 KILIM = 320/355/390 AΩ 三档)。由此我们把**充电电流 ICHG ≈ 0.822 × IIN** 控制在 **0.88-1.07A** (如果贵司推荐 390Ω, 则 0.67-0.82A)。

请确认:
- (a) 这个 KILIM/RILIM 关系与 ILIM 脚稳在 0.8V 的做法, 是否适用于**1S + 外部 BAT 节点带保护电路**的拓扑?
- (b) **ILIM 脚上的电阻功耗** 我们算的是 0.8²/300 ≈ 2.1mW —— 是否可忽略?
- (c) 若我们想同时限制"流入 BAT 的电流"而不是"流入 IN 的电流", 有没有更直接的器件/做法 (因为我们的 1.0A 实际是流过柔性段的)?

## 2. VSYS 脚: 不接可以吗?

我们的拓扑: BQ25896 在镜框, **电池在镜脚** (跨柔性连接器), 系统的 SYS 轨由镜脚侧的电池保护电路 (BQ2970 + 2 只 MOS) 产生, 因此 **BQ25896 的 VSYS 脚目前不接 (NC)**, 充电路径是 IN → 内部 BATFET → BAT → 柔性段 → 电芯。

请确认:
- (a) VSYS **悬空**是否允许? 数据手册对 VSYS 是否有"必须接最小负载/必须接电容"的要求?
- (b) 如果 VSYS 必须接, 我们能否把 VSYS 直接接回 BAT 脚 (绕开 BATFET)? 那样会失去输入端的反向阻断 —— 是否有更好的做法 (例如 BATFET 仍串在 BAT 路径上, VSYS 只接一颗电容)?
- (c) 我们的理解是: **VSYS 不接不影响充电功能, 只失去"电池缺失时由 IN 经 FET 给系统供电"这个特性** —— 对吗?

## 3. TS 温度检测: 三件式接法与跨板

我们按贵司手册的 TS 检测网络实现: **RT1 (REGN→TS) + RT2 (TS→GND) + 103AT NTC (与 RT2 并联)**, 手册给的 0°C→73.25% / 60°C→34.375% 我们复算一致 (0°C→73.26%, 60°C→34.39%)。

我们的特殊之处: **NTC 贴在电芯上 (镜脚侧), 而 TS 脚在镜框的充电板上**, 所以 TS 信号要跨一段柔性连接器 (高阻节点, 走线长约 30mm, 连接器与 FPC 的漏电流在 µA 级)。请确认:
- (a) 手册里 RT2 = 30.31k 的下拉**应该放在哪一侧**? 我们放在**连接器的远端 (NTC 侧)**, 这样 FPC 漏电流不会进入分压 —— 是否正确?
- (b) TS 断线 (连接器接触不良) 时, BQ25896 的行为是什么? 手册说 TS 断线 → 判定温度异常 → 停充, 我们理解为"安全停充" —— 对吗?
- (c) 是否建议在 TS 线上加一个小的保护电阻或 RC (我们目前是直连)?
