## 1. 需求摘要 (一句话)

**1×10 脚、0.5mm pitch、板对板 FPC 连接器 (ZIF)**, 用于镜框充电板 ↔ 镜脚主 PCB 的跨铰链连接; **双 pin 并联走 1.0A 级充电电流**, 另走 2 根回流 + 4 根信号 + 1 根高阻模拟 (温度检测) + 1 根预留。

---

## 2. 必须满足的硬判据 (逐条答复, 请逐项确认)

| # | 判据 | 我们的理由 |
|---|---|---|
| **C-1** | **脚数 = 1×10, pitch = 0.5mm** | 网表已定稿 (J_CHG pin map: 1/2 载流双 pin · 3/4 回流双 pin · 5 CHG_STAT · 6 PWR_GOOD · 7 VBUS_DET · 8 TS · 9 预留 · 10 TS 专用回流) |
| **C-2** | ★**单触点 DC 额定电流 ≥ 0.5A** | 载流工况: 只有 pin1/pin2 导通, 每脚 **0.411A** (充电电流 0.82A 双 pin 并联), 其余脚 ≤1mA。**请明确答复: 规格书里 "all contacts" 的 70% 降额条款是否适用于"仅部分触点导通"的场合** —— 这条决定我们能不能用 0.5A 的型号 |
| **C-3** | ★**FPC 可插厚度上限 ≥ 0.25mm** | 我们的 FPC 固定段用 **2oz 铜** (0.24-0.25mm), 弯折段 1oz (0.12-0.13mm)。**若贵司 ZIF 的可插厚度上限是 0.23mm, 则固定段必须降到 1.5oz** (载流能力与弯折寿命要重新权衡) ⇒ 请给**可插厚度上限的数值** (不是范围) |
| **C-4** | **机械防呆 (poka-yoke)** —— 反插会把 **BAT_CHG 短接 GND** (后果: 充电板 MOS 直通) | 必须**结构级防呆** (不只是壳体上的极化标记)。请说明: ① 是否有带防呆键的型号 ② 是否提供"仅 A 侧可插"的方案 (或 AutoLock 型) ③ 防呆特征如何与 FPC 弯折段共存 (弯折段只允许连续铜箔, 无元件/过孔/胶) |
| **C-5** | **座体高度 ≤ 2.0mm, 座体长度 ≤ 6.5mm** | 铰链区几何预算: 镜脚根部净高 37.0mm, 4 条跨铰链链路堆叠 27.0mm (余 10.0mm) |
| **C-6** | **额定电压 ≥ 5V, 绝缘/耐压说明** | 跨铰链侧有 VBUS 5V 与电池 4.2V |
| **C-7** | **额定插拔次数 ≥ 20 次** (镜腿开合不是插拔, 但售后拆装会插拔) | |
| **C-8** | **提供**: 型号 / 触点镀层 (金 vs 锡, 及其对 0.5A 持续载流与接触电阻的影响) / 单脚接触电阻典型值与最大值 (mΩ) / 温度等级 (-40~+85°C) / 包装与交期 / **单价与 MOQ** | 接触电阻直接影响跨铰链段压降 (我们算的是 37-111 mΩ/段) |

## 3. 需要的 FPC 配套能力 (若贵司也提供柔性板, 请一并答复)

| # | 需求 | 说明 |
|---|---|---|
| F-1 | **分段铜厚**: 固定段 **2oz** / 弯折段 **1oz** | 载流铜厚与弯折寿命冲突: 弯折段应变 ε = t/2R, 2oz 在 R3.0mm 弯折段寿命掉到 1/16~1/32 ⇒ 固定段厚、弯折段薄 |
| F-2 | **层叠 4 层, L2/L3 在 pin1-4 区域 keep-out** | 内层地平面会分流回流 → 阻抗与温升失控 |
| F-3 | **弯折段**: 半径 R ≥ 3.0mm, 区内**只允许连续铜箔** (无过孔/元件/焊点/胶/压点) | 铰链弯折寿命 |
| F-4 | **载流**: 每 pin 0.411A 持续 (1.07A 不接受, 触点天花板) | |
| F-5 | **FPC 长度/走线随结构件过铰链** 的工艺能力 (与压接/焊接的兼容) | |

---

## 4. 我们已定的前提 (供贵司判断, 不必回复)

- 充电电流上限 **0.82A** (ICHG, 由 `R_ILIM 390Ω` 硬件限流, 不依赖软件)
- 跨铰链段压降预算 **≤ 60mV @0.82A**; 温升预算 **≤ 30mW/段**
- 铰链段 FPC 长度: 结构定 (~31mm, 以结构终版为准)
