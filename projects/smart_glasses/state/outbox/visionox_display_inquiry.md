## 0. 我们是什么 (一句话, 让对方知道量级)

我们在做 **一体式智能眼镜样机 (先出 1 台)**: MIPI-CSI 单路 sensor → ISP → YOLOv5 INT8 80 类检测 → **MIPI-DSI 输出到微显示 + 衍射光波导双目**。
主控为**瑞芯微 RK3572** (4 TOPS / 12M ISP / 原生 4-lane MIPI-DSI 1.2)。目标: 端到端 <60ms、续航 ≥1h、整机贴皮肤温度 ≤43°C。

## 1. ★ 必须书面答复的 6 项 (决定能不能定案)

### Q1 ★★★ 单色还是全彩? (决定性项)
贵司 0.49 英寸 1920×1080 产品线**是否提供全彩 (RGB) 版本**? 若有, 全彩与单色两个版本的:
- 型号 / 料号分别是什么?
- **价格差多少** (元/片, MOQ 各是多少)?
- **峰值亮度 / 典型亮度** 各是多少 nits?
- 全彩版本是否需要**不同模组封装** (厚度/外形差异)?

> 我们的用法: **在眼镜里画 OD 检测框 + 显示检测结果**。若只有单色, 我们需要知道**可用的单色类型 (黄 / 绿 / 白 / 蓝)** 与**能否用颜色区分不同检测类别** (若无, 我们改用位置/纹理区分)。

### Q2 ★★ 接口与时序 (能不能直连 RK3572)
- 接口: 确认 **MIPI DSI (D-PHY) + I2C**; 请提供**详细规格书**: DSI **lane 数 (1/2/4 可配?)**、每 lane 最高速率、支持的**视频模式 (VESA/CEA) 与包格式**、**刷新率范围 (60/90Hz?)**、是否**必须用 DSC** (1920×1080@60 RGB888 ≈ 2986 Mbps payload, 4-lane 2.5Gbps 理论可行 ⇒ 想确认不用 DSC 能否跑满 60fps)?
- **I2C**: 地址、速率、需要哪些寄存器 (亮度/gamma/显示开关/序列发生器控制)?
- ★★★ **初始化序列 (init sequence) —— 请以书面文件形式提供** (寄存器序列 / 时序参数 / 电压时序图), 并说明: ①是否需要 SoC 侧驱动做 **TE (tearing effect) 同步** ②**能否提供可编译的 DSI 面板驱动** (适配 Rockchip BSP, 见 Q6) ③若不提供驱动, 贵司能否指定一家**已适配 RK3572 的模组厂/方案商** (我们要的是**能直接烧录**的方案, 不是自己猜时序) ★**这条对我们是硬项**: 我们的选型新判据 (2026-11-02) 是"**优先用公开可得的资料多的器件**" —— sensor 一侧就是这么定的 (公开可移植的驱动 vs 等原厂给寄存器表); ★**面板同理: init code 拿不到 = 驱动从零写 + 时序靠猜 = 量产风险**, 所以请把这条答得尽量具体 (文件形式, 不要只说"可以提供"）。
- **供电**: 逻辑电源 / 模拟电源 各自电压范围与电流 (典型/最大), **面板本体功耗 @ 典型亮度是多少 mW**?
- **工作温度**: 面板与模组各自范围 (眼镜佩戴环境接近体温, 但镜框内可能到 45-50°C)?

### Q3 ★★ 模组外形与光学 (能不能塞进我们的镜框)
- **模组外形尺寸 (长×宽×高) + 重量**? (我们现有镜框内光学腔体只有 14×10×6mm, 而新件必然更大 ⇒ 镜框要重新设计, 所以这个数是硬约束)
- **显示区尺寸** 与 **有效视场角** (模组口径 ~35°, 白色亮度衰减到 50%)?
- 是否有**现成的耦合/准直光学方案** (贵司有 See-through: Birdbath / Waveguide 方案线)?
  - 若有 **Waveguide 耦合方案**: 请提供该方案的 **整体外形尺寸 / 重量 / 出瞳直径 / FOV / 入瞳位置 / 与贵司屏的匹配关系**, 以及**是否可以做成"0.49" 屏 + 波导耦合"的一体化光机模组**?
  - 若有 **Lens group (透镜组)** 方案: 同上, 但请同时给出**它能提供的 FOV 与瞳距 (eye relief)**?
- ★**关键约束**: 我们要 **对角 120° / 垂直半视场 ≥30°** 的显示。请给出**贵司能提供的最大 FOV 组合**, 以及在 120° 对角下**分辨率会怎么变** (是否需要裁切/降采样)?

### Q4 ★★ 光生物安全 (口径与光引擎完全不同)
我们的目标是**衍射光波导双目**, 所以光生物安全的数据口径是"**经波导耦合后进入眼睛的光**", 不是"面板出光面":
- **出光面辐亮度** (cd/cm²) 与**出光面光谱** (峰值波长, 尤其**蓝光 ~460nm 的占比与强度**)?
- 在**面板峰值亮度**下的**光谱与光功率**?
- 工作温度升高 (45-50°C) 时亮度/光谱如何变化?
- 贵司是否有**光生物安全 (IEC 62471 / GB/T 20145)** 的测试报告可提供?
> 注: 硅基 OLED 是**面光源自发光**, 与我们此前评估的 LED 光引擎口径不同 ⇒ 这一项需要重新建立判据。

### Q5 ★ 商务与供货
- **单价 / MOQ / 交期** (首批 1-10 片与后续 1000 片级分别报)?
- 是否可提供**样品与评估板** (含屏 + 驱动板 + FPC/连接器)?
- **供货年限与生命周期承诺** (消费级眼镜通常要 3-5 年)?
- 是否可签署 **NDA** 后提供完整 datasheet + 驱动 IC 资料?

### Q6 ★ 与我方其余器件的匹配
- 是否有**配套 SoC 驱动/参考设计** (Linux/RK 平台) 可提供? 我们用 **RK3572 + Linux**, 需要确认屏的驱动是否已在 **Rockchip BSP** 里 (RK3572/RK3576/RK3588 的 DSI 驱动)? ★**具体化**: 请答 ①**适配 RK3572 的面板驱动是否可直接拿到** (源码或预编译) ②**是否已有人做过 RK3572 + 贵司屏的整机样机** (有的话请给板级参考设计/时序参数) ③若都没有, 贵司能否**代做一次适配** (报价与周期) —— ★**这条对我们是"能不能量产"级别的前置**, 不是加分项
- 贵司是否已适配过 **RK357x 平台** (若有, 请提供板级参考设计)?
