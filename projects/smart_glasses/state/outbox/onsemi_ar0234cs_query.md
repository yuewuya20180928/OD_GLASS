## 0. 我们是什么 (一句话, 让对方知道量级)

我们在做 **一体式智能眼镜样机 (先出 1 台)**: MIPI-CSI 单路 sensor → ISP → YOLOv5 INT8 80 类目标检测 → MIPI-DSI 输出到微显示 + 衍射光波导双目。
主控 **瑞芯微 RK3572** (4 TOPS / 12M ISP / 4-lane MIPI-DSI)。硬指标: **端到端 <60ms**、续航 ≥1h、贴皮肤温度 ≤43°C、整机功耗预算紧张。

**为什么选 AR0234CS**: 我们要在 **1/2.6" 靶面**上同时拿到 ①≥1920×1080@60 ②**全局快门** (相机装在镜框上沿、刚性绑定在头部, 滚动快门会让检测框错位) ③低畸变广角 (对角 ~120° 鱼眼) ④**公开可得的驱动与移植资料** (我们有一条硬性选型判据: 优先选开源数据多的器件 —— 社区已有 GPL 授权的 RPi / Jetson Orin NX / RK3588 移植实现, 对我们排期帮助很大)。

## 1. ★ 必须书面答复的 7 项

### Q1 ★★★ 电源域与 pinout (直接卡我们的原理图)
请提供 AR0234CS 的 **完整引脚表 + 电源域定义**, 重点:
- **VDD / VDD_PHY / VDD_DATA** 的推荐电压与容差 (我们按 **1.2V** 设计)?
- **VDD_IO** 的推荐电压 (**2.8V? 还是 1.8V/2.8V 双档?**) 与 **绝对最大额定值 (abs max)** ★★★
  > ★**这一条最关键**: 我们的 I2C 上拉现在拉到 3.3V, 若 VDD_IO 的 abs max < 3.6V, 我们必须把上拉改到 2.8V ⇒ **请给出明确数值与所在表格**。
- ★**是否还有独立的模拟电源轨 (VAA / VAA_PIX 类)?** 若**没有**, 我们会省掉一颗 LDO; 若有, 请给电压与电流。
- **各轨的典型/最大电流** (按 1920×1200@60 连续采集), 以及**去耦电容**推荐值 (我们每轨放 10µF + 100nF)。

### Q2 ★★★ CRA (主光线角) —— 一票否决级
- AR0234CS 的 **CRA (chief ray angle)**: 数值 + **线性还是非线性** + 曲线?
- 我们要做 **对角 ~120° 鱼眼 + 低畸变**, 请给出**贵司推荐匹配的镜头** (焦距/口径/畸变), 以及在 **~50° 半对角视场**下的**边角暗角/彩色阴影**评估。
- 文档 **AND9658-D「AR0234 Sensor Optical Specifications」** 能否提供?

### Q3 ★★ MIPI CSI-2 电气与时序
- **lane 数 (2-lane / 4-lane)** 与 **每 lane 最高速率**?
- 我们的负载: 1920×1200@60 **RAW10 ⇒ 1.382 Gbps payload** ⇒ 请确认在 **2-lane** 下能否跑满 60fps (以及建议的 lane 数)?
- **D-PHY 电平域** (CML 电平 / 摆幅)、**AC 耦合是否内置**、**MCLK 频率范围**、**RESET 极性与时序**、**上电时序要求** (各轨的先后与延时)?
- **SCCB/I2C 地址** 与 **最大 I2C 速率** (我们跑 400kHz 快模式)。

### Q4 ★★★ 功耗 (我们整机的热预算卡得很紧)
- **1920×1200@60 连续采集时的 active 功耗** (裸片值, **不是模组值**)? 分档给 (120fps / 60fps / 30fps) 更好。
- **standby / power-down 电流**?
- ★**请不要只给"模组 0.92W"这类数** —— 我们要裸片功耗才能并进整机的皮肤温度模型。

### Q5 ★★ ISP tuning / IQ 文件 (决定我们项目的工作量)
- 贵司是否提供 **ISP tuning 参数** (例如面向 Rockchip ISP3 的 IQ/JSON, 或面向其他 ISP 的 tuning 包)?
- 若有: **针对哪些平台 / ISP 版本 / 镜头** 调过? 能否提供**与我们的镜头组合对应**的版本, 或告诉我们该从哪份开始改?
- ★**这一条对我们是工作量级差异**: 公开渠道我们已经确认 **Rockchip rkaiq 的 isp3x/isp32 目录里没有 AR0234 的 IQ 文件** ⇒ 若贵司也没有, 我们要自己排一轮 ISP tuning (含暗室与灰卡标定) ⇒ **请如实回答, 我们好排计划**。

### Q6 ★★ Linux / 平台支持与参考资料
- 贵司是否提供 **官方 Linux (V4L2) 驱动** 或 **Rockchip 平台参考设计** (BSP / 设备树 / ISP 参数)?
- 我们已知社区有 GPL 授权的 **Raspberry Pi / Jetson Orin NX / RK3588** 移植实现 ⇒ ★**想确认: 贵司是否推荐其中某一个作为 RK3572 移植起点, 或有更权威的版本**?
- ★**若贵司能提供 AR0234 的寄存器编程序列 (register map / init sequence)**, 请一并提供 —— 我们需要它核对曝光/增益/帧长控制是否完整。

### Q7 ★ 商务
- **单价 / MOQ / 交期** (首批 1-10 片 与后续 1000 片级分别报)?
- 是否可提供**样品与评估板** (含 sensor + 镜头/模组)?
- **供货年限与生命周期承诺** (消费级眼镜通常要 3-5 年)?
