## 正文

Dear RK3572 支持团队,

我们正在设计一块基于 RK3572 SOM 的 demo 主板 (自绘原理图 + 自绘 PCB, 8 层), 用于评估 camera → ISP → NPU → DSI 显示这条链路。在做**接口对边评审**时, 我们需要 SoM 侧球位的权威信息, 特此请求两份资料。

### 问 ① — RK3572 SOM 的完整球位表 (4 座 × 100 球位)

我们手上已有的球位信息是**部分**的: 项目内的 `FET3572C_PIN_TABLE.csv` 记录了 P1 / P3 / P4 三座各 100 个球位, **P2 座只有 99 个**。

想请你们提供:

1. ★**完整的 4 座 (P1/P2/P3/P4) × 100 球位对照表**, 字段我们希望与现有一致:
   `座号 (P1~P4) / num (1~100) / 信号名 / 类型 (电源/地/信号/GND) / 电压域 / 方向 (输入/输出/双向) / 是否必须接 / 是否可悬空 / 上下拉默认值 / 所属功能块 (如 MIPI CSI / MIPI DSI / I2C / USB / PMIC / 其他)★`
2. ★**每个电源/地球位的推荐连接方式**: 直接接电源轨 / 经磁珠 / 经 0Ω 跳线位 (★我们现在的画法是"经 0Ω 跳线位 + 标注 DNP", 想确认这是不是你们推荐的做法★)
3. ★**哪些球位在 demo 阶段可以悬空** (★我们只需要让 camera / display / 供电 / 复位这几条链路先跑起来, 其余球位本阶段不接★)
4. ★**复位与上电时序**: `PG` (Power Good) 的输出球位、极性与上电顺序约束, 以及 `RESET_N` 是否由 SoM 内部拉/释放 (★我们目前的网表里 SoM 内部复位与外部 RC 复位并存, 想确认优先级★)

### 问 ② — P2 座 `num=40` 的确认

我们手上的 P2 座记录**恰好缺 `num=40`** (P1/P3/P4 都是 100 行, P2 只有 99 行)。

请确认二选一:

- **A**: 该球位**确实不存在** / 已被 NC 或合并 ⇒ 我们据此把它从真源里删掉并记录;
- **B**: 该球位**存在** ⇒ 请补上它的 `num` / 信号名 / 类型 (★我们怀疑这是我们抄录时漏了一行, 不是芯片的问题★)

### 附: 我们这边的现状 (供你们判断我们的用法是否合理)

- 主板: 160 × 100 mm, 8 铜层, 自绘 KiCad 原理图 + PCB; ★**目前只在"最小可用集"层面用到 SoM 球位: P1 10 个 / P2 9 个 / P3 19 个 / P4 14 个 = 52 个**★
- 相机: IMX415 (MIPI CSI-2) · 显示: MIPI DSI 屏 · 供电: 板载 DC/DC → SoM 各电源域
- ★**我们不会把"查不到的球位"自行猜一个接法** ⇒ 所以这份资料对我们是硬依赖 ★

Best regards,
ARS45 项目组
