## 一、封装与球位 (TBD-01 / TBD-05 / ISS-081)

1. **封装总球数**是多少? (我们内部按「**总球数 ≥72**」写选型条款) —— 临时假设: 按 8×10mm FCCSP 推测
2. **完整球位图** (含 NC 球与散热焊盘) 能否提供? 现在网表里 62 个 SoC 侧节点全部是占位 (TBD-01), 原厂回信后我们**只填球号、不重画**
3. **FCCSP 球间距 (pitch)** 精确值? —— 临时假设 0.4mm (贵司公开材料提到封装宽度 ≤8mm)
4. **逃线参考布局** (或推荐 PCB 层数/过孔策略) 能否给? 我们的最小引脚集是 41 球, 设计基线是 57 球 (双显示路径各留一路), 上界 91 球 —— 按 p≥0.4mm 交错 dog-bone 即可, **不需要 via-in-pad**

## 二、电源域与上电时序 (TBD-02 / TBD-12)

5. 各电源域的 **标称电压 / 典型电流 / 最大电流**? (V_CORE / V_SOC_IO / 各 IO 域) —— 临时假设: V_CORE 0.8-0.9V / V_SOC_IO 3.3V / IO 域 1.8V 与 3.3V
6. **上电时序**: 哪一路先起? RESET 何时释放? 内部 DCDC 与外部供电的关系?
7. **EN / SS / CT / MR 是不是独立引脚?** 我们的网表里这几类脚目前是 0 条 —— 若存在, 我们要把它们接上 (上电时序链); 若不存在, 我们按"内部自管"处理。**这一条最影响开机成功率**
8. 是否有 **电压监控/复位** 引脚 (POR)? 若有, 阈值是多少?

## 三、显示输出 (TBD-04 / ISS-083)

9. **DP1.4 是 TX、RX 还是两者都有?** 贵司官网「智能可穿戴」应用页写"集成 Display Port 1.4 与 USB 3.0", 公开资料又出现"DP1.4 RX"的说法 —— 两个口径不一致, 我们**不能据此下结论**。我们的网表因此保留了**双出口互斥** (DSI 原生 / DP+桥接芯片 二选一, 用 0Ω 位切换)
10. **是否有 MIPI DSI TX?** 公开渠道我们**没有找到任何 DSI 字样** —— 如果确实有, 我们就能省掉一颗桥接芯片 (省 100-300mW + 4-8 周采购 + PCB 面积); 如果没有, 我们按"必须桥接"准备 RFQ
11. 若确认要走 **DP → MIPI DSI 桥接**, 贵司是否有推荐型号或设计参考?

## 四、USB (TBD-10)

12. **USB 版本与引脚数**: USB 2.0 还是 3.0? PHY 有几路? 我们的方案只用 USB 2.0 D+/D− 做烧录与调试
13. **SoC 侧是否需要 USB VBUS 检测脚?** 这一条很关键: 缺了 VBUS 检测, USB 枚举与量产刷机链路的成立性就悬着 —— 我们的软件侧评审刚把它标成 blocker
14. USB 3.0 的 SS 差分是否引出? (若引出, 我们可以考虑充电板本地走 USB3, 避免 SS 差分跨铰链)

## 五、启动存储 (TBD-06 / TBD-11)

15. **启动介质形态**: 内置 boot storage / 外挂 SPI-NOR / eMMC? 挂在哪个控制器?
16. **建议容量**: 我们的固件约束是 rootfs ≤30MB, 因此 **flash ≥128MB** (64MB 的 SPI-NOR 装不下) —— 若贵司建议用 eMMC, 请给最小容量与封装 (eMMC 会占板面积, 影响板宽)

## 六、其他

17. 贵司是否有**模组/参考板**的原理图或 PCB 可以参考 (尤其电源树与显示连接)? 我们已按 8×10mm + 板宽 12mm 布局, 若贵司有更优的连接器/层叠方案, 我们可以跟
18. 评估样机阶段, 贵司是否提供**芯片样品与烧录工具链**? (我们已排 "ARS45 板端 INT8 转换链" 为放行阻断项之一)
