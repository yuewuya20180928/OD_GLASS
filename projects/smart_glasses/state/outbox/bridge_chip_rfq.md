# 桥接芯片并行询价 (RFQ) · 草稿

> ⚠️ **草稿状态: 待老板批准后询价/接触供应商。未经批准不得发出。**
> 关联 issue: ISS-003（Q16 显示 TX 未确认 → 是否需要桥接芯片）
> **为什么要并行**: 桥接芯片采购周期 **4–8 周**，而原厂回复也要 3–5 个工作日。
> **不能串行等** —— 若等原厂回信才去询价，光是芯片到货就把 G1 原理图/PCB 关卡拖后 2 个月。
> 所以我们**两边同时走**：原厂确认"有无 DSI TX"的同时，先把桥接方案询清楚（哪怕最后用不上，也只损失一次询价工时）。

## 一、需求规格（RFQ）

| 项 | 规格 | 备注 |
|---|---|---|
| **功能** | DisplayPort 输入 → MIPI-DSI 输出 | 我们的光机是 MIPI-DSI 输入 |
| **DP 输入** | DP 1.4 (HBR2, 4 lanes) 或 eDP | 取决于 ARS45 有无 DP TX（尚未确认，两种都要问） |
| **DSI 输出** | MIPI DSI 2–4 lanes | 目标 800×600@60fps，**可降到 30fps** |
| **分辨率** | 800×600 最低；能支持 1280×720 更好 | 我们不需要更高 |
| **★端到端延迟** | **< 10ms** | **关键项**。整链路预算是 60ms 硬指标，桥接芯片若吃掉 20ms，整个方案就废了 |
| **★功耗** | **< 100mW** | 我们整机预算是 1.22W 满载，贴皮肤镜腿只能承受 0.16–0.21W，**这颗芯片若放镜腿就致命** |
| **封装** | QFN / BGA，**≤ 6×6mm** | 镜脚内腔高度受限 |
| **工作温度** | 0–70°C 商业级 | 镜框内密闭，环境温度可能偏高 |
| **供电** | 单电源，尽量 ≤ 3.3V | 电源域越少越好（我们电源域清单还没拿到） |
| **数量** | 首件 1 台样机（1-2 片），后续小批量 | 需要报价档位 |

## 二、请对方回答的问题

1. 是否支持 **DP1.4 → MIPI-DSI** 转换？可否同时输出多路 DSI？
2. **端到端延迟**（从 DP 输入有效像素到 DSI 输出）的**典型值与最坏值**（P99）？**测试条件**是什么？
3. **整片功耗**（含 DP 接收器 + DSI 发射器 + 内部时钟）？
4. 是否需要**外部 EEPROM / 固件加载**？固件是否需要加密授权？
5. **DSI DDC/I2C 地址**是否可配置（我们还要接 sensor 的 I2C，**不能地址冲突**）？
6. 封装尺寸与 **PCB 面积占用**（含外围器件）？
7. **是否有现成评估板/参考设计**（原理图 + PCB + 固件）？我们按 spec-driven 走，需要参考设计。
8. **交期**（样品 / 量产）与 MOQ / 单价档位。
9. 是否支持**无 PTP 同步的 DSI 模式**（我们用异步显示，帧率与检测解耦）？


## 二之二、EMC / 辐射指标（来自 `HW/EMC_PRECHECK.md` R-02 / D4 —— 这颗芯片是潜在的辐射源）

桥接芯片是本机唯一的高频数字器件（DP 输入 + DSI 输出），若它辐射超标，**整机的 EMC 整改会全部落到这颗芯片上**，所以指标必须写进选型：

| 项 | 我们要什么 | 为什么 |
|---|---|---|
| **辐射发射** | 提供该芯片的**辐射发射测试数据**（频率范围 + dBμV/m），或明确"需整机测试、无芯片级数据" | 我们没有 devkit，只能整机测 → 芯片级数据能省一轮改板 |
| **传导发射** | DP 输入侧的传导噪声（尤其共模）是否有抑制措施？需不需要外部共模扼流圈？ | DP 线在镜脚里，与人体接触路径重叠 |
| **开关噪声** | 芯片内部时钟/PLL 频率是多少？会不会成为谐波源？ | 谐波落频点决定滤波布局 |
| **DDC / I2C 地址** | 可配置吗？会不会与 sensor 的 I2C 冲突 | 两条 I2C 都要挂在主控上 |
| **未使用引脚/未装 DNP 端头** | 本机显示链是"双出口 + 0Ω/DNP"方案，未装的那一路**会变成天线** | 备选方案要写清 DNP 端头怎么处理（这正是 R-02） |
| **ESD 等级** | 芯片本身的 ESD 等级 + 对端口的推荐防护方案 | Type-C 是人体触摸入口 |

## 四、并行策略说明（给老板看）

```
   原厂问询 ─────────────►  确认"ARS45 有没有 DSI TX"
        │                              │
        │ (同时进行, 不等)             ▼
        └──► 桥接芯片 RFQ ──► 若需要 → 4-8 周采购已启动
                                  若不需要 → 浪费一次询价工时
```

**代价对比**：
- 串行（等原厂 → 再询价）：最坏 **原厂 1 周 + 询价 3 天 + 采购 8 周 = 约 10 周**
- 并行（现在同时问）：**4–8 周采购从今天起算**，原厂回信只影响"用不用"，不影响"什么时候能到货"

样品阶段只做 1 台，**采购量极小**，所以并行询价的金钱成本几乎为零，**时间成本却省 2 个月**。
