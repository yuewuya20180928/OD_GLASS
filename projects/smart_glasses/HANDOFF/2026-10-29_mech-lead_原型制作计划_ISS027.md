- 发起方: **mech-lead** (结构总工, 带散热) 🔩
- 日期: 2026-10-29
- 结论: **原型不能一把梭** —— 拆成 **B1 工艺标定 (打 1 件 coupon) → B2 镜脚装配验证 (打 3 件) → B3 镜框与光学 (打 2 件, 卡 JBD) → B4 整机装配 (1 台, 卡 PCB/波导/固件)** 四批, 每批只解一个物理不确定量; **B1+B2 共 49 项实测不需要 PCB 也不需要 JBD**, 是当前唯一不被外部依赖卡死的路径; **PCB 必须在 B1 开工前冻结**, 否则改板 = L4 回滚 2-4 周 + 打印件全报废。

## B1 结论摘要

1. **四批解耦, 件数与验证项写死**: **B1** 打 **1** 件 `fit_coupon_340` (34 项: A5+B6+C7+D5+E5+F3+G3) / **B2** 打 **3** 件 (`temple_cage_340` ×1 + **R11 J_CHG 防呆试样 ×2**, 后者是**新增**件, 现有打印包里没有) 测 15 项 (H 段) / **B3** 打 **2** 件 (镜框主体 + 光学舱托架, 替换现有 TEMPLATE 模板态) / **B4** 装 **1 台 U1**。每批 5 条以内**硬判据**, 无一条是"基本可行"。
2. **验证矩阵三分类**: A 类 (打印件阶段就能测) **10 项** — 孔径收缩 / 最小壁厚 / 悬空极限 / 拉脱力 / 波导槽间隙 / H 段 15 项 / 镜脚侧干涉 / 打印件分件重量; B 类 (**必须等电路板**) **7 项** — PCB 孔位配合 / 跨铰链 4 链路装配 / T-13 / T-14 / 电池座载流 / M-CHRG / 并联热路实测; C 类 (**必须等整机+固件+仪器**, G3 范畴) **6 项** — M-NPU / M-E2E / M-SKIN / M-POWER / M-BATT / M-OPTIC + 佩戴体验。
3. **回滚五层, 成本差 3 个量级**: **L1** 打印参数 0.5-1 天 / **L2** 打印件几何 1-2 天 / **L3** 结构方案 1-2 周 (动 §0 锁死表, 需你与老板裁) / **L4** PCB **2-4 周 + 打样费 ¥2,000-8,000 (打印件全报废)** / **L5** 固件 1-3 天 (最便宜, 但动不了干涉)。判定顺序: 机械问题先排 L1→L2→L3, L3 之前不许碰 L4; L5 永远最后。
4. **给 G1→G2 的三条排期结论**: ① **PCB 板框/厚度/层数必须在 B1 开工前冻结** (SoC 已改选型, 板子还开着变更口子; 板厚 4 层 0.8 vs 6 层 1.0 差 **0.34g** 且吃掉 PCB 段 H 余量 0.20mm, 而整机已推算 **48.9-74.0g** vs 目标 30-40g); ② **JBD "回图" 与 "发货" 要当两个里程碑催** —— B3 只等 u1/u4 图, 不等实物 (实物 4-8 周); ③ **ISS-040 是本周唯一催办项** —— 解锁 B1 → B1+B2 → **G2 直接少 2 项** (M-PRINT + M-FIT 镜脚侧), 投入产出比最高。
5. **诚实边界**: 本文 **[实测] 实物条数 = 0**; **20 项**关键量在实物到手前只能标 **[0数据]** (§6 表逐项列出)。本机物理上无法打印/量测 (证据 `MECH/print/ENV_PROBE.log`); 本文所有 `[实测]` 只指**模型/脚本级**真值 (`verify_pack.py` 46/46 · 3MF 顶点与 STL 逐点相同 · STL 实体积 12.19cc / 4.43cc), **不是实物打印尺寸**。
6. **★ 顺手闭了 4 条 ISS-049 需求 (hw-lead 明确把决定权交给结构侧)**: `iss049_skeleton_profile` / `iss049_graphite_hchain` / `iss049_mount_screw` / `iss049_segment_order` —— 答复已登记进我的 `answers` (key 对上对方), 合并器显示 **"别人在等我" 从 4 项 → 0 项**。核心取值: 截面 = **台阶形 X19..33 满宽 15 / 其余 10**, 厚 **0.80mm** (→ **2.89g/对**, 落进 §2.4 B 的 "+1-3g"; 1.00mm 是 3.62g/对, 与 hw-lead 报的数**独立复算一致**), 石墨 **0.30 铺 PCB 内侧** (H 链 +0.30, 余 2.60/2.80mm), 骨架/石墨 **止于 X=60.00**。⚠️ 但 **0.80mm 的热学代价 (Tj 会升) 必须并进 U-3 一起算** —— §2.3.1 的 46.5°C 已超 43°C 红线, 只看重量选截面会翻车。
