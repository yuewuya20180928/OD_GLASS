## B1 结论摘要 (5 条, 每条带数字)

1. **逐件量产工艺已定 24 件**: 镁合金 **ADC12 压铸** (镜框主体 + 波导卡槽区, 2 件) · **PC/ABS 注塑** (镜腿上下壳 / 遮光罩 / 检修口盖板 / 鼻托托架 / 走线卡槽 / 摄像头窗口, 7 件) · **Al 6063-T6 CNC 铣削** (SoC 定位骨架 / 散热骨架 / 散热屏蔽罩 / 波导压条 ×3 / 分光件基准块 / **电池座 (新增)**, 7 件) · **硅胶模压 + 模切胶垫 + 标准件** (鼻托面 / 导热垫 / 石墨膜 / VHB / 密封垫 / 泡棉 / UV 胶 / M1.2 螺丝, 8 件) = **2+7+7+8 = 24**。**打印件/注塑件负责造型与容纳, 关键定位与散热由 CNC 件承担** —— 与 `MECH_BUDGET §5.5` 的既有分工一致, 本单把它升级成通用规则。

2. ★ **量产的杀手不是公差, 是脱模斜度**: 量产注塑公差 (±0.20) 比 FDM (±0.30) **紧** ⇒ V/H/L 三链最坏值反而**改善** (1.40→**1.60** / 0.65→**0.75** / 13.60→**13.90**); 但**镜脚下壳主腔深 38.00mm, 内外双面 1° 脱模 ⇒ 内腔横截面窄端少 1.327mm ⇒ 镜脚·H 链 (电芯段, 名义余量仅 0.95mm) 最坏变 −0.577mm ⇒ 几何上做不出来**; 即使皮肤侧做皮纹面 (α=0.5°) 也只救到 **0.087mm < 判据 0.40** ⇒ **靠公差或斜度都救不回来, 只能靠结构改**。

3. ★ **收缩敏感界面必须从注塑/压铸本体移走** (规则与具体收缩率无关): 假设档 1.0/1.5/2.0% ⇒ 镁合金镜框长向缩 **1.40/2.10/2.80mm**、镜脚内腔长缩 **1.30/1.95/2.60mm** ⇒ **铰链接口孔距 / 检修口磁铁沉槽 / Type-C 开口 / 隔热台阶**都不能留在收缩件本体上; 本项目**已有 6 件 CNC 件承担定位与光学基准**, 本单再新增 **电池座改 CNC 嵌件** (左右各 1, 与骨架共基准 ⇒ 电池不靠胶定位)。

4. ★ **阳极工序顺序选方案 A** (CNC 全部 → 去毛刺 → 阳极 Type III + 封孔 → **定位面/定位孔二次精加工**), 配 **A-B 两点基准 (同一平面内两条精铣带) + P1 圆销端面止推** (不用三点基准: 本项目定位指标是 ≤0.046mm 而非 micron 级, 对膜厚均匀性不敏感) ⇒ **PIN-SET-2 的 ≤0.046mm 重复性仍成立**; 图纸必标 6 条 (§4.3), 其中"定位面阳极后精加工 ≤5µm"与"Masking 区 (接地搭接 / 绝缘隔离 / P1·P2 销不阳极)"是必标项 —— 这条直接接住 ISS-024 §4.3 N1 的判定, **不推翻它**。

5. **打印件验证不了但量产会出问题的清单 = 27 条** (几何/公差 10 + 收缩/表面处理 5 + 工艺/装配 7 + 测试口径 5), 最硬 3 条: ① ★ **Rev B 打印包交付的是检具与试样, 不含任何量产外形件** ⇒ 脱模/分型/收缩/缩痕/顶针 **目前 0 个数据点**; ② **打印件的"松配合消化公差"在量产会变过盈** (让过孔 ⌀2.4 单边 0.20 → 注塑孔公差 ±0.10 ⇒ 装配压弯); ③ **打印件 M1.2 拉脱 ≥15N 不能外推注塑件** (失效机制从"层间拉脱"变成"塑料螺纹剥牙") ⇒ 量产螺钉柱必须**嵌金属螺母**。
