# [mech-lead→PM] ISS-084 — SoC 载板化/模组化 的结构代价评估 + 兜底路线初判

- 发起方: mech-lead (结构总工, 带散热)
- 日期: 2026-10-27
- 结论: **按任务书字面提法「镜框主板位加一层载板」→ 结构侧判定「不值得」**（解 D 已判镜框没位置，载板化不改变该判定，却要付 +2.30mm 厚度 / +34% 面积 / +2 件零件 / +3 道工序）。**载板化真正的硬收益是另一条：它把主板长度 76→69mm，修掉镜脚长度超差 1.3mm** —— 这条与载板装在哪无关。**兜底路线（现成模组）必须拆成两问：台架 EVT ✅ 可行且是现成路径；眼镜形态 EVT ❌ 几何否决（模组 45×55mm vs 镜脚净高 38mm，超 17mm）。**
- 依据: `MECH/SOC_CARRIER_EVAL.md`（本单正文）· `MECH/carrier_eval.py`（自证脚本，rc=0，自检 12/12）

---

## B1 结论摘要

1. **字面提法「镜框主板位加一层载板」→ 不值得。** `MECH/CLEARANCE_FIX.md` §3.5 解 D 已判「SoC+PCB 全部挪镜框」**镜框没位置、不可行**；载板化**不改变这个判定**（主板还是那块大板），却要付 **+2.30mm 厚度 / +34% PCB 面积（910→1215mm²）/ +2 件新增零件 / +3 道工序**。

2. **改问「镜脚主板位加一层载板」→ 不可能（几何超差）。** SoC 位前后叠层 壁0.8+隔热0.5+空隙0.3+PCB0.8+**SoC0.85**+导热垫0.3+骨架1.0+壁0.8 = **5.35mm**，镜脚上限 7.30 → 余量只有 **1.95mm**；B 档（BTB 载板）需 **+2.30mm** → **超 0.35mm**；C 档（FPC 载板）需 **+2.10mm** → **超 0.15mm**。→ **载板化强制 SoC 必须在镜框**。

3. **★ 载板化有一条硬的、与「装在哪」无关的收益：把主板长度 76mm 压到 69mm，修掉镜脚长度超差。** A 直接焊：电池40.5+主板76+余量15 = **131mm** vs 镜脚内腔 130 → **超 1.3mm**（hw-lead §7.2 ME-2 已标，但没算到「76mm 这个数本身就不够」这一步）；B 载板：**125mm → 余 5.2mm** ✅；C 载板：**122mm → 余 8.2mm** ✅。

4. **载板化不解除对原厂的依赖。** 载板自己也要球位图才能画 → 球位图永远不来，载板一样做不出来。它只买到「球位图来了但我们把引脚→功能映射搞错了」这一种情形下，**重投的是 383mm² 小板而不是 910mm² 大板**（面积 1/2.4）。**唯一真正解开依赖的是 D 档（供应商模组）**：模组厂自己出版引脚定义表（ISS-083 正在做的）。

5. **兜底路线必须拆成两问：台架 EVT ✅ 可行且是现成路径；眼镜形态 EVT ❌ 几何否决。** 模组级参考 **45×55mm**（SOM3559C_A1 规格书 `[官网]`）→ 镜脚根部净高只有 **38mm**，**超 17mm**；镜框上沿单侧连续段只有 **43mm** < 45mm → 也否决。**⇒ 模组只能上台架，不能进眼镜。**

6. ★ **结构侧的方向（建议，非拍板）：先做 D 档台架（ISS-083 已在做），同时在主板上预留 60 位 BTB 载板接口（成本≈0：只多一块 16×16 空板位 + 一颗连接器焊盘）。** 这样 ISS-083 一旦拿到模组引脚表，**主板不用重投**。
