## B1 结论摘要 (一句话 + 三选一 + 推演)

### B1-1 一句话结论

★**推荐 ISS-190 §7-2 的第 ② 条: 把 `Q_AND` 整颗改 DNP (网表表 A 的 L65/L66/L67 三行同改 + 表 B 的 `Q_AND.1/.2/.3` 三行同改) ⇒ `RESET_N` 上只剩按键一个拉低者 ⇒ 首台板能启动。**
★**它是我实测出来的, 不是抄的**: 我用 4 条 `/tmp` 反向用例证明 —— ★**① 的两个子项都切不断这条故障链**★。

### B1-2 故障链 (★行级, 逐行可查★)

| 网 | 行 | 内容 | dnp |
|---|---|---|---|
| PG_AND | L62 / L63 | `R_PG_PULL` 10k 上拉到 `RAIL_VDD_1V8_IO` | 必装 |
| PG_AND | L64 | `NET_PG_AND` (两路 DC-DC 的 PG 并联) | 必装 |
| PG_AND | L67 | **`Q_AND` 栅极挂在 PG_AND** | 必装 |
| PG_AND | L71 | **`Q_ENVC`** | **DNP** ★PG_AND 上唯一一行 DNP★ |
| PG_AND | L402 / L403 | `TP_PG_VCORE` / `TP_PG_VIO` | 必装 |
| RESET_N | L65 | **`Q_AND` 漏极 → RESET_N** | 必装 |
| RESET_N | L366 / L377 / L382 | `TP_RESET` / `NET_RESET_N` / `SW_RST` | 必装 |
| RESET_N | L409 | `U_SUPV` pin1 | **DNP** (监督器不参与拉复位) |

★**行级口径**: 两路 PG 的**连接行** (L62/L64/L402/L403) dnp **全是必装** ⇒ **「PG 源器件 DNP」不成立**; ★**器件级**: `U_DCDC_VCORE` (L79) / `U_DCDC_VIO` (L86) 的 **IC 行 DNP** ⇒ **两颗 DC-DC 实物不装 ⇒ 它们的 PG 脚根本不在板上** ⇒ **PG_AND 上没有任何实装器件能拉低它** ⇒ [推算] `PG_AND` 恒高 ⇒ `Q_AND` 栅极 1.8V ⇒ 导通 ⇒ `RESET_N` ≈ 0 ⇒ **首台板不启动**。

### B1-3 三选一 (★推荐 + 理由 + 后果★)

| # | 改法 (ISS-190 §7-2 原文) | 依赖 SoM 球位 TBD-01? | ★能切断故障链?★ | 结论 |
|---|---|---|---|---|
| ① | 把 `Q_ENVC` 从 `PG_AND` 上摘掉 / 或让 `Q_ENVC` 必装 | 否 | ★**否** ★ | **否掉** |
| **②** | **把 `Q_AND` 改 DNP** (复位回到纯 RC + 按键, 与 SoM 内部复位并存) | **否** | ★**是 (唯一一条)** ★ | ★**推荐** ★ |
| ③ | 等 SoM 球位 TBD-01 落地后再把真实 PG 接进复位链 | **是** | 现在无解 | **出局** (首台板等不起) |

★**否掉 ① 的理由 (用反向用例实测, 不是推理)★**:
- ★**RC1**: 只把 L71 `Q_ENVC` DNP→必装 ⇒ `pg_and.dnp_rows` 变 `[]`、`all_rows_populated` 变 `True`, ★**但 `q_and_gate_row_dnp` 仍 `必装`、`reset_n.q_and_drain_row_dnp` 仍 `必装` ⇒ 故障链一点没动** ★
- ★且 **① 的"必装"子项电气更糟**: `Q_ENVC` 栅极=PG_AND(恒高) ⇒ 导通 ⇒ 漏极把 `EN_VCORE` (L73) 拉到 0 ⇒ 将来装上 DC-DC 则 **V_CORE 永远使不上能** ⇒ 把一个 P0 换成另一个 P0。
- ★**"摘掉"子项改动面更大**: 网表里根本没有 `PG_VIO` 这条网 (L71 的 note 写的是 `[PG_VIO]`), 要"摘掉"就得新建网 + 把 `U_DCDC_VIO pin4` 从 `PG_AND` 迁走 ⇒ ★**同一引脚不能挂两条网** ⇒ 会破坏 L64 的"两路 PG 并联"意图 + 要重画两个 PG 测试点归属 ⇒ 收益 0 ★

★**推荐 ② 的三条理由★**: ① ★**唯一直接切断故障链**★ (Q_AND 漏极是 RESET_N 上唯一的"硬件常拉低"); ② ★**不依赖任何外部答复**★ (不等 TBD-01 / 不等原厂 ⇒ 首台板能投); ③ ★**与既有结论自洽**★ (网表 L409 的 note 已写明 Forlinx 官方载板复位电路 = 按键 + 100nF + ESD, 无监督器 ⇒ ② 是还原参考电路, 不是发明新东西)。
★**默认执行口径 = 「② + ① 的一个无害子集」**: 必做 `Q_AND` 三行 DNP; 建议同批 `Q_ENVC` 三行统一 DNP (消 BOM/网表口径差); ★**明确不做** "让 `Q_ENVC` 必装" ★; `R_PG_PULL` 是否也 DNP (省 180 µA) ⇒ **要老板单独点头**。

### B1-4 ★推荐方案的复位时序行为推演 (assert / deassert / 掉电)★

| 事件 | 行为 | 数字 | 证据 |
|---|---|---|---|
| **assert (拉低)** | 按下 `SW_RST` ⇒ 经 `R_SER_RESET_N` 1k 拉低; 戴维南 `R_th = 10k‖1k = 909 Ω`, `V_th = 1.8×1/11 = 0.164 V` | 从 1.8V 落到 0.7·VDD(=1.26V) 需 **≈36 µs** (工具口径 `tau_assert_us = 100.0` = 1k×100nF, 偏保守) | [推算] + [实测] |
| **deassert (释放)** | 1.8V 轨上来 ⇒ 10k 上拉 ⇒ 经 1k+100nF ⇒ `τ_release = (10k+1k)×100nF` | **τ = 1.1 ms**; 越过 0.7·VDD 需 **1.324 ms** | [实测] `tau_release_ms 1.1` / `t_reach_0p7vdd_ms 1.324` |
| **掉电** | 1.8V 轨塌 ⇒ 上拉源消失 ⇒ `RESET_N` 随轨落到 0 ⇒ **自动进复位** | 复位链不依赖 `Q_AND`、不依赖 SoM 球位 ⇒ 掉电方向行为确定 | [推算] |
| **对比现状** | `PG_AND` 恒高 ⇒ `Q_AND` 导通 ⇒ `RESET_N` ≈ 0 ⇒ **永远等不到 deassert** | 首台板不启动 | [实测+推算] |

★**改完之后 RESET_N 上还剩谁在拉 (行级)★**: 拉低者只剩 `SW_RST` (L382) 一个; `R_PU_RESET_N`/`R_SER_RESET_N`/`C_RST` 拉高; `TP_RESET` 测点; `U_SUPV` pin1 (DNP, 不参与); `Q_AND` (改后 DNP, 不参与) ⇒ ★**无条件常拉低 = 0 个** ★
★**RC 参数一个都没动** ⇒ 释放时间常数与今天完全一样 (1.1 ms / 1.324 ms) ⇒ ★**改 Q_AND 不影响任何 RC 口径** ★

### B1-5 后果 (诚实的代价)

★**得到**: 首台板可启动; 复位链 = Forlinx 参考电路; BOM 少 1 颗 (`Q_AND`, 本来就 `[待选型]` 没占采购成本)。
★**失去**: "PG 好了才放复位"的硬件互锁 —— ★**但两颗 DC-DC 都是 DNP ⇒ 这条互锁在首台板上从来只起"按住"作用, 从来没起过"放行"作用 ⇒ 现状下它 100% 是负收益** ★; 将来换 SoM / 装 DC-DC 时要把 PG 链接回来 —— 那正是 ③ 的工作, 与本次改动不冲突。
