## B1 结论摘要 (5 条, 每条带数字)

1. ★**ISS-181 官方板实测 (md5 611b869e · 18092 段 / 433 孔)**: unconnected **45** / DRC **0** / 板↔网表逐焊盘等价 **482/482** / 零铜网 **24** / 差分单边零铜 **11** / Gerber **30** 个 + 投产包 **51** 文件 ⇒ **G1 阶段门仍开 (unc≠0), 不许投板**。上周基线是 101 ⇒ **本周 101→45**。

2. ★**根因定量 (本周最硬的结论)**: 45 条里 **23 条是 DSI/CSI 差分腿** (距离 3.7~98.5mm); 器件参与 = CONN **21** / SOM_BTB **17** / RES **12** / CAP **10** / JST **5**。几何真值 = SoM BTB **0.4mm pitch · 0.2mm 焊盘 ⇒ 间隙仅 0.200mm** ⇒ 0.20mm 线 + 两侧 0.20mm 净距 = **需 0.600mm > 0.400mm pitch** ⇒ **沿排方向物理穿不过去**。★**自研 A\* 与 freerouting 2.1.0 两个独立引擎撞同一堵墙 (三重实证)** ⇒ **这是物理约束, 不是算法问题**。

3. ★**本周两条实测判据**: ① **0.0625mm 网格阶梯 (0.125 → 0.0625, margin 取半格 0.03125) ⇒ unc 45→42**, 且**退铜名单 0 / 差分死腿 0 / 逐网孤岛不变多** (Δ 侧全部达标) ⇒ **只差 DRC 12 条清零就能晋级** ⇒ **本周离"可下单"最近的一步**; ② **v57 臂 (BTB 出脚线宽 0.20→0.15mm, 6mil) ⇒ REJECT**: DRC **115** (108 条 `track_width` = **板规则**红 0.2 vs 实际 0.15 + **7 条真 clearance**) + unc 45→**60** + 退铜 **8** 网 + 孤岛变多 **17** ⇒ **单改线宽这条路判死** (且它的 DRC 红**不是几何红是规则红**, 改板规则才能消)。

4. ★★**证伪 STATE 里一条高危阻塞**: 「**RK3572 无官方 Brief Datasheet (本项目全部证据等级 = [媒体]/[模组厂口径])**」—— **官方 datasheet 就在项目库里** (`HW/RK3572_PIN_TABLE/RK3572_datasheet_V1.1.pdf` · Rockchip Rev 1.1 · 47 页 · 2,414,580 B · md5 `c0e3763036e2f6a3e8a2f68f2254851d` · PDF 元数据 Author=Rockchip / CreationDate=2026-04-14) ⇒ **证据等级 [媒体] → [官方]**。**未发邮件 / 未联系代理 / 未联系供应商**。

5. ★**官方 datasheet 连带推翻四条旧口径**: ① **封装 FCCSP550L / 14.3×15.5mm / 球 0.25mm / 球间距 0.42·0.52·0.65mm 混合 / 550 球** ⇒ **ISS-128「pitch 未知 ⇒ 板面积账与逃线层数只能 [推算]」这个前提作废** (最小 0.42mm 落在项目自定的「≥0.4mm 可行」区间 ⇒ **不需 HDI** ⇒ §0「4-6 层」锁死**不必为此破例**) ⇒ **ISS-118 / ISS-122 必须重算**; ② **内存单通道 32bit** (⇒ 订正 `CHIP_SHORTLIST_EVIDENCE` 把 **RK3576 的 216bit** 误用到 RK3572); ③ **ISP 单通道 12M pixels / 最大 4096×3072** ⇒ **Q03 的「余量 1.9% vs 50.7%」两个矛盾口径都不是 RK3572 的数** (那套按 RK3576 16M 算) ⇒ 按官方像素能力, RK3572 的余量是 **82.7%**; ④ **VO: DSI TX 与 DP 都有** ⇒ **Q16 对 RK3572 = 两者都有** ⇒ 打掉「RK3572 无 DP ⇒ 要加桥接芯片」那条推理链 (但**能直插标准 DP 口 = [0数据]**, eDP 是嵌入式形态, 须查 SoM 引脚图)。
