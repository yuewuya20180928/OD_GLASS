## B1 结论摘要

1. **磁场: 判定"无影响"** —— N35 ⌀4×1 磁铁 (Br typ 1.20 T) 端面 **40mm 处 B = 36.0 µT** (Br 上限 1.26 T → 37.8 µT), 与**地磁 25/50/65 µT 同一量级**; 建议落位 (板 X=5.00) 处 **B = 7.3 µT** (磁铁最靠里 15.1 µT) **低于地磁最小值 25 µT**。机理上电容式 MEMS 麦的换能链 (声压→硅膜位移→电容) **无静态磁场作用点** ⇒ 余量充足。`[推算]`+`[官方]`
2. **"按麦克风规格书的磁场敏感度核"这条路走不通 (不是漏查)**: 4 份主流 MEMS 麦规格书 (Infineon IM69D130 / IM67D128BV01 / Knowles MM20 / ST MP34DT04-C1) 全文检索 "magnet" = **0 命中** ⇒ **规格书里没有这一栏**。⇒ 改用三条替代证据链 (机理 / 地磁本底 / 本项目实算), 并把"静态磁场耐受 ≥100 µT"写成**选型硬判据 M-2** + 台架复测 4 步。`[0数据]`
3. **位置: 我把麦克风位置定死 = 板坐标 X=5.00 / Y=12.00 (镜脚 L=45.50)**, 声孔 ⌀1.00 在镜脚**外侧面**; 净空 **通窗 44.20 / 磁铁 54.80 (最坏 43.00) / 螺钉 55.30 mm** ⇒ **≥40mm 全部 PASS**; 且该处**金属骨架不在上方** ⇒ **不需要开骨架窗** (声学通道 3.00mm 直通)。`[推算]`
4. **≥40mm 判据的可满足带只有板 X ≤ 8.00** (对通窗与最坏磁铁取交集) ⇒ 铰链端是**唯一解**; M2 (X=17.00) / M3 (X=26.00, 即 mech-lead 假设的"根部 SoC 区") **全部 FAIL** (23.20~31.00mm)。⇒ M1 成立的前提是"跨铰链连接器座体悬出板端、只占焊盘 X 0..3" —— 该边界 [0数据] (ISS-105 open) **已登记 needs**。`[推算]`
5. **导光孔那半条在当前基线 N/A**: 充电板已按 ISS-014 决策 5 挪到**镜框** ⇒ LED 在框 ⇒ 镜脚侧无导光孔; 若 T-3c 复活 (LED 挪回镜脚), 导光孔必落 SoC 区 ⇒ 距通窗 **23.20** / 距磁铁最坏 **22.00** ⇒ **破 40mm 判据** ⇒ 复活时导光孔必须回镜框。另: **ISS-092 §4.3 的"磁铁↔SoC ≥68mm" 与它自己的尺寸链矛盾 —— 实际 28.00mm** (该处 B = 54.8 µT, 对 SoC 无功能影响, 但**数字必须订正**)。
