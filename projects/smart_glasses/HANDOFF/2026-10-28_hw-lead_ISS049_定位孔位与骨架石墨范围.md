# [hw-lead→PM] ISS-049 —— PCB 固定孔位改版 (PIN-SET-2) + 骨架长度上限 60.00mm + 石墨铺装范围 (定版)

- 发起方: hw-lead (硬件总工)
- 日期: 2026-10-28
- 结论: PCB 固定方式改为 **2×⌀2.0 H7 定位销孔 (骨架压装销) + 2×⌀1.4 M1.2 压紧孔**, 孔位 **P1(8.00,7.50) / P2(52.00,7.50) / S1(8.00,2.50) / S2(52.00,12.50)**, 与 SoC 逃线带 **零重叠 (0.000mm²)**; **骨架长度上限 = 60.00mm (止于 PCB 段后缘, 建议实现 58.00mm)**; **石墨铺装 X[0.00,60.00] × Y[0.00,15.00], 厚 0.30mm**; `skeleton_extent` 已登记。
- 依据: `projects/smart_glasses/HW/PCB_FIXING_PINSET2.md` (主文件) · `HW/pinset2_check.py` (36 项机械复算, rc=0) · `HW/pinset2_check.json` · `HW/pinset2_holes.svg` (孔位图)

## B1 结论摘要

1. ★**孔位定版 (PIN-SET-2)**: 2×⌀2.0 H7 定位销孔 + 2×⌀1.4 M1.2 压紧孔, 坐标 **P1 (8.00, 7.50)** / **P2 (52.00, 7.50)** / **S1 (8.00, 2.50)** / **S2 (52.00, 12.50)** (板坐标, 原点左下角, X=板长 0..60 铰链端在 X=0, Y=板宽 0..15)。**4/4 孔与 SoC 逃线带 X∈[20.20, 31.80] 的 2D 重叠 = 0.000mm²**; 最小孔心边距 2.50mm, 最小孔壁间距 3.30mm。〔[推算] §3.1/§3.3〕
2. ★**老口径作废, 机械复算证明**: MECH_BUDGET §5.1 的「2×M1.2 ⌀1.4 孔心到板边 2.50mm + 1×⌀2.0 H7」在 15mm 板下 **3/3 孔压 SoC 逃线带** (M1.2 孔压 Y 向 0.50mm; ⌀2.0 H7 孔压 2.00×2.00mm 完全落在带内); 12mm 板时 M1.2 孔**完全落在**带内 ⇒ **加宽不解, 必须沿板长移出**。〔[推算] §2.2〕
3. ★**骨架长度上限 = 60.00mm (止于 PCB 段后缘)**; **建议实现 58.00mm** (退 2.00mm: 与电池段前沿件 ≥1.0mm 空气隙 + 上壳后端壁 0.8 + 合缝 0.2)。⇒ ISS-042 解 A 那条并联热路 (**4.50 K/W, 进皮肤热量 92.5%→95.7%**) 在本方案下**不成立**。〔[决策]+[推算] §4/§6-T1〕
4. ★**石墨铺装范围 = X∈[0.00, 60.00] × Y∈[0.00, 15.00], 厚 0.30mm, 单片 0.54g**; 硬上限与骨架同 (不得越过 X=60.00); V 向必须覆盖 SoC 10.00mm + 两侧各 3.50mm 横向扩散带 = 15.00mm。〔[推算] §5〕
5. ★**隔热层没有被牺牲** (边界条件逐条复核): 0.50mm 垫 + 0.30mm 空隙位置厚度**一字未动** (R_隔热 = 165.1 K/W @SoC 投影); **新增硬约束**: M1.2 螺钉头**只准压 PCB 皮肤侧沉孔, 严禁压皮肤侧下壳** (否则金属跨过隔热层 = 又一条并联热路), 隔热垫在 2 处螺钉位开 **⌀3.0 让位孔**。〔[推算] §3.4/§6-T2/T3〕
6. ⚠️ **我自己新引入了一条热路, 已量化交 mech**: M1.2 钢螺钉 2 颗并联 **9.6 K/W** (有效导热长 1/2/3mm → 17.7/35.4/53.1); 在"骨架→PCB 皮肤侧"这一段把 54.2 K/W 压到 **21.5 K/W (2.5×)** ⇒ **皮肤侧热流会上升, 必须进 mech 的热模型**。〔[推算] §6-T4〕
7. ⚠️ **骨架重量超 MECH 口径 (交 mech 定形状)**: 满宽 60×15×1.0 铝 = **4.86g/对 ❌ 判死**; 台阶形 (SoC 段 14mm 满宽 + 其余 10mm) = **3.62g/对 ⚠️ 超「+1-3g」0.62g**。截面形状是结构侧决策, 我只给硬约束「SoC 段必须满板宽 15.00mm」。〔[推算] §4/§6-T6〕
8. ★**我改了自己 ISS-105(10-28 早)给的孔位**: 那一版是「2×M1.2 + 1×⌀2.0 H7 (单销)」; 本单按 ISS-049「改为配合金属骨架的 H7 销」改成 **双 H7 销 + 双螺钉** (单销约束不住绕销轴的倾斜; 双销基准跨距 44.00mm 角度重复性最好)。**板框 60×15 不变, 网表/BOM 不受影响** (孔位是 PCB 制造信息, 不是网表项)。

## B5 未决项与卡点

**Q1 (需要 mech-lead / 经项目总工转达, 期望 2026-10-31) —— 骨架截面形状与重量口径**
满宽 60×15×1.0 铝 = 4.86g/对 ❌ 判死; 台阶形 1.81g/侧 = 3.62g/对 ⚠️ 超 MECH_BUDGET §2.4 B「+1-3g」0.62g。请定截面形状 (台阶/U 形/槽形) 并复核重量口径。**我的假设**: 台阶形 (SoC 段 X 19..33 满宽 15.00mm, 其余段 10.00mm 宽, 厚 1.00mm)。

**Q2 (需要 mech-lead, 2026-10-31) —— 石墨厚度与装配位置**
石墨 0.30mm **未进 PCB 段的 H 链 (4.20mm)** ⇒ 要么石墨占骨架外侧空隙 (链要 +0.30), 要么它不是"面内扩展到镜腿上表面"的原件。**我的假设**: 石墨贴骨架外侧面, 骨架与上壳内壁之间留 0.30mm。

**Q3 (需要项目总工, 2026-10-31) —— MECH_BUDGET 版本口径**
任务写"与 MECH_BUDGET v1.2 对齐", 但 `MECH/MECH_BUDGET.md` 文件头标 **v1.1**, 我按 v1.1 正文 + `BOARD_WIDTH_15MM.md`(10-28) 对齐。请确认结构侧是否另有 v1.2 修订版 (若在我手上, 我再核一遍)。

**Q4 (需要 mech-lead, 2026-10-31) —— 螺钉从皮肤侧穿入的装配可行性**
PCB 皮肤侧 ⌀2.4×0.6 沉孔 + 隔热垫 2 处 ⌀3.0 让位孔 + 下壳不得承螺钉头; FDM 沉孔能不能打 (层纹方向)。**我的假设**: 按上述做; 沉孔打不出 → 改用 M1.2×0.5 沉头/盘头螺钉。

**Q5 (需要 mech-lead, 2026-10-31) —— 骨架/石墨前端能否延伸进铰链端余量区**
默认**不延伸** (止于板前缘 Z=0), 若允许可增大前端对流面。**我的假设**: 不延伸。

**Q6 (需要 mech-lead / 经 main, 2026-10-30) —— 铰链端 4 条跨铰链连接器 (54 触点) 的 X 占位**
未定 ⇒ 固定孔窗口 **X∈[4,12] 与 X∈[46,56]** 需锁定, 否则将来布局一动, 孔位要跟着动 (板框不动, 孔平移)。

**外部依赖 (不阻塞本单, 但投板前必须闭)**: 原厂纸面资料 (datasheet/HRM) 未回 ⇒ FCCSP 球位图未到, 逃线带 0.80mm 是推算值 ⇒ 若实际 pitch/球位图要求更大的逃线带, **P1/P2/S1/S2 的窗口 (X∈[4,12]/[46,56]) 还能吸收 (SoC 段 X[20.2,31.8] 不动)** —— 这是我选"窗口规则"而不是"死坐标"的原因。
