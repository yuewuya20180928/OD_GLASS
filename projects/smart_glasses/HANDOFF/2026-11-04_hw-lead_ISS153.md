## §3 ★"BQ25896 到底挂不挂在本板 I2C 总线上?" —— 明确答案: **不挂**

1. **它不在主板上**: 网表 `U_CHG` 的 board 列 = **`CHG_BOARD`** (镜框充电板)。
2. **它的 I2C 是充电板本地自闭环**: 网表 P10 页 `I2C_CHG_SCL` / `I2C_CHG_SDA` 两行 —— `U_CHG pin5` / `pin6` **只**接本地的 `R_PU_SCL` / `R_PU_SDA` (10k, 上拉到充电板唯一的逻辑轨 REGN 5V);
   ★**PM 已裁决"充电 IC 的 I2C 不跨铰链"** ⇒ `J_CHG pin9/pin10` 本版留空不接。
3. **跨铰链的只有两根 GPIO**: `U_CHG pin3 (PG)` → `J_CHG pin6` → 主板 `PWR_GOOD`; `U_CHG pin4 (STAT)` → `J_CHG pin5` → 主板 `CHG_STAT` —— **是 GPIO, 不是 I2C**。

⇒ ★**`0x6b` 不参与 I2C_A / I2C_B 的地址冲突判定**; 但地址必须写对 (将来软件要在线配充电参数, 走的是充电板那条自闭环总线) ⇒ 表里保留该行, 状态标"不在本板总线"。

### 4.2 `state/check_netlist_pins.py` —— 只加 C9 (C1~C8 一行未动)

**C9 = I2C 地址表一致性 (ISS-153)**, 四步:
1. `HW/I2C_ADDR_TABLE.md` 存在且能解析出表行;
2. **双向**: 网表上挂在 I2C_A/I2C_B 的**从设备集合** == 表里 `状态 = 本板在挂` 的行集合 (加了器件忘了加表 ⇒ 报红; 表里写了本板在挂但网表没有 ⇒ 也报红);
3. 每个从设备**网表里声明的地址** (`I2C 地址 0xNN`) == **表里该位号的地址** (不一致 ⇒ 报红);
4. **同一条总线内地址两两唯一** (含表里"预留"行, 如光机 0x72)。

★**"从设备"的机械判定** (写进门禁里, 不靠人眼): 挂在 `I2C_A*` / `I2C_B*` net 上的器件, 排除 `R_PU_*` / `TP_*` / `J_SOM_*` / `NET_*` / `RAIL_*` / `SoC*` / `GND`。
★**地址的唯一写法**: 行文本里的 `I2C 地址 0xNN` (B5/B6 就是为了让网表满足这条)。

## §8 换料流程 (已写死进 `HW/I2C_ADDR_TABLE.md` §8)

1. 拿新 sensor / 模组的**原厂 datasheet** ⇒ 抄 **7-bit 地址 + 地址选择脚接法** (IMX415: SLAMODE0/1; AR0234CS: SADDR; TMP117: ADD0);

4. 重跑 `gen_netlist.py` → `gen_netlist_pins.py` → `check_netlist_pins.py` (**C9 不过不许往下走**) → `check_netlist.py` → `check_kicad_net.py`;
