# [mech-lead→PM] ISS-099 + ISS-100: 板宽 15mm 结构侧连带 + J_CHG 选型 + FPC 加工图要求

- 发起方: **mech-lead** (结构总工, 带散热)
- 日期: **2026-10-28**
- 结论: **15mm 板宽在镜脚腔体上"装得下且几乎免费"** (三方向余量一字不变, 净高不用动); 面积缺口 310→160mm², **剩余用板长 50→60 补掉 (缺口 -10mm², 长度余量仍 14.5mm)**; **J_CHG 有解** (Hirose FH12-10S-0.5SH(55), 0.5A/触点, 座高 2.0mm), 但**选型判据要从 ≥0.35A 收紧到 ≥0.5A**, 且 **`R_ILIM` 300Ω 在 0.5mm pitch 下基本封死**。
- 依据: `MECH/BOARD_WIDTH_15MM.md` · `HW/J_CHG_SELECTION.md` · `MECH/FPC_FAB_NOTES.md` · `MECH/board_width_15mm_check.py` (rc=0)

## B1 结论摘要 (6 条, 每条带数字)

1. **15mm 板宽在镜脚腔体上装得下, 且是"几乎免费"的** —— H/V/L 三方向余量 = **0.95mm (最坏 0.65) / 8.50mm / 24.50mm**, 与 12mm 板宽时**一字不差** (板宽是垂直向尺寸, 不进前后尺寸链)。判定余量 ≥0.60mm ✅。
2. ★★ **"15mm ⇒ 镜腿根部净高 37→40mm、打印件要改版" 这条代价是错的** —— 它出自 `MECH_BUDGET.md` §1.4.2 的**已作废"叠放"模型**; 锁定的串行排布下垂直链 = `max(电芯段 29.50, PCB 段 21.00)` = 29.50, **净高 38mm 一毫米不用动, 3D 打印件不因板宽改版**。板宽只吃 PCB 段 3mm (该段余量 20.00→**17.00mm**)。
3. ★ **面积缺口账**: 12mm 板 600mm² → 15mm 板 750mm² = **吸收 150mm² (双面贴缺口的 48%)**; 缺口 310 → **160mm²**, 再扣真断电电路 8-12mm² → **剩 148-152mm²**。**"加长撞镜腿长度硬缺口" 也是过时模型的结论** (充电板已于 10-25 挪镜脚, 现长度需求 105.5 / 余量 24.50) ⇒ **建议板形 60×15 = 900mm², 缺口 -10mm² 基本闭合, 长度余量 14.50mm**。
4. ★★ **"J_CHG 装不下" 的根因是脚本 pitch 口径过期, 不是板宽** —— `MECH/hinge_usb_check.py` 仍用 1.27mm 旧 pitch (座体 13.43mm → [FAIL]), 而**网表 V1.5 已定稿 0.5mm** → 座体 **6.50mm**, **12mm 板就装得下 (余 5.50mm)**。改一行脚本比改板宽更直接 (建议 R-2)。
5. ★ **J_CHG 选型有解, 但判据要收紧**: **Hirose FH12-10S-0.5SH(55)** (0.5mm pitch / 1×10p / **0.5A DC 每触点** / 座体高 **2.0mm** / 50V / 耐压 150V / UL94V-0 / -40~+85°C / 20 次插拔 / 支持 FPC 0.18±0.05mm)。规格书的 **70% 降额条款**("全触点导通时用 70%")**在我们的工况下不触发** (只有 pin1/pin2 载流 0.411A, 其余 ≤1mA) ⇒ 0.5A 可用, 余量 1.22×; **但判据应写成"≥0.5A"**, 否则按保守读法 390Ω 档 (单 pin 0.411A) 自动不合格, 会被迫退 680Ω (充电 51min)。
6. ★★ **两条被硬判据挡死的路 (请写进 DECISIONS)**: ① **`R_ILIM` = 300Ω 在 0.5mm pitch 下基本封死** (单 pin 0.534A > 0.5mm ZIF 的 0.5A 额定天花板) ⇒ 300Ω 只能退 1.0mm pitch (座体宽翻倍, 铰链区装不下) ⇒ **300Ω 建议正式判死**; ② **机械防呆应升级为硬判据** —— ISS-085 F-6 的"反插 = BAT_CHG 短接 GND = 充电板 MOS 直通"是真硬伤, 而 FH12 只有"polarizing mark indicator"(人工标记, **不是机械防呆**), Amphenol ICC AutoLock 才明确写 poka-yoke。
