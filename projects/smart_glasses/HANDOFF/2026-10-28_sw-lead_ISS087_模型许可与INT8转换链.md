2. **★ 放行阻断项 L = 0 (实测 rc=0)**: 台账 11 条资产, 交付集 (candidate/active) **1 条** (Apache-2.0), licensing-hold **2 条** (AGPL, 未采购前禁入交付物), quarantined **4 条**, reference **4 条**; L1 许可未判定 **0** / L2 超 15MiB **0** / L3 chip ID **0** / L4 AGPL 无授权 **0** / L5 坏模型 **0**。**证据 [实测]**。★ **L=0 ≠ 可以量产** —— 见结论 5。

3. **★ 顺带查出台账原"主模型候选"是坏的**: `yolov5s-sim_320_clean.onnx` (及其 `_v2` 副本) **PC 侧推理就失败** —— `onnxruntime` 报 `Concat_527 ShapeInferenceError: Inferred=10 Declared=20` (只把输入 dim 改成 320, 图内 Reshape/anchor 常量仍是 640 尺度)。A733 当年做的 `416` 变体同病 (`Inferred=13 Declared=20`)。**唯一实测可推理的 yolov5s ONNX 是 640 那份** (`yolov5s-sim.onnx`, 推理 OK)。→ 已加 **C9 = PC 侧 1 帧推理冒烟** 门禁 (交付集内失败 = 新阻断项 **L5**), 坏模型已隔离。**证据 [实测]**

4. **★ AGPL 商业许可: 采购/法务路径 + 成本区间 (不采购 = 商用受阻)**: 官网明写 **"Embedded deployments in hardware, edge devices, … cameras"** / "Any commercial product" / "**custom-trained or fine-tuned YOLO models**" 均需 **Enterprise License** [官方]; 官方**无公开价** (全部 "Get a quote") [0数据]; 定价定性 = "one-time fee or subscription, 随规模浮动" [官方·定性]; **立项预算量级 10⁴–10⁵ USD** (一次性授权 US$5k–50k + 年费 US$2k–20k/型号/部署规模), 周期 **4–12 周** [推算]。**不采购的合规路径只有一条: 把固件连同训练脚本/配置/权重整体以 AGPL-3.0 开源发布** (AGPL §6) —— 与"量产优先 + 闭源"直接冲突 → **商用受阻**。**证据 [官方] + [0数据] + [推算]**。

5. **★ 转换链: 10 步 (B0~B9) 逐条机器判定 (READY 2 / PARTIAL 4 / BLOCKED 4)**: **READY** = B1 格式/opset 自检 (onnx.checker 通过, ir=7, opset=14, 245 节点/12 算子类型) + PC 侧冒烟 (PASS) · B6 算子覆盖表 (**12 种算子全部命中 A733 实测支持集**)。**PARTIAL** = B2 静态化 (加 `--build` 可全跑, 已实跑出 `_s640.onnx`) · B3 抽 3 路 head (加 `--build` 可全跑, 已实跑出 `_rt.onnx`; head 名 yolov5=`['350','498','646']`、yolox=`['798','824','850']`) · B4 量化 (校准集 100 张 + `.quantize` 资产齐, 缺量化器) · B9 登记 (缺板端产物)。**BLOCKED 4 步 = B0 工具链 / B5 导出+chip ID / B7 板端加载 / B8 打点 —— 全部卡在"原厂交付 Art.Galaxy + 有板"两件事上, 不是本机工程量**。**ARS45 板端 INT8 模型仍 0 个 / 转换 0 次 / 板端实测 0 次**。**证据 [实测]**
