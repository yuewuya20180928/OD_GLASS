## B1 结论摘要

1. **一句话**: 1 台样机**能**把 12 类用例全部"跑一遍", 但跑一遍的产出是**失效模式暴露**, 不是**寿命判定**; 真正能下"通过"结论的只有 2 项 (单次跌落结构完整性 / 化学介质不造成功能失效), 其余全部要 3 台 + 试样 + 老化/振动/弯折设备才能出结论。
2. **12 类用例** (8 类必选全覆盖): **T-01 跌落 / T-02 扭转 / T-03 弯折(镜腿反复开合) / T-04 镜腿拉力 / T-05 汗液浸泡 / T-06 化妆品 / T-07 酒精擦拭 / T-08 UV 老化** + **T-09 盐雾 / T-10 温度循环 / T-11 插拔+FPC 弯折 / T-12 整机振动**。每类给 **样品数 / 次数 / 判据** 三要素, 判据全部量化到可复核数字 (ΔE ≤ 3 / 点蚀 ≤ 0.05mm / ΔR ≤ +10mΩ / ΔR ≤ +20% / ΔL ≤ ±10% / MTF 衰减 ≤ 10% / 残余变形 ≤ 0.3mm / 孔椭圆度 ≤ 0.05mm / 焊点空洞率 ≤ 25%)。
3. **本轮能做 11 类, 不能做 1 类**: **T-09 盐雾本轮不做** (设备连续占用 4-10 天且破坏性最强, 留批次); 其中 **4 类零外部设备** (T-02 扭转 / T-04 拉力 / T-06 化妆品 / T-07 酒精擦拭) → 建议第一批就做, 成本 ≈ ¥800-1500。
4. **顺序是方案的一部分** (§B6): S0 基线快照 → 扭转 → 拉力 → 弯折(整机) → 振动 → **跌落** → **温循** → 酒精 → 化妆品 → **汗液浸泡** → **UV 老化**。理由: ① 温循是跌落隐裂的放大器 (跌落"看起来没事"的风险被消除); ② 汗液排在跌落之后 = 观察**耦合失效** (跌落隐裂 + 电解质 → 腐蚀加速), 单独做都看不到; ③ UV 放最后, 总周期 **≈ 115 天 (UV 单项占 83 天)** → **UV 老化箱必须最早约设备**, 否则最后卡死。
5. **顺手回答了 hw-lead 的待答需求 `rel_mount_stiffness`** (跌落的总闸): 承诺 **面接触 ≥ 40×8mm**, 2×M1.2 只防翘、⌀2.0 H7 销只防转, 承力面必须是金属骨架/机加工件 (不是 P2S 打印面), 且 **PCB 不进铰链弯折区 (弯折全部由跨铰链 FPC 承担, R≥3.0mm)** → 板弯 σ 从点接触的 115 MPa 翻成 **≈17 MPa**, 焊点弯折疲劳风险 ≈0。
6. **结构侧的数字没有一条被改动**: 镜腿厚 **7.3mm (340mAh 档) / 8.7mm (575mAh 档)**, 皮肤侧推算 **46.5°C** (0.23W 按需触发) / **96.1°C** (1.22W 满载, 红线 43°C ISO 13732-1), PCB **50×12×0.8mm(4层)**, FCCSP **pitch 0.3mm** 级封装, 端到端 **60ms** 口径不在本文范围 → 本文只管可靠性, 不动这些数。
