### 排查过的路径

1. **❌ 频率/电压假设**: DCDC2 想拉 0.96V 失败只给 0.8V → 重启板子 + 锁 492MHz (0.8V 够) → **仍然 hang** → 不是电压问题
2. **❌ NPU runtime PM**: `runtime_status = suspended` → 设 `control=on` → `active` → **仍然 hang** → 不是 driver 状态问题
3. **❌ power domain reset**: `/sys/.../pd_npu_test@0/power/control` 无效 (test PD, 不是真实 NPU 电源)
4. **❌ 输入数据**: `dog_640x640_rgb.dat` 全 0x72 (614400×2 byte) → 重新生成正确 RGB 后 → **仍然 hang** → 不是输入问题

### 🎯 真正根因（已 100% 锁定）

```
kernel VIPLite driver:    2.0.3.4-AW-2025-10-27   (Oct 2025, kernel 6.6.98-1-aw2511 自带)
userspace libVIPhal.so:  2.0.3.4-AW-2025-05-16   (May 2025, npu-runtime 2.0.3)
```

**5 个月 ABI 差异** → NPU 硬件 IRQ 永不响应 → `VIPDRV_WAIT_TASK` ioctl 永不返回。

证据:
- kernel dmesg 明确打 `VIPLite driver version 2.0.3.4-AW-2025-10-27`
- vpm_run 启动打印 `VIPLite driver software library version 2.0.3.4-AW-2025-05-16`
- 同 minor (2.0.3.4) 但 timestamp 差 5 个月, 内部 ABI 不一致
- 卸载重启都救不回 → 这是 kernel-userspace 协议错位, NPU 硬件 state 不对

### 2. npu-runtime 1.13.0 降级 (已实测)
- `apt-get install --allow-downgrades npu-runtime=1.13.0` 装成功 (88 KB)
- 但 vpm_run 输出:
  ```
  init vip lite, driver version=0x00010d00...
  VIPLite driver software library version 1.13.0.2-AW-2025-03-11
  gcvip_os_init[97], fail to read device vipcore
  gcvip_user_init[347], fail to initialize OS, status=-2
  ```

- **1.13.0 lib 用 gcvip_ API (旧 Vivante galcore SDK 风格), 期望 `/dev/gcviplite` 或类似设备节点**
- **当前 kernel driver 是 viplite (vipcore 199,0), 跟 gcvip API 不兼容**
- **结论: 1.13.0 比 2.0.3 更不匹配, 不可能 work**

### 3. kernel 降级 6.6.98-3 (没完整跑, 理论已排除)
- 6.6.98-3 是 6.6.98-1 的 patch update, 发布时间更晚
- vipcore driver timestamp 只会更新或相同, 不会回到 May 2025
- 且 23.6 MB deb 下载在 sandbox 限速 30 KB/s, 实际需 13+ 分钟

### 4. Allwinner Netdisk
- URL `https://netstorage.allwinnertech.com:5001/sharing/Mh23BhPHq` 是 Synology ShareLink
- HTML 显示 `id="login-form"`, 需要账号 + 密码
- 沙盒 curl 试拿 sharing_sid cookie 失败, API 返回 `error code 119`

## 学到新事实
- **1.13.0 lib 是 galcore SDK** (API `gcvip_*`, 设备名 galcore)
- **2.0.3 lib 是 viplite SDK** (API `viphal_*`, 设备名 vipcore)
- 旧 SDK 不能跟新 kernel driver 配, 必须匹配 kernel 版本的 viplite lib
- **apt 提供的 1.13.0/2.0.3 都不是 kernel 6.6.98-1 (Oct 2025) 的匹配版本**
