## ISS-097 规格成型 (我的活, 负载开关 + 真关机 + 功耗预算 V3)
- **选型判据 8 条** (型号**不凭记忆写**, 只写候选系列 + 必须核的参数清单): VIN abs max ≥5V / Iout ≥2A / **R_on ≤40mΩ @3.7V** (目标 ≤30mΩ; 注意 SYS 下限 3.5V 已等于 SoC UVLO, 低电量时欠压重启是固有行为) / 关机 IQ ≤5µA / **必须有反向阻断或 quick output** (关机插 USB 时防 5V 经 SoC IO 反灌电池) / 面积 ≤2×2mm / -40~85°C / ON 脚兼容 3.3V GPIO + 有确定默认态。
- ★**真关机拓扑 = SR 锁存 (2×小 MOS) + 负载开关**, **不是** SoC GPIO 直接拉高/低 —— 后者的"上电默认态"是死循环 (断电后 GPIO 高阻 → 又开机)。
- ★**"插电即唤醒"走 J_CHG pin6 (PWR_GOOD, BQ25896 开漏) → 镜脚侧 diode-OR → ON 脚**: **零新增 pin**; 关机时充电链仍在电池侧带电 ⇒ **关机也能充电** ✔ (PWR_GOOD 在 VIN 存在但未充电时是否有效 → 标 [待核 TI], 退化方案走 VBUS_DET + AON)。
- **功耗预算 V3 四档** (420mAh 电芯):
  | 档 | 功耗 | 续航 |
  |---|---|---|
  | **关机 (主域断, 留 AON)** | ≈58µA → **0.21mW** (AON 50µA 假设 + BQ25896 2µA + BQ2970 1µA + 开关 IQ ≤5µA) | **~8.4 个月** (AON 若 10µA → 20 个月) |
  | **深睡待机 (SYS 带电)** | 0.15W [V2 口径] | **2.8h** ❌ |
  | 按需触发 1s/10s | 0.23W → 皮肤 46.5°C ❌ | 电池直接撑不住 |
  | 满载 | 1.22W → 皮肤 88.6-96.1°C ❌ | — |
- ★**由此得出的产品结论**: **"长按 10s 关机"必须映射到真关机 (不能映射深睡)** —— 否则售后口径与续航都站不住; 而**真关机让"待机 <0.05W"成立** (关机 0.21mW, 差 240 倍)。
- 面积代价: 开关 + 锁存 ≈ **8-12mm²**, 而镜脚板面积**已缺 300mm²** ⇒ **又一条 15mm 板宽的论据**。
- ★自查发现: 我自己的 `VBUS_DET` 100k+100k 分压 = **50µA 常流** (关机时也在耗) ⇒ 要么删掉整条分压 (若原厂有 dedicated VBUS detect 脚) 要么高边加 NMOS 开关 ⇒ 已列入追加问。

## 2026-10-28 09:0x-18:5x — ★★★ P0 级拓扑缺陷 (板子会永远开不了机) + 2 个工具缺陷

### ★★★ 本项目迄今最严重的一个硬件缺陷 (hw-lead 查出, 我独立复核并修复)
**关机拓扑的"插电即开机"用 `Q_PG = N-MOS 低边反相`** (栅极=PG · 源极=GND · 漏极=ON)。
BQ25896 的 PG 是**开漏 LOW=输入源良好** [官方 "LOW indicates a good input source"] ⇒
- PG 低(有电) ⇒ N-MOS **关** ⇒ ON 只剩 10k 下拉 = 低 = **开关关** ⇒ **插电反而开不了机**
- SoC 拉高 PWR_CTRL 时若 Q_PG 导通 ⇒ **被拉到 GND 拉不高** ⇒ 开机路径彻底不通
⇒ **板子打出来是死的**

**★我的独立复核 = 四种接法推演 (不是照抄结论)**:
| 方案 | 接法 | 判定 |
|---|---|---|
| A | N-MOS 低边 (原) | ❌ 逻辑颠倒 |
| B | P-MOS 高边 + 漏极接 3.3V | ⚠️ 逻辑对, **但我第一版改法有洞** —— 库内 3.3V 全挂 SYS 下 (`U_LDO_IO33` 输入 = RAIL_SYS) ⇒ 关机即灭 ⇒ 漏极无电位 ⇒ **仍开不了机** ⇒ 自己否掉 |
| C | N-MOS + 额外反相器 | ❌ 多 1 颗 IC |
| **D** | **P-MOS 高边 + 漏极接 `BAT_SW`** | ✅ **采纳** —— 电池轨关机后仍带电 ⇒ **零新增 pin、零新增轨** |

电平推演: PG低⇒栅极≈0⇒Vgs≈-4.2V⇒导通⇒ON=BAT_SW=高⇒**开机** ✔ ｜ PG高⇒ON落10k下拉⇒Vgs=+3.3V⇒关⇒ON低⇒**关** ✔
