## 封存原因 / 教训 (供新项目参考)
1. **架构 A (OD 异步)** vs MT 同步拆 capture/process: 摄像头 30fps 时 A 涨 50%, MT 退步 1%
2. **BgrRing zero-copy** vs **bgr.clone() 0.5ms**: OD 慢 ≥5% 时 ring 满阻塞 main, clone 是最低开销方案
3. **SDP framerate 必须跟实际 fps 匹配**: 8/13 bug 留到 9/19 才发现
4. **uvcvideo vs VIN driver**: Allwinner A733 VIN driver 不可生产用 (panic), 走 USB UVC 路线稳
5. **delayed 3rd-party repo apt install**: 7-10 栽过一次 mode 744, install 后立刻 `ls -la` 检查
6. **ultralytics cls_id ≠ COCO cat_id + 1**: 按类名匹配生成 mapping
7. **arch64 cross-compile `-DCMAKE_C_COMPILER`**: 路径要含 aarch64 字符串强制走 aarch64 分支
8. **kernel driver vs userspace HAL**: timestamp 不一致 ABI 不配套 → inference hang, 必须整套换
