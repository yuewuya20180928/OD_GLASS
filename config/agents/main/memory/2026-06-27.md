## 01:30 — 03 个 opencv 包踩坑 → 修好 → imshow 弹窗跑通

### 时间线
1. 01:30 跑 `python demo_odapi_headless.py` 报 "cv2 is headless build" — 我写的兜底逻辑漏了 `use_png=True`，修了
2. 探用户 conda opencv 状态, 发现**三个包共存**:
   - `opencv-contrib-python` 4.13.0.92 (pypi)
   - `opencv-python` 4.13.0.92 (pypi)
   - `opencv-python-headless` 4.13.0.92 (pypi)
3. 建议 `pip uninstall opencv-python-headless` (1 行, 风险 0)
4. **结果翻车**: 卸完 cv2 整个模块废了 (`cv2 has no attribute cvtColor/namedWindow`)
   - 根因: 三个 opencv 包共用同一个 `site-packages/cv2/` 目录, 共享 `__init__.py` 和 .so
   - 卸 headless 时 pip 按 RECORD 把共享的 `__init__.py` 和 .so 一起删了
5. **修复**: `pip install --force-reinstall opencv-python==4.13.0.92` (1 行, 5 秒)
6. 01:41 用户报"已经能显示画面了" — 弹窗跑通 ✅

### 教训 (写进 MEMORY.md 铁律)
- **不要盲目 `pip uninstall opencv-python-headless`** — 三个 opencv 包共存时, 卸 headless 会清空共享的 `cv2/` 目录
- **修法**: `pip install --force-reinstall opencv-python==<ver>` (重写共享目录)
- 探 cv2 是否真有 GUI 只能**实测** (`cv2.namedWindow` 试调), 看 `qt/plugins` 目录不可靠

### 验证
- `python -c "import cv2; cv2.namedWindow('t'); cv2.destroyAllWindows(); print('OK')"` 不报错 = GUI 通了
- TF 2.20.0 + Keras 3.15.0 + NumPy 2.5.0 + RTX 3090 GPU matmul 全部 OK
