#### ★★B. ★★★v34 探针 (19:12–19:13, 只摆不布, ~20 秒/次) ⇒ **出了可执行方案**

★**决定性教训**: ★**"搬迁几个件"根本不管用** —— 排版是**行式装箱流** ⇒ 搬走挡路的件 ⇒ **后面的件立刻补位**
- 探针 A (搬 CK_P/CK_N/D1_P → 左下 (12,72)) ⇒ DSI 上走廊**仍有 3 个件** (D0_P/D0_N/D1_N 补进来) ⇒ **一点没腾出来**
- 探针 B (搬 → (43,64)) ⇒ **同样没腾出来**
⇒ ⇒ ★**唯一有效手段 = 禁放框 (keep-out)**: 圈住走廊 ⇒ 撞框的件**同排右移**绕开

★**探针 C = 成功方案** (`PCB_KEEPOUT="24.0,56.1,35.6,59.6"`, 不动路由器一行):
- ★★**DSI 上走廊: 3 个件 → 0 个 (空的)** ✔
- 掉件数 **0** · 异网焊盘搭接 **0** (自检 ≥0.20mm 全过) · **parity 全过** ✔
- ★★**意外收获**: 禁放框把**整排电容右移** ⇒ `CK_P 25.9→40.3` · `CK_N 30.7→45.1` · `D1_P 35.5→49.9` · `D0_P→58.7` · `D0_N→63.5`
  ⇒ ⇒ **CSI 第二跳起点整体离 CONN_CAM 更近 (最远那对近 14mm)** ⇒ **走廊更短、交叉更少 ⇒ 这一刀可能同时改善 CSI**
- 另: `TP_CSI_CK_N` 跟电容走到 (44.5,55.2) ⇒ **不再压着 `CONN_LIGHT` 的 DSI 脚** ✔
- 代价: DSI 下走廊仍 2 个件 (C_KEY_VM/R_KEY_VM) ⇒ 但上方走廊已空 ⇒ DSI 从上方逃 ✔
