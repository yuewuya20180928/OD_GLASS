### 排查过程 (5 个迭代修复)

#### Bug #1: 板端 /proc/PID/environ 看不到 drop-in GST_DEBUG
- **症状**: `/etc/systemd/system/camera-rtsp-v31.service.d/debug.conf` 设 `Environment="GST_DEBUG=*:5"`
- 实际 process 的 GST_DEBUG 还是 `rtspmedia:5,appsrc:4`
- **根因**: ExecStart 命令行 `/usr/bin/env ... GST_DEBUG=rtspmedia:5,appsrc:4 ...`
  - `/usr/bin/env` 设置的 env var 会覆盖 systemd Environment= drop-in
  - 必须从 ExecStart 移除 GST_DEBUG,让 drop-in 生效

#### Bug #2: stream-type=2 (random-access) → seek failed → preroll 503
- **症状**: appsrc 进入 PAUSED → PLAYING 时 gst_app_src_do_seek 失败
- **修法**: launch string + on_media_configure 都强制 stream-type=0 (stream)

#### Bug #3: appsrc wait preroll buffer 70ms → "Internal data stream error"
- **症状**: appsrc 在 need-data signal trigger 时 main loop 在 DQBUF wait (~70ms)
  appsrc 默认 max-latency 触发 → "Internal data stream error" → "streaming stopped, reason not-negotiated (-4)"
- **修法**: 在 on_need_data callback 里立即 push 一个 640x480 黑帧 (全 0 BGR) 作为 preroll
  - main loop 14.5 FPS 不够快, 必须在 signal context 直接 push

#### Bug #4: x264enc 拒绝 Y444
- **症状**: videoconvert 默认输出 format=Y444 (因为 x264enc getcaps 接受 high-4:4:4)
  x264enc 实际 init encoder 时 reject
- **根因**: option-string="profile=high" 是错的 (x264enc 不识别 `profile=` key)
- **修法**: 
  1. 改用 `g_object_set(x264, "profile", "high", NULL)` (property 形式)
  2. launch string 加 capsfilter: `! video/x-raw,format=I420,width=640,height=480,framerate=30/1 !`
     强制 videoconvert 输出 I420 (x264enc 默认能接受)

#### Bug #5: caps 协商 capsfilter I420 + framerate=30/1 (与 g_state.FPS 不 match)
- **修法**: g_state.FPS 20 → 30 (跟 launch string framerate 一致)

### 新铁律
- **【铁律】gst-x264enc 的 profile 必须用 property 设, 不是 option-string**
  - 错的: `g_object_set(x264, "option-string", "profile=high", NULL)` → "Bad name for option profile=high"
  - 对的: `g_object_set(x264, "profile", "high", NULL)` 或 `option-string="high"` (CLI 形式)
  - option-string 是给 x264 CLI 用, 不接受 gst property 风格的 `key=value`
- **【铁律】systemd ExecStart 命令行 env= 覆盖 Environment= drop-in**
  - ExecStart 用 `/usr/bin/env KEY=value ...` → process env KEY 设到最前
  - drop-in `Environment="KEY=value"` 永远被 ExecStart 覆盖
  - **调试 GST_DEBUG 必须在 drop-in 设, ExecStart 不能 hardcode GST_DEBUG=...**
- **【铁律】appsrc caps 协商需要 first buffer, 但 live appsrc 慢 main loop 会 fail**
  - appsrc 默认 max-latency (1s?) + need-data signal trigger 时等 buffer
  - main loop 如果 FPS 慢 (>1s 间隔), appsrc 在 buffer 到来前报 "Internal data stream error"
  - **修法**: on_need_data callback 里立即 push 1 个黑帧作为 preroll, caps 协商后 main loop 接管
  - 或: 用 gst_idle_add 让 push_buffer 在 GMainLoop context 跑 (避免主线程 wait)
- **【铁律】videoconvert 默认输出 4:4:4 (Y444)**
  - x264enc getcaps 接受 high-4:4:4, 所以 videoconvert 默认协商成 Y444
  - x264enc 默认 profile=constrained-baseline 实际 reject Y444 → "Internal data stream error"
  - **修法**: launch string 强制 capsfilter I420: `! video/x-raw,format=I420,... ! x264enc`
