- FPS 10.44 → **8.64 (-17%)**

- 默认 OMP 开 8 threads，远多于数据并行所需（3 个 memcpy / 3 个 generate_proposals）

- prefetch 在 streaming 模式无效（hardware prefetcher 已做）
- 去 std::vector copies 收益被 OMP 副作用掩盖
