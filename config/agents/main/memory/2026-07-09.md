## 🔍 新学到的 (建议归档到 MEMORY.md)

### 铁律扩展 1: <BOARD_SSH_PASSWORD> 板子镜像/SDK 生态复杂
- Radxa 提供 3 层: 官方镜像 (mainline kernel) / TinaSDK BSP (sunxi kernel, 含 NPU driver) / radxa-pkg apt 源
- 官方镜像的 mainline kernel **没有 NPU driver** (需要单独装)
- TinaSDK 的 NPU driver **只在 sunxi kernel 编译** (不能用在 mainline)
- Radxa 通过 `linux-aw2511` (Radxa 维护的 mainline + patches) 把 NPU driver port 到 mainline
- 装了 `linux-image-radxa-a733` meta-package 会拉 6.6.98-3-aw2511 (含 NPU driver)

### 铁律扩展 2: trixie_cli_beta_v2 不是"开箱即用"
- 文档说"内置 OpenClaw" = 预装 OpenClaw AI Agent (CPU 跑)
- **但没预装 NPU runtime** —— 需要单独 apt install
- 这跟"OpenClaw 是 Radxa 集成 AI" 的推断不同: **OpenClaw 是开源项目 (github.com/openclaw/openclaw), Radxa 只是把它集成进了镜像**

### 铁律扩展 3: docs.radxa.com 中文版 vs 英文版差异
- 中文版有百度网盘链接 (国内用户隐藏福利)
- 中文版 /cubie/a7s/app-dev/openclaw 详细讲 OpenClaw (AI Agent 安装)
- 英文版没有百度网盘
- 修 NPU 相关问题**先查中文版**可能更全

### 关键发现: Allwinner NPU driver 历史
- A733 用 Vivante VIP9000 (VeriSilicon, 3 TOPS)
- 旧 driver 叫 `galcore` (Vivante 老 SDK)
- 新 driver 叫 `viplite` (Vivante VIPLite)
- 设备文件可能是 `/dev/galcore` 或 `/dev/vipcore` (Radxa docs 倾向后者)
- TinaSDK 代码在 `gitlab.com/tina5.0_aiot/bsp/drivers/npu/aw_nna_vip/`
- mainline kernel backport 在 `radxa-pkg/linux-aw2511` patches 里
