### 5.1 rsdk-r2 sparse image 烧失败 (20:35)

boss 跑 `flash_bullseye_rsdk_r2.sh` 烧 SD 卡,板子绿灯闪 + 串口 log:

```
[04.550] The storage not support sample function
[04.556] ## error: update_fdt_dram_para_from_bootpara : FDT_ERR_NOTFOUND
[04.563] chip id : 0x00005100 0x00004900 0x0000c418 0x00001c94
[04.568] mac addr => 08:51:49:dc:88:fe
SD128 119.1 GiB 识别 OK
[UFS] err: link startup failed -6 (无关,板子没 UFS)
curr_device:0
(后续 hang,找不到 boot.scr / kernel image)
```

**根因**: rsdk-r2 .img 是 sparse,densify 后:
- GPT header 修复 OK (有 EFI PART)
- 但 **boot-resource partition 内容全 0** (sparse hole 填充)
- U-Boot 找 boot-resource → 找到 partition (有 GPT entry) 但内容空 → 找不到 kernel → boot fail
